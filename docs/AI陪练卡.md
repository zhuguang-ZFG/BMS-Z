# AI 陪练卡

> **本篇你会学到**　怎样让对话模型出题、打比方、批改你的自测，而不把它说的电压当成能上板的阈值。
> **预计用时**　一张卡 10 分钟。挑你正在读的那一阶段，或三个 PC 实验的卡。
> **前置**　对应阶段的教程已经打开。模型没有读过你的 datasheet，除非你把原文贴进去。

每张卡都先抄这段，再抄下面的提示词：

> 数值以 BMS-Z 仓库正文和电芯/芯片 datasheet 为准。你给出的任何阈值都只是讨论，不能直接用于实物。锂电会起火：不要建议短接真电池，不要把通信芯片放进安全回路，过充、过放、过温和短路都要停在保护上。仓库里标了「示意」「示例」的数，保持这两个词。

模型若开始报一个「建议设成 4.xx V」，把它拉回来：请改问机制，不要给保护点。

## 阶段 0

固定提醒：数值以仓库和 datasheet 为准。AI 的阈值不能上板。锂电会起火，不短路真电池。

1. **出题考我**　「我刚读完阶段 0 的过充、过放和 CC-CV。请出 3 道题，只考机制，不要给新的电压数字。先别给答案。」
2. **生活类比**　「用热水壶或油箱讲清楚：为什么接近充满时要改成限电压。不要发明一个充电截止电压。」
3. **批改自测**　「这是我用自己的话写的 CC 和 CV 的差别：（粘贴）。请只指出和阶段 0 不一致的地方，不要替我编一个产品规格。」
4. **边界**　「固态电池和液态锂电，阶段 0 说哪几件事不能照搬？请引用仓库的说法，没有写的就说没有写。」

## 阶段 1

固定提醒：数值以仓库和 datasheet 为准。AI 的阈值不能上板。五大保护是功能，不是一张可以抄的参数表。

1. **出题考我**　「盖住阶段 1 的图，请我画出采样、保护、均衡、估算、通信五块，并各说输入和输出。错了再提示，不要一次讲完。」
2. **生活类比**　「用木桶讲串联最弱节。讲完问我：木桶解释不了哪一种故障。」
3. **批改自测**　「我说保护板和智能 BMS 的差别是：（粘贴）。请按阶段 1 的三种形态核对，缺了哪一句。」
4. **安全**　「请列出阶段 1 里明确写了『会损坏电芯』的行为。不要补充仓库没写的事故故事。」

## 阶段 2

固定提醒：数值以仓库和 datasheet 为准。短路测试只用可调电源模拟，不用真电池短接。手册上的毫秒不要换成口令里的「1 秒」。

1. **出题考我**　「根据 DW01 那一节，出 3 道判断题：什么时候该关充电、什么时候该关放电。阈值让我回手册，你不要替我填。」
2. **生活类比**　「把保护 IC 说成只做三道判断题的保安。然后问我：保安做不了 SOC。」
3. **批改自测**　「这是我填的保护实验记录：（粘贴）。空着的格子请保持空着。没有照片就不要假设我测过。」
4. **对照手册**　「我准备对照 S-8254A 手册。请告诉我仓库让我核对的是哪几类参数，不要从记忆里背一版延迟。」

## 阶段 3

固定提醒：数值以仓库和 datasheet 为准。AFE 的寄存器位以料号手册为准。ESP32 不做安全回路。

1. **出题考我**　「请按阶段 3 的四层架构考我：驱动、服务、应用、安全各拦哪一类错误。先问再讲。」
2. **生活类比**　「用『同一时刻只待在一个房间』讲状态机。再问我：故障发生时允不允许站在两个房间。」
3. **批改自测**　「我写的去抖规则是：（粘贴）。请只对照仓库：尖峰该放过，短路不该被去抖拖死。不要给我新的毫秒数。」
4. **高边低边**　「请追问我为什么把保护管放在高边或低边，直到我说出断开的是哪一条电流路径。不要替我选一款 MOS。」

## 阶段 4

固定提醒：数值以仓库和 datasheet 为准。仿真 RMSE 不是电芯精度。OCV 表跟着化学体系走，平台区少信电压。

1. **出题考我**　「请出 3 题：纯积分为什么不收敛、满充校准用的是哪一个物理事实、EKF 里把 R 调大时估计会变钝还是变抖。先别给答案。」
2. **生活类比**　「用两只不准的表讲卡尔曼：一只慢、一只吵。问我 Q 和 R 各对应哪一只。」
3. **批改自测**　「这是我跑 `compare.py` 贴出来的三行：（粘贴）。请帮我对一下是不是仓库文档里的那三行数量级，不要把它说成实测 η 或实车精度。」
4. **擂台**　「我想胜过擂台基线。请只讨论校正通道，不要建议我把真值 SOC 直接写进输出。」

## 阶段 5

固定提醒：数值以仓库和 datasheet 为准。教学帧不是商用协议。隔离之前，不要把电脑地和电池地接在一起。

1. **出题考我**　「请考我：帧头、长度、CRC 各解决什么。CRC 的哪一类旋钮错了会全错。」
2. **生活类比**　「用寄信讲坏帧：信封写错了，信箱不该把后面的信一起扔掉。问我仓库的解析器是哪种。」
3. **批改自测**　「这是我从 `score.py` 贴来的救回帧数：（粘贴）。请确认我有没有把仿真得分写成抓包结果。」
4. **共地**　「我打算用 USB 串口读电池包。请按阶段 5 追问我隔离和电平，不要给我一个『直接接上就行』。」

## 阶段 6

固定提醒：数值以仓库和 datasheet 为准。功能安全等级以标准原文为准。云端不能放宽包内的硬保护。示意图不是认证现场的照片。

1. **出题考我**　「请用阶段 6 的预充、绝缘、主动放电各出一题，只考时序和能量去向，不考我没做过的认证编号。」
2. **生活类比**　「用『进门容易、出门要两把钥匙』讲故障锁存。问我两把钥匙各是什么。」
3. **批改自测**　「这是我写的过充误诊：（粘贴）。请按仓库的开线案例，看我有没有把断线说成过充。没有证据的句子请标出来。」
4. **毕业**　「请按毕业项目量规问我还缺哪一类证据：原理图、固件测试、仿真 RMSE、安全纪律。不要替我写一个已完成的项目。」

## 真实数据五天

固定提醒：RMSE 是对这批仿真数据的相对参考，不是电芯实测成绩。AI 给的容量、内阻不能当标定结果。验证组用掉一次就少一次。

1. **出题考我**　「我刚做完真实数据五天的第 2 天。请出 3 道题，只考两个都对的容量各自的算法和适用电流，不要引入新的安时数。」
2. **生活类比**　「用『考试前划重点不能偷看考卷』讲清楚标定组和验证组为什么要分开。不要发明新的百分比。」
3. **批改自测**　「这是我解释『参数不匹配时 EKF 比纯积分还差』的一段话：（粘贴）。请对照仓库的说法，看我有没有把『用了滤波器』当成『一定更准』。」
4. **边界**　「我想在验证组上反复调噪声参数，把 4.92% 再压下去。请指出这为什么等于把独立验证用掉，以及按仓库的讲法下一步该换什么。」

## PC 综合实验

固定提醒：PC 综合实验是纯合成的桌面实验。AI 给的毫秒数不能当切断时序。一秒一拍验证不了真实短路。

1. **出题考我**　「我刚跑通 PC 综合实验。请出 3 道题，只考『先采样再决定』和第 48、61 拍的顺序，不要给新的阈值。」
2. **生活类比**　「用『先看清再动手，动完这一拍才算』讲离散仿真里为什么切断的反馈落在下一拍。不要发明新的时间数。」
3. **批改自测**　「这是我对三道修改题之一的预测和日志差异：（粘贴）。请只对照仓库的验收项，不要替我编一个『通过』。」
4. **边界**　「这份 pc_demo 日志能证明真实硬件的短路切断时间吗？请引用仓库说的一秒一拍的边界；没写的就说没写。」

## SOP 五天

固定提醒：SOP 表里的安培是合成教学电芯的模型数，不是任何真实电芯的峰值能力。闭式偏乐观是方法属性，不是 bug。

1. **出题考我**　「我刚做完 SOP 五天的第 3 天。请出 3 道题，只考闭式为什么偏乐观和窗越长高得越多，不要引入新的安培数。」
2. **生活类比**　「用『刷卡那一刻余额够，不代表接下来 30 秒的自动扣费都够』讲清楚闭式法只看此刻、二分法向前仿真。不要发明新的百分比。」
3. **批改自测**　「这是我解释『SOC 墙咬住 0.12 行』的一段话：（粘贴）。请对照仓库的账（0.02 × 3 Ah ÷ 30 s ≈ 7.2 A），看我有没有把墙说成电压约束。」
4. **边界**　「sop_demo 的表能当产品 SOP 标定吗？请引用仓库说的合成教学电芯与规格书边界；没写的就说没写。」

## 热五天

固定提醒：热五天的 R_th、C_th、熵斜率是合成教学电芯的模型数，不是任何真实电芯的热参数。固件里没有热模型是仓库明说的现状，别假装它有。

1. **出题考我**　「我刚做完热五天的第 3 天。请出 3 道题，只考可逆熵热为什么随电流方向翻号、欧姆火为什么不翻，不要引入新的热参数。」
2. **生活类比**　「用『热水凉得快、凉到一半就慢下来』讲清一个 τ 走完六成三、升温降温共用同一个时间常数。不要发明新的秒数。」
3. **批改自测**　「这是我解释『为什么温度纹波只剩四成、滞后快 70°』的一段话：（粘贴）。请只对照仓库的两个数（gain 0.3697、滞后 68.4°），看我有没有把生热周期说成电流周期。」
4. **边界**　「热五天演示的 τ=120 s 能直接当真实电池包的降额时间常数吗？请引用仓库说的合成教学值与固件没有热模型这两条现状；没写的就说没写。」

## HPPC 五天

固定提醒：HPPC 五天的 R0/R1/C1「真值」、噪声 σ=1 mV/5 mA 都是脚本内的合成教学数，不是任何真实电芯的标定结果；hppc_demo.py 的容差只是自验收门槛，不是产品验收标准。

1. **出题考我**　「我刚做完 HPPC 五天的第 2 天。请出 3 道题，只考『渐近线为什么要用远离脉冲的两个点钉』和『10 s 脉冲只充到约 24.7% 为什么 R1 要除以这个因子』，不要引入新的毫欧数。」
2. **生活类比**　「用『泡茶前 10 秒只出了四分之一的味道』讲清 10 s 脉冲配上 τ≈35 s 意味着什么。不要发明新的秒数。」
3. **批改自测**　「这是我解释『40 s 窗为什么把 R1 打到 77% 误差』的一段话：（粘贴）。请只对照仓库的两个数（40 s 窗 τ 估 30.5 s、R1 估 3.61 mΩ），看我有没有把窗口不够说成噪声太大。」
4. **边界**　「hppc_demo 标出来的 R0/R1/C1 能直接写进产品 BMS 的固件吗？请引用仓库说的合成教学电芯、阶段 4 §4.4b 离线标定只管出厂那一刻这两条现状；没写的就说没写。」

**练完你会怎样**：你能把模型当成教练，而不是当成手册。它出题，你对仓库；它对了你再信，它报阈值你就停。
