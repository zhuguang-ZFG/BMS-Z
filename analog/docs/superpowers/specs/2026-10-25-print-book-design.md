# 《通往模拟电路之路》印刷版 · 设计规格

- 日期：2026-10-25
- 状态：方向已确认；规格二次深化完成，待作者复核
- 目标仓库：`analog-circuit-roadmap`（对应站点 v3.61）
- 关联规格：[离线整书与仓库工程化改进](2026-10-24-offline-book-and-repo-polish-design.md)
- 目标版本：印刷版第一版（book 2.0.0），保留现有 1.0 离线版直至新版发布

## 1. 背景与目标

现有站点有 60 个内容页、19 个核心章节（约 158k 非空白字符）、108 张 SVG 动画、20 集视频、3 套带实测数据的实验；离线整书目前是 A4、453 页的阅读版，还不是一本可直接付印的书。

本次把现有内容重写、扩写并重新编排为一份 16K、纯色印刷的教材兼工具书，交付内文 PDF 与印刷封面。成书目标：

1. **内容深度**：19 章全部达到“大典级”深度，每章 ≥15,000 非空白字符，目标 18,000；正文合计约 320k 字符。
2. **书籍结构**：五篇正文 + 前置 + 附录 A–H + 索引、参考文献等后置；目标 535–653 页，硬上限 700 页。
3. **多层读者**：主线可零基础顺读，进阶框服务工程师，章末速查与附录服务查阅。
4. **印刷质量**：16K、镜像版心、嵌入字体、三级书签、罗马/阿拉伯页码、目录/图表目录/索引页码、篇首页与章首页版式、独立印刷封面。
5. **可信内容**：19 章仿真全覆盖；3 套现有实测实验完整呈现；不编造实测数据、文献或案例。
6. **同源同步**：`docs/` 仍是唯一内容源；站点与书同步更新，页码、索引、封面只在书中生成。

## 2. 非目标

- 不做英文版；不改变 CC BY-SA 4.0 授权。
- 不以放大字号、增加空白或重复内容把书撑到 1000 页；按正常密度交付，目标 535–653 页，硬上限 700 页。
- 不拆分为上下册或套装；超过 700 页时构建失败，由作者决定删减或调整纸张，不由构建器自行拆卷。
- 不申请、伪造 ISBN 或条形码；只预留 ISBN/条码区域，由作者后续决定。
- 不做 CMYK 转换与印刷打样；交付 sRGB 内嵌字体 PDF + 印刷规格表，按印厂要求另行转换。
- 不重命名现有 61 个 `docs/*.md` 文件，不改变站点 URL 与现有锚点。
- 不重新渲染 `video/` 下的视频产物，不把视频文件打包进书。
- 不把 `analog-book/dist/`、构建缓存或字体源文件提交进仓库。
- 不直接复制厂商数据手册中的受版权保护图片，不再分发未获授权的厂商 SPICE 模型。
- 不做“先出一章试读版”的试点；19 章全部达到验收线后才发布 2.0。

## 4. 读者与内容分层

### 4.1 三层读者

| 层 | 读者 | 阅读方式 | 版式标识 |
|---|---|---|---|
| 主线 | 零基础或跨专业读者 | 顺序读第 0–12 章，跳过进阶框 | 正文，无特殊标记 |
| 工程师 | 已能画板、需要补原理与边界 | 主线 + “工程师视角”框 + 最坏情况分析 | 带左侧色条的进阶框 |

### 4.2 阅读路径

- **8 周入门**：第 0–6 章主线 + 每章前 4 题 + RC、LM358 两套实验。
- **16 周系统**：第 0–15 章 + 三套实验 + 每章全部练习。
- **工程师补强**：第 1、3、4、6、9、11–15 章 + 进阶框 + 附录 B/C/H。
- **排故速查**：第 16–18 章 + 附录 C + 索引。
- 第 0 章保留现有编号，作为入门过渡而非序章；在“怎样读”中说明它与前言的分工。

### 4.3 练习分层

每章练习分五类：概念判断、手算、设计决策、排故、仿真。题号形如 `6-1`…`6-10`；答案在附录 F。站点保留可折叠答案，书中答案统一后置。

## 6. 章节规格

### 6.1 固定章节模板

每章按以下顺序组织。源文件标题层级保持站点约定：章标题 `## 第 N 章`，编号节 `### N.x`，编号小节 `#### N.x.y`。书内映射为：章标题 → `h1`，编号节 → `h2`，编号小节 → `h3`；标题缺少 `id` 时构建分配确定性 ID（`<stem>--h2-<序号>` / `<stem>--h3-<序号>`），已有 `id` 保留并加页面命名空间。目录与三级书签只使用章和编号节，不展开小节。

1. **章首页**
   - 章号、章名、一句话导语。
   - “学完你应能”：3–6 条可检验目标。
   - “先修”：前置章节与最小知识。
   - “本章地图”：节级目录。
   - “本章要回答的问题”：2–3 个问题。
2. **主线正文**
   - 问题 → 直觉 → 物理图像 → 模型 → 推导 → 设计式。
   - 每个公式给符号、单位、假设、失效边界；推导不跳步。
   - 每个新概念至少一个具体数值算例或反例。
3. **工程师视角**（每章 ≥3 个）
   - 最坏情况、容差、温度、工艺、成本、模型边界。
   - 用“工程师视角”加粗标签开头，书内渲染为带色条的进阶框。
4. **常见误区与失败案例**
   - 每章 ≥3 条误区；失败案例必须有出处或来自仓库实测，不编故事。
5. **仿真实验**（每章 ≥1 个）
   - 标题形如“仿真 6-1 …”，给出 deck 路径、分析类型、关键设置、预期结果、该看什么、模型局限。
6. **实测/案例**
   - 仅第 1、4、6 章放三套实测实验的完整版；其他章如需引用，只引用数据和结论。
7. **设计速查卡**
   - 本章公式、判据、选型表，控制在一页内。
8. **本章小结与下一步**
   - 5–8 条要点；指向下一章或附录。
9. **本章练习**（8–12 题）
   - 五类题型；答案放 `<details>`，构建时移入附录 F。
10. **延伸阅读**（6–8 条）
    - 统一表格：作者/机构 | 标题 | 出版/版本 | 年份 | 为什么读。
    - 真实可查；网址或 DOI 写在标题格内。

### 6.2 三层内容的边界

- 主线不依赖进阶框；删掉进阶框后仍能读懂。
- 进阶框不重复主线推导，只给边界、代价与工程取舍。
- 速查卡不是章节摘要，只收公式、判据、选型参数。
- 练习不引入正文未讲的方法；排故题可以跨章，但必须给先修提示。

### 6.3 每章验收线（DoD）

| 项目 | 要求 |
|---|---|
| 总字数 | ≥15,000 非空白字符（不含 HTML/SVG/Math 标记） |
| 正文散文 | ≥12,000 非空白字符（不含代码块、表格、公式标记） |
| 进阶框 | ≥3 |
| 常见误区/失败案例 | ≥3 条，失败案例有出处或来自仓库实测 |

### 6.5 逐章蓝图

§6.4 是总量与方向；本节把 19 章拆到节级，作为扩写、审读与验收的共同合同。写作中发现更好的结构，先在 `analog-book/STYLE.md` 的“结构变更”记录理由，再同步修改本节与正文；不允许只在正文里私自改结构。

**通用约束**

- 每章至少 3 个完整算例（例 N-1…）、1 个可运行仿真（仿真 N-1）、4 个编号图表；练习 8–12 题且五类齐全（概念判断、手算、设计决策、排故、仿真）；延伸阅读 6–8 条。
- 新增内容必须回答三件事：为什么需要、真实电路里怎么失效、读者怎么验证；不许只增加定义。
- 与相邻章的分工写在每章“边界”里；同一推导只在一章展开，其他章交叉引用。
- 仿真只规定 deck 与断言指标，不在规格里写死“实测值”；最终数值以运行结果为准。
- 失败案例必须有公开出处或仓库实测；没有出处的只能写“常见现象”，不能写“某项目案例”。

### 6.6 写作与排版规则

- **语言**：第二人称、短句、先结论后推导；术语首次出现给英文；同一概念只用一套译名。
- **公式**：只给被引用的公式编号；编号形如 `(6.4)`；变量用斜体，单位正体；必须写假设与适用范围。
- **算例**：给定 → 求 → 方案 → 代入 → 校验 → 坑点；数字带单位与数量级。
- **失败案例**：只写有出处的公开案例或仓库实测；不编“某客户”。
- **书内去 emoji**：标题、正文、提示框、表格、SVG 文本中的装饰性 emoji 全部移除；`✅/❌/⚠️` 映射为 `✓/✗/注意`；箭头、希腊字母、数学符号保留。站点保留 emoji。
- **提示框语义化**：现有 `> 🎯 学完你应能`、`> 📚 先修`、`> 🧮 公式速查` 在书内转为“学习目标 / 先修 / 公式速查”标签框；未识别的 emoji 引用框保留为普通引用。
- **交互替身**：`.calc` 计算器必须配一段静态公式 + 一个算例；`study-player` 视频块在书内改写为“视频 D-xx（见附录 D）”，不保留播放器。
- **表格**：最多 6 列；跨页重复表头；表头不得为空；宽表拆成两张或改成图。
- **代码**：单行 ≤80 字符；超出则换行或缩短；书内 8.5pt 等宽。
- **图**：矢量优先；最小图内字号 7pt；图注含编号、标题、来源；数据图注明 CSV/deck 路径。
- **交叉引用**：站内链接改为“第 X 章 §X.Y”；外部链接改为章末尾注；不使用“见上文/见下文”这类无法定位的指代。
- **术语**：与附录 G 一致；新增术语先入表再使用。
- **写作规范文件**：新增 `analog-book/STYLE.md`，把以上规则、标题锚点、练习/答案/仿真/参考文献的标记格式写成可执行清单。

### 6.7 内容审读与事实核查

- **来源台账**：新增 `analog-book/data/sources.yml`。每条记录 `id`、`chapter`、`claim`、`source_type`（教材/数据手册/应用笔记/论文/仓库实测/仿真）、`citation`、`url_or_doi`、`verified_on`、`verifier`。正文中每个非平凡数值、每条失败案例、每条“业界公认”说法都挂 `id`；构建校验引用的 id 存在，反向检查未使用的来源。
- **三遍审读**：
  1. 技术审读：公式推导、量纲、数值、工作区判断、仿真断言、实测 CSV 与图的一致性；每章至少 1 名非作者审读者。
  2. 编辑审读：术语、译名、标点、单位、图表编号、交叉引用、练习与答案对应。
  3. 安全与合规审读：市电/高压/储能/热测试的安全警告；厂商图片与模型授权；实测数据的隐私与来源。
- **作者签字**：每章完成后在 `analog-book/data/chapter-signoff.yml` 记录 `chapter`、`draft_version`、`technical_reviewer`、`editorial_reviewer`、`safety_reviewer`、`date`、`open_issues`；`open_issues` 非空不得进稳定版。
- **来源优先级**：实测数据 > 公开数据手册 > 教科书 > 应用笔记 > 厂商博客 > 社区问答。低优先级来源只能支撑“经验判断”，不能支撑“定量结论”。
- **不可核实内容的处理**：删除；或降级为“经验上/通常”；或改成可运行的仿真/实验让读者自证。禁止用“某客户/某项目/某实验室”代替来源。
- **数据与图一致性**：实测图只能由 `measurements.csv` 生成，仿真图只能由 deck 输出生成；图注写 CSV/deck 路径；不允许手工改曲线或“美化”数据点。
- **抽样复审**：Phase 5 从每章随机抽 3 个算例、2 个公式、1 个失败案例重算/重查；抽检不通过则整章退回。
- **修订记录**：每章文末维护“本章修订”表（日期、版本、改了什么、为什么），构建时汇总到 `p9-12-changelog.md` 的 2.0 条目；勘误进 `p9-12-changelog.md` 的勘误条目，并在站点版本记录入口可见。
- **交叉对账**：Phase 5 对索引、术语、符号、参考文献做一次机器+人工对账；机器检查锚点与数量，人工检查“同一概念是否只有一套译名”。

## 7. 版式与印装

### 7.1 开本与版心

- 成品尺寸：185×260mm（16K）。
- 版心：145×218mm；上 20mm、下 22mm、内 22mm、外 18mm。
- 镜像版心优先用 Chromium `@page :left/:right`；Phase 0 验证，不支持则退回统一 20mm 左右边距，并在 `PRINT-SPEC.md` 说明。
- 内文不放满版底色；图片、表格全部落在版心内；封面单独出血。

### 7.2 字体与字号

| 用途 | 字体 | 字号/行距 |
|---|---|---|
| 正文 | 思源宋体（Noto Serif SC）Regular/Bold | 10.5pt / 17.5pt |
| 标题 | 思源黑体（Noto Sans SC）Regular/Bold | 篇 28pt、章 22pt、节 15pt、小节 12pt |
| 图表标题 | 思源黑体 Regular | 9pt / 13pt |
| 表格 | 思源宋体 Regular | 9pt / 13pt |
| 索引、术语表 | 思源宋体 Regular | 9pt / 12.5pt，两栏 |
| 代码 | JetBrains Mono Regular | 8.5pt / 12pt |
| 页眉页脚 | 思源黑体 Regular | 8pt |

- 字体均为 OFL 授权；仓库只提交按实际字符集子集化的 WOFF2 与许可证，源字体不入库。
- 书构建把子集 WOFF2 以 data URI 内联进单文件 HTML；PDF 由同一 HTML 打印，字体已加载并嵌入，不依赖 `dist/fonts/` 外部文件。
- 构建时用 `fonttools` 检查缺字；出现未覆盖字符直接失败，提示重新子集化。
- PDF 必须嵌入全部字体；用 PyMuPDF 检查 `get_fonts()`，不允许未嵌入字体。
- 数学公式沿用 MathJax SVG 输出（书中），站点继续 CHTML；公式字形随 SVG 路径，不依赖外部字体。

### 7.3 色彩、纸张与装订

- 墨色 `#1F2933`，品牌琥珀 `#B45309`，辅助灰 `#52606D`，分隔线 `#D9E2EC`；纸色 `#FFFDF8` 只用于屏幕预览与封面设计稿，内文打印页底色为白，不铺满版底色。
- 正文纯黑或墨色；浅灰只用于页眉页脚与图注，不用于正文。
- 内文 80g 纯质纸；封面 250g 铜版纸 + 哑膜；胶装。
- 书脊厚度：`spine_mm = pages / 2 × 0.10 + 1.0`；页数取最终内文（含补白）。650 页约 33.5mm。
- 若印厂纸张厚度不同，改 `cover.paper_caliper_mm` 重新生成封面，不手改封面文件。

### 7.4 页码、页眉与书籍结构

- 前置罗马数字（i, ii, …），正文、附录与索引阿拉伯数字从 1 连续编号；半书名页、书名页、版权页不显示页码。
- 偶数页（左）页眉放书名，奇数页（右）页眉放当前章/附录名；页码在外下角。
- 半书名页、书名页、版权页、篇首页、章首页、空白补页不排页眉页脚。
- 章另起新页；篇首页另起新页。若 Chromium 支持 `break-before: right`，篇首页强制右页；否则接受新页起排，不用 PDF 插页后处理。
- 目录、图表目录、索引、参考文献均单独起页。
- PDF 页码标签由 PyMuPDF 写入，不依赖 CSS 计数器；封面 PDF 不参与内文页码。

### 7.5 目录、图表目录与索引

- **详细目录**：篇 → 单元 → 章 → 节（源 `### N.x`，书内 `h2`），不展开小节；每条带点线与页码；6–10 页。
- **图表目录**：图目录、表目录各一份；每条含编号、标题、页码；6–10 页。
- **索引**：两栏，按拼音顺序；300–400 条；每条可有多处页码；主讨论页加粗；支持“见/参见”。
- **页码回填**：目录、图表目录、索引的每条链接后放固定宽度 `000` 占位；PDF 渲染后由 PyMuPDF 读取该链接的目标页，覆盖占位并写入实际阿拉伯页码。这样不需要第二遍渲染，也不会因页码字数变化改版。
- **目录区检测**：目录区包含目录、图目录、表目录三部分，从“目录”标题页开始，到第一章首页前结束；`图表目录`、`表目录` 子标题只用于分区，不作为结束标记。索引区从“索引”页开始，到“版本记录”页前结束。两类区域分别回填，不能把图表目录或索引误判为目录区。
- **书签**：三级——篇/附录为一级；章、附录内大节为二级；章内编号节（`h2`）为三级；附录内编号小节（若有）为三级。由目录链接目标顺序生成并校验数量。

### 7.6 图、表、公式与代码

- 图号 `图 6-3`，表号 `表 6-1`，按章递增；图注在图下，表注在表上。
- 每图必须有编号、标题、来源；数据图必须注明源 CSV 或 deck；示意图注明“作者重绘”。
- 表格最多 6 列；跨页重复 `<thead>`；行不跨页断裂；数字右对齐、单位统一。
- 公式只在被正文引用时编号；编号 `(6.4)`；公式块不跨页断开。
- 代码块单行 ≤80 字符；打印使用 `white-space: pre-wrap`，不横向溢出。
- 图内最小字号 7pt；Phase 5 出图表校样页，按最终尺寸检查。
- 交互组件：打印隐藏计算器输入控件与按钮，保留默认读数、静态公式与算例；视频播放器改为“视频 D-xx（见附录 D）”文字入口。

### 7.7 交叉引用与尾注

- 站内链接统一改写为“第 X 章 §X.Y”文本，并保留 PDF 内部链接；不显示 URL。

- 书末参考文献由各章“延伸阅读”表合并去重；同一本书只出现一次，标注首次出现章。

### 7.8 印刷封面

- 一份 HTML/CSS 生成前封、书脊、后封；页面尺寸 = `(2×185 + spine + 2×3) mm` 宽 × `(260 + 2×3) mm` 高；含 3mm 出血与角部裁切线。
- 前封：书名、副标题、作者、第一版、16K 标识、矢量电路纹样；品牌琥珀 + 纸色，纯色。
- 书脊：书名 + 作者，中文竖排；书脊 <6mm 时省略文字（本规格不会出现）。
- 后封：3–5 句简介、读者对象、5 条内容亮点、二维码（站点/仓库）、授权、版本、勘误入口；预留 40×25mm 空白 ISBN/条码区，**不写假号**。
- 输出 `cover.pdf` 与 150dpi `cover-preview.png`；封面书脊宽度必须与最终内文页数一致，构建时校验。
- 若作者后续提供 ISBN，填入预留区并重新生成；未提供则保持空白。

### 7.9 交付物与印刷规格

`analog-book/dist/` 下交付：

```text
analog-circuit-book.html      # 离线阅读版
analog-circuit-book.pdf       # 16K 内文，嵌入字体，sRGB
cover.pdf                     # 前封/书脊/后封，3mm 出血，裁切线
cover-preview.png             # 150dpi 预览
PRINT-SPEC.md                 # 开本、出血、书脊、纸张、装订、字体、色彩说明
```

`PRINT-SPEC.md` 至少包含：成品尺寸、版心、出血、书脊公式与实测值、页数、纸张、装订、字体清单与授权、色彩空间、PDF 版本、文件大小、建议打样页。CMYK 转换与打样由印厂执行，转换后需重新校色，不在本次构建内完成。

### 7.10 印前检查与打样

- **Preflight 清单**（构建自动检查 + 人工签字）：
  - 页面：185×260mm、页数为 4 的倍数、无空白页缺页、无内容越出版心。
  - 字体：全部嵌入、无缺字、无替代字体、字重正确。
  - 图：≥300dpi 等效（矢量优先）、无透明背景导致的黑块、无远程资源、图注/编号/来源齐全。
  - 色：内文以墨色与品牌色为主，sRGB 交付；印厂要求 CMYK 时转换后检查品牌色偏差、细线与反白字。
  - 线：正线最小 0.25pt，反白线最小 0.35pt，表格线 0.4pt；避免四色细线。
  - 出血：封面 3mm；内文无满版图，不需要出血；跨页图不跨订口。
  - 书脊：与最终页数一致；书脊文字距上下边 ≥10mm。
  - 条码/ISBN：预留区空白，不生成假条码。
  - 元数据：标题、作者、主题、关键词、版本、语言。
- **打样层级**：
  1. 16K 激光样：检查版心、字号、行距、分页、页眉页脚、目录页码；每波一次。
  2. 喷墨彩色样：检查品牌色、图灰度、表底纹、封面配色；Phase 5 一次。
  3. 装订样：按最终页数打印并胶装一本，检查书脊、翻开度、跨页图、页边距；Phase 5 一次。
  4. 印厂签样：提供 `PRINT-SPEC.md`、内文 PDF、封面 PDF、打样页清单；签样后才开印。
- **签样单**：记录日期、版本、页数、书脊、纸张、色彩、问题与处理；签样后任何改动都要重新出 PDF 并更新版本号。
- **勘误与重印**：首印后发现错误，进 `p9-12-changelog.md` 的勘误条目，并在站点版本记录入口可见；重印时只改勘误，不悄悄改内容；版本号递增。

## 8. 内容资产与可信度

### 8.1 仿真全覆盖

- 模拟器：ngspice（批处理模式），CI 安装；本机缺失时相关测试 skip 并给出安装提示，CI 不允许 skip。
- 目录：`assets/spice/ch00/` … `assets/spice/ch18/`，每章至少一个主 deck；共 ≥19 个 deck，允许同章多个变体。
- 每个 deck 配 `assert.json`：分析类型、输出文件、指标名、期望值、容差、单位；`scripts/run_spice.py` 运行并校验。
- 书内仿真图由 `scripts/plot_sim.py` 从运行结果生成 SVG，统一字体、线宽、配色；构建时生成到 `build/`，不提交生成图。
- 模型来源写入 `assets/spice/MODELS.md`：自有行为模型、公共领域模型、允许再分发的模型；厂商模型未授权则只给等效模型并注明局限。
- 每章仿真实验必须写“模型边界”：哪些寄生、温度、噪声、工艺未建模，结论不能外推到什么范围。
- 建议主实验：第 1 章 RC 频响、第 3 章偏置温度、第 4 章开关损耗、第 6 章 LM358 压摆/GBW、第 9 章 LDO 负载瞬态、第 12 章 Sallen-Key、第 13 章 Buck、第 16 章探头负载、第 17 章开路故障注入；其余章按同一标准配置。

### 8.2 实测案例

- 仅使用仓库现有三套：`assets/labs/rc/`、`assets/labs/lm358/`、`assets/labs/mosfet/`。
- 每套在书内呈现：目标、原理图、BOM、仪器与接线、步骤、`measurements.csv` 数据图、`reference.csv` 仿真对比、误差来源、常见坑。
- 没有实测照片的，使用重绘接线示意图并明确标注“接线示意，非实物照片”；**不生成假照片**。
- 不新增“实测数据”；后续作者补测时，必须同时提交 CSV、仪器条件与日期，才允许更新书内曲线。

### 8.3 附录资产

- A 动画索引：24 张关键帧（19 章各 1 张 + 5 张跨章概念帧）+ 108 条总表；静态帧用站点 reduce 版本；总表含章号与站点锚点。
- B 公式速查：沿用 `p0-08`，重排两栏；与各章公式符号一致，Phase 5 做符号对账。
- C 芯片速查：`p6-01`…`p6-05`；图片授权逐条保留。
- D 视频与资源：20 集视频清单（`p7-01`…`p7-03`）+ 书单/项目/社区/工具/FAQ/官方文档/经典论文（`p8-02`…`p8-09`）；每集给标题、时长、看点、站点链接；不打包视频。
- E 学习路线：按需求、按基础、按目标三条路线 + 分阶段路线（`p8-01`）+ 19 章总表（`p8-11`）+ 自诊断表（`p0-09`）。
- F 答案与自测：章别答案 + 综合 34 题 + 评分要点。
- G 术语表：`p9-15` 150–250 条，中文 + 英文 + 1–3 句定义 + 章号；并入 `p8-10` 黑话速查表，按拼音合并去重。
- H 模型边界：沿用 `p0-10`，补仿真模型与实测外推限制。

### 8.4 练习与答案

- 每章 8–12 题；题号 `N-1`…，五类题型齐全。
- 站点用 `<details><summary>答案</summary>` 折叠；书构建把答案移到附录 F，题目保留在章末。
- `p9-00-quiz.md` 的章别题目按章并入书内练习；综合 34 题留在附录 F。
- 答案给到可核对的程度：计算题给结果与关键步骤；设计题给评分要点与参考方案；排故题给判断依据。
- 构建校验：每题有答案或明确的“开放题评分要点”；答案编号与题目一一对应。

### 8.5 索引、术语、符号与参考文献

- **索引**：`analog-book/data/index-terms.yml`，300–400 条；字段 `term`、`english`、`primary`、`anchors`、`see_also`；`primary` 是主讨论锚点，对应页码加粗；文件按拼音顺序维护，构建校验重复项与锚点存在。
- **术语表**：`docs/p9-15-glossary.md`，150–250 条；每条含英文、定义、章号；并入 `p8-10` 黑话速查表；构建校验数量与链接。
- **符号表**：`docs/p0-12-symbols.md`，100+ 行；列：符号、含义、单位、首次出现章。
- **参考文献**：每章“延伸阅读”6–8 条，统一五列表格；合计 ≥114 条，去重后 ≥100 条，不足时补各章专属读物；去重结果写入 `analog-book/data/references.yml`，书末参考文献由该文件生成；构建校验每条至少关联 1 章。
- 以上四项在 Phase 5 做一次交叉对账：索引指向的术语必须在术语表或正文有定义；符号表必须覆盖各章公式用到的符号。

### 8.6 数据与引用可信度

- 仿真数据只来自 `assets/spice/**` 的可运行 deck；实测数据只来自 `assets/labs/**/measurements.csv`。
- 图注必须写明数据来源；没有来源的数据图不得进书。
- 文献必须可查：教材给版次/出版社/年份/ISBN，应用笔记给编号与厂商，网页给标题/机构/访问日期。
- 不编造引文、不伪造 DOI、不虚构“某实验室数据”；无法核实的说法降级为“经验判断”或删除。
- 版权页与附录 H 明确：仿真是模型结果，不是实测；实测只覆盖三套实验；读者设计需按数据手册与实测复核。

### 9.3 构建流水线

1. `python scripts/build_site.py --build` 生成站点；书构建不允许绕过站点直接渲染 Markdown。
2. 校验 manifest 覆盖率、数据文件 schema（`animations.yml`、`index-terms.yml`、`sources.yml`、`chapter-signoff.yml`）与文件存在；`references.yml` 由构建生成后校验；抽取每页 `<article>`；缺页/缺标题/缺字段立即失败。
3. 清洗站点专属 DOM：编辑按钮、headerlink、legacy anchor、共建页脚、gallery 控件、视频播放器、计算器输入控件；保留 `.reading-checkpoint`。
4. 书专用转换：
   - 章标题从 `##` 提升为 `h1`；编号节 `###` 提升为 `h2`；编号小节 `####` 提升为 `h3`；缺 `id` 的标题分配确定性 ID；生成章首页元数据。
   - 去 emoji；语义化提示框。
   - 图表编号与图注/表注。
   - 外部链接转尾注；站内链接转章节引用。
   - `.calc` 校验印刷替身；`.study-player` 转视频索引。
   - 章末练习从题库合并；答案移入附录 F。
   - 来源标注：非平凡数值、失败案例、定量结论挂 `sources.yml` 的 id；`final` 阶段缺失即失败。
   - 篇首页、前置页、后置页生成。
   - 索引与图表目录生成。
5. 内联 CSS/JS/图片/MathJax（SVG）/子集字体（WOFF2 以 data URI 嵌入）；禁止远程图片、iframe、video；不依赖 `dist/fonts/`。
6. 生成单文件 HTML；审计 ID 唯一、链接可达、资源内联、HTML 目标 <60MB、硬上限 80MB。
7. Playwright 加载单文件 HTML，按 `@page` 16K 尺寸与 `reduced_motion=reduce` 打印 PDF；等待字体、MathJax、图片。
8. PyMuPDF 后处理：
   - 元数据、页数、字体嵌入检查。
   - 定位目录区（目录+图目录+表目录）与索引区，按链接目标回填页码。
   - 写三级书签、罗马/阿拉伯页码标签。
   - 正文页页眉页脚；跳过篇首页、章首页、空白页。
   - 补页到 4 的倍数后重新计数。
9. 生成封面：读取最终页数 → 计算书脊 → 渲染 cover.pdf → 校验尺寸/出血/书脊文字 → 出 cover-preview.png。
10. 运行 PDF/封面断言；失败则不出稳定版。
11. 输出 `PRINT-SPEC.md` 与构建报告（页数、字数、图表数、公式数、字体、体积、来源覆盖率、审读未决项）。
12. `--check` 对既有产物跑同一审计，不重建；`--html-only` 供 PR/无浏览器环境使用。

### 9.4 书专用转换细则

- **章首页**：从章标题前后的引用块提取“先修/学完你应能/公式速查”；若缺失，构建失败并提示补写。
- **去 emoji**：只作用于书的 DOM，不改 `docs/`；SVG 文本在生成静态版时同步清理；书内文本断言无 emoji。
- **图表编号**：每章独立计数；图注/表注必须已有标题；无标题的图表进审计红灯，不自动用 alt 猜标题。
- **尾注**：同一章内按首次出现编号；`http(s)`、`mailto:`、站外相对链接都进尾注；站内锚点不进尾注。
- **练习/答案**：章内 `## 本章练习` 与题库章别题目合并；答案 `<details>` 移入附录 F；题目保留在原章；答案编号与题号一致。
- **计算器**：`.calc` 必须有 `.calc-print` 或紧随其后的“例 N-x”；构建校验；打印隐藏输入控件。
- **视频**：`.study-player` / YouTube 缩略图改写为“视频 D-xx（见附录 D）”；不内嵌视频。
- **附录 B–E、G、H**：按 manifest 文件顺序拼接并生成分隔页；B 两栏重排；E 依次路线/选读/诊断；G 术语表后接 `p8-10` 速查表并按拼音合并去重；H 补仿真模型边界。C/D 的图片仍走本地资产与授权署名，不做远程引用。
- **附录 A**：读取 `animations.yml`，生成 24 张关键帧 + 108 行总表；静态 SVG 使用站点 reduce 版本；总表每条含章号与站点锚点。
- **附录 F**：章别答案 + 综合 34 题；答案不折叠，直接排印。
- **索引**：读取 `index-terms.yml`，按拼音排序、两栏排印；`primary` 对应页码加粗；每条锚点生成链接与 `000` 页码占位；构建校验锚点存在。
- **图表目录**：从图注/表注生成条目；每条链接到图/表锚点，带 `000` 占位。
- **参考文献**：解析各章“延伸阅读”五列表；按标题+年份去重；书末按作者/标题排序。

### 9.5 页码回填与书签

- 目录、图表目录、索引中的每条链接后输出固定宽度 `000`；PDF 渲染后读取链接目标页，覆盖占位并写入实际页码。
- 覆盖使用白色矩形（与内文页底色一致）+ 页码文本；占位与页码均为 3 位，版式不因数字位数变化。
- 目录区识别：从“目录”标题页开始，到第一章首页前结束，覆盖目录、图目录、表目录；`图表目录`、`表目录` 只用于分区，不作为结束标记。索引区从“索引”页开始，到“版本记录”页前结束；不得依赖“页面无链接”判断。
- 书签：一级 = 篇/附录；二级 = 章、附录内大节；三级 = 章内编号节（`h2`）、附录内编号小节；数量与顺序从目录条目校验。
- 页眉：偶数页书名、奇数页章/附录名；半书名页、书名页、版权页、篇首页、章首页、空白页不排；页脚页码在外下角。
- 页码标签：前置罗马；正文、附录与索引阿拉伯连续编号。
- 补白：全书排完后在末尾补空白页到 4 的倍数；空白页不排页眉页脚，不进入书签。

### 9.6 封面生成

- 封面在**内文最终页数确定后**生成；先补白，再算书脊，再渲染封面。
- 宽 = `(2×185 + spine + 2×3)` mm；高 = `(260 + 2×3)` mm。
- 书脊文字位置由封面宽高与书脊宽度计算；书脊 <6mm 时不排字。
- 裁切线画在出血区四角；不遮挡文字。
- 封面 PDF 单独输出，不合并进内文；印刷厂可分别处理内文与封面。
- 封面预览 PNG 用于站点/README，不用于印刷。

| Phase 5 | 收口 | 附录 A–H、索引、术语、交叉引用、封面、PDF 总校、发布 |

**每波门禁**：

1. 内容：字数、必备元素、蓝图一致、无占位、无 emoji、练习/答案齐全。
2. 技术：该波仿真 deck 全过；数据来源可追；链接/锚点可解析。
3. 印刷：16K 样张无溢出；图表标题/编号齐全；表格不超 6 列。
4. 回归：站点测试 + 书浏览器测试全绿；不破坏现有 URL。
5. 审读：`sources.yml` 台账完整；技术/编辑/安全审读已签字；`chapter-signoff.yml` 的 `open_issues` 为空。

**Phase 5 额外门禁**：索引/图表目录页码一致；参考文献去重；封面书脊与页数一致；PDF <100MB；Pages + 镜像验收。

## 12. 风险与缓解

| 风险 | 缓解 |
|---|---|
| 净增约 160k 字符，工作量大 | 四波推进，每章固定模板与 DoD；每波独立验收，不一次性攒到最后 |
| 扩写变成“注水”，篇幅达标但信息密度下降 | 逐章蓝图 + 散文占比 + 算例/仿真/图表硬指标 + Phase 5 抽样复审；不达标整章退回 |
| 来源核查工作量被低估 | `sources.yml` 台账 + 三遍审读 + 每波审读门禁；Phase 5 预留专项审读时间 |
| Chromium 不支持镜像版心/篇首页右页 | Phase 0 验证；不支持则统一版心、篇首页新页起排；不用脆弱的 PDF 插页后处理 |
| 字体缺字或未嵌入 | 子集字体入库 + `fonttools` 缺字检查 + PyMuPDF 嵌入检查；缺字直接失败 |
| 页数超过 700 | 构建失败；先删重复/压缩图表，再与作者确认是否调整纸张或拆卷；不自动拆卷 |
| PDF >100MB | 优化 SVG/图片、去重复资源；仍超限则发布失败并报告最大资源 |
| 单文件 HTML 因字体/配图膨胀 | 子集字体 + 资源去重 + 体积审计；HTML 目标 60MB、硬上限 80MB，超限报告最大资源 |
| 引用/数据不可信 | 仿真来自 deck、实测来自 CSV、文献人工核验；无法核实的说法降级或删除 |
| 厂商模型/图片版权 | 只用自有/公共领域/可再分发资产；受版权图片重绘；厂商模型只给等效模型 |
| 站点与书篇号冲突 | 站点改用篇名，书用罗马数字 I–V；正文禁止“第 X 篇”硬引用 |
| 长章节拖慢站点 | 保留阅读导航与页内目录；书/站分开发布；不新增运行时依赖 |
| CI 时间过长 | PR 不强制 PDF；main/manual 才跑 PDF；PDF 作业单独超时 |
| 发布期站点被未完成书阻塞 | 扩写期 pages 只发站点；书稳定版只在 Phase 5 发布 |
| 封面书脊算错 | 封面在内文补白后生成；书脊公式参数化；构建校验尺寸与页数 |
| 索引/目录页码错位 | 固定 3 位占位 + PyMuPDF 按链接回填；测试覆盖三条抽检 |
| 字体源文件撑大仓库 | 只提交子集 WOFF2 与许可证；源字体下载到 `build/`，不入库 |
