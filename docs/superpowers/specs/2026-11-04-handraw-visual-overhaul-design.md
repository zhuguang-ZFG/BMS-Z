# Handraw 视觉整库改造设计（路径 B）

> 状态：已批准（2026-11-04）  
> 范围：整库静态插图 + 动画视觉，一并按 handraw 气质重做  
> 节奏：先钉全库统一画风包，再开第一批 20 张  
> 关系：本文件是视觉执行设计，**不推翻** `docs/教材彻底改造SPEC.md` v2.5；执行时对齐 SPEC §3（视觉/动画合同）与 §9（知识点入门→精通梯子）

---

## 1. 目标与边界

### 1.1 目标

将 BMS-Z 教材中的静态插图与站内因果动画，统一升级为 **handraw 手绘气质**：机制图用连续线概念表达，信息结构图用几何叙事表达；色板与禁区全库锁定，避免「几何 SVG 一套、手绘封面一套」的分裂观感。

### 1.2 路径定稿：B

**全部改为手绘位图序列，再由帧序列导出站内可暂停动画。**

- 真源：`storyboard/` 下的 handraw 位图帧（不是旧几何 SVG）。
- 导出：WebP / APNG，或在必要时重建为可暂停的 SVG/SMIL 等价物；须保留可暂停与首末帧静态可读。
- 旧几何 SVG：迁入 `archive/`（或等价归档路径），正文链接改指向新产物。
- 动画层线色、标注、危险高亮必须对齐本设计色板，不得另起一套。

### 1.3 明确不做

| 不做 | 说明 |
|------|------|
| 不把 handraw 静态图伪装成假 SMIL 动画 | 静态帧是真源；动画由帧序列导出，禁止「贴一张手绘当动画」 |
| 不删旧动画的静态可读性来换炫技 | 每条因果动画须保留可暂停；首末帧须可单独当静态图阅读 |
| 未授权不写「实拍」 | 图注不得声称实拍、示波器截屏、真机照片；统一「原理示意 / 非实拍」 |
| 不推翻 SPEC v2.5 | 本设计是 §3/§9 的视觉落地，不改知识点梯子、不改 KP 数量合同 |
| 本回合不改插图本体、不出图 | 本文只落设计合同；渲染须用户显式点名「出图」 |

## 3. 产物结构（§1）

对库中每张（或每组）原 SVG 因果图，改造后须具备：

1. **`storyboard/` 手绘位图帧**  
   - 每条因果 **3–8 帧** handraw 位图。  
   - 机制因果优先 FA-002；分层/对照/地图优先 FA-029。  
   - 色板锁 C-03；危险只用 C-15。

2. **由帧导出的站内可暂停动画**  
   - 格式：WebP / APNG，或重建 SVG（须可暂停）。  
   - 线色与标注对齐画风包；正文须配观察题（见 §5）。

3. **打印用首末静态帧**  
   - 首帧、末帧可单独嵌入讲义/打印稿，静态可读。

4. **旧资产处置**  
   - 旧几何 SVG → `archive/`（保留可追溯）。  
   - 正文、清单、缺口表中的链接改为新真源路径。

目录约定（执行时可微调，但语义不变）：

```text
docs/.../assets/<slug>/
  storyboard/          # 真源：handraw 位图帧
  <slug>.webp|.apng    # 导出动画（可暂停）
  <slug>-start.png     # 打印用首帧
  <slug>-end.png       # 打印用末帧
archive/.../           # 旧几何 SVG
```

## 4. 第一批 20 张与流水线（§2）

### 4.1 选片优先级

1. **`bms-roadmap`**、**`bms-signal-budget`**（全库门面与信号预算，优先示范画风包）。  
2. **骨干 13 个 KP** 各至少一张机制图（对齐 SPEC §9 骨干须补全 L1–L5 的视觉侧）。  
3. 余量补 **阶段 0–1** 高频因果图，凑满 **20** 张（条）。

选片清单在开批时写入执行计划或缺口表；本设计锁定优先级，不锁死最终文件名列表（以当时活跃 KP / 因果图为准）。

### 4.2 单条流水线

1. 从旧 SVG / 正文抽出因果步骤（3–8 步）。  
2. 按 FA-002 或 FA-029 + C-03/C-15 写 handraw 提示词并出帧（见 4.3）。  
3. **禁区审查**：无人、无卡通、无实拍措辞、色板合规。  
4. 由帧导出可暂停站内动画。  
5. 正文换链；补观察题与图注「原理示意 / 非实拍」。  
6. 旧几何 SVG 归档。

### 4.3 出图授权

- **默认只产出提示词与 storyboard 规格，不渲染位图。**  
- 仅当用户（或明确授权的会话）点名 **「出图」** 时，才调用 handraw / 图像生成。  
- 未授权不得批量渲染、不得提交大体积生成图进主线（除非另有提交合同）。

## 5. 验收与整库扩面（§3）

### 5.1 单张（条）过门

- [ ] 无人、无卡通 IP  
- [ ] 色板合规（C-03 主色；危险仅 C-15）  
- [ ] 首末帧静态可读（可打印）  
- [ ] 动画可暂停；正文有对应观察题  
- [ ] 图注含「原理示意 / 非实拍」  
- [ ] 旧 SVG 已归档；正文链接已更新  

### 5.2 批次与扩面

1. 第一批 **20** 张全部过门。  
2. 将实践沉淀为 `docs/`《视觉画风包》（含提示词模板、反例、抽检表）。  
3. 再按教材阶段 **0 → 7** 批量改造。  
4. 门禁增加 **画风抽检**（随机抽帧对照本设计 §2）。  
5. 任一失败项记入 gap / 视觉缺口表，**不得标完成**。
