# 零基础：前两周怎么走

> 只读中文也能走完前两周。英文视频/原文一律**可选**。  
> 安全装备与预算见 [器材清单](../budget.md)；生词查 [术语表](../glossary.md)。

⚠️ **真电池会起火。** 前两周尽量只用量好的旧电芯做**开路电压测量**；鼓包、漏液、电压异常的直接报废。护目镜与防火垫在碰真电池前备好——不要等阶段 2。

## 第 0 天：30 分钟小胜利（零器材也能做一半）

目标：亲手确认「电池有电压、充电会变慢」，建立直觉。

1. **有万用表 + 一节旧 18650/手机电池**（不鼓包）：静置后测开路电压，记下来。三元大约 3.0–4.2V，铁锂大约 2.5–3.65V——对不上也不要紧，阶段 0 会解释。  
2. **只有手机**：把电放到约 20%，插上充电器看进度——前半段快、接近 100% 变慢。那就是后面要讲的 **CC → CV**。  
3. 打开 [阶段 0 动画：锂离子与电子分头行动](../circuits/assets/li-ion-working.svg)（浏览器打开，GitHub 网页也能播），看懂「离子走里面、电子走外面」。

做完这三步，你已经比「只收藏资料」的人往前了一大步。

## 14 天路径（零基础默认）

| 天 | 做什么 | 完成标志 |
|---|---|---|
| 0 | 上面「第 0 天」 | 测过一次电压，或观察过一次充电变慢 |
| 1–4 | **[阶段 0](stage-0-前置知识.md) §0.1 必读**（电池化学 + CC-CV + SOC/SOH）+ 自测 0.1 | 能讲清：为何不能过充/过放、为何低温慎充、4.2V≠充满 |
| 5–6 | 阶段 0 §0.2 **快读**（RC / ADC / MOS / 电流采样 / 隔离）——不懂公式先记结论 | 知道背靠背 MOS 为什么要两颗 |
| 7 | 阶段 0 验收里与电池相关的几项；§0.3 嵌入式**可先跳过** | 勾选验收清单前 3–4 条即可进入阶段 1 |
| 8–12 | **[阶段 1](stage-1-认识BMS.md)** 全文 + 自测 | 能画出五大模块框图，背出五大保护 |
| 13–14 | 扫一眼 [预算清单 阶段 0–2](../budget.md)；可选：[瑞萨导读](../renesas-bms-tutorial-中文导读.md) 前两章 | 清楚阶段 2 要买什么；准备护目镜/防火垫 |

**阶段 0 §0.3（嵌入式）**：拖到开始抄保护板 / 碰 AFE 之前补齐即可，不挡你认识 BMS。
