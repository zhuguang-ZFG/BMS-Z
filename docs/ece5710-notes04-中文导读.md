## 一、一页速览

真实电极是多孔的：颗粒、电解液、粘结剂挤在同一个小体积里。直接拿微观方程去画每一颗球，网格会爆。连续介质的办法是：选一个够大、又还算均匀的平均体积，把相内部的细节平均掉，只留下能推动下一步的量（4–1…4–2 页）。

| 4.7 | 固体电流：有效电导 + 界面反应当源 | 4–23…4–26 |

> **口诀**　沿厚度只留 x，进颗粒再留 r。孔隙不画出来，用 ε、a_s 和有效电导把它折进去。
>
> **能记住**　伪二维是「一个空间维 + 一个径向维」。**能理解**　Bruggeman 为什么让有效电导比材料电导小。**能用**　能指出电芯电压、容量、SOC 在连续介质里仍用上一章的定义。

## 二、为什么要平均（§4.1）

微观方程最好写，因为材料均匀。电芯尺度要的是又快又能抓住主物理的宏观模型（4–1 页）。体积平均得到的就叫连续介质：物质被看成铺满它所占据的空间，孔隙几何被平均掉（4–2 页）。

平均体积里有两相。感兴趣的记为 α，其余并成 β（4–5 页）。模型可以写成三维，这门课收到一维：从负极集流体穿过隔膜到正极集流体，只留厚度坐标 x（4–3 页）。颗粒内部另开一个径向坐标，所以总维数是「空间一维 + 伪一维」。

## 三、平均定理在搬什么（§4.2–4.6）

这五节是数学工具。示性函数 γ_α 在 α 相里是 1，别处是 0。它的梯度集中在相界面上，和狄拉克 δ、界面法向连在一起（4–8…4–10 页）。脉冲函数收成 δ，是为了把体积积分落到界面上。

三条定理（4–4、4–16、4–20 页）说的是同一件事：平均之后，梯度和对时间的导数不能随便拖出平均号。界面上会多出一项。

- 定理 1：标量梯度的相平均 = 平均的梯度 + 界面上的 ψ n̂。
- 定理 2：矢量散度同样多一项界面通量。
- 定理 3：时间导数多一项界面运动速度。相界面如果在变形，这一项才活（4–21 页）。

相平均按整个平均体积来除，固有平均只按该相自己的体积来除（4–12…4–13 页）。盐的浓度用哪一种，答案不一样：整个电极体积里的「平均盐」会把固体占掉的空间也算进分母；电解液自己看到的浓度只用孔隙那一份。后面方程里的上划线，要分清是哪一种。

> 【译注】这些定理解释了等效电路为什么写不出孔隙。一旦平均，几何只剩体积分数 ε、比表面积 a_s、曲折度。`code/soc/` 连这三项都没有，它把剩余的慢过程收成一条 RC。读定理是为了知道信息丢在哪，不是为了在固件里实现 δ 函数。

## 四、固体电流和 Bruggeman（§4.7）

把微观的 ∇·(σ ∇φ_s) = 0 平均过去。球形颗粒的比表面积（4–24 页）：

```
a_s = 3 ε_s / R_s
```

界面反应变成源项。平均之后（4–24 页）：

```
∇·(−σ_eff ∇ φ̄_s) = −a_s F j̄
```

有效电导比材料电导小，因为电流要绕孔隙。一种写法是 σ_eff = ε_s σ δ / τ，收缩率 δ < 1，曲折度 τ ≥ 1。更常见的是 Bruggeman（4–24 页）：

```
σ_eff = σ ε_s^brug ，brug 常取 1.5
```

1.5 是习惯值，别的数可能更合适。更好的办法是按真实颗粒几何做微观仿真，或直接测量。讲义用 COMSOL 里一组矩形障碍物演示：有效扩散能不能代替把每块障碍物画出来（4–25…4–26 页）。结论是量级上可以，精细几何仍会留下误差。

## 五、两相的质量（§4.8）

固体锂浓度不需要再体积平均。假设每个 x 处有一颗球，浓度只随半径变，θ 和 φ 方向对称（4–27…4–28 页）。微观方程 ∂c_s/∂t = ∇·(D_s ∇c_s) 在球坐标里只剩径向那一项。这个 r 就是伪维度：每个 x 上挂一份径向方程。

电解液浓度要平均。界面边界条件用上一章的结果：法向扩散通量接上 (1 − t₊⁰) j（4–29 页）。直观图是一颗球和周围电解液的交界面（4–30 页）：锂离开颗粒，电解液里就多出相应的盐，迁移数决定有多少靠扩散、有多少靠迁移。

## 六、边界、电压和三种离散（§4.9–4.10）

外加电流从集流体进固体。负极集流体处把固体电位定成 0，隔膜一侧固体电流必须是 0（4–33 页）：

```
ε_s ī_s = −σ_eff ∇φ̄_s = I_app / A
```

A 是集流体面积，单位 m²。正极在 x = L_tot 处接入 −I_app/(A σ_eff)。颗粒中心 ∂c_s/∂r = 0，表面 D_s ∂c_s/∂r = −j̄，j̄ > 0 表示锂离开颗粒。电解液在两个集流体上没有通量（4–33 页）。隔膜两侧，离子电流等于进出电芯的总电流（4–34 页）。

电芯电压是正极集流体电位减负极集流体电位。固体和集流体等电位，又把负极定成 0，于是（4–35 页）：

```
v(t) = φ̄_s(L_tot, t) − φ̄_s(0, t) = φ̄_s(L_tot, t)
```

> 【译注】端电压在这里是两个集流体的固体电位差。阶段 2 的保护比较器看的是采样电阻上的分压，不是 φ̄_s 场。两边数字对不上时，先查采样链，不要用连续介质方程去改硬件阈值。

容量和 SOC 与上一章相同：两极安时容量取最小，z 仍是平均化学计量在窗口里的位置（4–35 页）。

方程齐了，还要会离散。讲义并列三种（4–36…4–37 页）：有限差分、有限体积、有限元。时间离散三者类似。有限元把空间写成一组基函数的和。电池文献三种都有人用。

## 七、COMSOL 只说明「算得动」（§4.11–4.12）

COMSOL 是商业有限元程序，选它是因为多孔电极的例子好讲，不是因为 BMS 必须买它（4–38 页）。归一化坐标 x̄ 在负极是 x/L_neg，在正极是 (x − L_neg − L_sep)/L_pos（4–39 页）。径向方程在每个 x 上各有一份，球心在底、表面在顶（4–40…4–41 页）。

实现时注意单位。Butler–Volmer 的指数项无量纲，j 是 mol/m²/s，所以 k₀ 的单位很别扭，要以软件里实际写下的那一行为准（4–43 页）。演示工况是静置、充电脉冲、静置、放电脉冲、静置（4–44 页）。截图是软件界面，不是本仓库的实验数据。

> 【译注】本仓库没有 COMSOL 模型，也不计划把 1.5 次方的 Bruggeman 写进固件。阶段 6 的算法清单仍停在等效电路能做的事：滞回、双卡尔曼、SOP、均衡。要做物理模型，先能指出 v(t) 是两端固体电位差，而不是 OCV 表的一次查表。保护阈值仍看阶段 0 和数据手册，不从 COMSOL 截图里读。
