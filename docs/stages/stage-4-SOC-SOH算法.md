# 阶段 4 教程：SOC / SOH / SOP 估算算法

> 对应学习路线的阶段 4。目标：实现可用的 SOC 估算（恒流工况误差 <5%），理解 SOH 与 SOP。
> 建议用时 1–3 个月。前置：阶段 3 验收（手里最好有一块能采电压电流的板子）。这是 BMS 的软件核心。

## 4.1 问题定义与误差全景

$$\text{SOC}(t) = \frac{\text{剩余可用容量}}{\text{当前满充容量}}$$

看似简单，四个误差源让这件事变难：

1. **电流测量零漂**——积分误差随时间累积；
2. **容量未知**——电池老化后满充容量 ≠ 标称容量；
3. **OCV 不确定**——OCV-SOC 曲线随温度、老化、滞回变化；
4. **温度**——低温可用容量骤降。

所有 SOC 算法本质都是：**安时积分为主干，用电压信息不断校正**。

## 4.2 安时积分（库仑计）

$$\text{SOC}(t) = \text{SOC}(0) + \frac{1}{Q}\int_0^t I(\tau)\, d\tau \quad(\text{约定：充电 } I>0,\ \text{放电 } I<0)$$

- 离散实现：`SOC += I * dt / Q`——充电 I>0 使 SOC 上升，放电 I<0 使 SOC 下降。符号约定必须在代码注释里写死，全项目统一；
- **致命伤是零漂**：1mA 的电流零漂，一天累积 24mAh——10Ah 电池一天漂 0.24%，一个月 7%，必须靠校准点周期性复位；
- 两个最常用的校准点：**满充校准**（CV 段截止电流判据 → SOC=100%）与**静置 OCV 校准**（长时间静置后查 OCV 表）。

## 4.3 OCV 法

- **OCV-SOC 曲线获取**：小倍率（0.05C）完整充放 + 分段静置，取均值成表；
- **滞回（hysteresis）**：充电 OCV 曲线与放电 OCV 曲线不重合，中间差几十 mV——单张表会引入系统性误差；
- **静置要求**：断电后极化电压消散需要时间（几分钟到几小时），未充分静置就查表会读偏；
- **LFP 的死穴**：平台区 OCV 斜率 <1mV/%SOC，采样噪声就有 2–5mV——平台区纯电压法基本失效，只能靠滤波算法融合。

## 4.4 等效电路模型

让"电压"在非静置状态下也能用的办法：建模。

- **Rint 模型**：$U = U_{oc} - IR_0$——太粗；
- **Thevenin（一阶 RC）**：$U = U_{oc} - IR_0 - U_{RC}$，$\dot{U}_{RC} = -\dfrac{U_{RC}}{R_1 C_1} + \dfrac{I}{C_1}$——工程主力；
- **二阶 RC**：极化分快慢两路，精度更高，参数更多。

参数辨识用 **HPPC 脉冲测试**：不同 SOC 点施加充放电流脉冲，从电压响应曲线拟合出 $R_0, R_1, C_1$（查 Plett 课程与 AlterWL 仓库的辨识脚本）。

## 4.5 卡尔曼滤波（EKF）

把电池写成状态空间：状态 $x = [\text{SOC}, U_{RC}]^T$，输入 $I$，观测 $U$。

**预测步**：

$$\hat{x}^- = f(\hat{x}, I), \quad P^- = A P A^T + Q$$

**更新步**：

$$K = P^- C^T (C P^- C^T + R)^{-1}, \quad \hat{x} = \hat{x}^- + K\,(U_{实测} - g(\hat{x}^-)), \quad P = (I - KC)P^-$$

- EKF 与线性 KF 的区别只在：$f$/$g$ 非线性（OCV 表），用雅可比矩阵 A、C 在当前点线性化；
- **调参直觉**：Q 大 = 不信任模型（跟测量走，响应快但抖）；R 大 = 不信任测量（平滑但滞后）；
- **发散诊断**：残差 $U_{实测} - g(\hat{x}^-)$ 持续偏大 → 模型错了（参数漂移/温度没补偿），不是滤波器错了；
- 上手路径：先在 MATLAB 跑通 [AlterWL 的 EKF 工程](https://github.com/AlterWL/Battery_SOC_Estimation)，再用 [Battery Archive 数据](https://www.batteryarchive.org/)换数据集验证。

## 4.6 SOH 与联合估计

- 老化的两个可观测后果：满充容量 $Q$ 下降、内阻 $R_0$ 上升；
- **双卡尔曼（联合估计）**：一个快 EKF 估 SOC（秒级），一个慢 EKF 估 $Q$ 或 $R_0$（天级）——慢参数当状态、快状态当已知，交替更新；
- **可观测性条件**：参数只有在电流激励下才"看得见"——长期静置或恒流不变化时，参数估计协方差会长大，设计算法时要监控；
- 在线 SOH 的朴素做法也有价值：记录每次完整充放循环的吞吐量与容量比值，长期拟合。

## 4.7 SOP（峰值功率）估算

SOP = 未来 T 秒（如 10s/30s）内允许的最大充/放电功率，取多约束的最小值：

- **电压约束**：$I_{max} = \dfrac{U_{oc} - U_{RC} - U_{限值}}{R_0}$（放电时不许端电压跌破下限）；
- **电流约束**：不超过电芯/系统最大允许电流；
- **SOC 约束**：低 SOC 区限制放电、高 SOC 区限制充电；
- **温度约束**：低温降额（析锂风险）。

工程输出：整车/逆变器按 SOP 限功率运行，这就是"电池能出多大力"的数字。

## 4.8 工程落地要点

- **OCV 表分温度**：至少 -10/0/25/45°C 四张表，插值；
- **满充校准判据**：CV 段电流 < 0.05C 且持续 t 秒，不是电压碰上限；
- **下电保存**：SOC 存 Flash（带 CRC 与双备份），上电先用 OCV 校验再决定采信哪个；
- **精度目标**：恒流工况 <5% 是入门线；车用全工况 <3% 需要温度补偿 + 联合估计；
- 仿真验证后再上板：[MiniBMS（Simulink）](https://github.com/ks-santosh/MiniBMS) 提供了完整被控对象，先在仿真里把算法调对。

## 4.9 自测题

1. 安时积分的误差为什么不收敛？两个校准点分别怎么工作？
2. OCV 滞回会给单表法带来什么误差？LFP 平台区为什么更糟？
3. Thevenin 模型里 $R_0$ 和 $R_1C_1$ 分别对应电池什么物理过程？
4. EKF 中 Q 和 R 调大各自有什么效果？残差持续偏大说明什么？
5. 双卡尔曼为什么能估容量？可观测性条件是什么？
6. SOP 为什么要取多约束最小值？低温对 SOP 的影响路径是什么？
7. 满充校准为什么用"截止电流"而不是"电压到达上限"？
