## 这本书想干什么

市面上讲 BMS 的书，大多在“讲知识”；这本书想讲的是**知识怎样变成证据**。

一颗电芯为什么在这个 tick 被判过压？一条 SOC 曲线凭什么说自己是准的？一个模型参数错了，残差会怎么告状？——BMS 的日常不是背公式，而是不断地回答：**谁量的、量了几次、拿什么对照、谁签字**。

这本书用 BMS-Z 的真实实验数据、可运行代码和 154 张动画做骨架，把“原理”落到“能复现的数字”上：

- 同一个 15 mV 新息：按斜率反演，SOC 0.05 处只值 0.2%、平台区值 1.9%；按 EKF 增益 K·e 算，平台区实际值 1.2%（先验与噪声把修正压住了）；
- R0 写大 10 倍，SOC RMSE 冲到 41.51%；C1 写大 10 倍，只有 1.00%；
- 100 拍里故意弄坏 1 帧，解析器仍收全 99 帧；
- 25,461 行外部数据，改 1 个字节就被 SHA-256 拦下；
- 被动均衡补 1 Ah 要 25 小时烧掉 4 Wh，主动均衡 0.5 小时只损 0.7 Wh；
- 400 V 系统按 100 Ω/V 算，绝缘低于 40 kΩ 就不许上高压。

这些不是“结论”，是**可以被你再跑一遍的实验**。

第 13、17、27 章的科学曲线可用 `python bms-book/generate_figures.py` 重算（另外需要 matplotlib；阅读和构建不需要）。指数辨识、新息时序与观测权重图给出全部合成条件。

## 怎么读

- 想建立全局观：0、1、2、7、22、26。
- 想做算法：10–17，配 `code/` 与 BMS-Z 的 `code/soc/`。
- 想吃透热这本账：14、30，配 `code/thermal_lump.py`。

每章结构固定：**本章罗盘（问题／交付／边界）→ 一个现场 → 原理 → 可复现数字 → 坑 → 练习**。罗盘不是摘要：它先约定这一章要回答什么、读完要留下什么证据，以及哪些结论仍不能从本章推出。

## 图解与交互怎么读

32 章正文现在每章都有图：全书 61 个图解位置，其中 33 个可以点击“播放动画”，每个配“先看哪里”和“看完追问”。默认显示矢量静态快照，停止播放后回到静态图；PDF 使用同一快照，保留图注与读图问题。

第 7 章提供 **保护时间预算实验**：拖动采样周期、确认拍数、判决与执行反馈时间，区分“首次观测后”和“物理故障最坏”两只时钟。第 10 章提供 **OCV 四项实验**：拖动 SOC 和斜率，看曲线、四项贡献与 5 mV 的局部换算。第 14 章提供 **SOP 三约束实验**：拖动 OCV、内阻、SOC 和预测窗，看主导约束、端口功率与欧姆生热怎样一起变化。

第 14 章还有 **热阻／热容实验**：拖动电流、热阻、热容、初温与预测窗，看末温、稳态、时间常数与热电流界。四组交互都标明教学边界并能恢复默认算例。第 7 章补齐时间预算与故障注入验收矩阵；第 29 章用实际字节轨迹展开跨分块、残帧、有界缓冲与恢复证据；第 8、11、14、16 章增加失效候选、解析推导、能量账与工况对照。新增科学图由 `python bms-book/generate_engineering_figures.py` 重算。

动画复用教程中的 SVG 真源；打印快照在 `assets/print/`，时刻清单在 `visuals.json`。重生成快照需 Playwright 与 Edge：`python bms-book/snapshot_visuals.py`；普通阅读和构建无需安装它们。离线 HTML 将静态图、动画与交互脚本全部内嵌。

每章末的「来源锚点」卡把该章证据来源结构化：类别（项目原始资料、开源项目、官方文档、开放课程、数据集、同行评议论文、商业教材、行业规范、认证记录、许可文本、开放资料、厂商文档、社区项目）、访问日期、书中钉死的冻结快照与许可。32 章正文一一登记，附录 D 末尾的「来源登记表」按类别汇总全部 92 条来源并标注每条被哪些章引用；登记表由 `manifest.json` 单一来源生成，构建期校验章章有锚、条条可解析、无孤儿条目。

## 代码

从仓库根准备环境（Python 3.10+、Node.js 24+）：

```bash
npm ci
python -m pip install -r bms-book/requirements.txt
python bms-book/build_html.py     # 生成 dist/bms-book.html（公式构建期渲染，插图内嵌，可断网阅读）
python bms-book/check.py          # 质量门：结构契约 + 15 份 demo 全跑 + 书↔demo 钉死数字对账
```

HTML 提供四条阅读路线、分部学习目标、32 张本章罗盘、章节标识，以及小节／图解／提示卡／交互统计徽章；支持手机排版、随系统切换深色模式、返回目录。`--out-dir` 指定输出目录；加 `--pdf` 额外生成出版级 PDF：标题书签、奇偶页眉（左页书名／右页章名）、带页码目录与「页码 / 总页数」页脚，并写入文档元数据（需 Chrome/Edge，`--browser` 可指定路径）。章节、罗盘、版本与实验清单统一维护在 `manifest.json`；以下单独实验命令从 `bms-book/` 目录运行。

发布链另外运行 `python bms-book/build_html.py --pdf` 与 `python bms-book/check_pdf.py`，反向检查 PDF 元数据、完整书签、每页页脚、奇偶页眉、目录链接页码、来源锚点卡数量与卷末索引页码（索引页码必须落在真的含有该术语的正文页，术语表本身不计入）。`publish_downloads.py` 在同级临时目录中生成稳定文件名、版本化副本、机器可读清单、SHA-256 和下载页，全部成功后才整体替换输出目录；Pages 随后对这份最终目录运行死链与孤儿页检查。派生文件继续留在 `dist/`，不提交进仓库。

v0.6.3 起这本书有卷首卷末：扉页、版权与引用/勘误页、本书约定三页排在目录之前，卷末是**术语索引**（`index_terms.json` 里 99 个词，页码由最终 PDF 文字层生成，每词最多列六页）；全书 79 张表统一编号为「表 X-N」（`check.py` 的表格契约门守着缺标题、跳号、串章）。

```bash
python code/soc_coulomb_ocv.py   # SOC 三条路的迷你对照
python code/ekf_soc.py           # 两状态 EKF vs 纯库仑
python code/hppc_fit.py          # 脉冲反推 R0/R1/C1；40 s 窗的偏差
python code/frame_parser.py      # CRC、坏帧、重同步
python code/thermal_lump.py      # 集总热模型：稳态、τ、熵热、低通
python code/cccv_charge.py       # CC-CV：恒流恒压的安时账
python code/ic_dv.py             # dQ/dV：两座峰的老化指纹
python code/balancing_energy.py  # 均衡：被动 25 h/4 Wh vs 主动 0.5 h/0.7 Wh
python code/data_audit.py        # 行级体检：8 项检查抓 3 类注入瑕疵
python code/insulation_bridge.py # 不平衡桥解绝缘电阻；平衡桥漏检对称退化
python code/pybamm_fit.py        # 仿真当裁判：平台标定 ECM，两端露馅
python code/uds_demo.py          # 迷你 UDS：会话、seed-key 解锁、DID、NRC
python code/measurement_budget.py # 测量：绝对上界、随机噪声、漂移、时序与保护裕量
python code/estimator_evidence.py # 估计证据：观测权重、NIS 时序、SOH 端点不确定度
python code/engineering_ledger.py # 工程账：热时间窗、电流界、RC 放电时间与能量
```

书中数字来自 BMS-Z 2026-10-09 的实测/合成记录；你的环境不同，结果可能有小数位差异（`check.py` 会把漂移当成失败提示你）。
