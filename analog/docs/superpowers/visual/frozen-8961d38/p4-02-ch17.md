## 第 17 章 故障模式速查总表

> **场景**：半夜产线停线，报障只有一句“不工作”。有人从芯片查起，有人从电源查起；前者还在翻原理图，后者已经换好一只鼓包的电容。故障速查表的价值，是让你先站在概率高的一边。

### 17.0 怎么用这张表（30 秒上手）

**表 17-1　故障速查表的五步用法**

| 步骤 | 动作 | 要点 |
|---|---|---|
| ① | **按症状对号入座**：先看四列表的「症状」列，找到最接近的一条（允许模糊匹配） | 症状描述越具体越好："5V 只有 3.1V 且纹波 400mV" 比 "电压不对" 强十倍 |
| ② | **读「头号嫌疑」**：这是统计上命中率最高的原因，不是唯一原因 | 表按**先验概率**排序——同一症状第一行永远比第三行常见 |
| ③ | **做「一分钟验证」**：必须能在断电或单次上电内给出是/否的答案 | 不能证伪的检查不是检查（见 [16.1](p4-01-ch16.md#ch16)） |
| ④ | **修根因**：命中后按「根因修复」处理，不要只换件 | 换件不换因 = 故障复发（[16.1 第 ④ 步](p4-01-ch16.md#ch16)） |
| ⑤ | **记录**：症状/根因/解法/复发率写进维修日志 | 团队的排故能力 = 日志厚度 |

> **注意**：三条铁律：**先量电源**，近一半故障在电源与连接；**先静后动**，万用表 → 示波器；**一次只改一个变量**。
> 表里所有「一分钟验证」都遵守同一个前提：**测量本身不能改变电路**（[16.3 Jim Williams 铁律](p4-01-ch16.md#sec163)）。

为什么"先验概率"值得独占一列？因为排故的成本分布极不均匀：查错方向的代价，远大于多查一条的代价。同一个症状，"电源没供好"和"某颗芯片内部损坏"都可能解释，但前者在真实故障里占大头（经验上电源与连接类合计常接近一半），验证只要一块万用表；后者要备料、拆焊，还可能误判。**先查"高概率 × 易验证"的组合，是每一格排序的共同逻辑。**

用表时还有一条纪律：症状列允许模糊匹配，但匹配上之后必须回读一遍自己的症状细节。"输出偏低"匹配到"输出偏低且纹波大"，就得先确认自己的板子纹波到底大不大——差之毫厘的症状，指向完全不同的根因，照方抓药会被表带进别人的故障里。症状描述的合格线是能写进记录表：含数值（多少伏、多少毫伏纹波）、含条件（空载还是带载、冷机还是热机）、含复现率（必现还是偶发）。"不工作"三个字连第一步都迈不出去。

症状描述的好坏直接决定查表质量。不合格："板子不工作"。合格："上电后 5V 轨只有 3.1V，纹波 400mV、频率 100Hz，空载带载一样，换电源依旧"。前者只能匹配上"不工作"三个字，后者一条就锁定 17.1 的两行。写症状时强制自己填四个空：**多少**（数值与单位）、**何时**（上电/运行/温度/带载）、**多常**（必现/偶发/复现率）、**改了什么**（最近变更）。四个空填满，表就替你干完了一半活。

这张表和维修日志是一个闭环的两端。表给出"先查什么"，日志记录"查完是什么"；每修完一单，把症状、根因、验证动作回填到表（你自己的版本）的对应格子里，格子里的先验概率就有了本地数据源。一年之后，团队的速查表会比通用表准得多——它押的是你们的工艺、你们的供应商、你们的设计习惯。这就是 17.0 第⑤步"记录"的真正用法：不是写总结，是给下一次分诊改概率。

### 17.1 电源类（故障占比最高的第一现场）

**表 17-2　电源类故障速查**

| 症状 | 头号嫌疑 | 一分钟验证 | 根因修复 |
|---|---|---|---|
| 输出为 0，输入正常 | 保险丝/保护管开路、调整管击穿、使能脚未拉高 | 断电测输入到输出通断；量 EN 脚电平 | 换保险/管，查使能上拉与上电时序 |
| 输出偏低且纹波大 | 滤波电容干涸（ESR 升高） | 示波器看纹波**频率**：100Hz → 工频整流后电容 | 换低 ESR 电解/并联陶瓷；按 [1.2](p1-02-ch1.md#ch1) 算容量 |
| 输出偏高且不可调 | 反馈分压下臂虚焊/开路、反馈脚浮空 | 断电实测分压电阻；量 FB 脚电压（应≈基准） | 补焊/换电阻；FB 走线远离 SW 节点 |
| 芯片反复重启 | 电源带载能力不足，瞬态跌落触发复位 | 负载阶跃时抓电源波形，看跌落深度与恢复 | 加大输出电容、降 ESR、提高电源裕量（[9.5](p1-10-ch9.md#ch9)） |
| LDO 输出振荡（几十 kHz~MHz） | 输出电容 ESR 落在稳定区之外 | 并联 1Ω 电阻串电容试；换钽/加 ESR | 按 datasheet 选电容（老 1117 要 22µF 钽） |
| LDO 发烫、输出随负载掉 | 压差过大、功耗 $P=(V_{in}-V_{out})I$ 超封装 | 量 $V_{in}-V_{out}$ 与电流，算功耗 | 换 DC-DC 或加散热/降输入电压 |
| 上电瞬间输出过冲 | 软启动缺失、反馈环路过快 | 单次上电抓 $V_{out}$ 前沿 | 加软启动电容、增大输出电容 |
| 开关电源啸叫（音频段） | 环路不稳/轻载跳周期、电感或陶瓷电容机械共振 | 听音定位 + 看 SW 波形是否跳周期 | 加假负载、调补偿、换电感（[13.2](p2-03-ch13.md#ch13)） |
| Buck 效率异常低 | 电感饱和/选型不对、开关损耗大、死区不当 | 量 SW 波形是否有台阶与尖峰；摸电感温度 | 换饱和电流足够的电感、降 $Q_{gd}$、调栅极电阻（[4.6](p1-05-ch4.md#ch4)） |
| SW 节点尖峰高、EMI 超标 | 功率环路面积大、缺 RC 吸收 | 探头接地弹簧测 SW（勿用长地线） | 缩小环路、加 RC snubber、缓驱动（[15.6](p3-02-ch15.md#ch15)） |
| 多路电源上电顺序错乱 | 时序依赖未设计（如 1.8V 先于 3.3V） | 三通道示波器同时抓各路上升沿 | 加 PG 串联/RC 延时/专用时序芯片 |
| 掉电后重启数据丢失 | 掉电检测太晚、复位阈值偏低 | 慢速降输入，看复位是否在 $V_{cc}$ 失效前触发 | 加 BOR/复位 IC、加大掉电保持电容 |
| 电池设备续航远低于估算 | 静态电流大（LDO 静态电流、分压采样、LED 指示） | 串 µA 表测关机/待机电流 | 换低 $I_q$ LDO、采样分压加 MOS 开关 |
| 电源噪声耦合进 ADC，读数跳 | 数字回流经模拟地、去耦不足 | 短路 ADC 输入看码值跳动（噪声底） | 按 [15.2 接地](p3-02-ch15.md#ch15) 分开回流、加 RC/π 滤波 |
| 热插拔/拔插头时板子复位 | 输入无 TVS/大电容，线缆电感尖峰 | 拔插时抓输入电压尖峰 | 加 TVS + 输入大电容 + 缓启动（[2.8](p1-03-ch2.md#ch2)） |
| 3.3V 只有 2.9V 且随温度变 | 基准/反馈电阻温漂、走线压降 | 断负载测空载电压；红外看哪颗电阻发烫 | 换低温漂电阻、加宽反馈走线（[9.1](p1-10-ch9.md#ch9)） |
| 电源纹波里混有开关频率的整数倍谐波 | 输出滤波不足、地环路拾取 | 对比近端与远端测量（排除探头环路） | 加 LC/磁珠，缩短探头地线（[16.3](p4-01-ch16.md#sec163)） |
| 电源输出端并联电容后反而更差 | 电容 ESL 与环路形成谐振峰 | 扫频看阻抗峰（或逐步增减电容试） | 按 [1.2](p1-02-ch1.md#ch1) 组合大+小容量、控制走线电感 |

> **为什么**：外壳烫手、输出随负载往下掉。压差乘电流的功率只有变成热这一条路，热积在封装里散不掉，结温一路往上顶。热会自己从高温流向低温，功率却不会自己找路。所以“换 DC-DC 或降输入”管的是生热的总量。

电源类坐在第一现场，有三个结构性原因。其一，**全板每个器件都是它的负载**：电源病一分，症状可以在任何地方冒出来，伪装成信号问题、软件问题、器件问题。其二，**它是板上唯一搬运能量的部件**：信号级电路出错多半是"不对"，电源出错常常是"烧了"，失效烈度高一个量级。其三，**它跨在板内外的交界上**：适配器、线缆、连接器、电池都压在它的边界，机械应力与环境应力的第一站都在这里。"先量电源"不是迷信，是三次筛选的合力：概率高、验证快、伪装性强。

表 17-2 里有几行的验证手法值得展开。"输出偏低且纹波大"要求**看纹波的频率，而不是只看幅度**：工频整流后的纹波是 100Hz（全波）或 50Hz（半波），开关电源的纹波挂在开关频率及其谐波上，LDO 输出上的 100Hz 纹波多半是从输入漏进来的，说明压差太小或 PSRR 不够。同样是"纹波大"，频率指认的方向完全不同——这正是"一分钟验证"必须设计成"能区分候选假设"的原因，只回答"大不大"的测量等于没做。

"输出端并联电容后反而更差"那一行背后是一条一般规律：不同材质电容并联，大电容的 ESL 与小电容的 C 之间会挤出并联谐振峰，扫频时阻抗不降反升（机理见 [1.2](p1-02-ch1.md#ch1)）。**去耦的目标是全频段低阻抗，不是某几个频点阻抗特别低**；追加电容之前，先想清楚它补的是哪一段。

> **教学示例**：症状"5V 只有 3.1V，纹波 400mV"。按表 17-2 先读嫌疑排序：滤波电容干涸、反馈下臂虚焊、带载超限都在候选里。第一步量纹波频率——100Hz，指向整流后的大电解；第二步量该电容两端纹波电流与温升——烫手且容量实测只剩标称三成，根因落定。整个过程两次测量，没换一颗芯片。换成先拆稳压器的做法，半小时后故障原样等你。

"LDO 输出振荡"那一行值得把机理说透。老款 LDO（如 1117 系列）的环路设计假定输出电容带几百 mΩ 的 ESR，由它造一个零点来补相位；换成 ESR 只有几 mΩ 的 MLCC，零点被推到环路带宽之外，相位裕度当场见底——**同一颗 LDO，换一类电容就从稳定变振荡**。处理办法有两条：按手册选指定类型与容量的输出电容，或选 datasheet 明确标注可用陶瓷输出电容的新款 LDO。这也是"一分钟验证"里"并联 1Ω 电阻串电容试"的原理：人为把 ESR 补回去，振荡消失即坐实根因（教学演示，与 [16.5](p4-01-ch16.md#sec165) 案例一同理）。

"多路电源上电顺序错乱"在带处理器与 FPGA 的板子上尤其常见：内核 1.8V 先于 IO 3.3V 上电，可能触发闩锁或累积应力。验证用多通道示波器同时抓各路上升沿，看先后顺序与单调性；修复手段按代价排序：利用稳压器 EN 脚与 PG 脚级联最省，RC 延时次之，专用时序芯片最稳。**上电时序是设计问题，不是调试问题**——表里能做的是确认它有没有按设计来，设计本身见 [9.5](p1-10-ch9.md#ch9)。

"电池设备续航远低于估算"那行背后是一份静态电流预算表：LDO 静态电流、分压采样、LED 指示、保护板自耗、MCU 睡眠电流，每项几 µA 到几十 µA，加起来常比主芯片的睡眠电流大一个量级。排查顺序是把 µA 表串进电池回路，再逐个功能区断电对比——**续航问题不是测出来的，是断电断出来的**。

### 17.2 放大与信号链类

**表 17-3　放大与信号链类故障速查**

| 症状 | 头号嫌疑 | 一分钟验证 | 根因修复 |
|---|---|---|---|
| 输出顶到电源轨（单侧饱和） | 反馈开路、输入超共模范围 | 量反相端是否≈同相端（虚短检验） | 补焊反馈电阻；确认输入共模在规格内 |
| 输出为零、无任何变化 | 运放没供电/电源脚虚焊、输入悬空 | 量运放电源脚**在引脚上**（不是走线上） | 补焊/加输入偏置路径（[12.8 单电源](p2-02-ch12.md#ch12)） |
| 增益远小于设计值 | 反馈电阻虚焊/错值、负载过重（输出电流限流） | 断电实测电阻；量输出电流 | 换对电阻；换能带载的运放或加缓冲 |
| 高频尖叫/自激（MHz） | 容性负载、反馈走线长、$R_f$ 过大 | 输出串 47Ω 试；手靠近看频率变不变 | 隔离电阻 + 反馈取电阻前；负载端取样需另设计补偿（[12.9](p2-02-ch12.md#ch12)） |
| 波形顶部/底部被削 | 输出摆幅不足、压摆率不够 | 降输入幅度看是否恢复 | 选轨到轨/高压摆率器件（[6.3](p1-07-ch6.md#ch6)） |
| 方波边沿变圆、上升时间变慢 | 带宽不足、探头/线缆电容 | 换 ×10 探头重测；算 $t_r≈0.35/BW$ | 提高 GBW 或降低节点电容 |
| 直流漂移（分钟级缓慢移动） | 温漂、热电势、空气流动 | 吹风/遮挡定位；短接输入看漂移是否消失 | 对称布局、低 $V_{os}$ 器件、等温接点（[11.6](p2-01-ch11.md#ch11)） |
| 输出噪声比算出来的大 | 电源噪声串入、地环路、电阻热噪声 | 电池供电对比；短路输入测噪声底 | 加 RC/π 滤波、缩短回路、降低电阻值（[11.6](p2-01-ch11.md#ch11)） |
| 两路通道增益/相位不一致 | 电阻容差、器件离散 | 交换器件看差异是否跟着走 | 用 0.1% 电阻、配对器件 |
| 差分放大 CMRR 很差 | 电阻匹配度不够、源阻抗不平衡 | 加共模信号看输出变化 | 用仪放/匹配电阻（[12.3](p2-02-ch12.md#ch12)） |
| 积分器输出饱和不动 | 输入失调积分到轨、缺泄放电阻 | 短接输入看是否慢慢回中 | 并泄放电阻/加自动复位（[12.4](p2-02-ch12.md#ch12)） |
| 采样值总差一个固定偏移 | 运放 $V_{os}$、基准误差、ADC 增益误差 | 输入已知电压做两点校准 | 软件校准或选低 $V_{os}$ 器件（[13.6](p2-03-ch13.md#ch13)） |
| ADC 读数跳得厉害 | 噪声、参考不稳、采样保持时间不足 | 短接输入看跳动幅度（噪声底） | 加 RC 抗混叠、加长采样时间、稳压基准 |
| 传感器读数随导线长度变化 | 引线电阻分压（PT100/应变片） | 换短导线/短接导线两端测差值 | 三线/四线制、恒流激励（[14.4](p3-01-ch14.md#ch14)） |
| 滤波器截止频率与设计不符 | 元件容差（尤其电容 ±20%）、寄生电容 | 实测电容值；扫频测 -3dB 点 | 用 1% 电容/实测后配值（[12.5](p2-02-ch12.md#ch12)） |
| 滤波器通带内有凸峰 | Q 值过高、运放带宽不足引入相移 | 扫频看峰高与位置 | 降 Q、选带宽足够运放（[1.5](p1-02-ch1.md#ch1)） |

[在线演示：推挽输出的交越失真](https://www.falstad.com/circuit/e-pushpullxover.html)：看输出在过零附近塌出一小段、输入却还在连续变化；把输入幅度调小，这段塌陷跟着变浅，与“降输入幅度看是否恢复”是同一条线索。

这张表出场率最高的验证动作是"量反相端是否≈同相端"，它是虚短检验，也是把故障劈成两半的刀：虚短成立，说明运放和反馈环路至少在直流上是活的，嫌疑转向输入源、供电与负载；虚短不成立，立刻缩到反馈网络开路、输出撞轨、供电异常、共模超范围四个方向（前提见 [12.1](p2-02-ch12.md#ch12)）。**一刀下去，排除的不是一个元件，是一整类机理。**

"增益远小于设计值"一行也值得多写两句。断电实测电阻之前，先在脑子里过一遍增益式：反相放大增益是 $-R_f/R_{in}$，电阻错值错一个数量级（100k 焊成 10k），增益就整齐地错十倍——这是 BOM 错料或贴装错误的典型签名；增益掉 20%~50% 且无规律，多半是负载过重拉低了输出，或反馈焊点的接触电阻混进了 $R_f$。**错误的"形状"本身就在指认根因**：整齐的错值指向物料，毛糙的偏差指向工艺。同样，"输出顶到电源轨"先看顶的是哪一根轨：顶正轨常是输入共模超上限或反馈开路，顶负轨（单电源下）常是输入信号出了共模范围——饱和的方向也是线索。

> **教学示例**：反相放大器设计增益 −10，实测 −2.1，输出无削顶。先量虚短：$V_-$ 比 $V_+$ 低 8mV 且随信号摆动，环路是活的，嫌疑转向元件值。断电实测：$R_{in}$ 标称 10kΩ 实测 47kΩ——错料。换上对料，增益回到 −9.98，收工。整个定位没拆第二颗件：先用虚短把"环路死没死"判掉，再用错值的"形状"锁定物料问题。

噪声与漂移类症状要特别说明测量口径。"输出噪声比算出来的大"，先把仪器底噪量出来：探头短接到地、同档位读一次，仪器底噪必须从结果里扣除——功率相减，不是幅度相减。"直流漂移"要分清是电路在漂还是仪表在漂：短接输入看零点，仪表自身的热电势与预热不足常常贡献了一大半。**先把测量链的底牌翻开，再评价被测电路**——这条在 [16.6](p4-01-ch16.md#sec-16-6) 有一整节，表里的每个"一分钟验证"都默许它成立。

信号链类还有一条容易被症状掩盖的次序：先确认"信号本来就长什么样"。传感器输出本身就带着 50Hz 工频耦合时，后级再怎么滤波也只是擦屁股；把传感器单独接到电池供电的前端看一眼"裸信号"，常常一次就把"前端污染"和"后级引入噪声"分开。**链路排故从源端开始验，不是从最后一级往回猜。**

总线类故障有一个共同的排查次序：**先物理层，再协议层，最后应用层**。示波器先看电平幅度、边沿形状、上拉是否在位，确认每条线都能干净地拉低、放高；再用逻辑分析仪或协议解码看地址、ACK、时序参数；两层都干净，才去翻固件配置。次序反了的典型惨状：固件里翻三天寄存器，最后发现是总线上多挂了一颗 10kΩ 上拉，上升沿拖过了规格上限。

"I²C 通信偶发失败"一行背后是一笔可以心算的账：标准模式要求上升时间 ≤1µs，上拉电阻与总线电容构成 RC，规范给出的上限是 $R_{p,max}=t_r/(0.8473\times C_b)$。总线电容 400pF 时 $R_p$ 不得超过约 2.9kΩ；有人图省电用 10kΩ 上拉，低速率下勉强能用，速率一提或线缆一长就偶发失败——**偶发的不是协议，是边沿**。下降沿从来不出问题，因为开漏管下拉是有源的，只有上升沿靠上拉电阻"拖"上去。

"UART 收到乱码"也有笔账：异步串口没有时钟线，靠双方各自分频逼近同一波特率，采样点设在比特中点附近，一帧十位累积下来，两端合计偏差逼近 4%~5% 就开始错位。两个标称 115200 的口，一个偏 +1.5%、一个偏 −1.5%，各自在示波器上都"合格"，连起来就是乱码——**分别测两端的实际位周期**，比猜哪边坏了快得多。电平不匹配（3.3V 与 5V 直连）则是另一种沉默杀手：当天能通信，半年后 IO 口击穿，症状变成"偶发死机"，与原始原因隔了十万八千里。

GPIO 悬空那一行值得记住物理图像：CMOS 输入阻抗高达 GΩ 级，悬空引脚既不耗电、电平也不确定，环境里的工频与开关噪声经寄生电容耦合进来，电平就在阈值附近随机游走。示波器探头一碰，探头阻抗把它拉到确定电平，"故障"当场消失，拔掉探头又回来——**测量让它消失，本身就是悬空的确证**。SPI 模式配错也有特征签名：数据整体错一位，或只在特定数据花样下出错——CPHA 错半拍，采样的全是错误时刻的电平；对照从机时序图核对模式 0~3，比换线快得多。

"板间通信距离一长就错"背后常常是地电位差：两段地的电位差出几伏并不罕见，单端信号的参考就此漂移，误码率飙升。差分传输把参考从"地"换成"两根线之差"，共模噪声被接收端减掉——这就是 RS-485、CAN 能跑几十米，而 TTL 单端跑不过一米的原因。实在要用单端长线，先共地、再降速、最后加驱动，三步按序来，别一上来就换光耦。

### 17.4 振荡类（所有"不该振荡却振荡"）

**固定排查顺序**（照做，不要跳）：

```
① 电源去耦（先看是不是电源纹波在放大）
  → ② 环路相位裕度（容性负载/反馈极点）
    → ③ 布线寄生耦合（输入输出靠近、长走线）
      → ④ 接地环路（公共阻抗耦合）
```

这个顺序的设计逻辑是"**从外到内、从便宜到贵**"：电源去耦用一块示波器就能验，相位裕度要懂环路才能判，布线寄生要翻 layout，接地环路可能得动板。每一层的验证手段也不同：电源看纹波谱，环路看阶跃响应的过冲，寄生看布局，地环路看多点之间的电压差。顺序颠倒的典型代价：改了三天补偿网络，最后发现是开关电源的纹波被放大器"忠实放大"——环路一直很好，病灶在窗外。

动手之前还有一条总原则：**先分清"自激"还是"外来"**。把板子改成电池供电（或断开可疑的外部源），振荡消失，就是外来干扰经电源或空间耦合进来；纹丝不动，才是电路自己振。再分第二刀：振荡频率随不随电源电压、负载、温度变化？自激振荡的频率由环路自己的参数决定，外来干扰的频率属于干扰源——**频率的"户口"在哪，嫌疑就在哪**。

地环路那一格给一个量级感：两个模块共用 5cm 长、约 50mΩ 的一段地铜，开关电流 1A 流过就是 50mV 的"地弹"，直接垫在小信号放大器的参考点上；若这段电流还是脉冲式的，示波器上看到的就是与开关频率同步的"振荡"。它看起来像运放自激，根因却在回流路径——这也是决策顺序把接地放在最后查的原因：它的症状最像前三者。

表里"接上探头振荡消失"那一行要专门警惕：探头电容替电路补上了相位裕度，**测量动作治好了病**。这类"测量依赖型正常"的板子最危险——实验室里一切正常，出厂后批量振荡（[16.3](p4-01-ch16.md#sec163) 的铁律管的正是它）。对策只有一条：修电路，不修现象，把相位裕度做到不挂探头也成立。

"振荡频率 ≈ 开关频率的分数"那一行展开一句机理：电流模式控制的变换器占空比超过 50% 时，电感电流的扰动会被逐周期放大，表现出来就是周期翻倍——SW 波形一宽一窄交替，输出纹波出现开关频率一半的分量，这叫次谐波振荡。斜坡补偿的原理是给电流环人为叠一个下斜坡，把放大系数压回 1 以下。**占空比一过 50% 就振、降到 50% 以下就好，是它的指纹**；验证时调高输入电压（减小占空比）看振荡是否消失，一分钟即可判明。

振荡类的根因修复常常落在布局而不是原理图：输入与输出走线靠近，会经寄生电容构成"第二反馈"；地线绕远，会经公共阻抗构成"第三反馈"。所以"根因修复"列里的缩小环路、加屏蔽不是工艺洁癖，是**把寄生反馈通道的增益降到安全线以下**。改版时把振荡敏感节点（反馈、补偿、高阻输入）写进布局评审清单，下一版板子才可能断根。

"只在带载时振荡"与"只在低温/高温振荡"两行合起来是一条一般方法：**振荡必有边界条件，找到边界就找到了环路里的薄弱环节**。把负载、温度、电源电压三个旋钮各扫一遍，记下起振与停振的两个临界点——临界点的位置就是相位裕度的粗测：离正常工作点越远，余量越大；贴着工作点的，修好之前都算带病运行。

| 器件"没坏但参数全变了" | 静电损伤（ESD 半伤）、过压应力 | 换新件对比参数 | 加防护、改操作规范（[2.8](p1-03-ch2.md#ch2)） |
| 整机温升导致外壳变形 | 无风道/密闭空间 | 测温升曲线 | 开散热孔、导热垫、降功耗 |

> **为什么**：电容鼓包，起点是纹波电流在它内部生热。热积在密封铝壳里散不掉，电解液被蒸干，液少则电阻更大，生热更多，循环自己往上走。可热量传得出金属壳，传不出干掉的芯。所以“选高纹波电流型号”管的是热平衡。

热类故障的定位顺序推荐"先扫后喷"：先用红外热像仪（或手指在安全电压下快速点触，超过约 60°C 就别摸）扫出温度分布图，异常热点自己会站出来；再用冷冻喷剂逐器件降温，看故障何时消失。次序反过来——先喷后扫——容易把整板喷冷，线索全灭。**温度测量永远先看分布，再看单点**：单个器件热是"它功耗大"，一片区域一起热是"热源在别处，这里只是散热路径"。

"三极管/MOS 反复烧"值得展开一句 SOA（安全工作区）：器件手册的 SOA 图横轴电压、纵轴电流，直流、10ms、1ms、100µs 各一条边界，脉冲越短能扛的功率越大。开关瞬间 $V_{DS}$ 与 $I_D$ 同时不为零的那段轨迹若越出边界，器件不会当场冒烟，而是累积损伤，几周后"莫名"击穿。**反复烧管的根因常常不在稳态，在那几十纳秒的开关轨迹里**——所以表里的验证动作是"抓关断瞬间的 $V_{DS}$ 尖峰"，而不是量静态电流。

"器件没坏但参数全变了"对应 ESD 的潜伏损伤：静电击穿不一定开路短路，常常只打伤一层栅氧或一个结，器件照常工作，漏电流、噪声、耐压却已暗降。这类"半伤"器件留在板上就是定时炸弹：换件时顺手把旧件单独标记留存，别扔回料盒，它是失效分析的证据，也是下次别案的参照。

电容鼓包那行还连着 [1.7](p1-02-ch1.md#ch1) 的寿命账 $L=L_0\times2^{(T_0-T)/10}$：鼓包电容的位置本身就是一张热源地图，它旁边往往坐着散热器或功率管。换电容时顺手把它的环境温度降下来——挪位、隔热、改善风道——收益比换更大容值的电容大得多。

热故障还有一类容易和热功耗混淆的：**机械热循环**。板子每天随环境升降温，焊点、连接器、大功率器件引脚被反复拉扯，故障呈"早晚坏、中午好"或"开机半小时后才出现"的节律。它与功耗过热的区分方法：限流供电观察——功耗问题在限流下仍发烫，热循环问题在恒温小功率下会消失。修理策略也不同：功耗问题降热，热循环问题减应力（软焊料、底部填充、结构固定），方向开反了越修越糟。

热类故障的预防端是降额：器件结温每降 10°C，寿命大约翻一倍（与电解电容同一条 10°C 法则的物理）。所以"刚上电就烫手"修好后不算完——量一遍满载稳态的温度分布，越过降额曲线的器件要么换封装、要么加散热、要么降功耗。**排故修的是"坏"，热设计管的是"不再坏"**，两者在 17.5 这张表里本来就挨着。

红外测温有两条使用纪律：裸金属与光亮表面的发射率低，红外读数会系统性偏低——贴一小段哑光胶带再测；热像仪看到的是表面温度，结温还要按热阻链折算（[17.5.1](#sec1751) 的公式反着用）。冷冻喷剂也有副作用：喷过的区域会结露，潮气本身就是漏电路径——喷完等表面回温干燥再下结论，别把结露漏电误记成原故障。

[在线演示：电感关断反冲](https://www.falstad.com/circuit/e-inductkick.html)：点一下开关把它断开的那一瞬，看电感把节点电压顶出一个尖峰，正是“三极管/MOS 反复烧”那一行要抓的关断尖峰。

#### 17.5.1 三十秒热设计估算（配 [14.5](p3-01-ch14.md#ch14)）

$$T_J = T_A + P \times (\theta_{JC} + \theta_{CS} + \theta_{SA})$$

**表 17-7　三十秒热设计估算的符号与数量级**

| 符号 | 含义 | 典型数量级 |
|---|---|---|
| $T_J$ | 结温（目标 ≤ 125°C，**留 20°C 裕量**） | — |
| $T_A$ | 环境温度（机箱内常比室温高 10~20°C） | — |
| $P$ | 器件功耗（LDO：$(V_{in}-V_{out})I$；MOS：$I^2R_{DS(on)}$ + 开关损耗） | — |
| $\theta_{JC}$ | 结到壳（datasheet 给） | TO-220 ≈ 1~3 °C/W |
| $\theta_{CS}$ | 壳到散热器（导热垫 0.5~1 °C/W，不涂硅脂 2~5） | — |
| $\theta_{SA}$ | 散热器到空气 | 小铝片 20~40，大散热器 2~10 |

**算一笔**：AMS1117 从 12V 降到 5V、负载 500mA → $P=(12-5)\times0.5=3.5W$。SOT-223 的 $\theta_{JA}≈60$ °C/W → $T_J=25+3.5\times60=235$ °C，**必炸**。换成 TO-220 + 大散热器（$\theta_{JC}+\theta_{CS}+\theta_{SA}≈3+1+5=9$）：$T_J=25+31.5≈57$ °C，安全。**结论：3.5W 就不该用线性稳压，直接上 Buck。**

> **为什么**：算完结温还要留裕量，因为热要连过三道温差：结到壳、壳到散热器、散热器到空气，最弱一环定上限。机箱里的空气早被前一颗器件加热过。热会自己找路散，硅只认总热阻，所以裕量管的是这条链上的不确定性。

间歇性故障是这一类的主战场，也是整个排故里最难缠的对手：它在台上不出现，一切测量都失去靶子。对付它有一套固定的"逼迫"流程。**第一步，把它变成半必现**：机械应力（按压、扭转、轻敲）、热应力（冷冻喷剂、热风枪）、电应力（电压拉偏、负载阶跃）三把扳手轮着上，每把单独用，记录哪一把能显著改变复现率。复现率从"一天一次"提到"按一下就坏"，后面的测量才有意义。**第二步，在复现窗口里测量**：示波器设单次触发、毛刺触发或欠幅触发，挂着等它；晃动试验里，万用表的通断蜂鸣档比眼睛好用——蜂鸣器一声断续，抵得上十分钟盯屏。**第三步，把临时修复做成可回退**：怀疑虚焊就重焊，但先拍照记录焊点原貌，方向错了还能还原现场。整套流程的纪律仍是单变量：按压有效就立刻停手缩小范围，别顺手又吹热风——两种应力一起上，好了也不知道是谁治好的。

这套"逼迫"流程画成动画更直观：[动画演示 5.116 间歇故障：先逼它现身，再在窗口里等它](p5-00-part5.md#demo116)——三把扳手轮流入漏斗，复现率逼上去之后，触发方式挂着等。

焊点与连接还有一条时间维度的账。焊点失效很少"焊完就坏"：多数是热循环里的应力疲劳，温度每变一次，不同材料的膨胀系数拉扯焊点一次，裂纹从角落慢慢长向中心，接触电阻从 mΩ 级爬到 Ω 级。**所以"时好时坏"的焊点在万用表上常表现为阻值漂移，而不是干脆开路**——只量通断会漏掉它，要在晃动与变温中量。连接器是同一个故事的慢放版：镀层磨损与氧化让接触电阻逐年上升，拔插几次"好了"，只是磨掉一层氧化膜，病根还在。面包板与杜邦线则是接触电阻的重灾区（单个插孔接触电阻从几十 mΩ 到 Ω 级不等，还随插拔老化），验证电路可以，拿它当"电路本身没问题"的证据不行。记录这类故障时，把"拔插后暂时恢复"写进症状栏，三个月后，它就是把两个案子拼成一个案子的关键线索。

<img src="assets/photos/web/scanned-multimeter-gossen.jpg" width="280" alt="Gossen 指针式万用表实物（Wikimedia Commons，CC BY-SA 3.0）">

> **实物照片**：指针表至今没被淘汰干净，原因就在这一节：接触电阻的缓慢漂移、晃动试验里的抖动，是指针连续摆动一眼可见的趋势；数字表每秒刷新三四次，慢变化全淹在跳字里。老师傅的工具箱里，指针表与数字表并排躺。

目视检查是这一类最便宜也最被低估的工具，但它有自己的手法：侧光斜照比正光更能暴露裂纹与锡桥；10 倍放大看焊点轮廓——润湿良好的焊点是平滑内凹的"裙边"，冷焊是灰暗的圆球，虚焊在引脚与焊料之间有一圈细缝。BGA 与底部端子器件目看不到，只能靠敲击、扭板复现加 X-Ray 抽检。**手法固定下来，目视检查的检出率才稳定**；"随便看一眼"不算检查。

焊接类故障的统计直觉也要校准：一块 200 焊点的板子，即使单点不良率只有 0.5%，整板"至少一个坏点"的概率也高达 $1-0.995^{200}\approx63\%$。**"焊工很好"与"批量总有几块要返修"可以同时成立**——良率是每块板的乘法，不是每个点的加法。对策也因此清楚：减少焊点总数（提高集成度、慎选连接器）、把单点不良率再压一个量级（工艺窗口固化），都比"加强检验"有效得多。

"只量通断会漏掉它"不是夸张，是几何问题：接触电阻从 mΩ 级爬到 Ω 级要经过漫长的漂移段，而蜂鸣档在这段里全程照响。把这条时间轴画出来，盲区窗口、指针表的优势、200 焊点那笔乘法账就各就其位。

### 17.7 上电即挂与保护类

**表 17-9　上电即挂与保护类故障速查**

| 症状 | 头号嫌疑 | 一分钟验证 | 根因修复 |
|---|---|---|---|
| 首次上电就烧器件 | 电源极性反接、电压档位错 | 断电量输入极性与电压 | 加防反接 MOS/二极管（[2.8](p1-03-ch2.md#ch2)） |
| 上电瞬间大电流（>安培） | 输入电容浪涌、短路 | 限流电源观察电流曲线 | 加缓启动/NTC/限流电阻（[2.6](p1-03-ch2.md#ch2)） |
| 电源一接上就保护跳闸 | 输入短路、电容击穿 | 断电量输入阻抗 | 找短路点，检查电容耐压 |
| 拔掉负载电源就正常 | 负载侧短路/过流 | 串电流表看负载电流 | 修负载，加限流保护 |
| 接口一插就重启 | 浪涌/ESD 灌入 | 拔插时抓电源与 IO | TVS + 限流 + 共模扼流圈（[15.6](p3-02-ch15.md#ch15)） |
| 反接后器件"半死" | 内部寄生通路部分损坏 | 换新件对比 | 加防反接，规范接线 |
| 保险丝反复烧 | 未找根因就换保险 | 串灯泡/限流电源测电流 | **先找为什么烧**（[16.1 第 ④ 步](p4-01-ch16.md#ch16)） |
| 静电一碰就死 | 无 ESD 防护、操作未接地 | 换件后用防静电手环复现 | 接口防护 + 工位接地（[2.8](p1-03-ch2.md#ch2)） |

上电即挂的现场，纪律只有一条：**第一次上电不许用裸电源**。限流电源（或串灯泡）把最坏情况锁死在"烧保险丝级别"，你才有机会在板子还活着的时候量到它病在哪。限流之下的上电电流曲线本身就是诊断书：电流冲到限值不再动，是硬短路；冲一下迅速回落，是输入电容的浪涌，属正常；缓缓爬升后稳住，多半是软启动或某个热过程在工作。**先读电流曲线，再决定下一步**，比断着电盲量阻抗快得多。

"保险丝反复烧"那一行还有一层选型背景：保险丝分快断与慢断，慢断型靠更大的熔化热能 $I^2t$ 容忍开机浪涌。电路含大输入电容或电机时，误用快断型会"开机就烧"，误用慢断型又可能保护不到真正的过载。换保险丝时看一眼类型与额定值，是排除"保险丝本身选错"这个候选的最便宜动作。

"反接后半死"提醒的是失效的灰色地带：被反接应力伤过的器件，可能参数漂了却还能工作。这种器件不能留在板上，它是定时炸弹；但也不必当场报废整块板。换下它、单独标记，留作失效分析样本；修复后的板子要按 [16.1 第 ⑤ 步](p4-01-ch16.md#ch16) 做完整回归，而不是"能亮就算修好"。

第一次上电之前，还有一串不通电的静态检查，花十分钟能挡掉一半"上电即挂"：目检极性器件（电解、二极管、IC 的 1 脚）方向；万用表量各电源轨对地阻值，接近 0Ω 就先别上电；核对电源电压档位与极性，可调电源先把电压拧到最低再慢慢升；确认保险丝额定值与类型对版。这套顺序的价值在于**把"必然烧"的故障拦在通电之前**——通电后才发现的短路，已经是第二次伤害。

```
├─ 输入电压在不在？ ── 否 → 17.1 电源类（保险/极性/连接）
└─ 是 → 关键电源轨都对吗？
   ├─ 否 → 17.1（带载跌落 / 纹波 / 使能）
   └─ 是 → 复位/时钟正常吗？
      ├─ 否 → 17.3（复位 IC / 晶振 / 上电时序）
      └─ 是 → 功能异常
         ├─ 完全不动 → 17.3（接口配置 / 固件 / 挂死）
         ├─ 读数不对 → 17.2（反馈 / 校准 / 噪声）
         ├─ 时好时坏 → 17.6（焊接连接）→ 再查 17.4（振荡）
         └─ 发热异常 → 17.5（功耗 / 短路 / 散热）
```

读图指引：从顶端往下，每个节点只问一个能用一次低成本测量当场回答的问题；答案为“否”就向右出列，落到对应条目表，不再往下走。注意出口卡的颜色：电源类占了两张——这与 17.0 的统计一致，电源与连接类合计接近一半，所以树的前两问都押在电源上。

这棵树要会用，先读懂它的三个设计取舍。第一层永远问电源，因为电源故障概率最高、验证最便宜；第二层问复位与时钟，因为它们是"数字系统是否活着"的最低判据；第三层才轮到功能分支。**每往下走一层，验证成本就上一个台阶**——所以树上问题的顺序不可调换，调了就是在烧钱。分支粒度也有讲究：每个分叉必须能用一次低成本测量当场判定；"固件可能有 bug"这种问题不配占一个分叉，因为它一分钟内证伪不了。

落地到自己产品时，这棵树是模板，不是圣旨。把团队历史上真实发生过的故障统计一遍，按"症状 → 头号嫌疑 → 一分钟验证"补进对应分支，顺手按自己的数据重排每格的先验概率——通用表里排第一的嫌疑，在你的产品上可能根本不存在。这张表真正的价值，是**逼着团队把排故经验从师傅的脑子里搬到纸上**：维修日志（[16.4](p4-01-ch16.md#sec164)）是它的数据源头，树是日志的压缩算法。每个季度把日志里的复发率回填一次，树的排序就会越用越准——这是少数会"越用越聪明"的文档。

> **教学示例**：拿到一块"完全无反应"的控制板，按树走。输入电压在不在？——在，24V 正常。关键电源轨都对吗？——5V 正常，3.3V 只有 1.1V。于是直接落在 17.1 的"输出偏低"分支，不必先查 MCU，不必刷固件。量 3.3V 稳压器输入正常、EN 脚为高；断电测输出对地阻值只有 8Ω——负载侧近短路。逐个断开 3.3V 上的去耦电容，断到第三颗时阻值恢复：电容击穿，落定。从开箱到定位二十分钟——树的价值不在"知道答案"，在**每一步都有理由地跳过十几个分支**。

> **相关链接**：配套动画 [动画演示 5.102 排故决策树](p5-00-part5.md#demo102)——从"上电无反应"一路走到具体表项。

> **精髓**：这张表的价值不在"全"，而在**顺序**——每格第一行是统计上的头号嫌疑。真正的排故高手赢在**每次都从最高概率的地方开始查**，每一步都能被证伪。
