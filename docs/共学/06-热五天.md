# 共学：热五天

> **本篇你会学到**　电池的温度的从哪儿来的：欧姆火为什么跟电流平方走、可逆熵热为什么充放方向相反、温升为什么按 τ=R·C 爬、正弦负载下温度为什么变成一个被压扁又迟到的波纹。
> **预计用时**　5 天，每天大约 30–60 分钟。
> **前置**　做过 [SOC 五天](01-soc五天.md) 或读过阶段 4。装好 Python 3.10+，在仓库根执行过 `pip install -r code/requirements.txt`。不接电池。

⚠️ 本篇全部是一颗**合成教学电芯**的模型输出：R_th 1.0 K/W、C_th 120 J/K（所以 τ=120 s）、产热内阻 49 mΩ、熵斜率 −0.4 mV/K——不是任何真实电芯的热参数。它教的是「温度从哪儿来」这件事本身；`code/firmware/` 里没有热模型，产品热管理要拿规格书和实测定参数。

## 第 1 天：欧姆火：稳态温度是解出来的

**读**　[ECE5710 Notes07 中文导读 §2–§3](../ece5710-notes07-中文导读.md)：四项生热里，析锂热和副反应热在日常工况是「出事才有」的项；本篇只留两个主角——欧姆火 $I^2R$（永远在烧）和可逆熵热（第 3 天见）。稳态的含义：产热 = 散热，温度不再爬。

**看**　[P = I²·R：电流翻倍，发热四倍](../circuits/assets/mos-rdson-heating.svg)。2 A 烧 0.20 W，8 A 烧 3.1 W——4 倍电流不是 4 倍热，是 16 倍。这条平方律就是演示里 `p_ohm` 的全部。

**跑**（演示本体，仓库根）：

```bash
python3 code/soc/thermal_demo.py
```

PowerShell：

```powershell
python code/soc/thermal_demo.py
```

2026-10-09 在本仓库跑通（Python 3.13，不到 1 秒），四行主输出是：

```text
[D1 稳态] 放 10 A：解析 T_ss = 31.117 °C，跑 40 min 到 31.117 °C（P_ohm = 4.90 W）
[D2 时间常数] 一个 τ=120 s 走到总温升的 63.2%（理论 1−1/e = 63.2%）
[D3 可逆热] 同幅值 10 A：充到稳态 28.693 °C，放 31.117 °C（差 +2.424 K——熵项翻了个方向）
[D4 正弦] 电流周期 600 s，生热纹波 2ωτ≈2.5：仿真温幅 0.5818 K vs 解析 0.5797 K；滞后 仿 68.4° vs 析 68.3°；均值 仿 26.568 vs 析 26.568 °C
```

末尾六行自验收应全部 `[PASS]`。今天只看 D1：解析解和 40 分钟仿真逐位对上。

**交**（手算对账，先纸上算）：稳态时散热 = (T−25)/R_th，产热 ≈ I²R = 100 × 0.049 = 4.9 W，R_th = 1 K/W，所以纯欧姆账是 25 + 4.9 × 1 = 29.9 °C。可脚本给的是 31.117——多出来的 1.2 K 哪来的？用一条命令把两笔账分开：

```bash
python3 -c "import sys; sys.path.insert(0,'code/soc'); import thermal_demo as th; print('ohmic only =', round(th.T_AMB_C+th.p_ohm(10)*th.R_TH,3), '| steady(-10) =', round(th.steady_temp_c(-10),3))"
```

PowerShell：

```powershell
python -c "import sys; sys.path.insert(0,'code/soc'); import thermal_demo as th; print('ohmic only =', round(th.T_AMB_C+th.p_ohm(10)*th.R_TH,3), '| steady(-10) =', round(th.steady_temp_c(-10),3))"
```

2026-10-09 输出：

```text
ohmic only = 29.9 | steady(-10) = 31.117
```

**口诀**　稳态是产热等于散热。欧姆火认平方，不认方向。

**今天你解锁了**　你能手算一颗电芯的纯欧姆稳态温度，并知道演示的全量模型比它多算了什么。

**短自测**　把电流从 10 A 加到 20 A，稳态温升是第 1 天那笔账的 2 倍吗？

<details>
<summary>先自己答再展开</summary>

不是。产热走 $I^2R$：电流翻倍，4.9 W 变 19.6 W，纯欧姆温升从 4.9 K 变 19.6 K——4 倍。这就是为什么保护参数里过流倍数和允许时间是指数级敏感的。
</details>

## 第 2 天：升温降温走同一个 τ

**读**　Notes07 导读的集总模型段：$C_{th}\,dT/dt = P - (T-T_{amb})/R_{th}$。它的解是指数：离目标温度越来越近，每过 τ = R_th·C_th 走完剩余差距的 63.2%。注意 C_th 在这里是**热容**（J/K），不是电容。

**看**　[热管理三路线](../circuits/assets/thermal-paths.svg)：自然对流 → 风冷 → 液冷，搬的就是这个 R_th——R 越小，同样 4.9 W 稳态温升越小，而且 τ=R·C 也越短，凉得越快。

**跑**（降温也是同一个 τ，仓库根）：

```bash
python3 -c "import sys; sys.path.insert(0,'code/soc'); import thermal_demo as th; sim=th.simulate(lambda t: 10.0 if t<1800 else 0.0, 2000); T0=sim[1800][1]; Tk=sim[1920][1]; print('T(hot)=%.3f T(+tau)=%.3f decayed=%.1f%%' % (T0,Tk,100*(T0-Tk)/(T0-25)))"
```

PowerShell：

```powershell
python -c "import sys; sys.path.insert(0,'code/soc'); import thermal_demo as th; sim=th.simulate(lambda t: 10.0 if t<1800 else 0.0, 2000); T0=sim[1800][1]; Tk=sim[1920][1]; print('T(hot)=%.3f T(+tau)=%.3f decayed=%.1f%%' % (T0,Tk,100*(T0-Tk)/(T0-25)))"
```

2026-10-09 输出：

```text
T(hot)=28.693 T(+tau)=26.353 decayed=63.4%
```

断电后一个 τ（120 s）掉掉了剩余温升的 63.4%——和理论 63.2% 的零头差是欧拉积分步的，不是物理的。演示 D2 行从升温侧量，也是 63.2%：升温降温共用一个时间常数。

**交**　贴这条输出和演示的 D2 行，写一句：为什么保护固件「故障后静置多久可以复位」不能按毫秒算。

**口诀**　升温降温同一条指数。一个 τ，走完六成三。

**今天你解锁了**　你在自己电脑上量出升温侧和降温侧的 τ 是同一个数，并知道 120 s 的热惯性意味着什么。

## 第 3 天：可逆热：充电吸热，放电补火

**读**　Notes07 导读 §3 的可逆项：Π = T·(∂U/∂T)，熵热功率 = Π·I。合成教学值取 ∂U/∂T = −0.4 mV/K（真实电芯的符号和大小随化学体系与 SOC 变，这里只教机制）：充电 I>0 配负斜率 → 这一项是负的，**吸热**；放电反向 → **补火**。欧姆火两副面孔都是正，熵热一翻身方向就反。

**跑**（同幅值充 vs 放，各跑到稳态）：

```bash
python3 -c "import sys; sys.path.insert(0,'code/soc'); import thermal_demo as th; print('charge:', round(th.steady_temp_c(10),3), 'discharge:', round(th.steady_temp_c(-10),3))"
```

PowerShell：

```powershell
python -c "import sys; sys.path.insert(0,'code/soc'); import thermal_demo as th; print('charge:', round(th.steady_temp_c(10),3), 'discharge:', round(th.steady_temp_c(-10),3))"
```

2026-10-09 输出：

```text
charge: 28.693 discharge: 31.117
```

同是 10 A，差 2.424 K——正好约等于 2 × (|Π·I| ≈ 298 × 0.0004 × 10 ≈ 1.2 W) × R_th。欧姆火对电流方向装聋，熵热对它翻脸；两者的差把充放稳态分开了。

**交**　贴输出，纸上算一遍 298 K × 0.4 mV/K × 10 A 是多少瓦，再写一句：快充发热评估里只算 I²R 会偏向哪边。

**口诀**　欧姆火装聋，熵热翻脸。一充一放，稳态差两度半。

**今天你解锁了**　你能把 2.4 K 的充放稳态差拆成「两笔 1.2 W 的账」，并说清哪一项在充电时倒着走。

**短自测**　演示 D4 为什么故意把熵项关掉再量正弦？

<details>
<summary>先自己答再展开</summary>

熵热 $\propto I$ 是正弦（频率 ω），欧姆火 $\propto I^2$ 含恒定项加二倍频（2ω）——两个频率混在一起，温度曲线就不是单一正弦，幅值和滞后没法对账。关掉熵项，生热只剩 2ω 一个频率，低通公式才能逐位比。
</details>

## 第 4 天：正弦负载：温度是生热的低通

**读**　Notes07 导读 §5.2（同 §4 频域那半段）：一阶热系统对正弦生热做两件事——幅值除以 $\sqrt{1+(\omega\tau)^2}$，相位落后 $\arctan(\omega\tau)$。正弦电流的生热在 2ω（$I^2\propto\sin^2$，一半频率翻倍），温度是它的低通：压扁、迟到，均值不掉。

**跑**（手算三件套对账，仓库根）：正弦幅值 8 A → 平均与纹波生热都是 $I_0^2R/2$ = 1.568 W；纹波角频率 ω = 4π/600（生热周期 300 s，**不是**电流的 600 s）：

```bash
python3 -c "import sys, math; sys.path.insert(0,'code/soc'); import thermal_demo as th; w=2*math.pi*2/th.PERIOD_S; g=1/math.hypot(1,w*th.TAU_TH); pa=th.I_SINE_AMP**2*th.R_HEAT/2; print('Pbar=%.3f W mean=%.3f C | gain=%.4f amp=%.4f lag=%.1f' % (pa, 25+pa, g, pa*g, math.degrees(math.atan(w*th.TAU_TH))))"
```

PowerShell：

```powershell
python -c "import sys, math; sys.path.insert(0,'code/soc'); import thermal_demo as th; w=2*math.pi*2/th.PERIOD_S; g=1/math.hypot(1,w*th.TAU_TH); pa=th.I_SINE_AMP**2*th.R_HEAT/2; print('Pbar=%.3f W mean=%.3f C | gain=%.4f amp=%.4f lag=%.1f' % (pa, 25+pa, g, pa*g, math.degrees(math.atan(w*th.TAU_TH))))"
```

2026-10-09 输出：

```text
Pbar=1.568 W mean=26.568 C | gain=0.3697 amp=0.5797 lag=68.3
```

和演示 D4 行对账：均值 仿 26.568 = 析 26.568；温幅 仿 0.5818 vs 析 0.5797 K；滞后 仿 68.4° vs 析 68.3°。三个数全对上。

**交**　贴两行（手算 + 演示 D4），写一句：τ=120 s、纹波周期 300 s，温度为什么只把纹波压到四成、滞后却快 70°。

**口诀**　温度是生热的低通：快纹波压扁，慢平均照收。

**今天你解锁了**　你用量角器的单位看懂了热时间常数：纹波比 τ 越快，温度里越看不见它——1 秒级的脉冲热量，整颗电芯的温度计根本不去。

**短自测**　对手握的 NTC 热敏电阻来说，第 4 天这条 68.4° 的滞后意味着什么？

<details>
<summary>先自己答再展开</summary>

意味着「读到的温度」不是「此刻的生热」：NTC 看到的温度峰值比生热峰值晚将近四分之一周期。等温度读数上来再降额，控制环永远在纠上一次的偏差——§4.7b 充电地图把温度窗口做成「可查表的工程包装」，一部分代价就在这条滞后上。
</details>

## 第 5 天：反过来：从温度曲线挖出 R 和 C

**读**　把第 1、2 天的公式倒过来用就是辨识：稳态给 R_th（ΔT_ss = P·R_th），时间常数给 C_th（τ = R_th·C_th）。这就是 [SOC 五天](01-soc五天.md) 拆电压脉冲的热的版本——同一个方法论：**稳态支参数、动态支时间常数**。电的那一半在 [阶段 4 §4.4b 在线辨识](../stages/stage-4-SOC-SOH算法.md#44b-在线辨识让参数跟着电池走-应用)：那里 RLS 让 R0、R1 跟着电池走，思路同型。

**跑**（今天你当辨识工程师——先纸上算，再用命令核对）：一颗合成电芯在恒定 30 W 加热下从 25 °C 出发，实测稳态 **55 °C**、且 **150 s 时恰好 44.0 °C**。求 τ、R_th、C_th。提示：$T(t)=T_{amb}+\Delta T_{ss}(1-e^{-t/\tau})$，把 150 s 点代进去解 τ。核对命令（只核对，答案先自己算）：

```bash
python3 -c "import math; print('tau =', round(-150/math.log((55-44.0)/(55-25)),1), 's')"
```

PowerShell：

```powershell
python -c "import math; print('tau =', round(-150/math.log((55-44.0)/(55-25)),1), 's')"
```

2026-10-09 输出：

```text
tau = 149.5 s
```

（离整数 150 的零头是 44.0 这个读数只给了一位小数。）

**交**　贴你的手算过程和这条命令输出，再答两问：① R_th 和 C_th 各是多少（提示：30 W 和 30 K 稳态差给 R，R 和 τ 给 C）；② 用第 4 天的账回答——这颗电芯 1 秒短路为什么「温度计还没反应」，而 10 分钟过流保护必须动作为时已晚？

**口诀**　稳态给 R，快慢给 C。曲线倒过来读就是辨识。

**今天你解锁了**　你用两个温度点反推出了一整套热参数，并知道哪些热危险是温度计「看不见」的。

**短自测**　为什么仓库演示用 $dT/dt=(P-\Delta T/R)/C$ 的显式欧拉就够，固件里却连这个模型都没有？

<details>
<summary>先自己答再展开</summary>

PC 上步长 1 s 对 τ=120 s 的系统绰绰有余（每步只走差距的 0.8%），精度和速度都够教学；固件里没有热模型是仓库明说的现状（Notes07 导读原话），产品热模型要过标定、降额、诊断三关才配进控制环——擂台第 1 期也不考热。合成演示教的是「这个模型长什么样、怎么对账」，不是「拿去用」。
</details>
