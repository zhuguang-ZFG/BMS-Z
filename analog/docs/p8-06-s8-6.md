## 8.6 GitHub 仓库

开源仓库适合做三件事：核对书里的一句话、复现一张图或一个数、看清一个项目怎样组织证据。star 数只用来发现，不能当质量结论。每个入口先记仓库、tag 或 commit、许可证、访问日期；能复现的才写进笔记。

**开源书共读：入门、进阶、精通**

| 层级 | 开源书或课程 | 许可（以仓库原文为准） | 读哪几章 | 交付什么 |
|---|---|---|---|---|
| 入门：建立回路直觉 | Tony R. Kuphaldt, *Lessons In Electric Circuits*（DC / AC / Semiconductors） | Design Science License | DC 卷的回路、电容与交流；Semiconductors 卷的二极管、BJT、MOS | 用 ngspice 复现一个 RC 或整流波形，写清理想源、元件公差与探头负载 |
| 进阶：把 MOS 级做成设计 | Boris Murmann, *Analysis and Design of Elementary MOS Amplifier Stages* | CC BY 4.0 | ch2–ch6：CS 传输特性、频响、CG/CD、偏置、多级 | 选一级 CS 或 CD，交负载线、增益、带宽、偏置四本账 |
| 精通：在开源 PDK 上闭环 | *COCOA*；JKU *Analog Circuit Design* | CC BY 4.0；Apache-2.0 | COCOA 的 crawl / walk / run 三部分；JKU 的 gm/ID、ngspice 与版图流程 | 用开源 PDK 做两级 OTA，交 DRC/LVS、PVT 与测试记录 |

**三本书的分工**　*Lessons In Electric Circuits* 给你回路语言和元件直觉，器件模型浅，不能替代后面的设计训练。Murmann 的书把 MOS 模型按问题逐层加：先用平方律看传输特性，频响不够再加电容，增益误差大了再加 $r_o$，噪声或失配成为限制时才加相应模型。COCOA 与 JKU 把设计放进开源 PDK 和可复现仿真，适合练“从公式到流片检查”的整条链。

**怎么读，才不变成收藏夹学习**

1. **钉版本**：记 tag 或 commit、工具链、许可证和访问日期；只写“最新版”等于没有版本。
2. **只追一条量**：例如从 MOS 的 $V_{GS}$ 追到 $I_D$、$g_m$、增益和输出摆幅，不先铺开整本书。
3. **复现一个数**：选书里一个有明确输入的例子，用 ngspice、Python 或手工重算；结果对不上，先查假设，不急着改公式。
4. **写差异**：记下开源书的模型边界与本书哪一节不同；差异本身就是设计判断，不是“谁对谁错”。
5. **交作品**：每级至少交一页可复核记录：网表或代码、运行命令、输入假设、结果、失败路径。

**共读作业**　任选一本，按上面的层级交一页记录。入门可复现 RC 充电的 63.2% 时刻；进阶可把 Murmann 的一级 CS 放大器算到指定增益与带宽；精通可在 JKU 的 IIC-OSIC-TOOLS 镜像里跑通一次 Xschem + ngspice 仿真，再说明 DRC/LVS 还需要哪些文件。只收藏、不交付，不算读完。
