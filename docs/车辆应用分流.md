# 车辆应用分流：自行车、摩托车、汽车不能混成“电动车”

> **适用口径**　中国大陆；状态核对日期 2026-10-30。
>
> **先记一句**　车辆类别不是按“48 V／72 V／400 V”一刀切出来的。电压只影响器件与绝缘设计，产品身份还取决于整车定义、性能、公告、登记与适用标准。

## 一张图景先分开

- **电动自行车像一只紧凑的智能插线板**：一块板既测量又切断，大电流通常直接穿过板载 MOS 与分流器；最怕待机耗电、板内热点、线束松动和成本挤压。
- **电动摩托车像一座更重的收费站**：车流更大、持续时间更长，收费杆、散热、通信和机械固定都要升级；有的仍用板载 MOS，有的开始转向外部接触器和预充。
- **电动汽车像一栋楼的消防系统**：每层从板采样，中央主控决策，主接触器负责断高压；另有预充、HVIL、绝缘监测、碰撞信号、诊断和功能安全，任何一级失联都要落到安全态。

共同的电芯、采样、保护、SOC／SOH／SOP 和通信原理放在主线教程；应用差异从功率开关、隔离与验证开始分叉。

## 电动自行车

截至 2026-10-30，GB 17761-2024 已于 **2025-09-01** 实施。它是非机动车产品语境；本项目不以电池电压、串数或电机铭牌单独判断产品身份。

**BMS 关注点**

- 紧凑集中式保护板或智能 BMS；
- 背靠背 MOS、分流器、充放电端口与休眠；
- 电池包内阻燃、温度点、连接器和防篡改；
- UART／BLE 等消费级通信不得进入独立安全闭环。

**开源学习样本**　LibreSolar `bms-8s50-ic`：只学习高边 MOS、AFE＋MCU、板载电流采样、CAN 与热沉布局。它只有 3–8 串，**不是常见 48 V 电动自行车的现成板**。

## 电动轻便摩托车／电动摩托车

GB/T 24158-2018《电动摩托车和电动轻便摩托车通用技术条件》截至 2026-10-30 仍为现行标准，2025-08-04 复审结论为继续有效。GB 7258-2026 已发布，但要到 **2027-07-01** 才实施；当前项目与登记仍要核对现行有效规则和过渡安排。

**BMS 关注点**

- 持续电流、铜损、分流器与 MOS 热；
- 高边开关、独立充电端口、预放电／预充；
- CAN、RS-485、诊断与防水连接器；
- 机械固定、热沉和振动环境；
- 串数或功率继续上升时，评估外部接触器与主从式架构。

**开源学习样本**　LibreSolar BMS C1：3–16 串、集成高边 MOS 与电流传感，项目明确列出轻型电动车应用。它适合讲“高功率集中式 BMS”，但不能因为 70–100 A 就把它叫成通过认证的摩托车产品。

## 电动汽车

GB 38031-2025《电动汽车用动力蓄电池安全要求》已于 **2026-07-01** 实施。电动汽车牵引电池的主线不是“把两轮车板加粗铜皮”，而是系统级证据链。

**BMS 关注点**

- BMU＋CMU 主从采样与隔离菊花链；
- 外部主正／主负接触器、预充和粘连诊断；
- HVIL、IMD、主动放电与碰撞后安全态；
- 车载 CAN、UDS、网络安全与版本化参数；
- 功能安全、HIL、EOL、追溯和变更影响分析。

**开源学习样本**

- ENNOID-BMS：STM32 主控、LTC68xx 从板、isoSPI、隔离 CAN、预充与外部接触器；适合先看结构。
- foxBMS 2：主控、接口板、12／14／18 节从板和版本化发布；适合学习研究平台怎样管理硬件版本、软件与测试。

## 为什么不按电压直接分车

同样写“48 V”，可能是储能模块、电动自行车电池、轻型摩托车子系统或实验电源；同样写“72 V”，也不能自动推出机动车分类或某套安规。正确顺序是：

1. 先确认整车产品类别与适用标准；
2. 再写电池串数、最高工作电压与故障电压；
3. 再选 MOS 还是接触器、是否隔离、要不要主从式；
4. 最后用测试与认证证明，而不是用“车规”“高压”两个词代替证据。
