# 维护说明

> **本篇你会学到**　外链巡检为什么有 16 个域名要人手点，CI 又守着哪几件事。
> **预计用时**　维护者月度复查时用。
> **前置**　[共建任务板](共建任务板.md) 的 T2。

外链由 [lychee 月度巡检](../.github/workflows/links.yml)（反爬站点按 `.lychee.toml` 配置豁免）；代码测试、ruff 静态检查与文档相对链接/SVG 计数随 PR 运行，文档站的构建与产物对账也随 PR 运行（tests.yml 的 site-build job：构建挂了、产物有死链、某页没人链到，在 PR 上就拦下，不等合并）。发现错误欢迎提 Issue。

文档站（[在线版](https://zhuguang-zfg.github.io/BMS-Z/)）由 [deploy-pages workflow](../.github/workflows/deploy-pages.yml) 发布：push 到 main 触发 VitePress 构建，构建完先跑 [check_pages.py](../.github/scripts/check_pages.py) 对产物逐条对账站内链接与锚点，不过不发版——源码侧的检查器看不见产物，这道门只在部署前。正文写法不为站点让步：跨出 docs/ 的相对链接、目录链接、docs 内的源文件链接由渲染期插件（[escaping-links.ts](.vitepress/escaping-links.ts)）改写成 GitHub URL，动画与照片（circuits/assets/）按原相对路径拷进产物。改站点时三处单一来源要一起看：[site-assets.json](.vitepress/site-assets.json)（哪些仓库根文件由站点托管，值不带 base，自己写了 base 会被 VitePress 再补一次变双写）、[base.ts](.vitepress/base.ts)（`/BMS-Z/` 前缀，config 与首页数据共用）、config.mts 的 githubSlugify——它与 check_docs.py 的 slug 规则是双胞胎，改一边另一边必须同步，锚点对账靠这个对上。

同一道 [check_pages.py](../.github/scripts/check_pages.py) 还做反向对账：产物里哪一页没有任何别的页面链到它，就报「孤儿」。侧栏的「其他」是兜底不是归宿——新文件落进那里，说明归组表（sidebar.ts 的 ROOT_GROUPS）该给它加一条了。闸门与部署分两处：site-build job 在 [tests.yml](../.github/workflows/tests.yml) 里（PR 与 push 都跑），deploy-pages.yml 只管发（只有 main 能进）。同一份 dist 检查跑两次是有意的，PR 上红一次好过合并后部署红、线上停更。

公式沿用正文既有的 `$…$` 与 `$$…$$`（和 GitHub 同一套写法），站点侧靠 `markdown.math` 渲染，需要 dev 依赖 `markdown-it-mathjax3`。它经 speech-rule-engine 把 `@xmldom/xmldom` 钉死在 0.9.10（13 条高危公告），所以 package.json 用 `overrides` 抬到 0.9.12——换数学库或升依赖时记得一起复核这一条。数学块必须独占一行：写在句子中间的 `$$…$$` 块级规则不认，全站唯一一处（阶段 4 §4.1 的「原理」行）已按仓库既有约定改成单 `$…$`。

分享卡片与收录靠三份产物级配置，绝对地址都从 [base.ts](.vitepress/base.ts) 的 `SITE_ORIGIN + BASE` 拼，只这一份。sitemap 的 hostname **必须带尾斜杠**：VitePress 内部用 `new URL(item, hostname)` 解析，hostname 少个尾斜杠会把整段 base 丢掉（实测产出 `https://host/AI陪练卡.html`，正确是 `https://host/BMS-Z/AI陪练卡.html`）。每篇的 og 摘要按「frontmatter > 正文那句『本篇你会学到』（59 篇里 27 篇有）> 站点简介」取，不新编文案。站点图标在 `docs/public/favicon.svg`（VitePress 原样拷到 dist 根），画的是仓库自己那套色板：底 `#0d1117`、线 `#e6edf3`、闪电 `#3fb950`。预览图暂时借 GitHub 的仓库社交预览（`opengraph.githubassets.com`，对任何公开仓库稳定出图）；站点自己的 1200×630 封面还没有，别拿生成图凑。

版本基线见 [Releases](https://github.com/zhuguang-ZFG/BMS-Z/releases)；变更记录见 [CHANGELOG.md](../CHANGELOG.md)。

月度复查时手动点一下这 16 个被 `.lychee.toml` 整站排除的域名：`nxp.com`（对 bot 一律 404）、`analog.com` / `eet-china.com` / `st.com`（HTTP/2 与 lychee 客户端不合——上游 [issue #2264](https://github.com/lycheeverse/lychee/issues/2264) 尚无强制 HTTP/1.1 的开关）、`e2e.ti.com`（Akamai 对机房 IP 间歇超时）、`doc.embedfire.com`（runner 超时，野火 CAN 章节仍公开在版）、`dangdang.com` / `szlib.org.cn`（按来源 IP/方法拦截）、`catarc.org.cn`（源站 502 临时豁免，2026-10-05 复查仍 502，恢复后再移出排除）、`ptacts.uspto.gov`（按 UA/来源拦截，版权存档页仍在）、`batterydesign.net`（runner 侧 TLS 握手失败，按来源拦截）、`tao.hvcis.com`（2026-10-05 转载页在 runner 上返回 530，不是 404。PS-305D 已改链到龙威产品页；焊台套装已改链立创商城安泰信 AT937A。隔离 USB 模块仍留在正文：2026-10-06 没有同价位、巡检能打开的模块页。下次家宽再验这一条）、`912688.com`（2026-10-05 实测：run 37418605023 中商品页先超时、重跑 502，本机也超时；预算清单里的链接保留）、`faradion.co.uk`（2026-10-06 run 37421586094：应用页先报 10 分钟限流退避，再返回 503。本机同一地址 200，正文留下）、`aibangsib.com`（2026-10-06 本机 200，标题是「超钠新能源推出全系列两轮车钠电电池包方案」。runner 在 run 37422058461、以及 main 的 37419451978、37416650229、37405206888 上超时）、`epever.com.cn`（2026-10-06 run 37421847639 上 BMS-Link PDF 超时。本机 1.4 秒返回 200，正文留下）。`tao.k7dj.com` 和 `jlc-smt.com` 已移出排除：万用表改链优利德官方系列页，ESP32-C3 改链立创商城同一料号，两页 lychee 均 200。上面这 16 个不在巡检范围内，真关停了 CI 不会报。

CI 只做"抓错误"的检查，不做格式化：Python 用 ruff 的 bug 类规则（见 [ruff.toml](../ruff.toml)），C 用 `gcc -Wall -Wextra -Werror`。格式化工具会把代码里对齐的中文注释打散，反而更难读——理由写在 ruff.toml 顶部。

仓库简介现在写的是 148 张动画。分类模板在 `.github/DISCUSSION_TEMPLATE/`。

讨论区已经开启：[Discussions](https://github.com/zhuguang-ZFG/BMS-Z/discussions)。FAQ、共学、作品墙、擂台、阶段 2 和门户的入口都指向这一页。分类现有 11 个，slug 等于中文名：公告（公告，仅维护者可发）、综合、建议、投票（投票）、求助问答（问答）、作品展示、打卡、保护板（问答）、算法（问答）、协议（问答）、固件（问答）。`.github/DISCUSSION_TEMPLATE/` 里的 7 个文件已经对上分类：打卡、求助问答、作品展示、保护板、算法、协议、固件。slug = 中文名 = 模板文件名，这些发帖表已经套上。新增或改名分类时，名称要和模板文件名相同，否则表不会套上。
