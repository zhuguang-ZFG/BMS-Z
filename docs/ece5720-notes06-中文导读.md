## 一、一页速览

功率限制回答：按现在的状态，未来 ΔT 秒里恒定的充放电功率最大能到多少，还不违反设计约束（6–1 页）。本章的约束是端电压，外加 SOC、电流和功率上限。

| 方法 | 电芯模型 | 怎么求电流 | 原文 |
|---|---|---|---|
| PNGV HPPC | v = OCV(z) − i R | 代数，一次除法 | 6–4…6–6 |
| 二分搜索 | 完整 ESC，预测 ΔT 秒 | 每次猜测都把模型向前跑 | 6–7…6–13 |

> **口诀**　功率看未来 ΔT 秒，不看这一瞬间。多条约束取最紧的那一条。简单电阻法在高 SOC 会偏乐观。
>
> **能记住**　放电电流 (OCV − v_min) / R_dis。**能理解**　为什么充电电流在这套符号里是负数。**能用**　能把阶段 4 的 SOP 公式对上 HPPC，并把例子里的 4.35 V 留在例子里。

## 二、问题（§6.1）

估计给出状态和参数，控制要用它们算功率（6–1 页）。计算必须是预测：从现在起 ΔT 秒内如果一直维持这个功率，电压仍要合法，而且更新要比 ΔT 更勤（6–2 页）。放电功率、充电功率可以分开设 ΔT。

符号（6–3 页）：包有 N_s 串、N_p 并。放电电流为正。每一节有自己的 SOC、OCV 和电阻。包功率不是「平均节再乘节数」就完事，最紧的那一节决定整包。

## 三、HPPC：一个电阻就除出来（§6.2）

Partnership for a New Generation of Vehicles 的 HPPC 方法，是讲义拿来当标准简单法的那一个（6–4 页）。先做脉冲测试，在不同 SOC 和温度下存 R。模型是：

```
v(t) = OCV(z(t)) − i(t) R
i_dis,max = (OCV(z) − v_min) / R_dis,ΔT
```

包的放电功率用最低允许电压乘上各节电流上限里最小的那个，再乘 N_s N_p（6–4 页）。充电把 R 换成充电电阻，电压顶到 v_max。因为充电电流为负，幅值最大的充电电流是带符号电流里更负的那个（6–5 页）：

```
i_chg,min = (OCV(z) − v_max) / R_chg,ΔT
```

SOC 约束用同一段 ΔT。恒电流下 z(t+ΔT) = z(t) − (η ΔT / Q) i。放电取 η = 1，充电取 η ≤ 1（6–5 页）。于是：

```
i_dis,soc = (z − z_min) / (ΔT / Q)
i_chg,soc = (z − z_max) / (−η ΔT / Q)
```

卡尔曼滤波若给出 SOC 标准差，可以把估计再收缩 3σ（6–6 页）：放电用 z − 3σ，充电用 z + 3σ，功率更保守。最后每一节的电流上限取电压、SOC、电流、功率各条里最紧的，包再取所有节里最紧的。

> 【译注】阶段 4 §4.7 的放电电流 |I| ≤ (U_oc + U_RC − U_min) / R₀，就是这条 HPPC 再加一个已经存在的极化电压。阶段 4 还写了 2 s / 10 s / 30 s 三档。本章的算例把 ΔT 固定成 10 s。公式形状相同，时间必须写在功率旁边。`code/soc/` 不算 SOP。

## 四、完整模型和二分（§6.3–6.4）

一个电阻太粗。乐观会过放，悲观会浪费电池（6–7 页）。增强做法假设从现在到 ΔT 输入恒定，用二分搜索找让预测电压刚好落到 v_min 或 v_max 的电流（6–8…6–10 页）。

二分的停止条件是区间小于公差。讲义的 `bisect` 先看两端函数值是不是异号，最多迭代次数按 log₂(区间/公差) 估计（6–11 页）。ESC 的状态方程是线性的，ΔT 秒的预测可以做成 `simCellKDT`：电流恒定，A、B 按温度取，把 R₀、R、M 带上（6–12…6–13 页）。每猜一个电流就仿真一次。这比 HPPC 贵，但用的是和 SOC 估计同一套模型。

功率仍是各节预测电压乘电流，再按串并联加总（6–9 页）。

> 【译注】二分法每次猜测都要把 ESC 向前跑 ΔT 秒。`code/soc/cell_model.py` 已经能做单节一步预测，但没有 ΔT 秒的功率搜索，也没有 N_s 串取最小。阶段 4 的公式停在闭式除法，和 HPPC 同一级。

## 五、40 串的例子（§6.5）

算例是 LiPB 电芯，N_s = 40，N_p = 1，名义容量 7.5 Ah，充放电的 ΔT 都是 10 s（6–15 页）。表上的限值：

| 量 | 最小 | 最大 |
|---|---|---|
| 单体电压 | 3.0 V | 4.35 V |
| 单体电流 | −200 A | 200 A |
| SOC | 0.1 | 0.9 |

单体功率限在同一张表里写成 −1 到 1，单位按讲义符号，不要自行改成另一种产品规格。二分结果被讲义当成「这套模型下的真能力」，理由是前一页的电压已经贴住模型（6–15 页）。这是模型对模型，不是道路真值。

两种方法大体同形。高 SOC 时 PNGV HPPC 偏高，最多大约 9.8%；中低 SOC 又偏低（6–15 页）。低 SOC 差得远，是因为只有二分法加了 SOC 边界。若整车按 HPPC 的乐观值去放电，有的工况会过放、缩短寿命，有的工况又没用满（6–15 页）。放大图在 6–16…6–17 页。近期的强充电会暂时抬高可用放电功率，因为极化方向反了（6–18 页）。

章末把前提说破：这一章假设功率应该用来守住电压。真正的问题是高倍率带来的增量损伤。下一章改从损伤算功率（6–2、6–18 页）。

> 【译注】4.35 V、3.0 V、±200 A、7.5 Ah、40 串、9.8% 都只属于这个 LiPB 算例。铁锂的电压窗、某种车的过充阈值，都不能从这张表抄。阶段 0 的大约 4.2 V / 铁锂 3.65 V 仍是教学用的化学窗口，和 4.35 V 不是同一个数。低温析锂也不在这一章的电压公式里，它留到下一章和阶段 4 的温度降额。
