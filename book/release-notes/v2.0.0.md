# 《从模拟电路到 BMS》v2.0.0 发布说明

随 GitHub Release `v2.0.0` 发布。

## 这是什么

《从模拟电路到 BMS》是原来的《通往模拟电路之路》与《BMS 实战：从一颗电芯到一套证据链》合并而成的两卷本硬件自学路线，一条线从器件原理走到电池管理系统。v2.0.0 是合并后的首个正式版本。

- **卷一《通往模拟电路之路》**：从欧姆定律与 RC 走到运放、基准、PCB 与排故。
- **卷二《BMS 实战：从一颗电芯到一套证据链》**：32 章 + 附录 A–E，把「为什么」讲到能复现，把「谁签字」写进流程。
- 两卷共享系列扉页、阅读指南、两卷总目录与合并术语表。

## 介质与获取

每一卷提供三种介质，同一次书稿构建：

| 介质 | 说明 |
|---|---|
| 单文件 HTML | 内嵌目录、公式与交互，双击即开 |
| 出版 PDF（A4） | 书签、目录页码与页眉完整 |
| EPUB | 电子书阅读器适用，spine 与目录完整 |

另有 16K 印刷分册（打印店装订版，每卷上下册）随 Release 工件提供，不进 Pages 分发。

- 在线阅读与下载入口：<https://zhuguang-zfg.github.io/BMS-Z/>（下载页：站点的 `/downloads/`，含 SHA256SUMS.txt 与 downloads.json）
- 稳定文件名：`volume-1.html` / `volume-2.html`（及 `.pdf` / `.epub`），固定版本副本带 `-v2.0.0` 后缀。

## v2.0.0 变更摘要

- 《通往模拟电路之路》整卷并入本仓库（`analog/`），与卷二共用 schema 3 丛书装配器 `book/build.py` 与统一审计闸（21 项出版契约）。
- 站点并轨：一套导航、一套全文检索，卷一全部页面站点化（计算器、动画、公式在线可用）。
- 跨卷互引与共享卷首；合并术语表 72 条；跨卷引用构建期审计 0 悬空。
- 卷二插图扩充：接入 3 张已付费手绘候选，新增 12 张自绘概念矢量图（零文字零数字，暖纸墨线工程手绘风）。
- 构建链修复三处图片 gate 根因（多属性 alt 吞并、画廊模态占位、下载页懒加载与尺寸补齐）。
