## 整站搬到文档站

`docs/` 全文现在是一个 VitePress 站点，61 个页面。原来只能一页一页翻的地方多了搜索框、侧栏分组和「上一篇｜下一篇」；深色模式跟系统走，色板和《动画画风规范》同一套。

- 公式渲染回来了。`$…$` 与 `$$…$$` 在站点上成了公式，不再是原文。写在句子中间的那一处（阶段 4 §4.1）按仓库约定改成单 `$…$`，GitHub 和站点两种渲染器都认。
- 源文件写法一个字没改。跨出 `docs/` 的相对链接、目录链接、docs 内源文件链接在渲染期改写成 GitHub URL，动画和照片按原相对路径进产物——在 GitHub 上读、在 Obsidian 里读、在浏览器里读，三种习惯都还在。
- 分享卡片齐了：每篇有 `og:title` / `og:url` 和摘要（用正文那句「本篇你会学到」，没有就不新编）、`sitemap.xml`、favicon，404 页是中文的。

## 中文搜索能搜到句中词

以前搜「油箱」，正文里 9 页有这个词，搜索只翻到 3 页；搜「采样」38 页只到 28 页。不是页面坏了，是搜索引擎把整句中文当成一个词。

- 现在汉字串按两两一组切词，门禁 8 个词全部翻满，582 个段落全在索引里。
- 代价写在账上：索引从 1018KB 涨到 2176KB（gzip 524KB）。它是搜索框那段组件的动态 chunk，只有真打开搜索才下载，不搜的人一个字节都拿不到。
- 「被动均衡怎么发热」这类长句按 or 命中再用排序收敛，第一段就是你要的那节。改成 and 试过，这类长句 0 条命中，所以没有采用。

## 代码少算错三处

这三处在打 1.1.0 标签之后、文档大改之前就进了仓库。固件和协议的行为因此和旧说明不同，算法文件本身这一版社区页没有再改。

- 均衡该停会停：电流归零、拔枪，或电压掉出均衡门槛，同一拍关掉。拔枪后剩下的一点正电流，不再被当成「充满了」。
- 坏字节后面的好帧还能找回来。长度或 CRC 失败之后会接着扫，流结束时也可以 `flush()`。合法数据里碰巧出现的帧头，仍当数据。
- SOC 三条曲线在同一步上比较。以前真值和估计值会错开一拍，图上看起来像算法的错。
