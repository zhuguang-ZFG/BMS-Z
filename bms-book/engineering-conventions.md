# 工程深研约定：符号、单位、时间与数据身份

适用范围：BMS v3 新深研正文、图版、实验适配和报告。旧书稿与 `code/soc` 的公共接口继续使用充电为正；本约定明确边界，不要求读者猜测某个文件是否已迁移。依据：[总 SPEC §7](../docs/BMS系统教材SPEC-v3.md#7-数值模型代码与数据合同)、[P0.3/P0.7 执行计划](../docs/superpowers/plans/2026-11-08-bms-depth-rebuild.md)。

## 1. 读者侧量与旧接口

| 量 | 新深研读者侧 | 旧 `code/soc` 接口 | 边界转换 |
|---|---|---|---|
| 电流 | `I > 0` 放电，`I < 0` 充电 | `I_legacy > 0` 充电 | `I_legacy = -I`，恰好一次 |
| SOC | `z`，0–1 的无量纲比例 | `soc`，0–1 | 不翻符号、不乘 100 |
| 极化状态 | `v_p`，端电压表达式中的有符号压降 | `u_rc`，端电压中的有符号加项 | `u_rc = -v_p` |
| OCV、端电压 | 同一正负端子间的电压，V | 同一参考端子，V | 数值不翻符号 |
| 电阻/电容/容量 | `R0/R1` Ω，`C1` F，`Q` Ah | 同单位 | 值不因翻转电流而改变 |

`v_p` 是有记忆的状态，不能用 `abs(u_rc)` 替代：由放电转为充电后，原有正极化压降可以暂时保留。`C1` 的 F 与容量 `Q` 的 Ah 不是同一种量。协方差、偏置、控制方向和热公式也应按各自状态定义转换，不能只翻端电压中的一个符号。

一阶 RC 的同一个物理模型写作：

```text
新：dz/dt = -I/(3600 Q)
    dv_p/dt = -v_p/(R1 C1) + I/C1
    V = U(z) - I R0 - v_p

旧：dsoc/dt = I_legacy/(3600 Q)
    du_rc/dt = -u_rc/(R1 C1) + I_legacy/C1
    V = U(soc) + I_legacy R0 + u_rc
```

映射时同时转换输入与极化状态，SOC 和端电压应保持相同。旧 `TheveninCell` 会将 SOC 限于 0–1；映射回归使用未触边界的工况。限幅不是电量守恒的证明，也不能用它掩盖越出模型适用域。

若把 EKF 整个状态从 `x_old=[soc,u_rc]` 迁到 `x_new=[z,v_p]`，令 `T=diag(1,-1)`，则 `x_new=T x_old`、`P_new=T P_old Tᵀ`、`Q_new=T Q_old Tᵀ`，观测雅可比从 `[U′,1]` 变为 `[U′,-1]`；电压方差 R 不变。交叉协方差也要翻号，不能只转换状态值。电流偏置适用同一线性映射：旧接口 `+20 mA` 偏置对应新约定 `−20 mA`，不要在两边都加同号偏置。

## 2. SOC、百分比、单节与整包

1 A 持续 3600 s 积分为 1 Ah。因此 `Δz = -I Δt/(3600 Q)`；`Q=2 Ah`、1 A 放电 720 s，SOC 从 0.80 到 0.70。SOC 误差 `0.01` 是 **1 pp（百分点）**，不是 0.01 pp。`SOC (%) = 100z`，相对百分比误差还须声明分母。

能量 `E_Wh = ∫V I dt/3600`，其中新约定正值表示流向外部的电能；`E_J = 3600 E_Wh`。电流方向变换、容量积分和能量积分要共用同一符号登记。温度测量可用 °C，绝对温度/熵热公式用 K；电压标准差单位 V，方差单位 V²，不能把 5 mV 直接当作 `R`。

每份场景配置标明单节或整包、串并数、端子参考、化学体系、容量条件、温度、初始 SOC 和极化。只有电芯一致且连接压降可忽略时，才能把单节电压直接乘串数；实际约束检查逐节量，不能用包平均替代最弱单节。名义容量与标定条件下的可用容量分别登记。

## 3. 时间侧与输出位置

新 ZOH（区间恒值输入）场景定义 `I[k]` 作用于 `[t[k], t[k+1])`，状态为 `z[k], v_p[k]`，时间差 `dt=t[k+1]-t[k]`：

```text
a = exp(-dt/(R1 C1))
z[k+1] = z[k] - I[k] dt/(3600 Q)
v_p[k+1] = a v_p[k] + R1(1-a) I[k]
V(t[k]+) = U(z[k]) - R0 I[k] - v_p[k]
V(t[k+1]-) = U(z[k+1]) - R0 I[k] - v_p[k+1]
```

电流在 `t[k+1]` 改变时，状态连续，欧姆项立即变化；必须用新电流重算 `V(t[k+1]+)`。旧 `TheveninCell.step(I_legacy, dt)` **先更新状态再返回电压**，其返回值对应恒值输入的区间末端左侧。`terminal_voltage(I_legacy)` 只计算当前状态下的电压，不再积分。把返回值误记为区间开始会错位一拍。

实测 RW3 是另一种输入身份：样本电流属于各自 `time_s`，首个样本积分为零，区间电量按相邻样本的梯形积分计算。EKF 用区间平均电流预测状态，用末端采样电流计算欧姆项。RC 预测将区间平均电流当常值输入，这是实测回放的近似，不能声称对任意线性变化电流也是精确离散解；积分间隙内未观测的变化仍是不确定性。

样本时间、接收时间、处理/判决时间、动作命令时间、有效反馈时间分开记录。连续 0.20 s 与连续三拍是不同确认规则；窗口端点、比较符号、历史预热、调度和重置条件必须属于场景合同，不能互换。

## 4. 场景与数据角色

同一算例的图、手算、代码、答案共用一个 `scenario_id` 和配置摘要。改变容量、OCV、噪声、采样方式、输入或验证用途时，建立新场景身份。适配记录列原始字段/单位/符号、执行过的变换与新字段身份，禁止根据曲线趋势自动翻电流。

NASA RW3 的源记录放电为正；本库 [转换器](../code/soc/prepare_nasa.py)已翻成充电为正，随库 CSV 继续由旧接口读取。新深研若适配该 CSV，只在边界再取一次负号；既不能把它当未转换原始数据，也不能对已适配值再翻一次。

| 数据角色 | 可以怎样称呼 | 不能据此声称 |
|---|---|---|
| `observation` | 实测电流、电压、温度及其时间/源行身份 | 已直接测到 SOC 或内部状态 |
| `synthetic_truth` | 已知生成方程下的合成状态 | 真实电芯的独立真值 |
| `reference` | 由测量电流、标定容量、起点假设构造的参考 SOC | 独立绝对 SOC 准确度 |
| `prediction` | 前向模型或估计器输出 | 未经留出/实测的泛化保证 |

RW3 固定标定分组是 OCV step 0、容量 step 2、脉冲 step 5/6/7；验证为 step 32–49。验证电压可以用于 EKF 的在线观测更新，不能反向拟合参数或反复选择 Q/R 后仍称独立验证。现有报告只能证明所执行的标定函数未读验证组，不能证明操作者从未看过或调过该工况。跨电芯、温度、寿命阶段验证另需合适数据。

`metrics` 的 SOC RMSE/末端误差均相对 `soc_reference`，以 pp 表示；`voltage_rmse_mv` 是用计算参考 SOC 驱动的开环模型与实测电压之差，不是盲测 SOC 的证明。`diagnostics` 使用更新前电压新息和 NIS，不读取参考 SOC。低 NIS 不能单独归因于 R 过大，也不能证明状态准确。

python -m pytest code/soc/tests/test_engineering_conventions.py code/soc/tests/test_real_data.py -q -p no:cacheprovider
