## C. 原理简化审计（§3.10 C，报告门）

字段：`页面 | 开篇是否现场问题 | 首个术语出现在证据之后 | 抽象段后距最近证据字符数 | 动画/实物达份额 | 取回≤3句 | 结论`

**判断列（前两列与取回列）由评审勾选；字符数为脚本实测。**

实测命令（唯一口径，表中数字由它生成）：

```bash
python tools/visual_gap_audit.py --stages
```
