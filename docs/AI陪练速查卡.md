# AI 陪练速查卡（打印版）

<p class="print-hint">Ctrl/Cmd + P 打印；建议 A4 双面、缩放 100%。打印时本站导航与页脚自动隐藏。</p>

> **一句**　模型给候选，程序给判定，人签字。

## 三圈

| 圈 | 可以做什么 | 错误成本 |
| --- | --- | --- |
| 能放手 | 解释机制、起草文档与注释、出题批改、从你贴的原文里检索 | 浪费时间 |
| 要签字 | 故障归因（只给候选）、保护阈值（只认 datasheet 与正文）、改代码与配置、任何「结论」 | 返工或事故复盘 |
| 别碰 | 安全回路、寄存器 / 凭据 / OTA 签名、无人复核的自动动作、现场高压 | 不讨论概率 |

## 六种提示

| 提示 | 一句话 | 你要它交什么 |
| --- | --- | --- |
| 出题 | 先问后讲 | 3 道只考机制的题，先不给答案 |
| 类比 | 用生活物讲机制 | 一个类比，加一句「它解释不了什么」 |
| 批改 | 只对照你贴的原文 | 指出不一致，不替你补规格 |
| 边界 | 问「哪一层决定」 | 机制与分层，不给阈值 |
| 证据链 | 每个数回链原句 | 出处、原文、适用条件；找不到写「待查」 |
| 反例 | 让结论失效 | 一个只用已贴原文的反例 |

## 取证与判定

| 判定 | 什么时候用 |
| --- | --- |
| 可用 | 原文有这句，单位和适用条件也对得上 |
| 降级 | 机制讲得通，但数值没出处；只能讨论，不能上板 |
| 待查 | 仓库没找到；记下要查哪本手册、哪一页 |
| 打回 | 编数字、串型号、与原文冲突，或建议绕过保护 |

**五探针**：要出处 / 要原文 / 要运行结果 / 要反例 / 换问法再问。

**三停**：报阈值就停；无出处就降级；劝你绕保护就结束。

**8 分制**：机制、证据、边界、复述各 0–2 分；≥6 分且机制、边界不为 0 才算过。

## 写代码五关

| 关 | 一句话 | 不过会怎样 |
| --- | --- | --- |
| 1 需求单 | 要什么、怎么验、只许改、不许碰 | 模型自己发明验收条件 |
| 2 最小改动 | 一次只修一个问题；不顺手重构、不加依赖 | diff 一大就说不清 |
| 3 跑真门 | 原样贴命令、退出码、关键输出 | 「应该能过」不是证据 |
| 4 差异审查 | 测试 / 异常 / 行为 / 依赖 / 生成物 | 测试绿了，契约没了 |
| 5 人签字 | 交付单齐全，人签字才合并 | 草稿被当成结果 |

## 差异审查五看

| 看什么 | 危险信号 | 处置 |
| --- | --- | --- |
| 测试 | 断言变宽、加 skip、删用例、期望值跟着实现改 | 打回；测试是契约 |
| 异常 | `except Exception: pass`、静默默认值、错误码被吞 | 打回，除非原文要求降级并计数 |
| 行为 | 默认值、单位、符号、调用顺序被顺手改 | 拆成单独改动，补测试 |
| 依赖 | 新包、版本漂移、lock 变化 | 先讨论，不放进这次任务 |
| 生成物 | 手改 SVG、缓存、报告 | 打回；改生成器再生成 |

## 代码交付单

```text
【任务】一句可验收的行为
【改动】文件 + 每个文件改了什么（每文件 ≤5 行）
【没有碰】安全回路 / 阈值与寄存器 / 依赖 / 生成产物 / 凭据
【测试】哪条先红、现在为什么绿
【本机跑的】命令 + 退出码 + 关键输出（原样粘贴）
【已知风险】这次改动仍证明不了什么
【回滚】改哪几个文件、按什么顺序退回
【签字】姓名 + 日期；阈值与安全相关改动需要第二个人
```

## 一次陪练的流程

1. 贴原文（至少一段）+ 固定提醒 + 会话守则。
2. 选一个角色、一种提示，一次只做一件事。
3. 回仓库对账：每个数值、单位、位宽、地址都找原句；找不到记「待查」。
4. 打分并记错题；下一轮只补最弱的一项。
