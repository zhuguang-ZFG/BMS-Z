# 入门可读性与手绘插图补充计划

日期：2026-11-08。接续 SPEC v2.6 连续课程。用户要求继续提高入门可读性，并指出新主线缺少手绘插图。本轮以学员实际能跟着做、在首次接触概念时有图可看为交付目标。

## 发现的问题

- 前三课仍默认读者懂“负载、标称、额定、等效模型”，算式符号与单位转换有跳步。
- 第 4 课要求换输入，却没有交互窗口的进入、输入、退出步骤；下载默认分支也不保证包含尚在 PR 中的课程代码。
- 第 6 课突然使用布尔值、比较、列表遍历与数学模块；后面的保护时间、通信字节也需要小步解释。
- 新主线前六课没有手绘机制图；第 9 课复用旧图的数字与贯穿项目不一致。科学曲线不能承担器件、连接与事件的全部解释。

## 本轮合同

1. 保留 24 课、8 模块、同一 4S 项目、原工程边界和默认折叠答案。新术语先用本课对象解释；变量逐个对应，关键算式补单位和中间一步。
2. 第 4–6 课给出可直接照做的命令、编辑位置、保存、预期输出与常见错误处理；公开示例统一使用可见文件名 `my_bms.py`，兼容早先的 `.tmp-my-bms.py`。
3. 为第 1–6 与第 9 课新增七张手绘教学图，每图回答一个问题。采用现有 handraw 自绘 SVG → 高清 WebP 路线；主色 C-03，危险点缀 C-15，真实连接关系、量尺或时间轴承担解释，不能只有文字框。
4. 手绘图的数字与课文逐项核对。保留可编辑源、生成器、正文导出、观察题和“原理示意 / 非实拍”；新增图不计入动画，也不补专项授权照片配额。
5. 手机宽度、PDF 与 EPUB 实际看图检查字级和裁切；离线版保存全部图。主图在静态页面可读，科学图保持可复算。
6. 本轮自动检查与编辑审阅不代替 W5 真人试读。
