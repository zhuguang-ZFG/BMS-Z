# 章节契约模板（ch0–18 重写通用骨架）

> 每章按本骨架重写；顺序固定，槽位标记 `<!-- slot:* -->` 保留在正文里，供 `scripts/check_chapter_contract.py` 扫描。
> N 为章号占位；`### N.x` 小节编号随章内实际重排，槽顺序不得颠倒。

```markdown
<a id="chN"></a>
## 第 N 章 〈章名：说清这一章管什么〉

> **场景**：〈桌上或现场能感知的一件事〉 ｜ **难度**：〈入门/进阶/精通〉
> **白话**：〈一句话说清本章主角〉 ｜ **先修**：〈ch 列表或「无」〉
> **学完你应能**：〈两到三条可判定的能力〉

<!-- slot:hook -->
### N.1 钩子现象
〈一个现场或桌上能感知的现象；两三句，不灌背景。〉

<!-- slot:intuition -->
### N.2 直觉
〈先不写公式，把因果链讲顺；允许画歪歪扭扭的手稿图。〉

<!-- slot:quant -->
### N.3 定量推导
〈公式 + 限定条件 + 数量级；条件写全，无出处不写死数字。〉

> **口诀**：〈一句「一点就懂」，进第八篇顺口溜总表同源。〉

<!-- slot:limits -->
### N.4 失效边界
〈何时模型崩、典型翻车长什么样；给出可观察的征兆。〉

<!-- slot:lab -->
### N.5 动手验证
〈仿真或实作步骤，可复现；写明仪器/工具与预期读数。〉

<figure>
  <img src="assets/figures/chNN-hero-〈主题〉.svg" alt="〈图的一句话内容〉">
  <figcaption>〈含数字的读图指引：图上哪个数、对应哪条式子。〉</figcaption>
</figure>

> **图问**：〈图前一问，指向本图要回答的那个问题。〉

**算一笔**：〈条件写全（电源/阻值/温度/频率），结果可手算或仿真复核；无出处标「示意」。〉

<!-- slot:selfcheck -->
### N.6 自检
〈可判定对错的题；至少一题指向设计判断。〉

### 验收清单
- [ ] 观察：〈现象级证据，写明判据〉
- [ ] 计算：〈数值题，条件写全〉
- [ ] 测量：〈仪器与合格判据；或仿真步骤与预期读数〉

<!-- slot:advanced -->
### N.7 进阶框（可选）
〈跳过不影响过关；放推导细节、边角料、延伸阅读。〉

<!-- slot:citations -->
### 参考与出处
- 〈至少 1 条可核对的厂商文档 / 应用笔记 / 已登记 OSS；写明型号与章节或 URL。〉
- 〈教学示意数字标明「示意」。〉
```

四件套对照（缺一不算契约达标）：

| 交付物 | 落点 |
|---|---|
| 口诀卡 ×1 | `> **口诀**：`，同步登记 `docs/p8-11-s8-11.md` |
| 手绘主图 ×≥1 | `assets/figures/chNN-hero-*.svg`，FA-029 纸墨，中文标注，图问 + 含数字读图指引 |
| 可复现数值例 ×≥1 | `**算一笔**：`，条件写全 |
| 验收清单 | 观察/计算/测量三条，至少勾两条过关 |
