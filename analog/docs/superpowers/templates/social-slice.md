# 三平台社媒切片模板（公众号 / B 站 / 小红书）

> 同源锁（spec §9.2）：切片结论与本章验收清单一致；**禁止新增未经 docs 收录的「新结论」「新数字」**；每条可回溯到章号 + 口诀卡；主视觉走 [yang0/handraw-style](https://github.com/yang0/handraw-style) 配方（见 `docs/superpowers/visual/2026-11-03-dna-lock.md`），色板不与正文打架。

字段固定（每条切片都要填全）：

```yaml
章号: chN
口诀: 〈一句话，与 p8-11-s8-11.md 总表字面一致〉
钩子句: 〈现象级开场，两三句内把"疼"点出来〉
关键数值:
  - 值: 〈含单位的数字〉
    出处: docs/pX-0N-chM.md#锚点 〈或 assets 内图/动画文件名〉
验收一句: 〈本章验收清单里可勾的那一条〉
CTA: 〈回书 / 回站：对应 docs 页或动画中心链接〉
尺寸:
  bilibili: 16:9 封面
  wechat: 2.35:1 头图（由 16:9 裁切）
  xiaohongshu: 3:4（由 9:16 裁切）
主视觉: yang0/handraw-style 配方（style: FA-029；纸 C-30 #fdf8ea；墨 C-31 #16202b；标记 C-29 #a4630f）
```

三条规矩：

1. **数字必须带出处字段**：写不出 `docs/...#锚点` 的数字不要发。
2. **裁切不裁内容**：三个平台的尺寸变体都必须保住口诀与关键标注（发前按 §10.5 勾选）。
3. **结论只做压缩，不做改写**：验收清单说"过关算什么"，切片就说什么；加戏 = 违规。

上架前走 `docs/superpowers/checklists/social-ship.md`（§10.5 可勾选副本）。
