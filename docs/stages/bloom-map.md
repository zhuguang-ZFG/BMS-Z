# 布鲁姆能力地图

零基础从这里选一层，点进一节就能开始。不必先通读七阶段总表。

阶段 0–6 仍是练习场的默认顺序。这一页是能力索引：电路详解和 `code/` 按层挂在下面，不另起一条路线。

⚠️ **锂电池实验有真实火灾风险。** 碰真电池前先备护目镜与防火垫。安全纪律与器材见 [预算清单](../budget.md) 与 [阶段 2](stage-2-保护板实践.md)。本页出现的阈值都是示例，以电芯和芯片 datasheet 为准。

**零基础默认入口**：[理解 · 一块电池里在发生什么](stage-0-前置知识.md#011-一块电池里在发生什么-理解)。读完阶段 0 的 §0.1，再决定要不要按天走 [前两周怎么走](getting-started.md)。

## 怎么用

1. 选一层，读那一层的一句话目标。
2. 点「第一入口」做完，再做自检。做不出就留在这一层。
3. 已经有具体任务（做保护板、只做算法、读商用 BMS）→ [按目标选路线](按目标选路线.md)。每条捷径标了布鲁姆层。
4. 想按天走完前两周 → [前两周怎么走](getting-started.md)。

六层是累积的。应用层默认你认得记忆层的词，也讲得清理解层的机制。改标题造成的旧锚点见 [迁移表](bloom-migration.md)。

## 小节模板约定

新小节标题末尾加一层：`[记忆]` `[理解]` `[应用]` `[分析]` `[评价]` `[创造]`。

混进了两层就拆开。暂时不能拆，在节首写 **先读/后读**，写明哪几段是哪一层。评价和创造不要写进记忆节。

节末三件套，放在正文后面：

> **原理**　机制，不是只有步骤。
> **证据**　datasheet、标准、论文，或可复现实验 / 仿真的链接。
> **延伸阅读**　可选加深；英文资料标可选。

没有把握的证据就写明 **待补证据**，并在 [共建任务板](../共建任务板.md) 加一条。不要编一个看起来像论文的链接。

标题一改，锚点就变。改完把旧 → 新写进 [迁移表](bloom-migration.md)。
