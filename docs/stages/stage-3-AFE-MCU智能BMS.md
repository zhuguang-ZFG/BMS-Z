# 阶段 3 教程：AFE + MCU 智能 BMS

> 对应学习路线的阶段 3。目标：设计并实现一块"采样 + 均衡 + 保护 + 通信"的完整智能 BMS。
> 建议用时 1–2 个月。前置：已通过阶段 2 验收。这是整条路线工程量最大的阶段，也是从爱好者到工程师的分水岭。

## 3.1 架构之变：保护板 → 智能 BMS

保护板的保护逻辑是**写死在模拟电路里的**；智能 BMS 把"感知"与"决策"分开：

```
电芯 → RC 滤波 → AFE（高精度采样 + 硬件保护兜底）
                    │ I2C / SPI
                    ▼
                  MCU（策略、算法、通信）→ MOS 驱动 / 继电器
                    │
                    ▼
              UART / CAN / BLE 对外
```

- **AFE（模拟前端）**干粗活：多串电压高精度测量、温度采集、内置独立硬件保护（MCU 死机也能保护）、均衡开关驱动；
- **MCU** 干细活：可编程保护策略、SOC 算法、均衡调度、通信协议、故障记录；
- 关键设计原则：**硬件保护（AFE 内置或独立保护 IC）兜底，软件保护在前**——双通道冗余，量产的门票。

## 3.2 AFE 精读（以 TI BQ769x0 / BQ769x2 为线）

以数据手册为骨架，按信号链顺序读：

**输入级**

- VC0…VCn 引脚跨接各串电芯；每路串 RC（阻值容值照抄手册推荐，理由见阶段 0）；
- 支持的最高串数：bq76920 = 5S，bq76940 = 15S，bq76952 = 16S（选型先看串数）；
- **开线检测**：采样线断开时对应通道读数异常，AFE 有专门诊断功能，量产必启用。

**测量子系统**

- 内部 MUX 逐串切换 + 高精度 ADC 轮询扫描；全部串扫完一轮需要固定时间（手册给出），固件按周期读数即可；
- 电流：外部检流电阻 + 内部库仑计（CC），同时给瞬时值与积分值；
- 温度：多路 TS 引脚接外部 NTC + 片内温度。

**保护子系统（硬件兜底）**

- OV/UV/SCD/OCD/OT/UT 全部可配阈值与延时（寄存器），触发后**不需要 MCU 干预**直接拉 ALERT/驱动 MOS；
- 子系统独立时钟，MCU 死机照样保护——这就是"双通道"的硬件半边。

**均衡**

- 内部每串一个开关，外接均衡电阻；MCU 写寄存器选择对哪些串放电；
- 注意手册的占空比/热限制：内部开关长时间导通会发热，均衡调度要轮询分时。

**通信与供电**

- I2C（bq769x0）或 SPI/I2C/HDQ（bq769x2 系列），可选 CRC 校验——**强烈建议开 CRC**；
- AFE 直接从电池组取电，自带 LDO（REGOUT）给 MCU 供电；进出 shutdown 模式控制整机静态功耗。

> 读手册实操：找 bq76920 数据手册，把"寄存器地图"一节全部过一遍，给每个寄存器标注"状态类/配置类/保护类"。

## 3.3 高压与菊花链（ADI LTC6811 视角）

超过 16 串（储能 48V+、车用 96–400 串）换思路：

- **LTC6811**：单芯片 12 串，多颗**菊花链**级联覆盖上百串；
- **isoSPI**：变压器耦合的差分 SPI——每级之间完全电气隔离（解决阶段 0 讲的共模问题），抗扰强、可长线；
- 架构对应阶段 6 的 BMU/CMU：每个从板一颗 LTC681x 管一段电芯，主控通过 isoSPI 轮询；
- 入门工程精读：[vamoirid/LTC6811+STM32 工程](https://github.com/vamoirid/Battery-Management-System-LTC6811-STM32)，重点看它的驱动分层与断线检测实现。

## 3.4 固件架构

推荐四层（对照 [LibreSolar/bms-firmware](https://github.com/LibreSolar/bms-firmware) 读源码）：

| 层 | 职责 | 要点 |
|---|---|---|
| 驱动层 | AFE 寄存器读写、CRC、开线检测 | 读失败重试与计数，绝不静默吞错 |
| 服务层 | 周期采样（10–100ms）、保护判定、均衡调度 | 保护判定用**去抖**（连续 N 次超限才动作） |
| 应用层 | 状态机、SOC 算法（阶段 4）、通信协议 | 状态机集中管理，禁止到处散落 if |
| 安全层 | 看门狗、故障锁存、参数校验 | 独立看门狗 + AFE 硬件保护兜底 |

**主状态机最小集合**（阶段 6 扩展成量产版）：

```
初始化 → 待机 → 充电 ⇄ 充电末端均衡
           ⇅
          放电
           ↓（任一保护触发）
         故障（锁存/等待恢复条件）
```

## 3.5 原理图与 PCB 要点

- **采样走线**：每串采样线尽量等长、紧贴、远离大电流回路；分压点在接插件处就近；
- **均衡电阻**：按最高单体电压与目标均衡电流选阻值，功率留 2 倍余量；布局在板边利于散热，远离 AFE 基准源（热会带偏精度）；
- **功率地 vs 信号地**：检流电阻采用开尔文接法，功率地与信号地单点汇合；
- **隔离区**：通信口（UART/CAN）与电池侧之间划隔离带，隔离器件下方不走线不铺铜；
- **ESD/浪涌**：采样输入端、通信口加 TVS。

## 3.6 调试流程（先模拟后真电池）

1. 供电：先只上电，查 REGOUT、MCU 电源、静态电流；
2. 通信：读 AFE 芯片 ID/状态寄存器，I2C 不通先查上拉与地址；
3. 单串采样：接电芯模拟器，逐串给 3.7V，核对每串读数误差（目标 <10mV）；
4. 全串与温度：全通道扫一遍 + NTC 读数对照温度计；
5. 保护：模拟过压/欠压，验证 AFE 硬件保护动作与 MCU 软件保护动作**各自独立生效**；
6. 均衡：置一节高压，充电末端看均衡是否按调度工作、板子温升是否可接受；
7. 真电池接入：先小电流充放，逐步加大。

常见故障速查：采样值跳变→虚焊/排线接触；某一串恒定异常→开线或该路 RC 焊错；I2C 读回全 FF→上拉缺失或 AFE 未供电。

## 3.7 自测题

1. 为什么智能 BMS 还需要 AFE 内置的硬件保护？软件保护不够吗？
2. AFE 输入 RC 为什么不能自行改大阻值？
3. 开线检测的原理是什么？（断线后该串读数为什么会偏）
4. 被动均衡为什么要"分时轮询"而不是全串同时开？
5. isoSPI 解决了菊花链的什么问题？
6. 保护判定为什么要去抖？去抖时间与误触发/漏触发怎么权衡？
7. 检流电阻为什么要开尔文接法？

## 3.8 动手任务与验收

**动手任务**

1. 以 [LibreSolar bms-c1](https://github.com/LibreSolar/bms-c1) 为蓝本，抄板设计一块 8–16S 智能 BMS（原理图 + PCB），投板焊接；
2. 烧录 [bms-firmware](https://github.com/LibreSolar/bms-firmware)（或自写 bq769x2 驱动），按 3.6 流程完成七步调试；
3. 写一份调试记录：每步的现象、数据、结论（这份记录就是你的工程资产）。

**验收清单**

- [ ] 全串电压采样误差 <10mV（电芯模拟器下）
- [ ] 硬件保护与软件保护能分别独立触发，动作阈值与延时符合配置
- [ ] 被动均衡按调度工作，满载均衡时板温可接受
- [ ] 能讲清自己板子上 AFE 每个外围元件的作用
