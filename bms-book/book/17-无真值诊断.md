# 第 17 章 无真值诊断：没有答案时怎么听诊

::: story 现场
现场没有参考 SOC。你只有模型、电流、电压，和一条越看越不对劲的残差曲线。怎么判断是“模型参数错了”，还是“电压表坏了”？

BMS-Z 的答案很漂亮：**参数错，残差跟着电流走；传感器坏，残差只是整体偏。** 前者相关性 −0.288，后者是一个常数偏移。你不用知道真值，也能把两种病分开。
:::

## 17.1 新息：仪表和模型吵的那一架

每拍先预测，再和测量对账：

$$
e_k = z_k - h(\hat{x}_k)
$$

它只用“模型预测”和“仪表读数”，**不需要参考 SOC**。

一个 15 mV 的新息，可能是 SOC 猜错、R0 写错、电压表偏置、温度变化或噪声。一个方程，多个未知——所以新息不能直接当成 SOC 误差。

## 17.2 三个诊断数

| 指标 | 回答什么 | BMS-Z 实测（generic → calibrated） |
|---|---|---|
| 新息 RMS | 一般差多少 | 15.137 → 3.699 mV |
| 新息均值 | 一边倒还是两边晃 | −0.338 → +0.492 mV |
| NIS | 相对噪声算不算大 | 0.5340 → 0.0325 |

电压 RMSE 更直观：generic **186.3 mV**，标定后 **21.8 mV**。同一个滤波器，参数换了，残差跟着变。

::: principle 一句话
**RMS 看大小，均值看见偏，NIS 看“相对噪声算不算大”。** 三个数都不需要真值。
:::

## 17.3 参数错 vs 传感器坏

BMS-Z 用同一段工况、同一个种子做了四组对照：

- **R0 偏大**：残差随电流显著变化（BMS-Z 该组相关系数 −0.288，负相关；符号取决于残差定义与电流方向约定）；
- **电压表偏置**：残差整体平移，与电流无关；
- **容量错**：残差随 SOC 漂移；
- **温度错**：残差在温度变化时出现台阶。

区分方法不是“看曲线像不像”，而是**做相关性**：把残差对电流、温度、SOC 分别回归，看谁解释得多。BMS-Z 报告的 −0.288，就是参数错留下的一条“跟着电流走”的指纹——先看相关性与形状，再谈符号。

## 17.4 诚实标注：参考值不是真值

BMS-Z 的报告里有两行很关键：

```text
reference_kind = coulomb_reference_from_same_measured_current_and_separate_calibration_capacity
independent_soc_truth = False
model_fitted_on_validation = False
```

意思是：参考 SOC 是用同一路实测电流积分出来的，和被评估的估算器共享误差源；模型也没有在验证段上调参。

所以“和参考差 0.2%”不等于“精度 0.2%”。诊断数的价值在**相对比较**（generic 对 calibrated），不在宣称绝对精度。

::: trap 坑
拿“参考 SOC”做真值，然后调参调到曲线重合。你调的是“和参考的一致性”，不是“和物理的一致性”；换一个工况，误差会回来。
:::

跑 BMS-Z 的 `python code/soc/real_data.py`，打开 `real-data-output/report.json`，读 `diagnostics` 里的三列。然后把 R0 改大 10 倍，再跑一次，观察新息 RMS 与电流相关性怎么变。
:::
