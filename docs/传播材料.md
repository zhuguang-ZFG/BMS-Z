## 第 7 章：三种读法

同一批数字（57 / 77 / 23 ms、4250 / 4150 mV、100 mV 回差）出三种形态，用途不同：

| 形态 | 打开 | 什么时候用 |
|---|---|---|
| 一页纸 | [HTML](/spread/07-protection-tick.html) · [PDF](/spread/07-protection-tick.pdf) · [长图](/spread/07-protection-tick.png) | 读完第 7 章回看一遍；PDF 可离线转发 |
| 卡片组 | [第 1 张](/spread/cards/07-protection-tick/xhs-01.png)（五张，`xhs-01..05.png` 同名递增） | 小红书 / 公众号刷屏 |
| 讲师版 | [网页 PPT](/spread/deck/07-protection-tick.html) | 现场讲：`P` 键演讲者模式，`←/→` 翻页，九页各带讲稿 |

一页纸的六个小节：四个时间点 → 两只时钟 → 阈值与回差 → 三层保护 → 验收矩阵 → 合闸四步。讲师版九页：`hero dark → light → dark → light → hero light → dark → light → hero dark → light`。

## 怎么重出

```
python tools/spread/build_chapter_cards.py --validate        # 32 张章卡（本页表格一起更新）
python tools/spread/build.py        07-protection-tick      # 一页纸 HTML / PDF / 长图（字体内置、离线可读）
python tools/spread/build_cards.py  07-protection-tick --validate   # 第 7 章五张卡；校验通过才覆盖已发布 PNG
python tools/spread/build_deck.py   07-protection-tick      # 讲师版
```

源稿在 `tools/spread/`，产物在 `docs/public/spread/`；两者都入库，所以传播物不会悄悄落后于书。一页纸的字体在构建时就子集化进 HTML，删掉了 `fonts.g*` 的 preconnect——断网打开也不掉字体；页面右下角那个字体/配色按钮是技能自带的设计工具，点了才会去取在线字体。

`bms-book/tests/test_spread_artifacts.py` 守着这条合同：一页纸不许有加载期远端请求，32 张章卡与第 7 章三件套必须都在。
