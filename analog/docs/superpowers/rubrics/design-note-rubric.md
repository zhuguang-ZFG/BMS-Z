# 设计说明量规（非认证）

> 用途：判定 §4.2「设计说明五块」过关与否的打分口径。**结论只有过关 / 不过关，不是证书**；自测分数不能替代本量规（与 CONTRIBUTING 立场一致）。配套模板：`docs/superpowers/templates/acceptance-design-note.md`。

| 块 | 过关 | 不过关 |
|---|---|---|
| 指标 | 五类指标写全且可测 | 缺项或不可测 |
| 选型 | 有型号或选型窗+否决理由 | 只有「选用合适器件」 |
| 极限 | ≥3 corner + 预期行为 | 只写「注意温度」 |
| 测试 | 顺序+仪器+判据 | 无判据 |
| 失败预案 | 优先怀疑点+下一刀测量 | 「再检查一遍」 |

使用规则：

1. 五块逐行判，**任一块落在"不过关"列，整份设计说明不过关**；不算平均分。
2. 判"过关"要能指出原文哪一句满足了"过关"列的描述；指不出的按不过关处理。
3. 极限工况的 corner 至少覆盖温度、负载、供电、容差中的三类；预期行为写到"该节点电压/波形如何"。
4. 测试步骤须写明仪器与档位，判据必须是数值或波形特征；"正常"两个字不算判据。
5. 失败预案要给优先级排序的怀疑点与"下一刀测量"；只写"再检查一遍"按不过关。
6. 本量规用于章末设计作业（ch14/ch16/ch18）与读者自评；不对外颁发任何认证。
