# 比喻地图：这个仓库怎么打比方

> 技术书最怕两件事：术语吓跑人，比喻骗住人。这个仓库的对策是——**比喻只当门牌，不当教材**。每个比喻后面都钉着出处，进门之后，账和公式还是老老实实的。
>
> 这些比喻散落在各篇里，这里收成一张地图。忘了哪个比喻指什么，回这页查。
