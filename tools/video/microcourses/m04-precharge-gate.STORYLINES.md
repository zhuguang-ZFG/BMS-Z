# m04 故事线：预充超时能不能再等等

## 推荐 A · 一条爬不动的曲线

**装置与形式**　整片只有一条母线电压曲线和一只预充继电器。前半段画正常例：400 V、1 mF、170 Ω，横轴是秒，曲线在 0.17 s 到 253 V、0.51 s 到 380 V，主闸的竖线只落在 95% 之后。后半段把同一条曲线换成故障例：停在约 40 V，斜率趋平，主闸的竖线始终没有出现。

- 前两秒：曲线上一个红点停在 40 V，旁边写着「再等等？」；笔尖把问号圈住，不给答案。
- 节拍：先算正常例 → 为什么不能直接合主闸 → 三步顺序 → 四项反馈 → 两笔账 → 回到故障曲线 → 判据 → 复算。
- 画面：FH-022 课本边角漫画；孔雀蓝画曲线与反馈，那不勒斯黄画时间常数与算式，赭石画合闸动作，红色只标「禁止合闸」。
- 声音：曲线停住时用短 whoosh；主闸允许合上那一拍用 tick；禁止合闸用 blip。

同一组参数贯穿全片，观众只需要记住一条曲线和四个反馈项。故障例不另编数字，只标「约 40 V」——它本来就是示意图。

## B · 三个继电器排队上班

把小继电器、主继电器、预充支路画成三个排队的小人，谁先动手谁后动手。人物记忆点强，但会把「为什么」压成「谁先谁后」，预充失败判据只能当旁白补，容易变成流程背诵。

## C · 一笔焦耳账

整片只算 ½CU² = 80 J 这笔热账，从电阻选型讲到温升。它适合做选型专题，但预充的核心判断是「母线爬不爬」，热量只是代价；把重心放在这里会让观众以为预充是个散热问题。因此留给阶段 6 深读。
