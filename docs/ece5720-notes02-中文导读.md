## 二、两种电芯模型（§2.1–2.2）

BMS 要估 SOC、健康、功率，仿真包之前得有电芯模型（2–1 页）。等效电路快、稳，内部电化学状态看不见。物理模型在宽工况下更能外推，也能看内部，用来猜老化，但慢，还有收敛问题（2–1…2–2 页）。ECE5710 已经把物理模型降到和等效电路差不多的阶数。这一章两种都回顾，然后接到包上。

ESC 的离散形式和 [Notes02（5710）](ece5710-notes02-中文导读.md) 相同（2–3…2–4 页）：SOC 按库仑计数走，各 RC 支路按 exp(−Δt / RⱼCⱼ) 衰减，输出是 OCV 加滞回减各支路电压减 R₀ i。写成矩阵就是 v_k = OCV(z_k) + C x_k + D i_k，其中 D = −R₀。

物理模型回顾五件套：固体电位、固体扩散、电解液扩散、电解液电位、Butler–Volmer（2–5…2–6 页）。降阶路径是线性化、传递函数、DRA（2–7 页）。包仿真的例子主体用 ESC，因为要跑整车时间尺度。

> 【译注】`code/soc/cell_model.py` 是去掉滞回、只留一条 RC 的 ESC。拿它做单节桌面验证，对应 [ECE5720 Notes03](ece5720-notes03-中文导读.md) 的方法。它没有车，也没有并联。

## 三、从车速到电池功率（§2.3–2.4）

设计电池包时，要在图纸走远之前仿真（2–8 页）。任务用车速–时间曲线描述。讲义点名 UDDS、HWFET、纽约市循环和 US06（2–9 页）。每秒算一次：要贴上目标车速，需要多大加速度，因此需要多大力，因此电机要多少转矩和功率（2–10 页）。

期望加速度（2–11 页）：

```
a_des = (v_des − v_actual) / 1 s
```

1 秒是这条离散仿真的步长，不是车辆动力学时间常数。力里还有空气阻力和滚动阻力（2–12 页）：空气阻力用密度、迎风面积、风阻系数和上一拍车速的平方；滚动阻力用滚动系数和正压力。坡道另加。这些是纵向模型，没有轮胎滑移。

电机：转速低于额定转速时，最大转矩是额定转矩；高于额定转速时按功率近似成转矩乘转速等于常数（2–13 页）。算出来的加速度如果会让电机超速，就不能直接积分车速（2–14 页）。仿真要先夹转矩，再夹转速，再更新车速。

## 四、续航例子，以及它的恒压假设（§2.5）

前面的方程只回答「电机跟不跟得上速度曲线」，并假设电池给得起功率（2–15 页）。功率换成电流时，讲义先假设电池包电压恒定，并标明这是个差的假设（2–16 页）：

```
I = P_kW · 1000 / V_nom
SOC ← SOC − I · 1 / (3600 · Q_Ah) · 100%
```

续航按「这次循环掉了多少 SOC」线性外推到允许的 SOC 窗口。窗口用的是额定最大、最小 SOC，不是 0% 到 100% 的化学窗口。

代码分 `setupSimVehicle.m` 和 `simVehicle.m`（2–16 页）。参数被写成雪佛兰 Volt 纯电模式的粗描述，依据是车辆发布前的公开信息和推测，讲义写明大概接近，但没有核实（2–17 页）。US06 图上的功率、电流、转矩是这个假设包的输出，不要抄进设计任务书。

> 【译注】阶段 1 的木桶讲的是串联。这一章的续航外推还有第二层简化：电压不变。电压会掉，同样的功率就要更大的电流，SOC 掉得更快。功率限制的正经算法在 [Notes06（5720）导读](ece5720-notes06-中文导读.md)。Volt 的数字不要写进阶段 4 的验收。

## 五、恒功率和恒压（§2.6）

恒压假设拿掉之后，ESC 在一个采样里可以看成「过滤后的开路电压 vf 后面串一个 R₀」。功率 p = v i，v = vf − R₀ i，得到二次方程。为了得到正的端电压，根号前取减号（2–19 页）：

```
i_k = ( vf − √(vf² − 4 R₀ p) ) / (2 R₀)
```

判别式为负，说明这一拍的功率电芯给不出。恒压段更简单：i = (vf − v_limit) / R₀（2–19 页）。

两种充电曲线：实验室常用 CC/CV，先恒流再恒压；xEV 充电机更常见 CP/CV，先恒功率再恒压（2–19 页）。例子从 50% SOC 充到电压上限，两条曲线都画了（2–20 页）。代码骨架在 2–21…2–22 页，包括电压顶到 maxV 就改成恒压，以及滞回状态的指数更新。那是 ESC 仿真，不是充电器产品逻辑。

## 六、并联模块（§2.7）

一节一节更新，得到的是电芯。包要先决定串并联（2–23 页）。高能量包常常把电芯先并成模块（PCM），模块再串联。讲义的结构图是多并再串的一种画法（2–24 页）。

同一块 PCM 里，端电压必须相同。电流按各节 R₀ 分流。整理后模块电压是各节「开路侧电压」的加权，权重是 1/R₀（2–25 页）。内阻小的节电流大。容量不同时，同样的安时会把瘦节的 SOC 拉得更开。

例子（2–26 页）：正文写 N_s = 2、N_p = 3。SOC 在 30%–70% 之间随机，R₀ 在 5 mΩ–25 mΩ 之间随机，容量在 4.5 Ah–5.5 Ah 之间随机。放到最低节碰到 5% 就停，充到最高节碰到 95% 就停，45 min 后静置。图里能看到各节 SOC 散开，各 PCM 的平均 SOC 也不重合。脚本里极耳电阻例子是 125 µΩ（2–37 页），只属于这份示例代码。

> 【译注】阶段 1 §1.1 的木桶是串联容量由最弱节锁死。这一节加的是并联：电压相同，电流按内阻分，先撞上 5% 或 95% 的那一节让整块 PCM 停。`code/firmware/bms.c` 的均衡看的是串联压差，没有并联分流模型。5% / 95% 是仿真停止条件，不是保护阈值。
