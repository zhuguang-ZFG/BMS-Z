# 零基础：从第一课开始

打开 [第 1 课：电压、电流与电量](../course/01-units.md)。先分清 V、A、Ah 和 Wh，再算四节串联的电池包；前三课只需纸笔和计算器，第 4 课才开始使用电脑。

新的 [24 课连续路线](../course/index.md)沿同一个虚拟 4S、2 Ah 电池包展开：认识 → 测量 → 保护 → 估算 → 充电与均衡 → 通信 → 整合 → 工程验证。每三课留下一个作品，每课做完变式题再展开核对；英文资料均为选读。

## 第 0 天：30 分钟小胜利（零器材也能做一半）

这是旧链接保留的入口。今天只做一件事：完成第 1 课，写清一节标称 3.7 V、2 Ah 电芯的额定能量估计，以及 1 A 放电半小时流出的电量。无需操作裸电芯、旧手机电池或自制负载。

## 什么时候读旧阶段和完整书

已有电路或嵌入式基础，可按 [目标路线](按目标选路线.md)找专题。需要电化学机理、模型推导、器件和完整工程案例时，进入 [32 章深读书](../reading.md)或 [原阶段 0 电池专题](stage-0-主线-电池.md)。这些资料不再是零基础第一周必须读完的长文。

真实硬件实验另需正确接法、额定仪器、独立保护与现场指导；器材见 [预算清单](../budget.md)。PC 仿真不验证电芯安全、板级保护或 HIL 性能。W5 真人试读仍待验收。
