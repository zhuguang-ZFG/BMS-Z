# BMS-Z 教材彻底改造 SPEC

> **状态**　执行中 v1.1
>
> **基线日期**　2026-11-02
>
> **用途**　约束后续全库改造。它规定“改成什么样”和“怎样算完成”，具体教学方法继续引用[教学设计规范](教学设计规范.md)，阶段安排继续引用[项目改造计划](项目改造计划.md)。

## 1. 最终结果

BMS-Z 要从“内容丰富的资料库”变成一套可以顺着学、随时查、亲手验证的教材。陌生读者应能完成下面这条闭环：

> 找到入口 → 看懂机制 → 算出数量级 → 识别适用边界 → 做一次验证 → 留下一份可复算证据

彻底改造不等于删短所有内容。主线负责第一次理解，选读负责深化，完整讲义负责查阅和兼容旧链接。公式、实验数值、条件、安全边界、来源与授权不能因改写而丢失。

## 3. 内容分层

每个阶段和长章只能承担一种主要阅读角色。

| 层级 | 读者目的 | 建议规模 | 必须保留 |
|---|---|---:|---|
| 主线 | 第一次建立因果链 | 单页 0.8–1.5 万字符；超过即评估再拆 | 最小公式、贯穿算例、关键安全边界、一次取回 |
| 选读 | 处理旁支、推导和工程深化 | 单页尽量不超过 1.5 万字符 | 完整条件、推导、反例、来源 |
| 完整查阅 | 搜索、旧锚点、系统复习 | 不设硬上限 | 全部原始信息和稳定锚点 |
| 速查 | 工作时快速找参数或步骤 | 一屏到三屏 | 单位、适用对象、版本和回链 |

以下做法不算完成分层：

- 在 4 万字页面顶部写“后面可以跳过”；
- 把长内容全部塞进 `<details>`，却仍让首次入口加载和搜索同一页；
- 只拆文件，不写阅读顺序和完成标志；
- 选读页重复主线的整段解释。

## 4. 单元内容契约

一个可独立阅读的知识单元必须具备九项信息：

1. **唯一目标**：读完只承诺一个主要能力。
2. **现场问题**：先出现现象、故障或异常数字，不从定义开场。
3. **对象身份**：首次出现的缩写和变量用普通话说明它是什么。
4. **最小机制**：只引入回答当前问题所需的结构与公式。
5. **贯穿算例**：同一组输入走到结论，中途不换数字。
6. **可见证据**：实物、波形、日志、图解或实验结果至少一种。
7. **反例边界**：指出一个合理但证据不足的判断为什么失败。
8. **取回任务**：不看答案也要判断、手算、画图或运行一次。
9. **下一步**：明确去下一主线、选读还是实验，不用资源堆收尾。

若某项不适用，页面要说明原因，不能默默缺失。

## 5. 文字改造标准

文字精修遵循“先修结构，再修句子”。不以口语化、错字或故意粗糙冒充真人写作。

### 5.1 必须做到

- 一段只推进一个判断；因果超过两层就拆句或配图。
- 结论第一次完整解释，后文只增加新条件或回链，不换近义词重讲。
- 公式前先说结果是什么、输入从哪来；公式后写数量级和能支持的结论。
- 阈值写清对象、工况、版本和来源；教学数字标为“示意”。
- 安全动作区分命令、反馈、故障判定和最终处置。
- 主语尽量具体：写“AFE 采样”“BMU 下令”“接触器反馈”，少写“系统进行处理”。
- 标题回答问题或给出判断，减少“概述”“浅析”“赋能”“全面了解”等空标题。

### 5.2 应删除或改写

- “众所周知、显而易见、值得注意的是、综上所述”等无信息转场；
- “从……到……”“不仅……更……”连续成簇的模板句；
- 每节重复的“原理—证据—延伸阅读”空框，若没有新增判断就合并；
- 把三个近义词并排当作强调；
- 先宣布“下面将详细介绍”，再把标题复述一遍；
- 没有来源的“通常最高等级”“行业普遍认为”“绝对安全”。

### 5.3 不得为了变短而删除

- 公式、单位、符号定义；
- 实验输入、输出和误差；
- 适用范围与失效条件；
- 安全警告、法规版本与生效日期；
- 图片作者、许可证与原始链接；
- 能复现实验或构建结果的命令。

## 6. 视觉系统标准

视觉不是装饰配额。每张图必须回答“它长什么样、怎样工作、怎样变化、怎样测到”中的至少一个问题。

### 6.1 五种图各负其责

| 类型 | 回答的问题 | 最低要求 |
|---|---|---|
| 实物照片 | 器件、接线和实验台长什么样 | 标出观察对象；记录作者、来源、许可证；非本仓库拍摄不得称“实拍” |
| 手绘机制图 | 电流、热、数据或状态怎样传递 | 一图一问；箭头有物理含义；颜色和符号全篇一致 |
| 连续图 | 前后顺序和中间状态是什么 | 3–6 帧；每帧只新增一个变化；同一对象位置尽量稳定 |
| 动图 | 哪个量随时间或操作变化 | 第一帧可读；最后一帧是完整答案；正文给观察任务与静态解释 |
| 波形/数据图 | 证据在哪里 | 轴、单位、工况、采样条件和关键点齐全，不用示意曲线冒充实测 |

### 6.2 配图组合

- 讲器件识别：优先“实物照片 + 手绘剖面或等效电路”。
- 讲动作时序：优先“接线图 + 3–6 帧连续图 + 关键波形”。
- 讲算法：优先“输入数据 + 中间状态 + 输出误差”，不放无关电池插画。
- 讲故障：优先“正常/异常对照 + 冻结帧或日志 + 处置时间线”。
- 连续三个抽象段落后，必须出现图、表、算例、问题或实验中的一种。
- 每 400–1200 字检查一次是否需要视觉证据；这是审查间距，不是强制堆图。

### 6.3 视觉禁区

- 不用微缩器件摆拍、装饰电池、发光芯片等“科技感”图片填空。
- 不把示意图标成示波器截图、台架实测或产品内部结构。
- 不在图片中塞长段正文；核心文字必须在页面中可搜索、可复制。
- 不让动画承担唯一解释；静态模式和打印版仍须可读。
- 不为增加数量重复表达同一结论。

## 7. 页面模板

主线页按下面顺序组织，允许因主题删减，但不得打乱因果：

1. 读完能做什么；
2. 一个现场问题；
3. 实物或现象；
4. 最小机制图；
5. 一组贯穿数字；
6. 正常到异常的连续过程；
7. 一个反例和适用边界；
8. 三题以内的取回；
9. 下一篇主线与选读入口。

选读页开头必须写清“什么时候需要读”。完整查阅页开头必须指回短主线，并说明它保留旧锚点。

## 8. 迁移顺序

### Wave 0：冻结基线

- 记录所有阶段、章节的字符数、第一次阅读字符数、图数和构建结果。
- 给已有照片补全来源和许可证；来源不明的先标风险，不继续扩散。
- 保存旧锚点清单，后续拆页不得直接破坏外链。

### Wave 1：清理入口和长主线

- 完成阶段 0、阶段 6 的短主线落地和导航收口。
- 审计阶段 1–5、7；超过阈值或包含两条独立任务链的页面拆分。
- 首页、阶段尾部、学习总纲全部指向短主线，完整页只作查阅。

### Wave 2：重构书稿

- 复核第 12、14、24、27 章的拆分效果。
- 下一批处理第 1、7、30 章，再按审计结果推进其余章节。
- 每章先做内容契约，再改段落；推导迁移时做逐段守恒测试。

### Wave 3：补视觉证据

- 先补高频硬件对象：接触器、熔断器、NTC、分流器、AFE 板、母线与典型实验台。
- 再补高认知负担过程：预充、HVIL、绝缘下降、热传播、故障锁存、SOC 漂移、SOP 收敛。
- 每个主题至少检查一次“实物—机制—过程—证据”是否缺环，不要求四类全有。

### Wave 4：全库文字精修

- 先删重复结论和模板转场，再缩段、拆句、校正主语。
- 对每个数字和绝对判断回查来源；无法确认的改成条件化表达或列为缺口。
- 统一术语、单位、全半角符号和中英文空格。

### Wave 5：任务式试读

- 找 3–5 名未系统学过 BMS 的读者，不提前讲解。
- 让读者完成“解释、手算、找故障、选下一步”四类任务。
- 记录停顿句、误解、回看次数和完成时间，不只问“觉得好不好”。
- 同一停顿点至少出现两次，才进入结构性修订清单；安全性错误一次就修。

### Wave 6：跨媒介收口

- 把书、阶段、图、视频和代码挂到稳定概念 ID。
- 同一阈值、公式和算例尽量由同一数据源生成或检查。
- 更新打印书、站点、动画索引、视频分镜和资源预算。

## 9. 自动质量门

后续应把下列规则逐步加入脚本。先报告，稳定后再阻断构建。

- 主线页超过 1.5 万字符时报警，超过 3.5 万字符时构建失败或必须声明豁免。
- 生成页正文与源稿逐段守恒；代码围栏中的标题不能误触发拆分。
- 主线不得重新混入已声明的进阶推导。
- 图片文件存在，位图有宽高，SVG 可解析，打印版可离线显示。
- 每张外部图片存在作者、来源与许可证记录。
- 内链、锚点、上一页/下一页和侧边栏入口可达。
- 同一页面的完全重复段落为零；近似重复只报告人工复核。
- 全量 VitePress、离线书、课程图和站点资源预算测试通过。

自动门不判断“好不好懂”。可读性最终以任务式试读结果为准。

## 10. Definition of Done

### 单页完成

- [ ] 阅读角色明确：主线、选读、查阅或速查。
- [ ] 唯一目标和完成标志可用一句话说清。
- [ ] 公式、数字、条件、安全边界和来源无损。
- [ ] 没有重复结论、空转场和无主语的泛化描述。
- [ ] 视觉承担识别、机制、过程或证据任务。
- [ ] 图片在手机、桌面、打印和断网模式下可读。
- [ ] 至少有一次不看答案的取回。
- [ ] 下一步链接不会把读者送回长而无边界的资料页。

### 一个阶段完成

- [ ] 第一次阅读总路径清楚，主线之间没有跳步。
- [ ] 选读不会阻塞验收，完整讲义仍可搜索旧锚点。
- [ ] 至少有一个 PC 可完成的验证任务；涉及真电池时安全条件明确。
- [ ] 新读者能在不问作者的情况下找到入口并说出完成标准。

### 全库完成

- [ ] 所有阶段和书章都有稳定阅读角色与概念映射。
- [ ] 长主线、重复正文、无授权图片和失效内链为零。
- [ ] 3–5 名陌生读者完成关键任务，严重安全误解为零。
- [ ] 在线站点、断网整书、视频分镜和代码实验口径一致。

## 11. 决策记录

后续出现下列判断时，必须在 PR 或改造日志里记一行原因：

- 为什么拆页或不拆页；
- 为什么选择照片、手绘、连续图或动画；
- 为什么删除、保留或移动一段推导；
- 为什么某个阈值只作教学示意；
- 为什么允许一项质量门豁免。

记录只需包含：`对象 / 决定 / 依据 / 风险 / 后续复核点`。这样以后能继续改，而不必重新猜当时的意图。
