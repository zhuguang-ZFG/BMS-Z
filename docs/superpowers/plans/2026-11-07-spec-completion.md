## 本轮补齐

- 80 条 L3 取回任务与核对标准由同一份 `ladder` 生成到离线书；原有章末三题、安全边界和通过标准不变。新增的是读者可以独立作答的入口。
- 图解索引从 `ladder.media` 生成 KP 与级别回链，不把最高等级当作图解已经兑现的等级。
- `tools/tests` 加入 CI 与 PowerShell、Bash 本地门；6 个新增回归覆盖独立取回、配额去重与 HTML 照片识别、图解级别、归档保护与总数口径。
- 新增 `visual_gap_audit.py --quotas`。下限直接读 SPEC §3.8，只计主线嵌入且存在的资产；普通链接、视频缩略图、缺失文件和代码示例不计。
- 补齐阶段 1、3、4、5 的实物配额；新增的珠状 NTC 纠正旧浪涌抑制器照片误配，来源、作者、许可证与转载日期留档。未把探头照片写成已安装照片。
- 核对标准在 HTML 中默认折叠，打印时展开，打印后恢复，避免 PDF 只有标题而没有标准正文；EPUB 使用静态内容。
- 存量机制图生成器跳过 manifest 已归档的旧源，默认覆盖与临时对账都不会复活旧 SVG；社交卡及 GitHub 简介真值门统一调用 SVG+handraw 去重总数。
- 复核并补入 5 个照片文件：LibreSolar 采样接口局部、低压汽车熔断器、汽车继电器、压接正反例、低压线缆绝缘破损。B-02 关闭，B-05/B-09 从待补转为部分覆盖；B-06 增补有作者区域注释的均衡电阻，B-03 增补电芯测温点但不猜 NTC 型号。所有图均记录作者、原图、许可证与处理方式。
- 撤回两张 DIY BQ76940 照片：上游只写代码为公有领域，照片授权未明确。阶段 3 改用授权明确的 LibreSolar 与电池包照片，5/5 配额不依赖被撤回图片；全图与同视角裁剪按 1 点去重。
