# 阶段 6 教程：精通——工程化与毕业项目

> 对应学习路线的阶段 6。目标：硬件、固件、算法、功能安全、量产五条线全部打通，完成一个可发布的 BMS 产品级项目。
> 这一阶段没有固定周期——它是把前五阶段的点连成面的过程。毕业标准见末尾。

---

## 6.1 硬件精通

### 6.1.1 高压电池系统架构

```
        ┌─────────────┐
        │  BMU 主控    │ ← 对外 CAN / 绝缘检测 / 继电器驱动 / SOC 汇总
        └──────┬──────┘
               │ isoSPI / CAN（隔离）
   ┌───────────┼───────────┐
┌──┴──┐     ┌──┴──┐     ┌──┴──┐
│CMU 1│     │CMU 2│ ... │CMU n│  ← 每块从板管 12-18 串（LTC681x / BQ769x2 级联）
└─────┘     └─────┘     └─────┘
BDU 配电盒：主正/主负继电器、预充回路、熔断器、电流传感器
```

### 6.1.2 预充回路（必会设计）

- 为什么：母线电容（逆变器侧）直接上电 = 短路冲击，烧继电器触点；
- 时序：先合**预充继电器**（串电阻）→ 监测母线电压升到电池电压的 90–95% → 合**主继电器** → 断预充；
- 电阻计算：$t \approx 3RC$ 内完成预充，电阻功率按单次冲击能量 $E = \frac{1}{2}CU^2$ 选型（脉冲额定，不是连续功率）；
- 预充失败判据：超时母线电压不上来 → 外部短路或电容过大，禁止合主继电器。

### 6.1.3 绝缘检测（IMD）

- 电桥法：在 B+/B- 与机壳（地）之间交替投切已知电阻桥，测两组电压解方程得 $R_{iso+}$、$R_{iso-}$；
- 判据：车规通常 <500Ω/V 报警，<100Ω/V 故障；
- 误差源：母线电压波动、Y 电容充放电——采样要在投切稳态窗口内做。

### 6.1.4 EMC 与热失控防护

- 采样链是模拟小信号，功率回路是 du/dt 与 di/dt 源：分区布局、屏蔽、采样线双绞；
- 继电器线圈的续流与 PWM 保持（吸合后降占空比省电降温）；
- 热失控链：单体泄气 → 温度骤升 → 级联。BMS 能做的是**早发现**（温升速率 dT/dt 报警比绝对温度更敏感）与熔断隔离。

## 6.2 固件精通

### 6.2.1 量产状态机

在阶段 3 最小集合上扩展：

```
初始化 → 自检 → 待机 → 预充 → 就绪 ⇄ 充电 ⇄ 充电末端均衡
                         ⇅      ⇄ 放电
                        故障（分级：提示/限功率/断开）
                         ⇅
                        休眠 ⇄ 运输模式（深度低功耗）
```

规则：所有迁移集中在一个状态机函数里；每个状态明确"进入动作/周期动作/退出动作"；故障状态必须记录快照。

### 6.2.2 故障管理（DTC 体系）

- 每个故障：触发条件 + 去抖 + 等级 + 恢复条件 + 是否锁存；
- **快照**：触发瞬间冻结关键数据（电压、电流、温度、SOC、时间戳）——现场问题复盘全靠它；
- 故障码对外按 UDS 风格编码（车规）或自定义表（储能/消费）。

### 6.2.3 参数与标定系统

- 参数区：Flash 独立扇区，结构体 + 版本号 + CRC + **双备份**；
- 标定项：电流零漂（出厂必做）、电压增益、NTC 偏移；
- 防写穿：写次数计数 + 磨损均衡；参数更新先写备份区再切换。

### 6.2.4 Bootloader 与 OTA

- 双区（A/B）或 单区+备份 方案；
- 升级流程：接收 → CRC 校验 → 写备份区 → 标记切换 → 重启验证 → 失败自动回滚；
- 铁律：**bootloader 自身永不被 OTA 覆盖**；升级中断电必须能恢复原固件。

## 6.3 算法精通（阶段 4 的深化清单）

- OCV 滞回建模：在状态里加滞回电压项（Plett Vol. II 的方法）；
- 双卡尔曼落地：快/慢滤波器交替的节奏、慢滤波器的激励门控（电流变化不足时冻结参数更新）；
- SOP 完整版：多约束 + 持续时长分级（2s/10s/30s）+ 温度查表降额；
- 均衡策略工程化：入口条件（充电末端、压差 > 阈值、温度允许）、目标（电压对齐 vs 容量对齐）、热约束下的分时调度。

## 6.4 功能安全落地（以过充为例走一遍流程）

1. **危害识别**：单体过充 → 热失控起火；
2. **场景分析**：充电中电压采样失效 / MOS 粘连 / 充电机失控；
3. **ASIL 定级**：车用防过充通常 ASIL C–D；
4. **安全目标**：任何单点失效不得导致单体电压超过安全限值；
5. **功能安全要求（FSR）**：双通道独立保护——MCU 软件保护 + AFE/独立保护 IC 硬件保护；
6. **技术安全要求（TSR）**：ADC 自检与开线检测周期 <100ms；保护 MOS 驱动回路诊断；通信 CRC + 超时；独立看门狗；
7. **验证**：每类失效注入测试（断采样线、短路 MOS、停喂狗）确认硬件通道独立生效。

深入学习：[《车用 BMS 功能安全设计方法论》（MDPI Energies 2021）](https://www.mdpi.com/1996-1073/14/21/6942) + [batterydesign.net《BMS 功能安全》](https://www.batterydesign.net/battery-management-system/functional-safety/)。

## 6.5 量产与测试

### 6.5.1 出厂标定与 EOL 测试清单

- 标定：电流零点（零电流读数写入参数区）、电压增益（标准源比对）；
- EOL 必测：全串采样精度、通信收发、保护阈值抽测、绝缘电阻、静态功耗、固件版本与序列号烧录。

### 6.5.2 HIL 测试

- **电芯模拟器**：多通道可编程电压源模拟各串（入门可用电阻分压链，参考 [EEVblog 实操帖](https://www.eevblog.com/forum/projects/lithium-battery-cell-simulatoremulator-for-bms-testing/)）；
- **故障注入清单**：断任意采样线、短相邻采样线、NTC 开路/短路、通信中断、继电器粘连、电流超限——逐项验证 BMS 行为符合安全要求；
- 边界工况：-20°C 启动、满充保持、深度过放恢复、长期静置唤醒。

### 6.5.3 标准速查（按你的产品选）

| 领域 | 标准 | 一句话定位 |
|---|---|---|
| 车用功能安全 | ISO 26262 / GB/T 34590 | ASIL 体系母标准 |
| 车用 BMS 技术条件 | [GB/T 38661-2020](https://openstd.samr.gov.cn/bzgk/std/newGbInfo?hcno=DB3ACC49AC4A146FAA311BB468ACA290) | 技术要求与试验方法 |
| 车用 BMS 功能安全 | GB/T 39086-2020 | BMS 专属功能安全要求 |
| 储能 | UL 1973 / IEC 62619 | 固定式储能电池安全 |
| 消费/运输 | UL 2580、UN 38.3、IEC 62660 | 电芯级与运输安全 |
| 远程监控 | GB/T 32960 | 车载终端数据上报格式 |

## 6.6 毕业项目指南

**需求模板**（先写死再动手）：

```
串数/化学体系：16S LFP
持续/峰值电流：100A / 200A(10s)
保护清单：OVP/UVP/OCP×2/SCD/OTP/UTP/低温禁充/绝缘
均衡：被动 150mA，充电末端
算法：安时积分 + OCV 校准（+ EKF 加分项）
通信：UART（调试）+ CAN（系统）
结构：BMU 一体板 或 BMU + CMU×2
```

**里程碑**（每个里程碑都要可验证）：

1. 原理图评审（发 EEVblog / EEWORLD 求评）→ 2. PCB 投板焊接 → 3. 采样与驱动调通 → 4. 保护项全部实测通过 → 5. SOC 恒流误差 <5% → 6. 通信接入上位机 → 7. 完整文档（原理图说明、寄存器/协议文档、测试报告）

**发布清单**：开源仓库含 KiCad 工程、固件源码、BOM、测试报告、README（带实拍图与接线图）→ 发到社区接受评审。
