## 代码少算错三处

这三处在打 1.1.0 标签之后、文档大改之前就进了仓库。固件和协议的行为因此和旧说明不同，算法文件本身这一版社区页没有再改。

- 均衡该停会停：电流归零、拔枪，或电压掉出均衡门槛，同一拍关掉。拔枪后剩下的一点正电流，不再被当成「充满了」。
- 坏字节后面的好帧还能找回来。长度或 CRC 失败之后会接着扫，流结束时也可以 `flush()`。合法数据里碰巧出现的帧头，仍当数据。
- SOC 三条曲线在同一步上比较。以前真值和估计值会错开一拍，图上看起来像算法的错。

## 动画加到 147 张

仓库简介里曾经写「38 张」。那是更早的数。v1.1.0 的发布说明写的是 38 张加到 54 张。这一版未发布的改动把目录加到 **147** 张。

- 多出来的图是在讲机制：预充和短路的时间、均衡的能量、采样怎么排队、卡尔曼怎么校正、CAN 怎么仲裁。数字标着示意，不是示波器截图。
- 旧图也加了沿曲线移动的点和底栏数字，文件名没换，原来的链接还在。
- 和「147」直接对应的三批是 PR #20（94→109）、#21（109→125）、#22（125→147）。更早的加图在 #6、#7 和再往前的文档提交里，更新日志按 54 以后的台阶记着。

## 导读、预算和链接

- Plett 两门课 14 章都有了中文导读。先是需求章和电池入门（PR #10、#11），其余十章在 PR #15。讲义里的算例仍然不是保护阈值。
- 预算清单补了推荐开发板（PR #12），又按能打开的页面复核了价位（PR #16）。焊台改到立创商城上能巡检的安泰信 AT937A 页面（PR #19）。美元不换算成人民币。隔离 USB 模块没有换成一个「看起来差不多」的链接。
- 会把巡检拖垮的大 PDF 直链拿掉了（PR #8，SDSU 上的作者稿）。野火 CAN 那一页在 runner 上超时，链接留着，域名排除（PR #14）。页面还在，只是机器人不稳。
