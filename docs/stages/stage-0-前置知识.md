## 0.1 锂电池化学基础

### 0.1.1 锂电池怎么工作（极简版）

- 充电：锂离子从正极脱出，经电解液嵌入负极石墨层间；放电时反向。
- 正极材料决定特性：
  - **三元锂（NCM）**：能量密度高，热稳定性差，乘用车主流；
  - **磷酸铁锂（LFP）**：安全、寿命长、成本低，但电压平台极平（SOC 难估）；
  - **钴酸锂（LCO）**：消费电子。

### 0.1.2 为什么过充过放"碰不得"

- **过充**：正极过度脱锂 → 结构坍塌；电解液氧化分解产气 → 鼓包；严重时负极析锂形成锂枝晶 → 刺穿隔膜 → 内短路 → **热失控**（起火）。
- **过放**：负极铜集流体氧化溶解；再次充电时铜在隔膜上沉积成枝晶，容量永久损失，甚至内短路。
- **温度约束**：
  - 低温（<0°C）充电：锂离子来不及嵌入石墨层，只能在负极表面析出金属锂——所以 BMS 必须禁止低温大电流充电；
  - 高温（>45°C）：SEI 膜加速生长，老化速率倍增。

### 0.1.3 关键参数（要求背下来）

| 参数 | 三元锂 NCM | 磷酸铁锂 LFP |
|---|---|---|
| 标称电压 | 3.6 / 3.7 V | 3.2 V |
| 满充电压 | 4.2 V | 3.65 V |
| 放电截止电压 | 2.8–3.0 V | 2.5 V |
| OCV 平台 | 有明显斜率 | 极平（SOC 估计难点） |

- **容量 Ah**：1Ah = 以 1A 电流放电 1 小时。能量 Wh = Ah × 标称电压。
- **C 倍率**：1C = 1 小时放完额定容量的电流。例：10Ah 电池 0.5C 充电 = 5A。
- **内阻**：欧姆内阻 + 极化内阻；随温度降低、SOC 降低、老化加深而增大。内阻是 SOP（峰值功率）估算的核心变量。

### 0.1.4 CC-CV 充电（必须吃透）

1. **预充**（可选）：深度过放的电池先用小电流（0.05–0.1C）恢复到安全电压；
2. **恒流 CC**：恒定电流充至满充电压；
3. **恒压 CV**：恒定电压，电流自然衰减，降至截止电流（0.05–0.1C）判为充满。

- 为什么不能一直恒流到底：极化会让端电压虚高，强行恒流会导致过压析锂。
- 重要结论：**"电压到达 4.2V"不等于"充满"**，必须等 CV 段电流衰减到截止值。这也是 BMS 做 SOC=100% 校准的正确时机。

### 0.1.5 SOC 与 SOH 的定义

- **SOC（荷电状态）** = 剩余可用容量 / 当前满充容量，0–100%；
- **SOH（健康状态）** 两种口径：
  - 容量口径 = 当前满充容量 / 出厂额定容量；
  - 内阻口径 = 当前内阻 / 初始内阻。
- 这两个量是 BMS 算法的核心输出，阶段 4 专攻。

## 0.2 电路基础（只学 BMS 用到的部分）

### 0.2.1 分压与 RC 滤波

- AFE 每串采样输入前都有一级 RC：限流保护 + 抗混叠滤波 + ESD 泄放。
- 截止频率 $f_c = \dfrac{1}{2\pi RC}$。
- 阻值/容值必须按 AFE 数据手册推荐值选取，切忌随意改：
  - R 过大 → AFE 输入漏电流在 R 上产生额外压降，直接变成采样误差；
  - C 过大 → 均衡开关切换后电压稳定时间变长，采样与均衡互相干扰。
- **断线检测**：采样线断开时，该串读数会被邻近串的滤波电容拉偏而显示异常——这是 BMS 必做的诊断项，阶段 3 会用到。

### 0.2.2 ADC 与误差链

- **分辨率 ≠ 精度**。12bit 只说明量化台阶足够细；真实精度由基准电压误差、失调误差、增益误差、INL、温漂共同决定。
- BMS 要求单体电压测量达到 ±5mV 量级：靠 AFE 内部出厂校准 + 产品出厂标定实现。
- 参考电压（基准源）的温漂会 1:1 进入误差预算，分析误差时从它开始。

### 0.2.3 MOSFET 作为保护开关

三个关键参数：

- $V_{DS}$ 耐压：必须大于整包最高电压加裕量；
- $R_{DS(on)}$ 导通电阻：决定发热 $P = I^2 R$，多颗并联可分摊；
- $Q_g$ 栅极电荷：决定驱动难易与开关速度。

- **体二极管**：单颗 MOS 的寄生二极管使其无法双向阻断 → 同时禁止充电和放电需要**两颗背靠背**串联（共源极或共漏极）。
- **雪崩耐量（EAS）**：关断感性负载时的能量冲击指标，继电器/接触器回路要核算。

### 0.2.4 电流采样

| 方案 | 优点 | 代价 |
|---|---|---|
| 低边分流电阻 | 简单便宜 | 抬高地电位；无法检测对电池负极短路 |
| 高边分流电阻 | 地干净 | 需要高共模放大器或隔离 ADC |
| 霍尔 / 磁通门 | 电气隔离，可测大电流 | 精度与零漂是挑战，需出厂零漂标定 |

储能/车用主流是高边分流或霍尔；SOC 安时积分的精度上限由电流传感器决定。

### 0.2.5 隔离

- 为什么必须隔离：电池包负极与整车地/大地不等电位；菊花链上相邻从板共模电位可能相差几十到几百伏。
- 常用手段：数字隔离器（磁耦/容耦）、光耦、隔离 DC-DC 电源、isoSPI 这类变压器耦合差分链路。

## 0.3 嵌入式开发基础

### 0.3.1 BMS 用到的 MCU 外设

- **GPIO**：继电器/MOS 驱动、外部唤醒、LED/蜂鸣器；
- **ADC**：NTC 温度采样、辅助电源监测；
- **定时器/PWM**：均衡驱动时序、看门狗喂狗节奏；
- **独立看门狗（IWDG）**：安全件必备——主循环卡死时自动复位，配合硬件保护 IC 构成双保险。

### 0.3.2 三种通信接口的要点与坑

| 接口 | 最常见的坑 |
|---|---|
| I2C | 忘加上拉电阻；地址冲突；从机时钟延展；总线锁死（SCL 打 9 个脉冲恢复） |
| SPI | CPOL/CPHA 模式配错数据全乱；片选时序；菊花链级联 |
| UART | 波特率误差需 <2%；3.3V/5V 电平不匹配；未共地 |

- AFE 典型接口：TI bq769x0 系列用 I2C；ADI LTC6811 用 SPI，多板级联用 isoSPI。

### 0.3.3 C 语言关键点

- `volatile`：硬件寄存器、中断与主循环共享的变量必须声明，否则编译器优化会读旧值；
- 位操作：读-改-写寄存器（`|=`、`&= ~`、移位）——AFE 配置全是位域；
- 固定宽度类型 `uint8_t/uint16_t/uint32_t`：协议解析必备；
- 结构体打包与字节序：解析通信帧时注意对齐与大端/小端。

### 0.3.4 怎么读数据手册（以 TI BQ76920 为例）

1. 先看**功能框图**：采样输入 → MUX → ADC → 控制逻辑 → 通信接口，建立整体观；
2. 再看**寄存器地图**：状态寄存器（电压/温度/故障标志）与配置寄存器（保护阈值、均衡使能）分两类记；
3. 看**时序图**：上电顺序、通信建立时序；
4. 应用电路**照抄官方推荐**，第一版不要自由发挥。

### 0.3.5 开发环境建议

- **STM32**：HAL 库上手最快；LibreSolar 固件基于 Zephyr RTOS，顺带可以学 RTOS 与设备树；
- **ESP32**：ESP-IDF 或 Arduino，阶段 5 对接商用 BMS（UART/BLE）的主力平台。
