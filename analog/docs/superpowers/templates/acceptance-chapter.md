# 章末验收清单模板（每章通用）

> 用法：每章 `<!-- slot:selfcheck -->` 槽内放本清单。**观察 / 计算 / 测量三条里至少勾两条才算本章过关**；设计类章（ch14、ch16、ch18）另须指向设计说明作业（见 `acceptance-design-note.md`）。

```markdown
### 验收清单
- [ ] 观察：〈本章现象级证据，桌上或仿真里能看到的一件事〉
- [ ] 计算：〈用手算或仿真复核的一道本章数值题，条件写全〉
- [ ] 测量：〈用万用表 / 示波器 / 仿真探针可复现的一次测量，写明判据〉
```

写清单的三条规矩：

1. 每条都能判对错——判据写清数值范围或预期波形，不留「大概理解了」式软项。
2. 数值题条件写全（电源、阻值、温度、信号频率），无出处不写死数字。
3. 测量条注明仪器与合格判据；无法实测时允许写仿真步骤与预期读数。
