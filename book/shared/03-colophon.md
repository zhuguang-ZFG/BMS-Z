# 版本、许可与勘误

## 版本

- 合并版以两卷原有编号与页序为准；正文不因合并重排。
- 每卷独立构建 HTML、PDF 与 EPUB，产物版本与构建报告一并发布。
- 目录、页序与两卷 manifest 对账；跨卷引用由构建期审计拦截悬空目标。

## 许可

- 正文：CC BY-SA 4.0。
- 代码：MIT。
- 卷一转入的第三方图片、字体与工具仍按原许可署名，清单见卷一「版权、引用与勘误」页与仓库 LICENSE。

## 引用

引用本书请注明书名《从模拟电路到 BMS》、卷次、章节与版本。两卷可分别引用；跨卷引用沿用「卷一/卷二·第 N 章《标题》」格式。

## 勘误

请在项目仓库的 Issues 中附上卷次、章节、版本与复算过程。确认的勘误进入下一版构建报告；不静默改写历史版本。
