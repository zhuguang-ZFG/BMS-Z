# m04 故事线：预充超时能不能再等等

## 推荐 A · 一条爬不动的曲线

**装置与形式**　沿用同一条母线电压曲线和预充支路。前半段为理想恒压源、空电容、无并联负载：400 V、1 mF、170 Ω，0.17 s 约 253 V，约 0.51 s 到 380 V。95%仍差20 V；主闸竖线须以完整许可成立为前提，不能由比例单独触发。后半段换成约40 V的异常示意，超时未达设计条件则禁止合闸，根因待查。

- 前两秒：曲线上一个红点停在 40 V，旁边写着「再等等？」；笔尖把问号圈住，不给答案。
- 节拍：先算正常例 → 为什么不能直接合主闸 → 三步顺序 → 命令与反馈 → 能量分账 → 回到异常曲线 → 判据 → 复算。沿用5段/12个beat，不新增镜头。
- 画面：FH-022 课本边角漫画；孔雀蓝画曲线与反馈，那不勒斯黄画时间常数与算式，赭石画合闸动作，红色只标「禁止合闸」。
- 声音：曲线停住时用短 whoosh；主闸允许合上那一拍用 tick；禁止合闸用 blip。

同一组参数贯穿全片，曲线与证据清单一起解释：有效测量、压差/过程、保护时序、独立反馈和器件接通限制。命令不是反馈，辅助触点不单独证明主路径导通或断流。约40 V只描述示意曲线；支路、负载、参数和测量均可能造成升压不足。

## B · 三个继电器排队上班

把小继电器、主继电器、预充支路画成三个排队的小人，谁先动手谁后动手。人物记忆点强，但会把「为什么」压成「谁先谁后」，预充失败判据只能当旁白补，容易变成流程背诵。

## C · 一笔焦耳账

可用源供/阻热/容储三账展开选型专题：到95%为152＝79.8＋72.2 J，理想稳态160＝80＋80 J。电容储能没有全变成阻热，脉冲曲线、瞬时功率、重复间隔与热降额还须核对。本片用这笔账支持许可与器件边界，完整选型留给阶段6深读。
