# 每章引用清单模板（发布前勾选）

> 用法：每章 `<!-- slot:citations -->` 槽（`### 参考与出处`）发布前对照勾选；`scripts/check_references.py` 做静态扫描。

```markdown
### 参考与出处（发布前勾选）
- [ ] 关键数字可回溯到 datasheet / 应用笔记 / 已验证算例（写明型号与章节或 URL）
- [ ] 示意数量已标「示意」，未写成保证值
- [ ] 本章至少 1 条 `analog-book/data/references.yml` 的 `ref-***` 已列入 `chapters`
- [ ] 若引用 GitHub OSS：已登记 license + 用途（灵感/工具），未复制无许可代码
- [ ] 未把可选教法读物（如杨建国风格笔记、ADI《新概念模拟电路》PDF）当成参数权威源
```

写法规矩：

1. 每条引用给出**可检索的身份**：书用 ISBN/作者+书名；datasheet 用「厂商 + 型号」；网页用官方 URL，不写会过期的深层直链。
2. 「参考与出处」承载出处，不承载广告位：与本章数字无关的延伸视频放「配套视频」，不混入。
3. 《新概念模拟电路》等教法读物标 `optional-deep-read`，只进阅读推荐，不进参数溯源链。
