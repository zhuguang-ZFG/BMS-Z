# m02 故事线：电压什么时候能当 SOC 的尺子

## 推荐 A · 一张读数过四道资格门

**装置与形式**　一条刚撤掉放电电流的记录从左到右穿过四道门：电流归零、变化率够小、温度匹配、充放电历史匹配。每过一门，读数才更接近“可查表的 OCV”。

同一个样本从 3.450 V 带载、3.490 V 刚撤流，慢慢走向 3.620 V 放电支；最后把它放到 LFP 平台上，5 mV 仍能盖住约 6.7 个百分点，说明“合格参考”也有信息强弱。

- 前两秒：电流刚归零，屏幕立刻盖章“OCV？”又被红笔划掉。
- 节拍：刚撤流 → 立刻回弹 → 慢松弛 → 滞回仍在 → 平台斜率 → 四门资格 → 复答
- 画面：同一条曲线连续增长；四道门只在结尾汇总，不用四张并排卡片。
- 声音：回弹用短促 blip，资格门逐项通过用轻 tick，BGM 中性。

## B · 电压尺的刻度会伸缩

把 OCV 曲线画成一把会变形的尺子：两端刻度拉开，平台区刻度挤在一起；同样 5 mV 的噪声块盖住不同数量的 SOC 刻度。它非常适合解释平台斜率，但会弱化“刚撤流不能查表”的时间条件。

## C · 两条历史轨道

同一 SOC 上，充电轨和放电轨并行，静置样本必须先确认来自哪条轨道。形式是两条铁路合而不并。它能讲透滞回，却装不下温度、变化率与平台信息，因此留作滞回专题。
