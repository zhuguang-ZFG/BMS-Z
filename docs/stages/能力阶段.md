# 五个能力阶段：从看懂电池到交付系统

> 这是一张能力检查表，不是另一套课程。默认学习顺序仍是 [24 课连续课程](../course/index.md)；本页回答“现在能做什么、下一步缺什么”。
>
> 它与 `docs/stages/` 的 stage 0–7 不同：stage 是专题练习场，能力阶段是跨课程、阶段页、书稿与工程单元的能力检查点。它也与单个知识点的 L1–L5 梯子不同：梯子量一个知识点有多深，阶段量一组能力有没有接上。
>
> 前置用短任务核对，不要求先读完某章；过关看可观察证据，不看读完打卡。计划中的单元（D13–D28、C2–C4、R01–R04）仍按计划身份标注，不当作已交付。

## 入门——看懂电池与安全边界

**先修自检**：能换算 V、A、Ah、Wh，说清电流方向；不要求电化学。若这四项说不清，先做 [第 1 课](../course/01-units.md)。

**必修**：电芯、模组、电池包与 BMS 的职责；电压、电流、容量、能量、倍率与串并联；充放电过程，以及温度、内阻、极化对端电压的影响；开路电压与端电压的区别，SOC 不能直接等同于电压百分比；不同化学体系的差异与实验安全边界。入口：[第 1–3 课](../course/01-units.md)、[阶段 0](stage-0-主线-电池.md)、[阶段 1](stage-1-认识BMS.md)、[D01–D03](../../bms-book/engineering/README.md)。

**动手**：用注明来源的公开数据或仿真数据，画一组充放电的电压、电流、温度与累计 Ah/Wh 曲线。

**交付物**：曲线图 + 数据来源、单位、工况 + 「这组数据能/不能支持什么」的短说明。

**过关条件**：独立复算容量与能量，统一单位和电流方向；解释负载掉压与静置回弹；指出数据不能支持哪些结论。

**下一站**：[基础](#基础让测量结果可信)。

## 基础——让测量结果可信

**先修自检**：完成入门；会分压/分流、代数和采样基本概念。短任务：给一条采样链标出参考点、量程和电流方向。需要补课先看 [B01 电路与能量](../../bms-book/bridges/B01-电路与能量.md) 与 [B03 误差矩阵与拟合](../../bms-book/bridges/B03-误差矩阵与拟合.md)。

**必修**：分压、分流器、NTC 与 ADC 的工作原理；采样时序、量化、偏置、增益误差、温漂与标定；误差预算，以及独立性与相关性如何进入合成；滤波效果与检测延迟的取舍；电流偏置怎样造成 SOC 累积漂移。入口：[第 4–6 课](../course/04-first-run.md)、[D04 测量与误差传播](../../bms-book/engineering/D04-测量与误差传播.md)、[D05 AFE 与动态采样](../../bms-book/engineering/D05-AFE与动态采样.md)、[S1 样章](../../bms-book/engineering/S1-精度够了保护为什么反而慢了.md)、[measurement_budget.py](../../bms-book/code/measurement_budget.py)。

**动手**：完成一条电压或电流测量链的设计说明、误差预算、标定与独立验证。

**交付物**：测量链说明、误差预算、标定数据、独立验证数据与对比报告。

**过关条件**：标定数据与验证数据分开；能比较修正前后误差；解释不同量程与温度下的表现；量化误差对后续算法和保护的影响。

**下一站**：[进阶](#进阶让采集保护与通信可靠协同)。

## 进阶——让采集、保护与通信可靠协同

**先修自检**：完成基础；了解中断/任务、超时、CRC 与状态机基本概念。短任务：画一次超时后的故障锁存与恢复。需要补课先看 [B04 时间与状态](../../bms-book/bridges/B04-时间与状态.md)。

**必修**：AFE 采样、开线诊断、均衡条件与限制；MOS、接触器与预充过程；保护阈值、迟滞、去抖、锁存与恢复；MCU 驱动、CRC、超时、重试、看门狗与数据新鲜度；上电、自检、运行、故障、降级与恢复状态机。入口：[第 7–9 课](../course/07-limits.md)、[第 13–18 课](../course/13-charging.md)、[D06–D10](../../bms-book/engineering/README.md)、[D08 保护与时间预算](../../bms-book/engineering/D08-保护与时间预算.md)、[S3 样章](../../bms-book/engineering/S3-预充时序母线起来了许可还差四样证据.md)、[固件状态机](../../code/firmware/bms.c)。D19–D20、D22–D23 仍为 planned。

**动手**：在模拟输入或受控低能量台架上，完成「采集→判断→动作→恢复」完整链路，并注入断线、通信超时、CRC 错误、复位与陈旧数据。涉及真实硬件的部分先看 [阶段 2 的安全纪律](stage-2-保护板实践.md)。

**交付物**：状态转移表、故障注入用例、可重放日志与测试记录。

**过关条件**：每个状态转移都有输入条件、时限、输出动作和恢复条件；输入失效后不得继续使用旧数据获得运行许可；所有关键故障有可重放日志与测试证据。

**下一站**：[工程](#工程用证据建立-socsoh-与-sop)。

## 工程——用证据建立 SOC、SOH 与 SOP

**先修自检**：完成基础与进阶；具备线性代数、概率统计和数据划分基础。短任务：说明辨识数据与验证数据为何必须分开。需要补课先看 [B02 变化与采样](../../bms-book/bridges/B02-变化与采样.md)、[B03 误差矩阵与拟合](../../bms-book/bridges/B03-误差矩阵与拟合.md)、[B05 数据身份与留出](../../bms-book/bridges/B05-数据身份与留出.md)。

**必修**（按序）：电流积分及误差累积；OCV 校正的温度、静置、滞回与平台区限制；等效电路模型、HPPC、参数辨识与离散化；可辨识性、激励条件与独立验证；EKF 的状态、观测、雅可比、噪声协方差、初始化与残差；SOH 指标、参考值来源与 SOP 多约束。入口：[第 10–12 课](../course/10-counting.md)、[D02 动态等效模型](../../bms-book/engineering/D02-动态等效模型.md)、[D11 HPPC 与参数辨识](../../bms-book/engineering/D11-HPPC与参数辨识.md)、[D12 SOC 基线与校准](../../bms-book/engineering/D12-SOC基线与校准.md)、[S2 样章](../../bms-book/engineering/S2-一条电压曲线能识别出多少东西.md)、[soc_coulomb_ocv.py](../../bms-book/code/soc_coulomb_ocv.py)。D13–D17 仍为 planned。

**动手**：在相同验证工况下比较电流积分、OCV 辅助与 EKF；分析容量、内阻与功率限制随温度、SOC 和老化的变化。

**交付物**：模型卡、参数集、辨识记录、验证报告、SOP 约束与预测时间窗。

**过关条件**：辨识数据与验证数据隔离；报告平均误差、最大误差、收敛时间和失效场景；能解释算法何时优于基线、何时失效；不以同一模型生成的数据验证自身后宣称已获实测验证；SOP 说明预测时间窗，并考虑最弱单体、电压、电流、温度和老化约束。

**下一站**：[精通](#精通解释取舍并交付可复现系统)。

## 精通——解释取舍并交付可复现系统

**先修自检**：完成工程；具备需求、版本、测试与 V&V 基本概念。短任务：把一条需求写成可观察的验收条件。

**必修**：需求追踪、整包误差与时序预算、功耗预算、异常降级、保护独立性、系统故障注入与版本化发布。入口：[第 19–24 课](../course/19-loop.md)、[阶段 6 毕业项目](stage-6-精通与毕业项目.md)、[32 章深读](../reading.md)。D21、D24–D28、C4、R01–R04 仍为 planned；C1 为现有草案，不等于综合项目完成。

**综合项目**：针对明确的化学体系、串数、用途和温度范围，交付一套参考 BMS。

**交付物**：需求与架构说明、数据及来源、模型参数、代码、依赖说明、测试用例、测试结果、运行日志、发布说明和已知限制。

**过关条件**：另一位读者能在干净环境复现约定结果；关键需求都有对应证据；能解释模型、滤波、保护时间和恢复策略的选择依据。教材项目通过不等同于获得认证或满足量产安全要求。

## 怎么用这张表

- **默认按 24 课顺序学习**。阶段是检查点，不是跳课许可证；每次过关后再进入下一阶段的高阶内容。
- **已有基础**：先做阶段前的短任务。通过可跳读对应课程，但安全边界、独立验证和来源核对不能跳。
- **没过关**：回到链接的课或单元补证据；没有证据的能力写「待核查」，不写成「已掌握」。
- **按目标选专题**：见 [按目标选路线](按目标选路线.md)；需要推导、完整案例和来源时见 [32 章深读](../reading.md)。
- **本页只指路**：不复制课程正文，也不把 planned 单元当作已交付；详细合同见 [整库 SPEC §12](../教材彻底改造SPEC.md#12-能力阶段单元闭环与样板单元2026-11-10-补充)。
