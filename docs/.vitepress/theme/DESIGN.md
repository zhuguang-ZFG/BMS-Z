# BMS-Z 界面与文案约定

网站面向独立学习 BMS 的读者。先给一个能理解、能操作的例子，再提供教程、书与实验入口。

## 改造前的问题

- 首页三枚主按钮、四张资源卡和四条目标路线重复承担导航，开始学习前需要连续作选择。
- 标题与摘要反复使用“证据链”“闭环”“交付”等词，读者仍需要自己推断具体要做什么。
- 电芯插画与页面深色主题不匹配；卡片胶带、不规则圆角和硬阴影把注意力分散到装饰上。
- 清单勾选被叫作“包 SOC”，容易把学习完成情况与电池状态混淆；未开始的阶段也没有进入最小值计算。
- 首页内容包含几个层次相近的大面板，阅读和实际操作之间缺少直接联系。

## 设计方向

产品：中文 BMS 自学手册，提供分节教程、伴读书、动画和可运行实验。

性格：耐心、准确，有纸本笔记的温度。

材质：实验台上的手册、墨线、电芯与测量记录。保留已有纸墨配色和青色链接，和现有技术插图保持一致。

重点画面：首页的可操作掉压图解；伴读书的封面预览。其他导航使用轻边线和文字。

统一细节：墨线下划线和测量标注。手绘用于解释电芯与电路关系，不给每张卡叠胶带、随机圆角或噪点滤镜。

## 结构与维护

- `HomeWorkshop.vue` 组织首页；`home.css` 只作用于首页组件和首页容器。
- 首页正文由 Vue 组件渲染，不进入 VitePress 的 Markdown 本地搜索；`docs/index.md` 明确标记 `search: false`，搜索入口仍覆盖全部教程、伴读书和资料页。
- `VoltageNotebook.vue` 用原生 SVG 与范围输入联动电流、电压、计算式和曲线。示例取 `Uoc = 3.70 V`、`R₀ = 20 mΩ`，电流范围 `0–30 A`，仅展示 `U = Uoc − I × R₀`。
- 图中电压表与负载并联；示例不把极化、温度变化或容量消耗画成已建模结果，不提供电芯规格或保护阈值。
- `index.data.ts` 保持构建期数据与清单条目同源；动画数量从资产目录计算，并由产物检查核对首页实际显示。清单状态继续使用既有存储格式，完整讲义和拆分页中同一条验收去重计数。
- 主线入口使用拆分后的阅读页；完整讲义、能力地图、共学、全部目标路线和参考资料仍有入口。
- `custom.css` 负责全站阅读、侧栏、代码、表格、深色和打印样式。技术图表的语义配色继续来自 `tools/visual_palette.json`。
- 正文优先交代现象、条件和下一步操作。公式、数值、单位、参考来源与确定程度不能因精简文案而丢失。
- 改动生成页时应修改源稿或生成器，再运行对应准备脚本；不直接改 `docs/book/` 或阶段拆分页。

## 检查

构建使用 `npm run docs:build`；站内链接与锚点使用 `.github/scripts/check_pages.py`。界面需检查桌面与手机、浅色与深色、键盘操作、撤去负载和最大电流、清单读写与页面切换。

本次设计流程参考 Unslop，作者 Damir Sokolovsky，CC BY 4.0；中文文案按 Humanizer-zh 检查；手绘方向参考 Handraw 的概念线描条目（Conceptual Line Drawing：极少线条、视觉隐喻、留白）。界面图解为项目内可维护 SVG，不含外部生成图片。
