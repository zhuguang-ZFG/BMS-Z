# 设计说明作业模板（「精通」落地标准）

> 来源：spec §4.2 原样拷贝。读者（或章末设计作业提交物）必须能交出一份**设计说明**，至少含下表五块。达不到 = 本章/本阶段未过关；**题库分数不能替代**。

| 块 | 必须有 |
|---|---|
| 指标 | 输入/输出范围、带宽或响应、功耗或效率、精度、环境温度 |
| 选型 | 关键器件型号或明确选型窗（含备选与否决理由） |
| 极限工况 | 至少 3 个 corner（温度、负载、供电、容差等）及预期行为 |
| 测试步骤 | 可复现的测量顺序、仪器与合格判据 |
| 失败预案 | 若不合格，优先怀疑点与下一刀测量 |

各块写作要求：

1. **指标**：五类指标写全且可测；缺一类或写了「足够快」式模糊量即不过关。
2. **选型**：给出型号或明确选型窗；备选与否则理由各一句。
3. **极限工况**：至少 3 个 corner，每个写「工况 → 预期行为」。
4. **测试步骤**：按测量顺序编号，写明仪器档位与合格判据。
5. **失败预案**：写优先怀疑点排序与下一刀测量；「再检查一遍」不算。

打分口径见 `docs/superpowers/rubrics/design-note-rubric.md`（过关/不过关，不是证书）。
