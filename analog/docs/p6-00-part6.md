# 第六篇：常用芯片实物图鉴与速查

> 这一篇不讲原理，只当工具书用：认元件、查型号、读手册、读色环；要知道"为什么"，从每张表跳回对应章节。

## 本篇地图

| 节 | 用来干什么 |
|---|---|
| [6.1 实物图鉴](p6-01-s6-1.md) | 认脸：晶体管、电容、电阻、LED、功率管的实物照片 |
| [6.2 常用芯片速查表](p6-02-s6-2.md) | 运放/比较器/基准/稳压等常用型号一句话选型 |
| [6.3 官方 datasheet 直达](p6-03-s6-3.md) | 原厂官网直链，认准厂家 Logo |
| [6.4 datasheet 阅读法](p6-04-s6-4.md) | 50 页手册只读 6 个地方，10 分钟拿到设计参数 |
| [6.5 元件标识速查](p6-05-s6-5.md) | 色环、数码法、耐压码——拿到手就能读出值 |

## 怎么读这一篇

- **遇到具体元件时来查**，不必通读；每张表的设计目标都是 1 分钟内给出答案。
- 读不懂参数含义时，跳回 [第 6 章 6.3 节的逐项解析](p1-07-ch6.md#sec-6-3)。
