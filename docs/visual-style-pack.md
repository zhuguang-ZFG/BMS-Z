## 禁区

- 无人、无卡通 IP、无萌系角色、无假品牌 Logo。
- 不写「实拍」「示波器截屏」「真机照片」。
- 不大面积铺 C-15；不引入第三主色。
- 不把静态帧伪装成假 SMIL 动画。

## 图注合同

每图必须带「原理示意 / 非实拍」。正文链接处保留观察题。

## 与动画画风规范的过渡

- 未归档旧 SVG 仍守 `docs/circuits/动画画风规范.md`（`viewBox` 800、SMIL、类名配色）。
- handraw 产物不要求 `viewBox 800` 与类名配色体系；但导出动画须可暂停，首末帧须静态可读、可打印。
- 同一图不得双源并存：换链后旧 SVG 进 `archive/`。
