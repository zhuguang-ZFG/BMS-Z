# 器材与预算清单

> 走完整条学习路线（阶段 0–6）要买什么、大约多少钱、什么可以省。
> 价位为 2026 年国内电商/二手的**参考量级**，会波动；关键词都给了，自行比价。
> 两条原则：**安全装备不议价**；**软件能解决的先不买硬件**（阶段 4 全程零器材）。
> 零基础学习顺序见 [前两周怎么走](stages/getting-started.md)——前两周不必买齐后面阶段的东西。

## 总账

| 路线 | 内容 | 合计（量级） |
|---|---|---|
| **最低路线** | 必需项 + 二手/自制替代 + 示波器靠借 | **¥600–1000** |
| **舒适路线** | 必需项全买新 + 入门示波器 | **¥2500–4500** |
| 毕业项目另计 | 打板 + 物料 + 结构件（视规模） | ¥500–2000 |

## 安全装备（最先买，不议价）

| 物件 | 参考价 | 说明 |
|---|---|---|
| 护目镜 | ¥20–50 | 电解液喷溅防护，真电池操作必戴 |
| 防火垫 / 灭火沙 | ¥50–100 | 操作台标配；锂电起火首选**大量水或水基灭火器**降温防复燃（干粉只压明火、易复燃）；沙土用于围堵蔓延 |
| 耐温手套 | ¥20–40 | 测均衡电阻温升、拆板时防烫 |

## 分阶段清单

### 阶段 0–1（认识 BMS）：¥100–300

| 物件 | 参考价 | 必需 | 替代方案 |
|---|---|---|---|
| 万用表 | ¥60–150 | ✅ | 借用；优利德/胜利入门款足够 |
| 旧 18650 / 旧手机电池 | ¥0 | ✅ | 拆闲置设备（鼓包漏液的不要） |

### 阶段 2（保护板实践）：¥200–500

| 物件 | 参考价 | 必需 | 替代方案 |
|---|---|---|---|
| 3S/4S 保护板成品 ×2 | ¥10–40 | ✅ | 注意先报化学体系（三元/铁锂阈值版本不同） |
| 可调直流电源（30V/5A） | ¥200–400 | ✅ | 二手；或先用 12V 电源 + 分压链做 3 串以内实验 |
| 电阻分压链材料（电芯模拟器） | ¥20–30 | ✅ | 精密电阻 + 洞洞板，做法见 [阶段 2 §2.6](stages/stage-2-保护板实践.md) |
| 电子负载 | ¥200–600 | 可选 | 大功率电阻 + 开关 + 电流表自己搭 |
| 微安表（μA 档） | ¥0–150 | 可选 | 入门万用表的 μA 档通常够用 |

> ⚠️ 别买"多路输出"台式电源当电芯模拟器——必须确认**每路隔离浮地**，否则烧板烧电源（教程里的经典死因）。

### 阶段 3（AFE + MCU）：¥300–800

| 物件 | 参考价 | 必需 | 替代方案 |
|---|---|---|---|
| STM32 开发板 + ST-Link | ¥50–150 | ✅ | 任意手头的 MCU 板都可起步 |
| AFE 开发板 / 评估板 | ¥100–300 | 二选一 | 或直接打板：立创 EDA 免费打样 + 物料 ¥100–300 |
| 逻辑分析仪（24MHz 8ch 入门款） | ¥30–60 | ✅ | 调试 I2C/SPI/UART 的性价比之王，买 |
| 焊台 + 耗材 | ¥100–300 | ✅ | 借用/学校实验室 |
| 热风枪 | ¥100–200 | 可选 | 拆焊多脚芯片才需要 |

### 阶段 4（算法）：¥0

| 物件 | 参考价 | 说明 |
|---|---|---|
| PC + Python（numpy/matplotlib） | ¥0 | 先用本仓库 [code/soc](../code/soc/) 跑通三种估算器 |
| MATLAB/Simulink | 校园版/试用 | 非必需，Python 全替代 |
| 公开电池数据集 | ¥0 | [Battery Archive](https://www.batteryarchive.org/) |

### 阶段 5（通信与集成）：¥100–400

| 物件 | 参考价 | 必需 | 替代方案 |
|---|---|---|---|
| ESP32 开发板 | ¥25–60 | ✅ | 带 BLE，阶段 5 主力 |
| 隔离 USB 串口 | ¥40–100 | ✅ | **别省**——教程反复强调的共地风险就靠它挡 |
| 商用 BMS 一块（JK/JBD/小象） | ¥100–300 | ✅ | 二手即可；逆向与集成对象 |
| USB-CAN 适配器 | ¥100–300 | 可选 | 不做 CAN 对接可先不买 |

### 阶段 6（毕业项目）：¥500–2000+

打板、物料、结构件视方案定；参考 [毕业项目指南](stages/stage-6-精通与毕业项目.md#66-毕业项目指南-创造) 的需求模板先算 BOM。

## 缓买清单（新人最容易浪费钱的地方）

| 物件 | 为什么缓 |
|---|---|
| 示波器 | 阶段 2 才开始有用，且入门款（¥1500–3000）在此之前全程吃灰；先借/用学校实验室。**真要用时记住：探头地夹直通大地，夹错点烧板**（[阶段 2 §2.6](stages/stage-2-保护板实践.md)） |
| 可调电子负载（大几百的专业款） | 入门用电阻 + 开关足够完成保护实测 |
| 热成像仪 | 只有调试均衡热设计才用得上；先"手摸 + 温度贴片" |
| 成品多通道电芯模拟器 | 自制分压链 ¥30 解决入门需求；HIL 阶段再考虑 |

## 省钱渠道

- **二手**：示波器、电源、商用 BMS 在闲鱼大量流通，BMS 逆向练习买二手反而好（本来就要拆）；
- **学校/公司实验室**：示波器、电源、焊接设备先借用，确认自己会坚持走下去再购置；
- **立创**：EDA 免费 + 每月免费打样券，阶段 3 打板成本主要剩物料；
- **开源平替**：逻辑分析仪固件（sigrok/PulseView 免费）、Python 替代 MATLAB。
