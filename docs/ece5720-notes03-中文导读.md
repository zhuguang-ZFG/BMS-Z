## 一、一页速览

原文的逻辑链：

1. **SOC 没有传感器**（3.1）——只能用电压、电流测量**推断**；
2. 纯电压法、纯电流法都有硬缺陷（3.2）——出路是**模型+滤波**把两者融合；
3. 融合的数学框架是**序贯概率推断**，落地为统一的**六步过程**（3.6）：预测三步 + 校正三步；
4. 六步在三种模型假设下的具体化：线性 KF（3.7）→ EKF（3.11）→ SPKF（3.16）；
5. 工程收尾：传感器偏置增广（3.19）、电池包规模的 **bar-delta 分解**（3.20–3.22）。

## 二、定义与容量口径（§3.1–3.2）

**状态 vs 参数**（3–1 页）：状态变化快（SOC、扩散电压、滞回电压）；参数变化慢（容量、内阻、老化量）。本章估状态，下章（Notes04）估参数。

**SOC 的精确定义链**（3–4…3–6 页）：

- 满充/满放用 **OCV** 到达制造商规定电压定义（可随温度变），如 25 °C 下 LMO 4.2 V/3.0 V、LFP 3.6 V/2.0 V；典型实现是 CC 到截止电压后转 CV 至电流无穷小；
- **总容量** = 满充放到满放移出的电荷；**SOC = 剩余容量 / 总容量**；
- **放电容量 ≠ 总容量**：按负载端电压截止，受内阻影响，随倍率/温度变，且总容量本身随老化慢变；**标称容量**只是厂商给定型号的 1C 室温代表值。

**为什么值得估准**（3–2…3–3 页，五条）：寿命（防止过充过放造成永久损伤）、性能（有误差带才敢用满容量）、可靠性（任何工况下一致）、密度（不必过度设计）、经济性。

**3.2 三种路线的对比**（3–7…3–8 页）：

- **纯电压法**（端电压查 OCV 曲线；"Tino"法用模型 OCV 查表）：漏掉损耗、扩散电压、滞回；OCV 平台区稀释精度；估计噪声大，加滤波又引入延迟；
- **纯电流法**（库仑计数）：短期、初值已知、能频繁复位时可用；受电流传感器波动/偏置/容量误差/漏电影响，**误差界随时间无界增长直到复位**；
- **基于模型的状态估计**：同一输入过真实系统与模型，量测输出与预测输出的差驱动校正——输出误差同时含状态误差、量测误差、模型误差，更新必须对三者仔细权衡；**在特定条件下 Kalman 滤波给出最优状态估计**。

> 【译注】这就是本仓库 `code/soc/compare.py` 三方案对比的理论原文：纯安时积分（`CoulombOnly`）= "current-based"，静置/满充锚点（`CoulombWithResets`）= 给库仑计装上"复位"机制（对应"误差界增长直到复位"），`EKFEstimator` = 模型法。对照表里的量化结果（纯积分 RMSE 10.62% 无界漂、EKF 0.20%）就是 3.2 节论断的实验版。

## 三、概率地基与六步过程（§3.3–3.6）

3.3–3.5 是工具复习，只留与滤波器直接相关的点：

- **假设链**（3–14 页）：中心极限定理 → 状态、过程噪声、传感噪声都建模为高斯随机向量，且噪声与状态不相关。原文坦承"实践中从不严格成立，但文献与实践的共识是该方法仍然非常好用"；强非线性场合的例外是粒子滤波；
- **Bayes 规则与条件期望**（3–13 页）：Kalman 滤波本质上就是递归计算条件期望 𝔼[xₖ | 𝕐ₖ]（𝕐ₖ = 到 k 时刻的全部量测）；
- **序贯概率推断定义**（3–9 页）：用全部量测 𝕐 估计动态系统的当前状态；过程噪声与传感噪声使状态永远算不"准"，只能算分布。

**六步过程**（3–22…3–23 页，一般非线性模型 xₖ = f(xₖ₋₁, uₖ₋₁, wₖ₋₁)、yₖ = h(xₖ, uₖ, vₖ)）：

```
预测（时间更新）
  1a 状态预测：  x̂ₖ⁻ = 𝔼[f(xₖ₋₁, uₖ₋₁, wₖ₋₁) | 𝕐ₖ₋₁]
  1b 协方差预测：Σₓ̃⁻,ₖ = 𝔼[(x̃ₖ⁻)(x̃ₖ⁻)ᵀ]，x̃ₖ⁻ = xₖ − x̂ₖ⁻
  1c 输出预测：  ŷₖ = 𝔼[h(xₖ, uₖ, vₖ) | 𝕐ₖ₋₁]
校正（量测更新）
  2a 增益：      Lₖ = Σₓ̃ỹ,ₖ⁻ · Σỹ,ₖ⁻¹
  2b 状态更新：  x̂ₖ⁺ = x̂ₖ⁻ + Lₖ(yₖ − ŷₖ)
  2c 协方差更新：Σₓ̃⁺,ₖ = Σₓ̃⁻,ₖ − LₖΣỹ,ₖLₖᵀ
```

**KEY POINT**（3–23 页）：输出不只是 x̂ₖ⁺，还有 Σₓ̃⁺,ₖ——真值以高置信落在 x̂ₖ⁺ ± 3√diag(Σₓ̃⁺,ₖ) 区间里。**误差带是滤波器输出的一部分**（附录 3–96 的 χ² 表即用于多自由度置信界）。

> 【译注】六步是一切 KF 变体的"主板图"：线性 KF/EKF/SPKF 只是给 1a/1b/1c 三个期望和 2a 的两个协方差提供不同算法。读任何 KF 代码先找这六步对应哪几行——本仓库 `EKFEstimator.step()` 里就是 1a/1b（predict）+ 1c/2a/2b/2c（update）的直白实现。

## 四、线性 KF（§3.7–3.10）

**模型**（3–24 页）：xₖ = Aₖ₋₁xₖ₋₁ + Bₖ₋₁uₖ₋₁ + wₖ₋₁，yₖ = Cₖxₖ + Dₖuₖ + vₖ；w、v 互不相关、零均值白高斯，协方差 Σ_w̃、Σ_ṽ。

**附录总结**（3–92 页，六步实例化）：

```
x̂ₖ⁻ = Aₖ₋₁x̂ₖ₋₁⁺ + Bₖ₋₁uₖ₋₁
Σₓ̃⁻,ₖ = Aₖ₋₁Σₓ̃⁺,ₖ₋₁Aₖ₋₁ᵀ + Σ_w̃
ŷₖ = Cₖx̂ₖ⁻ + Dₖuₖ
Lₖ = Σₓ̃⁻,ₖCₖᵀ[CₖΣₓ̃⁻,ₖCₖᵀ + Σ_ṽ]⁻¹
x̂ₖ⁺ = x̂ₖ⁻ + Lₖ(yₖ − ŷₖ)
Σₓ̃⁺,ₖ = (I − LₖCₖ)Σₓ̃⁻,ₖ
```

3–92 页脚注的工程细节：**丢量测时直接跳过更新**（等效 Lₖ = 0）——只预测不校正，协方差照常增长，如实反映"没新信息"。

## 五、EKF 与 ESC 模型实现（§3.11–3.14）

**EKF 思路**（附录 3–93 页）：非线性模型在工作点做一阶泰勒展开，雅可比

```
Âₖ = ∂f/∂xₖ |xₖ=x̂ₖ⁺    B̂ₖ = ∂f/∂wₖ |wₖ=w̄ₖ
Ĉₖ = ∂h/∂xₖ |xₖ=x̂ₖ⁻    D̂ₖ = ∂h/∂vₖ |vₖ=v̄ₖ
```

然后套线性 KF 的五个方程（时间更新用精确非线性 f/h 传播均值，协方差用雅可比传播）。

**在 ESC 模型上的具体雅可比**（3–49…3–51 页）——过程噪声建模为**电流传感器误差**（真实电流 iₖ+wₖ，测得 iₖ）：

```
∂zₖ₊₁/∂zₖ = 1              ∂zₖ₊₁/∂wₖ = −Δt/Q
∂i_R,ₖ₊₁/∂i_R,ₖ = A_RC     ∂i_R,ₖ₊₁/∂wₖ = B_RC        （A_RC=diag(exp(−Δt/RⱼCⱼ))，B_RCⱼ=1−exp(−Δt/RⱼCⱼ)）
∂hₖ₊₁/∂hₖ = Ā_H,ₖ          ∂hₖ₊₁/∂wₖ = −|γΔt/Q|·Ā_H,ₖ·(1 + sgn(iₖ+w̄ₖ)·ĥₖ⁺)
∂s/∂s = 0，∂s/∂w = 0       （瞬时滞回符号状态不贡献雅可比）
```

输出方程 yₖ = OCV(zₖ) + M₀sₖ + Mhₖ − ΣⱼRⱼi_Rⱼ,ₖ − R₀iₖ + vₖ 的雅可比：

```
∂y/∂s = M₀   ∂y/∂h = M   ∂y/∂i_Rⱼ = −Rⱼ   ∂y/∂v = 1
∂y/∂z = ∂OCV(z)/∂z —— 由 OCV 标定数据差分近似（原文 dOCVfromSOC 代码：前后差分平均 + 插值）
```

一个易漏的实现细节（3–51 页）：**输出方程里的 iₖ 不含 wₖ**——否则过程噪声与传感噪声相关，违反 KF 假设。

> 【译注】逐条对本仓库 `code/soc/estimators.py` 的 `EKFEstimator`：状态 x = [SOC, U_rc]（ESC 的简化——无滞回、单 RC）；`C = [docv_dsoc(x₀), 1.0]` 就是 [∂OCV/∂z, ∂y/∂U_rc 的对应项]；`docv_dsoc`（code/soc/cell_model.py）= 原文 dOCVfromSOC 的查表版；`residual = v_meas − v_pred` 即 yₖ − ŷₖ。我们的实现少了滞回两个状态——要升级成完整 ESC-EKF，把本节 3–49/50 的雅可比补进去即可，没有概念缺口。

## 六、SPKF（§3.15–3.18）

**EKF 的两个痛点**（3.15）：雅可比推导/实现繁琐且易错；强非线性处一阶展开精度差（且 |·|、sgn 这类函数在零点本来就不可微，3–50 页推导只能"忽略"处理）。

**SPKF 思路**（附录 3–94/95 页）：不求导。构造增广状态 xᵃ = [xᵀ, wᵀ, vᵀ]ᵀ，围绕其均值按协方差平方根撒 2·dim(xᵃ)+1 个 **sigma 点**，让每个点**精确**通过非线性 f/h，再用一组权 α⁽ᵐ⁾/α⁽ᶜ⁾ 重组均值与协方差：

```
时间更新：χ 点过 f → x̂ₖ⁻ = Σᵢ αᵢ⁽ᵐ⁾χˣ⁻ₖ,ᵢ；Σₓ̃⁻,ₖ = Σᵢ αᵢ⁽ᶜ⁾(χˣ⁻ₖ,ᵢ − x̂ₖ⁻)(·)ᵀ
输出估计：χ 点过 h → ŷₖ = Σᵢ αᵢ⁽ᵐ⁾𝒴ₖ,ᵢ
增益：    Σỹ,ₖ、Σₓ̃ỹ,ₖ⁻ 同样按 σ 点加权求和；Lₖ = Σₓ̃ỹ,ₖΣỹ,ₖ⁻¹
更新：    x̂ₖ⁺ = x̂ₖ⁻ + Lₖ(yₖ − ŷₖ)；Σₓ̃⁺,ₖ = Σₓ̃⁻,ₖ − LₖΣỹ,ₖLₖᵀ
```

权重 α 由少数超参算出（3–60 页表；记 L = dim(xᵃ)）。各方法 sigma 点集合构造相同——X = {x̄, x̄+γ√Σ_x̃, x̄−γ√Σ_x̃} 共 p+1 = 2L+1 点，√Σ 用 Cholesky 取**下三角**（MATLAB 默认返回上三角需转置；numpy 的 `cholesky` 直接给下三角，3–59 页）——区别仅在这组加权常数：

| 方法 | γ | α₀⁽ᵐ⁾ | αₖ⁽ᵐ⁾（k≥1） | α₀⁽ᶜ⁾ | αₖ⁽ᶜ⁾（k≥1） |
|---|---|---|---|---|---|
| UKF | √(L+λ) | λ/(L+λ) | 1/(2(L+λ)) | λ/(L+λ) + (1−α²+β) | 1/(2(L+λ)) |
| CDKF | h | (h²−L)/h² | 1/(2h²) | (h²−L)/h² | 1/(2h²) |

超参（3–60 页脚注）：λ = α²(L+κ)−L 为缩放参数（原文印刷 10⁻² ≤ α ≤ 1；注意此 α 是超参，与权重记号 α⁽ᵐ⁾/α⁽ᶜ⁾ 不是一回事）；κ 取 0 或 3−L；β 并入先验信息，高斯随机变量取 β = 2；h 可取任意正值，高斯取 h = √3。两组权各自和为 1。UKF 与 CDKF 推导路径不同、最终方法本质相同；CDKF 只有 h 一个调参，实现更简单，理论精度还略高。代价：每拍要跑 2n+1 次模型仿真——状态多时明显贵于 EKF。

> 【译注】对本仓库的意义：单 RC、无滞回的 Thevenin 模型非线性很弱（只有 OCV 一处），EKF 已够（实测 RMSE 0.20%）；什么时候该想到 SPKF？——模型加上滞回（|·|、sgn 不可微点）或做参数联合估计时。熊瑞书 4.1 的 AEKF（自适应）走的则是另一条路：在线调 Σ_w̃/Σ_ṽ。

## 七、工程问题与 bar-delta 分解（§3.19–3.22）

**传感器偏置增广**（3.19/3–83 页）：把电流传感器偏置建成新状态 iₖᵇ = iₖ₋₁ᵇ + nₖ₋₁ᵇ（n 是虚构噪声，让滤波器能在线调整偏置估计）——治"库仑计零漂"的标准做法。

**速度问题与 bar-delta 分解**（3.20–3.21）：对 Ns 节电池包，每节都跑全状态 SPKF 太贵。分解为：

- **一个 pack 级 "bar" 滤波器**（SPKF）：估 pack 平均 SOC、平均扩散电流、平均滞回 + 偏置状态。为简化方程引入**逆容量** Q_inv 概念：pack 平均 SOC 方程 z̄ₖ = z̄ₖ₋₁ − iₖ₋₁Δt·Q̄_inv（3–83 页；若同时估各节容量则 Q̄_inv 时变）；
- **每节一个单状态 "delta" 滤波器**：ΔSOC = z⁽ⁱ⁾ − z̄，用单状态 SPKF；Δ电阻、Δ逆容量用单状态 EKF（动态足够线性）。delta 状态变化慢，可**降采样更新**（3–85 页）；
- 输出 = pack 平均状态 + 各节 delta 状态（3–86 页）。

**验证方法学**（3.22）：HIL 给基线真值但难知全部内部状态；**桌面验证**（模型生成合成数据）可知全部真值、适合调参，结论有效性受模型精度限制。验证场景清单：正常运行、SOC 初值错误、传感器故障（故障+噪声）、温度漂移、新旧电芯混用、不同工况、电流传感器偏置。3.22 算例：4 节 pack，真容量 6.5/7.0/7.5/8.0 Ah、真内阻 2.0/2.25/2.5/2.75 mΩ、真初值 SOC 40–55%、偏置 0.5 A，算法侧故意给错初值（容量全猜 6.2 Ah、偏置 0 A）跑 UDDS+静置循环。

> 【译注】桌面验证就是本仓库 SOC 演示的方法论：`cell_model.py` 扮演"数据生成器"（真值可知），estimators 扮演"BMS 算法仿真"；`compare.py` 的演示工况让三种估算器全部以 0.7 的错误初值起步（真值 0.8），`test_soc.py` 再对机制下断言——正是 3.22 清单里的"improper SOC initialization"场景。bar-delta 是下一步上电池包时的路线图——目前 code/soc 只到单节。
