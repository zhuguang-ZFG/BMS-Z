## 关键接口决定

1. **先纠错再扩写**：P0修现有教学/代码和其派生内容，允许进入现有站；新增深研正文仍按P1隔离预览/P2搜索门执行。来源取样、适配回归和软件回放不能当作完成三份样章。
2. **预充函数边界**：旧`close_verdict(pack_v, measured_v, ratio)`的名字保留兼容入口，新增`voltage_condition_met`；`allowed`固定False，因为输入不足以提供真实许可。旧`weld_suspect`撤销为`bus_requires_investigation`，防止把残压、回灌或卡值自动写成粘连。S3再设计带独立证据的教学状态机，不用假布尔值填空模拟硬件通过。
3. **数值真源**：400 V/1 mF/170 Ω仅理想教学；精确95%为0.5092744865 s，3τ为0.51 s/380.085 V，不把90%也写成3τ。到95%源/阻/容为152/79.8/72.2 J；带初始残压用电容增能而非总储能做守恒。
4. **数据报告**：历史CSV不改；新增报告schema与字段解释其参考、单位、时间积分及谱系。归档/MAT摘要从已有metadata复制，只有CSV/组/源行是本次验证。标定函数与验证隔离不证明操作者从未调过参数，报告明确这一限制。
5. **先修和所有权**：B01–B04缺失桥梁只登记唯一未来路径，P0不创建空教学页；B05提取书21现有段。跨单元共用章由单一负责人合并，KP/阶段页由真源生成。

## 图与旧成品的剩余范围

P0没有重新制作整套媒体。开线SVG中“一次对比即识别”等泛化需在S1/D05按具体诊断时序重新核验；预充旧手绘帧、打印图和视频成品要按新事实源在S3重制。附近正文已经明确示意/条件/许可边界，旧媒体不得单独当完整技术证据。历史图版验收记录保留为当时版本，不沿用来宣称本次事实修订已完成全部视觉验收。
