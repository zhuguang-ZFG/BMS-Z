>
> **计数口径**（§3.8）：动画点 = 1 张独立 SVG 动画，或 1 组 3–6 帧连续图；实物点 = 1 张合格实物照片（§3.6：主体明确、来源/作者/授权齐全、非实拍不冒充）；手绘机制点 = handraw 机制图，一图一问，不与动画点混算。
>
> 缺额必须进本表；关闭前对应阶段不得标「视觉完成」。配额是**下限**，已有资产可计入。

## D. 关闭规则

1. 每条缺口关闭时必须写：资产路径 + 图注 + 关闭日期，并跑 §10.7 门禁。
2. 新建 SVG 同步进动画索引与 §3.5 数量对账门；新建照片同步进 PHOTOS.md 与 B 表。
3. 缺口状态只能从「待补」→「部分覆盖」→「已覆盖」；跳级关闭视为无效。
4. 本表与 [kp_gap_audit](kp_gap_audit.md) 的 ladder 媒体字段互为回链：W3 补媒体时同步更新 ladder.media[]。
