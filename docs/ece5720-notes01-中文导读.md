## 二、包怎么串，BMS 站在哪（§1.1）

单节电压窗口由化学体系定死。要高电压就串联，要大电流就并联（1–3 页）：

```
Vpack = Ns · Vcell
Ipack = Np · Icell
```

模块电压讲义里常压在 50 V 以下，整包常压在 600 V 以下——前者为了人员安全，后者为了功率器件的价钱。电流尽量小，线径和 I²R 损耗才小。模块两端的极端是「先并后串」和「先串后并」，工程上多半在中间。一个 3P6S 模块是 18 节，功率和能量大约是单节的 18 倍，实际上到不了这个整数，后面讲不均衡时会回来。电芯焊或拧在带本地采样和均衡的板上，避免上百根线拉回主控。

BMS 要做的五件事（1–1、1–4 页）：保护使用的人，检出不安全并响应；保护电芯少受滥用损伤；在正常使用里延长寿命；让包维持在能完成设计功能的状态；告诉整车或充电机此刻怎么用（功率限制、充电电流）。管理本身有成本，电池便宜到「想不起上次更换」的产品不必上全套。讲义把 HEV、PHEV、增程式和纯电统称 xEV：差别在电池有多大、有没有纯电里程，共同点是高压大电流。

> 【译注】阶段 1 [§1.3](stages/stage-1-认识BMS.md#13-bms-的五大功能模块-理解) 的五块是采样、保护、均衡、状态估算、通信诊断。讲义把均衡和 SOC 放进「性能」，把接触器、预充、绝缘放进「采样与高压控制」。名字对不齐没关系：阶段 1 先认识功能，接触器和绝缘的做法在阶段 6。

## 三、采样：电压、温度、电流（§1.2）

**电压**（1–5…1–6 页）。锂离子包每一节都要测。电压是均衡的输入，也是大多数 SOC、SOH 算法的输入。漏测一节，过充可以在没人看见的那一节走到热失控。讲义用 LTC6803 当例子：一颗看一个模块里最多 12 节，菊花链隔离通信，包内合计大约 120 节；均衡可以片内或外接；供电可以取自模块或外部；温度大约四路。选型时要问的是：一颗看几节、整包能看几节、被动还是主动均衡、精度、温度路数、芯片之间几根线、单节成本。这颗芯片是 2013–2015 年讲义里的例子，不是采购建议。

**温度**（1–6…1–7 页）。性能和老化都随温度剧烈变化。低温不要充；热管理把温度留在安全带里。温度突变可以是电芯已经在失效。理想是测每节内部温度。有靠得住的包热模型时，可以在模块外贴一个或几个传感器，再标定到内部。产品里常用热敏电阻：阻值随温度明显变，放进分压（或已标定的惠斯通电桥），ADC 读电压，软件用一张「电压 → 温度」的反查表。热电偶输出很小，还要冷端补偿，讲义认为更适合实验室。

**电流**（1–8…1–9 页）。电流用于保护、滥用记录，以及大多数 SOC、SOH。两条路：

- **分流器**：小阻值精密电阻串在回路里，多半放在低压端。I = Vshunt / Rshunt。功率端和采样端要分开，也就是四线、开尔文。零电流时分流器本身没有失调，安时积分少一条随温度走的零点；测量电路仍可能引进失调。它和电池包不隔离。阻值随温度变，要测温并标定。电阻自己发热，小信号放大后的走线要防干扰。
- **霍尔**：测电流产生的磁场，和包电流隔离，不必再加隔离电路。磁滞要用反馈电路压住，成品里通常已经带上。零电流仍有失调，而且随温度变：室温校过零，温度一变又会报出一小段假电流。能确定此刻真是零电流的场合（讲义举 HEV）要经常再校。

> 【译注】开尔文把引线压降剔出电流读数，算例在 [详解② §8](circuits/02-采样链与AFE芯片.md#8-电流采样安时积分精度的天花板-分析) 和 [详解⑤ §2](circuits/05-BMS电路板绘制与设计要点.md#2-采样线-应用)。`code/soc/compare.py` 里那 +2 mA 零漂，就是讲义说的「传感器电子学会另加失调」：纯积分没有复位时，这条小电流会一直累进 SOC。NTC 分压和反查表的方向，见 [详解② §6](circuits/02-采样链与AFE芯片.md#6-温度采样ntc越热阻值越小-理解)。阶段 3 的教学芯片是 BQ769 一族，问的仍是讲义那张选型清单。

## 四、高压接触器与预充（§1.3）

高压包在设计上与底盘地隔开：同时碰到机壳和包内任意一点，应当是安全的（1–10 页）。不用的时候，高压母线在正负两端都和负载断开，所以要两只能扛大电流的接触器。负载侧常常是电容。两只主接触器一起合，冲击电流可以把触点焊死，或把熔断器打掉。第三只是预充接触器。

讲义里的顺序（1–10…1–12 页）：

1. 静止时先合负端接触器，把负载的负端和包的负端接上。
2. 再合预充。预充电阻限制电流，母线电容被慢慢灌满。电阻温度过高，或母线电压与包电压在规定时间里靠不到一起，按负载短路处理，整包断开。这两路电压要用高阻抗分压和隔离运放来看。
3. 两边电压足够近、而且来得及，才合正端主接触器。负载改走低阻路径，预充接触器打开。

下电顺序讲义写得没有上电那么确定：突然断开可能拉弧、粘连，电容里存的能量有时够把弧灭掉；断开主接触器之前先把预充路径接上，主触点有旁路，粘连风险小一些，但预充电阻可能被打掉。电容往往把电阻也保住了。这是讲义里的两难，不是一条可以照抄的下电规程。

> 【译注】同一条因果在 [阶段 6 §6.1.2](stages/stage-6-精通与毕业项目.md#612-预充回路合闸的艺术-应用) 和 [详解① §3.2](circuits/01-功率回路-MOS保护与预充.md#32-解法与计算-应用)：先小电流灌满母线电容，再合主闸。那里的 400 V、1 mF、170 Ω 是本仓库的示例，不是这章讲义里的数。`code/firmware/` 的状态机没有预充状态，文件头写明了，不要把骨架当成带预充的量产固件。

## 五、绝缘与温度窗口（§1.4）

**绝缘**（1–13…1–15 页）。要回答的问题是：一只手碰电池端子、一只手碰机壳，安不安全。包与机壳之间的两条漏电路写成 R1、R2，理想值是无穷大。绝缘电阻 Ri 取两者里较小的那个。讲义转述 FMVSS 的判据：用导线把机壳分别接到包的正端或负端，流过的电流小于 2 mA，才算绝缘够。于是

```
Ri > Vb / 0.002 = 500 · Vb
```

Vb 用伏特、Ri 用欧姆时，这就是 500 Ω/V（1–13 页）。BMS 测 Ri 的办法，是用高阻抗电路测正端对机壳的 V1 和负端对机壳的 V2，阻抗讲义写 ≥ 10 MΩ。这已经打破了严格隔离，但漏电流小到讲义认为可以接受。两只电压表的极性都取正。R1、R2 是分压，V1/R1 = V2/R2。V2 > V1 时先解低压侧的 R1，否则解高压侧的 R2。

做法是用开关把一只已知大电阻 R0 接到电池与机壳之间，R0 本身要够大（讲义写到 500·Vb 这一量级），再测投切之后的电压。低压侧故障、测得 V2′ 时（1–14 页）：

```
R1 = R0 · V2′ / [ (1 + V1/V2) · (V2 − V2′) ]
```

高压侧对称，测得 V1′ 时（1–15 页）：

```
R2 = R0 · V1′ / [ (1 + V2/V1) · (V1 − V1′) ]
```

幻灯片上还写了未约分的分母（V1+V2 − V′ − V′·另一侧电压比），和上面是同一个量。够不够，仍看较小的那个是否大于 Vb/0.002。

**热**（1–16 页）。讲义不展开控制策略，只给窗口：锂离子在使用中大约 10 °C 到 40 °C 最能用得久。纯电有时风冷就够；激烈的混动可能要液冷或蒸发冷却。低于大约 0 °C 还去充电，电芯损伤的风险高，该加热再充。冷却液进出口温度可以送给包的热模型。同一页的安全窗口把几件事故画在电压–温度平面上：充电析锂、过放时铜集流体溶解、SEI 分解、隔膜熔化、电解液放热、正极释氧直到热失控。

> 【译注】阶段 6 [§6.1.3](stages/stage-6-精通与毕业项目.md#613-绝缘检测imd-分析) 用的是电桥两次投切，口诀是「投切两次，得到两个方程」。那里的 <500 Ω/V 报警、<100 Ω/V 故障是 GB/T 38661、ISO 6469 一路的教学示例，和讲义转述的 FMVSS「2 mA / 500 Ω/V」不是同一条条款。产品用哪一条，以适用标准为准。低温禁充和过放铜溶解在阶段 0 [§0.1.4](stages/stage-0-前置知识.md#014-温度电池的脾气-理解)、[§0.1.3](stages/stage-0-前置知识.md#013-过放安静的杀手-理解)。

## 六、保护、充电、CAN、日志、续航（§1.5）

保护同时对着两头：电芯不要跑出允许的环境，人不要吃到电池失效的后果（1–17 页）。能量如果沿短路或机械损伤一下子放出来，后果可以很严重。短路时几百安培可以在微秒里起来，保护必须跟上这个速度。锂离子失效可以走到起火，车用环境里保护不能省。清单是：充放电过流、短路、过压、欠压、环境过热与自身过热、绝缘丧失、滥用。能做的时候留后备路径。

限度怎么划（1–18 页）：厂家标定的红区是很可能造成永久损伤的区域；外面并不自动等于可以长期用。设计把工作点收进更小的绿区，保护器件负责把电芯拦在绿区里，白区是裕量。电压也一样画。热熔断器在超温时断开接触器；普通熔断器可能不够快；主动检测靠 BMS 盯着故障。串在主电流路上的每一只保护器件都增加阻抗，送到负载的功率变小。

充电分两种（1–19 页）。随机充电，例如制动回馈，靠给逆变器功率限制来管。插电充电要管电流、电压和均衡；常见是先恒流再恒压，也可以有更复杂的曲线；大多数锂离子电芯在低温下不该充，所以要加热。讲义用当时的乘用车数量级说明功率从哪来：大约 200–300 Wh/英里，300 英里对应大约 60–90 kWh；3 分钟充满大约要 1.8 MW。家用大约 15 A、110 V（约 1.5 kW）要 40–60 小时；大约 30 A、220 V（约 6.6 kW）要 10–15 小时。这是 2013–2015 年讲义里的乘法，不是今天某款车的规格。

CAN 是车载网络的工业标准，为高电气噪声设计（1–19…1–20 页）。两线。讲义给的两档速率：大约 1 Mbaud 给发动机、稳定性和运动控制；大约 100 kbaud 给灯、车窗、后视镜和仪表。协议要规定寻址、速率与优先级、发送顺序、检错与处理、控制信号。数据帧依次上总线。帧里能看见标识符、控制场、数据、CRC 和应答。

日志（1–20 页）为保修和诊断留下不正常事件：种类（电压、电流、温度越限）、持续时间和幅度；也可以记循环次数、每次行驶开始时的 SOH。存在「历史芯片」一类非易失存储器里，需要时读出。硅序列号芯片可以帮忙对上是哪一台。

续航（1–21 页）问的是能量耗尽之前还能走多远。它和包里的总能量成比例，又被车、开法、坡度、风和冷热拉开。讲义认为各厂家会有自己的算法，BMS 先把算法要的输入交出去，尤其是包里还剩多少能量。

> 【译注】短路按微秒关、软件轮询来不及，[阶段 2 §2.3](stages/stage-2-保护板实践.md#23-多节保护s-8254a-与多通道芯片-理解) 用 I²t 示例把这件事算过。CAN 上谁先发、CRC 管什么，在 [阶段 5 §5.4](stages/stage-5-通信与集成.md#54-can车上的官话-理解)。故障快照的五要素在 [阶段 6 §6.2.2](stages/stage-6-精通与毕业项目.md#622-故障管理dtc-体系-应用)；`code/firmware/` 的快照只覆盖教学状态机里的那几条，不是讲义的整本历史芯片。

## 七、荷电状态到底是什么（§1.6）

xEV 要两个数（1–22 页）：包里还剩多少能量，以及眼前还能进出多少功率。纯电更在意能量（还能走多远），混动更在意功率（还能不能加速、还能不能吃制动电），插电和增程两个都要。能量至少要各节 SOC 和容量；功率至少要各节 SOC 和电阻。这三样都不能直接测，只能估计。手里有的是各节电压、包电流和温度。

差的估计方法更好写、更好验证，结果更松。松的后果是：顶到电压或电流限制时突然改功率，驾驶感觉差；或者过充过放伤电芯；或者为了盖住不确定度把包做大。三条都在花钱、加重量或加体积。这门课的前提是：算法和能跑算法的电子做好了，包可以做小，总成本可以下来。

电化学上，SOC 联系着负极固体颗粒里锂的平均浓度（1–23 页）。化学计量比 θ = cs,avg / cs,max，设计上留在 θ0% 和 θ100% 之间。这一时刻的荷电状态是

```
zk = (θ − θ0%) / (θ100% − θ0%)
```

电压不能当成 SOC 的直接读数（1–24 页）。电压看的是温度和颗粒表面浓度，SOC 看的是颗粒平均浓度，两者一般不相等。温度变了，电压变，平均浓度不变，SOC 不变。静置改变电压，不改变平均浓度。使用历史会让稳态的表面浓度和平均浓度错开，这就是滞回。SOC 只随电流变：外部回路的充放电，以及电芯自己的自放电。

电流关系（1–24…1–25 页），放电电流为正：

```
z(t) = z(0) − (1/Q) ∫₀ᵗ η i(τ) dτ
```

η 是库仑效率，接近 1，又不到 1。Q 是总容量，单位安秒，数的是电极里 θ0% 到 θ100% 之间能放锂的位置。按这个定义，Q 不随温度和倍率变。用这条积分估 SOC 叫库仑计数。讲义点名：第 3 章会说明它的硬限制。

「包 SOC」这个词讲义认为定义不清，不该用（1–25 页）。一节已经空、一节已经满的时候，包 SOC 该是 0（不能再放）、100（不能再充），还是平均 50？三个答案都站不住。这件事同时说明需要均衡（第 5 章）。若目标是设定点控制，平均 SOC 也许够用；若目标是油表，真正要的是包的能量。

> 【译注】本仓库的电流符号和讲义相反：阶段 4 约定充电 I>0、放电 I<0，端电压写成 Uoc + I·R。把讲义公式抄进 `code/soc/` 之前先把符号翻过来。`compare.py` 的纯积分、带复位积分和 EKF，就是 1–24 页「只能靠电流积分」和后文「电压只能间接用」的对照；定量限制在 [Notes03 导读](ece5720-notes03-中文导读.md) §3.2。总容量不随倍率变、放电容量随倍率变，Notes03 导读第二节把这两个词拆开了。[阶段 1 §1.2](stages/stage-1-认识BMS.md#12-木桶效应亲眼看看浪费有多大-理解) 的木桶，就是这里「不要报一个包 SOC」的中文版。

## 八、能量、功率和健康度（§1.7 与诊断）

能量是能做的功，单位 Wh，是一个总量。功率是在不越出电芯和电子设计限度时搬能量的速率，P = IV，是瞬时量（1–26 页）。功率过高会加快老化。功率估计要覆盖未来 ΔT 秒，刷新要比 ΔT 更勤。进阶算法在后面的章。这里先给常用的简单法：做脉冲测试，把不同 SOC、不同温度下的等效电阻列成表。

```
Rchg,ΔT = ΔVchg / Ichg
Rdis,ΔT = ΔVdis / Idis
```

模型先收成 v(t) = OCV(z(t)) − i(t)·R，放电电流仍为正。只守端电压在 vmin 和 vmax 之间时（1–27 页）：

```
Pdis = vmin · (OCV(z) − vmin) / Rdis,ΔT
Pchg = vmax · (vmax − OCV(z)) / Rchg,ΔT
```

充电功率在 i 为负时算出来是负的，报告时习惯改成正数，所以上面第二式已经取了正。这两式假设起始是平衡态，实际使用要再降一档。电芯总能量是 OCV 对 SOC 的积分（1–27 页）：

```
E(t) = Q ∫_{zmin}^{z(t)} OCV(ζ) dζ  ≈  Q · Vnom · Δz
```

总能量按这个定义也不随温度和倍率变。高倍率和低温下拿不出全部能量，所以功率估计还得另做。

包的功率，用这个近似时，取所有电芯里算出的最小功率，再乘电芯节数（1–28 页）。包的能量要先问：放出多少安时，会把最低的那一节放到 zmin。这段安时之后，第 k 节变成

```
zlow,k = zk(t) − Ah / Qk
```

再把各节从 zlow,k 积到当前 zk。积分后的 OCV 可以预先做成表，运行时只查表。最弱的一节先到 zmin，别的节还剩一段到不了的荷电，这段不算进可用能量。

诊断上要报 SOH，讲义说这个词没有唯一定义，一般是在量化老化（1–28…1–29 页）。能测的两个指标是当前容量和电阻。寿命期内容量可以掉大约 20%–30%（容量衰减），电阻可以升大约 50%–100%（功率衰减）。在线估 Rk 和 Qk 就是寿命的指示，第 4 章再做。有人再定义 SOL，想预测还剩多少寿命或日历时间。未来的滥用可以和过去不同，老化会加快或放慢，所以只看 R 和 Q 不够，第 7 章改看内部的物理退化。

章末提醒：后面讨论的不少方法已经有专利，文献里常见的方法也多半是公司为自己做的。商业实施要有权利人的许可。讲义用这句话鼓励做出和已有专利足够不同的方法。这是课程里的提醒，不是法律意见。

> 【译注】阶段 4 [§4.7](stages/stage-4-SOC-SOH算法.md#47-sop电池此刻能出多大力-分析) 的 SOP 是电压、电流、SOC、温度多条约束取最紧的一条，时间窗分成 2 s / 10 s / 30 s。本节的 Pdis、Pchg 只守电压，是那条电压约束的简化起点，还没把极化电压和温度降额放进去。容量掉、内阻升，[阶段 4 §4.6](stages/stage-4-SOC-SOH算法.md#46-soh-与联合估计让算法把电池看透-分析) 用慢滤波器去估；讲义里的 20%–30% 和 50%–100% 是寿命尺度的数量级，不是本仓库的 EOL 阈值。
