# BMS 参数速查卡：公式、示例阈值与排障入口

> 适合已经看过教程、正在读电路或调代码时快速回查。每行只保留计算式、使用条件和原章节；推导、动画与实测方法请点回正文。
> 还没选方向 → [按目标选路线](stages/按目标选路线.md)；找学习材料 → [资源总纲](bms-resources.md)；生词 → [术语表](glossary.md)。

**先分清三类数字**：公式里的单位换算、教学代码的配置值、真实产品的限值。下面的配置值仅用于 PC 仿真与测试；真实电芯、保护 IC 和产品的阈值须查对应规格，不能把三元锂与磷酸铁锂的配置混用。

## 1. 单位与符号先对齐

| 量 | 本仓库约定 | 最常见的错法 |
|---|---|---|
| 电流 I | 充电为正，放电为负；公式用 A | 从外部数据集导入时没转换符号 |
| 容量 Q、时间 t | Q 用 Ah；积分的 t 若用秒，除以 3600 | 把 mAh 当 Ah，或秒直接代入小时公式 |
| SOC、容量型 SOH | 比值用 0–1，百分数显示时乘 100% | 把 0.8 与 80 混在同一算法里 |
| 电阻、电容 | 公式用 Ω、F；1 mΩ = 0.001 Ω，1 µF = 10⁻⁶ F | mΩ、µF 没换算，功耗与时间相差几个数量级 |
| 配套固件输入 | 电压 mV，电流 mA，温度 0.1°C | `temp_c10=600` 是 60°C，不能传入 60 |

符号来源：[阶段 4 §4.2](stages/stage-4-SOC-SOH算法.md#42-安时积分库仑计主力但它会梦游-分析)、[固件输入与配置](../code/firmware/bms.h)。

## 2. 常用公式：算完还要查条件

| 想算什么 | 速查式 | 使用条件与正文 |
|---|---|---|
| 安时积分 | ΔSOC = I·Δt / (3600·Q) | Δt 用秒，Q 用 Ah；零漂会累积，需校准点。[阶段 4 §4.2](stages/stage-4-SOC-SOH算法.md#42-安时积分库仑计主力但它会梦游-分析) |
| 容量型 SOH | SOH = 当前满充容量 / 额定容量 | 内阻型 SOH 是另一口径，不能混报。[阶段 4 §4.6](stages/stage-4-SOC-SOH算法.md#46-soh-与联合估计让算法把电池看透-分析) |
| 端电压与极化 | U = OCV(SOC) + I·R₀ + Urc | 充电 I > 0；带载端电压不是 OCV。[阶段 4 §4.4](stages/stage-4-SOC-SOH算法.md#44-等效电路模型让电压在动态中也能用-分析) |
| RC 低通截止频率 | fc = 1 / (2πRC) | AFE 输入阻值还受漏电流、采样建立时间约束，不能只按 fc 选。[阶段 0 §0.2.1](stages/stage-0-前置知识.md#021-rc-滤波手册让你放你就放-理解) |
| ADC 量化步长 | LSB ≈ Vref / 2ⁿ | 分辨率不等于精度，还要计基准、失调、温漂和布线误差。[阶段 0 §0.2.2](stages/stage-0-前置知识.md#022-adc-与误差刻度细--尺子准-理解) |
| 分流电阻电流、发热 | I = Ushunt / Rshunt；P = I²Rshunt | 毫欧级测量用开尔文连接，先扣电流零点。[详解② §8](circuits/02-采样链与AFE芯片.md#8-电流采样安时积分精度的天花板-分析) |
| MOS 导通损耗 | P ≈ I²RDS(on) | 用实际栅压与温度下的导阻；背靠背两管要计算整条路径。[详解① §1.3](circuits/01-功率回路-MOS保护与预充.md#13-选型三参数数据手册第一页-评价) |
| 栅极驱动时间 | t ≈ Qg / Idrive | 用于估算驱动能力；并联 MOS 的总栅电荷增加。[详解① 自测 2](circuits/01-功率回路-MOS保护与预充.md#4-自测-理解) |
| 被动均衡的三笔账 | Ibal ≈ Ucell / R；P ≈ Ucell² / R；t ≈ ΔQ / Ibal | 最后一式 Q 用 Ah、I 用 A、结果为小时，且未计分时停顿；还要做热预算。[详解③ §2](circuits/03-充电均衡与计量.md#2-被动均衡电路热与调度-分析) |
| 理想 RC 预充至约 95% | t ≈ 3RC；R ≈ t / (3C) | 适用于母线电容初始近零的理想 RC 估算；实际要检测电压与超时。[详解① §3.2](circuits/01-功率回路-MOS保护与预充.md#32-解法与计算-应用) |
| 电容储能 | E = ½CU² | E 用 J；预充、放电电阻查脉冲耐量与重复间隔。[阶段 6 §6.1.2](stages/stage-6-精通与毕业项目.md#612-预充回路合闸的艺术-应用) |
| NTC 下臂分压 | Vout = Vcc·RNTC / (R固定 + RNTC) | 此接法下温度升高、中点电压降低；换上下臂后方向改变。[详解② §6](circuits/02-采样链与AFE芯片.md#6-温度采样ntc越热阻值越小-理解) |
| SOP 限制 | 取电压、电流、SOC、温度约束允许值中的最小值 | 先统一充放电方向和持续时间，再取约束；不能只算 U·I。[阶段 4 §4.7](stages/stage-4-SOC-SOH算法.md#47-sop电池此刻能出多大力-分析) |

两个单位自检：10Ah 电池以 −2A 放电 1 秒，ΔSOC ≈ −0.00005556（−0.00556 个百分点）；4V 加在 100Ω 均衡电阻上，电流约 40mA、功耗约 0.16W。两者都是算术示例，不是器件推荐值。

## 3. 保护参数：示例要成套读

下面**只对应** [test_bms.c 的 CFG](../code/firmware/test_bms.c)，不是所有教程、DW01 型号或化学体系的统一配置。`bms_tick()` 未绑定实际周期，所以“3 拍”不能直接写成“3ms”。

| 项目 | 触发示例 | 动作与恢复 |
|---|---|---|
| OVP 过充 | 任一单体 >4250mV，连续 3 拍 | 禁充；最高单体 <4150mV 后清除该项 |
| UVP 过放 | 任一单体 <2800mV，连续 3 拍 | 禁放；充电器在场且最低单体 >3000mV 后清除 |
| OCD 放电过流 | 放电幅值 >10000mA，连续 5 拍 | 禁放；放电幅值 <5000mA 后清除 |
| SCD 短路 | 放电幅值 >30000mA，软件本拍动作 | 双断并锁存；电流进入 (−100,+100)mA 窗口后解锁；真实短路切断仍需硬件保护 |
| OT 过温 | 温度 >600（60°C） | 双断；温度 <550（55°C）后清除 |
| 低温禁充 | 充电低于约 0 °C（典型；以电芯规格书为准） | 禁止充电。低温充电会析锂。教学固件 `bms.c` 没有这一项，只有上面的过温；真实产品必须做 |
| 被动均衡入口 | 充电器在场、净电流 >0、最高串 ≥3600mV、压差 ≥30mV | 电流归零、反向、拔枪、最高串跌破门槛或压差 <15mV 时停止均衡 |

**组合条件也要测**：OVP + UVP 要合并成双断；旧故障存在时新短路仍须升级；某一项恢复不能清掉另一项。代码约定见 [固件走读](../code/README.md#firmware五条纪律的代码落点对应阶段-3--6-应用)，原理见 [保护三要素](stages/stage-1-认识BMS.md#14b-五大保护每一条背后都有一个事故-理解)。

## 4. 带着症状回查

| 现象 | 优先核对 | 对应入口 |
|---|---|---|
| ADC 位数很高，单体电压仍不准 | 基准、失调、输入漏电、MUX、布局与标定分别占多少误差 | [采样链误差预算](circuits/02-采样链与AFE芯片.md#1-采样链全景与误差预算-分析) |
| SOC 越跑越偏，或撤流后突然跳变 | 电流符号与零漂、容量口径、真值采样时刻、静置是否真的满足 | [算法落地要点](stages/stage-4-SOC-SOH算法.md#48-工程落地要点-评价) + [配套实现](../code/README.md#soc三种估算器的分歧只有怎么校正对应阶段-4-分析) |
| CRC 总错，或坏帧后好帧也丢了 | 多项式、初值、反射、输出异或、覆盖范围；长度、端序、重同步与超时边界 | [协议逆向](stages/stage-5-通信与集成.md#56-协议逆向方法论当一回协议侦探-分析) + [解析器走读](../code/README.md#protocol五条军规逐条落对应阶段-5-应用) |
| 保护板不恢复，或恢复后再次出错 | 每项故障的回差、恢复方向、锁存条件与叠加故障 | [保护决策](stages/stage-1-认识BMS.md#17-保护决策逻辑状态机雏形-理解) + [保护实测](stages/stage-2-保护板实践.md#26-保护板实测方法本阶段核心技能-应用) |
| 均衡很慢或电阻很热 | ΔQ/I 的时间量级、I²R 功耗、分时占空比、采样前是否关闭均衡 | [被动均衡](circuits/03-充电均衡与计量.md#2-被动均衡电路热与调度-分析) |
| 接触器已断，母线仍有电压 | 区分残余电荷、预充支路与粘连；核对电压变化和判定窗口 | [粘连检测](circuits/04-系统安全与量产.md#22-粘连检测命令断了电断没断-分析) |
