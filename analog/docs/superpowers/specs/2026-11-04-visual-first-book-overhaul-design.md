## 1. 为什么必须重做

上一轮完成了内容契约、静态图补齐、动画扩量和打印分镜，但验收重点仍是“文件存在、数量过线、打印不丢字”。这能防止缺图，不能保证好读。

当前问题有四层：

1. **图分布失衡**：图片常堆在章首或个别小节，中后段仍有大块连续文字。
2. **图没有替代文字**：不少图只是段落后的补充，正文并未因此缩短，读者仍要先啃完长段落。
3. **动画数量不等于教学质量**：153 张动画看似很多，但部分只是同一模板换题目，缺少镜头、主次、焦点和参数变化。
4. **生成器压死迭代**：`scripts/generate_svgs.py` 已达 9589 行，所有主题、图元、节拍和输出都塞在一处，任何视觉升级都会牵动全库。

这轮“彻底”不是继续追加几十张相似 SVG，而是同时改造：

- 正文视觉密度和插入位置；
- 静态插图的构图与教学职责；
- 动画的视觉语言、节拍、交互和打印回退；
- 文字与图之间的职责分工；
- 生成、审查、回填和发布工具链。

## 3. 成功标准

全部满足才可宣称视觉改造完成。

### 3.1 数量与分布

- 正文内嵌视觉锚点从 200 提升到 **至少 390**。
- 独立动画资产从 153 提升到 **至少 220**，但新增数量不得掩盖旧动画质量问题。
- 静态分析图与实物图合计从 86 提升到 **至少 180**，其中实物照片只在“器件识别、测量、装配、失效实物”场景使用，不拿照片替代原理图。
- 每章连续纯正文间隔目标 400–1200 字；**硬上限 1500 字**。超过 1200 字必须说明原因，超过 1500 字直接失败。
- 同一小节内不得连续堆两张无文字承接的图；相邻视觉之间至少保留 400 字或一个完整三级标题。
- 每个超过 800 字的二级小节至少有一个内嵌视觉锚点。
- 只有链接、表格、公式、计算器不能冒充插图数量。

### 3.2 教学质量

- 每张图必须承担一种明确职责：现象、结构、推导、对比、流程、边界或实验。
- 每张图前有问题，图后有“看什么”和至少一个可回对正文的数字、公式或判据。
- 至少 35% 的复杂说明段由图替代，正文缩为 1–3 句导读；公式、量化指标和失效边界不得删除。
- 同一概念不允许“正文解释一次、图注再抄一次、动画字幕又抄一次”。三者必须分工。
- 读者只看图和图注，也能复述本节的因果链；只看正文，也不会丢公式和关键数值。

### 3.3 视觉质量

- 所有新图必须登记 handraw-style 的 `style_id`、`layout_id`、`color_ids` 和最终提示词。
- 每张图五项评分均不低于 4/5：教学必要性、事实精度、构图层级、风格一致性、印刷可读性。
- 动画另加两项：运动叙事、交互节奏；七项总分至少 30/35。
- 禁止装饰性大图、微缩桌面摆拍、无关人物、童话拟人元件、空洞色块拼贴和纯文字海报。
- 公式、器件参数、引脚名、波形坐标和中文正文必须由确定性 SVG/HTML 图层绘制，不交给生图模型猜字。

### 3.4 发布质量

- 站点、离线书、A4 PDF、16K 分卷、视频和社媒使用同一视觉资产清单。
- 网页动画有播放、暂停、重播、速度和减弱动效路径；无 JavaScript 时仍可读。
- 印刷版使用关键帧分镜，不截断公式、字幕和图注。
- 19 章全部过闸后才允许更新 ship-gate、提交、推送和部署。

## 5. handraw-style 使用契约

### 5.1 工具边界

指定使用 `yang0/handraw-style` 作为视觉设计与提示词主链，但项目构建不得依赖开发者机器上的绝对路径。

- 生成阶段使用 handraw-style 的 367 种风格、170 种图型和 36 种主题色。
- 仓库只提交最终资产、最终提示词、选择结果和来源锁；不复制整个外部仓库。
- 记录上游 URL、提交哈希和使用的索引版本；升级上游必须重新跑视觉回归。
- 当前本地上游完整校验存在一处与本项目无关的绝对路径泄漏，因此本项目只锁定并校验实际使用的 style/layout/color 条目，不把上游全库校验作为 CI 前提。

### 5.2 插图规划流程

每张图必须按以下顺序产生：

1. 用 article-illustration-planner 扫描章节，确定插入点和要替代的繁文。
2. 从 handraw-style 全库动态选择视觉风格，不维护“关键词→固定风格”的死映射。
3. 为信息结构选择明确的图型 ID。
4. 记录主题色与语义色。
5. 生成视觉底图或构图参考。
6. 由确定性 SVG 图层覆盖电路、公式、数字、坐标和中文标注。
7. 经人工审图后回填正文，并删减被图替代的文字。

### 5.3 推荐图型集合

图型按信息结构选择，不按章节机械分配：

| 教学任务 | 优先图型 |
|---|---|
| 元件/系统中心标注 | IG-002 中心主图标注 |
| 两种方案、正常/失效对比 | IG-004、IG-011 |
| 排故与设计流程 | IG-008 |
| 时序、充放电、状态推进 | IG-009、IG-028 |
| 层级、能量或误差预算 | IG-012、IG-024 |
| 设计象限与选型 | IG-014、IG-015 |
| 反馈与控制闭环 | IG-019 |
| 器件内部结构与 PCB 层叠 | IG-026、IG-027 |
| 高密度公式和波形讲义 | IG-033 |
| 编辑式知识主图 | IG-032 |

### 5.4 风格与色彩

- FA-029 `Geometric Diagrammatic Narrative` 只保留为技术图候选，不再作为所有图的机械外壳。
- 先用 ch0、ch8、ch17 三章做风格试片，从全库动态选出 3 套候选，再锁定一套主风格和最多两套辅助风格。
- 2026-11-05 确认的新图色族为 C-34 奶油白纸、C-32 炭黑墨、C-35 石板灰阴影、C-26 柿子橙重点，主风格为 FF-015。旧 C-30/C-31/C-29 资产在逐张审查迁移前仍保持现役；不能把换色算作重做。辅助风格尚未选择。
- 风格参考图只影响线条、媒介、质感和色彩，不得带入参考图中的人物、场景、文字和构图。

### 5.5 图文模式边界

- 概念主图、章节 hero 可使用纯图模式。
- 信息图可使用图文模式确定构图，但最终中文、公式和参数仍由代码层重绘。
- 不允许把 AI 生成的中文小字直接放进教材成品。
- 不允许用一张“看起来很高级”的图替代准确的电路连接和波形关系。

## 6. 静态插图分类

每张静态图必须属于以下一种类型，并在 manifest 中登记。

| 类型 | 目的 | 典型内容 |
|---|---|---|
| V1 现象主图 | 先让读者看见问题 | 电容充电、地弹、热失控、探头负载 |
| V2 结构图 | 看清对象关系 | 器件剖面、拓扑、信号链、回流路径 |
| V3 定量图 | 把公式变成空间关系 | 曲线、预算条、面积、尺度、容差 |
| V4 对比图 | 看清取舍和边界 | 正常/失效、快/稳、便宜/可靠 |
| V5 流程图 | 支撑操作与排故 | 测试步骤、决策树、设计闭环 |
| V6 实物证据 | 连接抽象与现场 | 芯片、探头、焊点、仪器读数 |

禁止把 V6 实物照片当作 V2 原理图使用。

## 7. 动画 V2 规格

### 7.1 旧动画处置

153 张旧动画逐张进入清单，只能得到三种结论：

- **Rebuild**：主题有价值，但视觉、节拍或信息组织不合格，重新设计。
- **Retire**：与其他动画重复，或静态图更合适，删除正文入口并保留迁移记录。
- **Keep after review**：事实、构图和节拍全部过新量规；预计应是少数，不得默认保留。

不允许“换背景色、加纸纹”后就算重做。

### 7.2 动画类型

| 类型 | 叙事目标 |
|---|---|
| A1 机理动画 | 电荷、电流、能量、磁通怎样移动 |
| A2 推导动画 | 公式如何从电路一步步生长出来 |
| A3 参数扫描 | 改一个参数，曲线和工作点怎样变化 |
| A4 失效边界 | 从正常跨过阈值后哪里先坏 |
| A5 操作演示 | 探头、上电、测量、排故动作顺序 |

### 7.3 节拍与镜头

- 每个动画 4–7 个命名节拍，每拍只讲一个动作。
- 开场 1 秒内提出问题或显示初态，不允许先播装饰循环。
- 使用非线性缓动，禁止所有图元同速、同时出现。
- 每拍必须有唯一视觉主角；旧信息降权，不得全屏同权闪动。
- 至少使用两层运动：主对象运动 + 焦点/镜头/标注运动。
- 参数扫描必须显示当前值、工作点和变化方向。
- 结尾保留可停留的结论帧，不自动闪回初态破坏阅读。
- 文章默认播放一次；重播由用户触发，不做无限循环干扰阅读。

### 7.4 交互

网页播放器支持：

- 播放 / 暂停 / 重播；
- 0.5× / 1× / 1.5×；
- 节拍跳转与当前节拍标题；
- reduced-motion 静态关键帧；
- 键盘与屏幕阅读器标签；
- 无 JavaScript 的静态回退。

### 7.5 架构

保留 SVG 作为离线与印刷友好的交付格式，但废止“所有主题写在一个 9589 行文件中”的继续扩张方式。

建议结构：

```text
scripts/visuals/
  tokens.py
  primitives.py
  timeline.py
  layouts.py
  render.py
  scenes/
    ch00_*.py
    ch01_*.py
    ...
assets/svg-v2/
docs/superpowers/visual/
  visual-manifest.yml
  animation-v2-manifest.yml
  prompts/
  reviews/
```

旧 `assets/svg/` 在迁移完成前只读；新动画通过 manifest 切换，禁止一次性覆盖导致无法对照。

## 8. 文字改造规则

视觉改造必须真正减少阅读负担。

- 图替繁文时，先列出必须保留的公式、数字、条件和结论。
- 被图替代的 4–10 段文字缩成 1–3 句导读；不得只是插图后保留原文全文。
- 长列表优先改为流程、矩阵、剖面、参数图或对比图。
- 公式推导保留正文可复制版本；图负责步骤关系，不负责成为唯一公式来源。
- 删除重复比喻、重复解释和图注复述，但不删除失效边界与工程条件。
- 每章改造后字符数原则上下降 10%–25%；若字符数上升，必须由新增实验步骤或事实来源解释。

## 9. Manifest 与可追溯性

每项视觉资产至少记录：

```yaml
id: ch08-sample-hold-charge
chapter: 8
anchor: ch8-sample-hold
kind: animation
purpose: parameter-sweep
style_id: FA-029
layout_id: IG-009
color_ids: [C-30, C-31, C-29]
source_facts:
  - docs/p1-09-ch8.md#ch8-sample-hold
prompt_file: docs/superpowers/visual/prompts/ch08-sample-hold-charge.md
output: assets/svg-v2/ch08-sample-hold-charge.svg
print_fallback: assets/figures-v2/ch08-sample-hold-charge-storyboard.svg
text_replaced: ch08-sample-hold-charge-copy
status: draft
review_scores: {}
```

硬规则：

- 无 manifest 不生成；
- 无来源不写死数字；
- 无 prompt 记录不算使用 handraw-style；
- 无 print fallback 不得进入正文；
- 无审图分数不得标记 accepted。

## 10. 自动化验收

新增或改造以下检查：

| 闸 | 失败条件 |
|---|---|
| `audit_visual_density.py` | 章节视觉数不足、最长无图段 >1500、视觉聚集 |
| `check_visual_manifest.py` | 缺 style/layout/color/prompt/source/output |
| `test_visual_manifest.py` | ID 重复、文件缺失、章节/锚点不存在 |
| `test_visual_distribution.py` | 二级小节 >800 字无图、连续堆图 |
| `test_animation_v2.py` | 节拍不足、无限循环、无结论帧、无 reduced-motion |
| `test_visual_fidelity.py` | 图中数字/公式无法回对正文来源 |
| `test_visual_player.py` | 播放、暂停、跳拍、键盘、无 JS 回退失败 |
| `test_print_storyboard.py` | 打印关键帧缺字、过小或顺序错误 |
| `test_visual_quality_floor.py` | 任一人工评分维度 <4/5 |

数量闸和质量闸必须同时通过。

## 11. 分阶段策略

### P0 基线与冻结

- 当前动画、视频和 PDF 作为对照样本保留，不推送为最终版。
- 建立视觉审计脚本、manifest 和质量量规。

### P1 三章试片

- ch0：零基础直觉与比喻；
- ch8：全书最长章、结构和时序复杂；
- ch17：视觉断层最严重的排故章。

每章至少重做 6 张静态图和 4 个动画，生成原版/新版接触表，用户确认风格后再扩量。

### P2 高风险章节

优先 ch17、ch18、ch0、ch15、ch8、ch16、ch10、ch2，把最长无图段全部压到 1500 字以内。

### P3 全书覆盖

完成其余 11 章，达到每章视觉预算和文字压缩目标。

### P4 动画库重构

完成 153 张旧动画处置，重建不合格项，新增到至少 220 张；上线播放器与打印分镜。

### P5 五线派生

重建站点、离线书、A4 PDF、16K 分卷、视频与社媒视觉资产。

### P6 发布

全闸通过、人工审图签字后，才允许提交、推送和部署。

## 12. 非目标

- 不为了加图删掉公式、量化指标、来源和失效边界。
- 不把整书做成社媒卡片合集。
- 不把 AI 生图中的文字当正式教材文字。
- 不把每章强行套同一个信息图模板。
- 不以动画数量替代动画质量。
- 不在试片未确认前批量生成数百张资产。
- 不复活平行正文源；`docs/*.md` 仍是内容权威源。

## 13. 主要风险与对策

| 风险 | 对策 |
|---|---|
| 图多导致页数爆炸 | 双卷页数预算前置；优先图替繁文而非只加图 |
| AI 文字和电路幻觉 | 生图只负责底图与构图；公式、电路、中文由确定性图层绘制 |
| 风格混乱 | 三章试片后锁主风格与辅助风格；manifest 强制登记 |
| 动画 CI 太慢 | 场景模块化、抽样浏览器测试、全量静态结构检查 |
| handraw-style 上游变化 | 锁 commit；提交解析后的提示词与最终资产；构建不依赖外部目录 |
| 旧链接失效 | 新旧资产并存迁移，manifest 控制切换，保留重定向 |
| 读者被动画打扰 | 默认单次播放、可暂停、reduced-motion、结论帧停留 |
