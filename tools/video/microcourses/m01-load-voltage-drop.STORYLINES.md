# m01 故事线：满电一拧把为什么掉两格

## 推荐 A · 同一块仪表盘，一次加速实验

**装置与形式**　把电池包、内阻、负载和仪表盘放在同一个连续画面里；一次拧把让电流从 0 A 变成 20 A，端电压沿同一根时间轴下跳，松开后回弹。

观众先看到“满电掉两格”，然后镜头进入电池包内部，把 `20 A × 20 mΩ = 0.40 V` 贴回仪表读数；同一输入再换到低温的 120 mΩ，压降变成 2.40 V，最后回到仪表盘回答：掉的是带载电压，不是电量瞬间消失。

- 前两秒：满电图标在拧把瞬间掉两格，旁边只出现一句“电去哪了？”
- 节拍：现象 → 三根探针 → 室温一笔账 → 低温同一笔账 → 撤载回弹 → 边界 → 一题验收
- 画面：BMS-Z 深色底；电池与回路占画面 55%，右侧时间轴占 35%；青色表示读数，琥珀表示电流，红色只给越界或压降。
- 声音：旁白为时钟；开关闭合、数字落地和回弹各一个短音效，BGM 保持中性。

## B · 电压表受审

电压表站在“证据席”，SOC、内阻、温度和电流逐个出示证据。形式是一次交叉询问：同一个 3.5 V 读数可能来自低 SOC，也可能来自大电流与高内阻，最后判词是“电压不是电量的直接读数”。

前两秒是电压表被盖章“没电？”又立刻打上问号。它更适合讲不可辨识，但人物化会稀释本课唯一的一笔 `I×R` 账，所以不选。

## C · 冬天地铁站

把锂离子比作晚高峰乘客，低温让通道变慢；拧把相当于突然加大发车需求，门口拥堵表现为更大的压降。形式是从地铁站连续变形到电池回路。

前两秒是站台从畅通变拥堵。它记忆点强，但更接近“为什么低温内阻大”，会让主问题从端电压与 SOC 的区别偏到电化学机制，所以留作后续低温微课。
