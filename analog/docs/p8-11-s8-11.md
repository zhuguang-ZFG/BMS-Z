## 8.11 十九章顺口溜总表：一章一句，过目不忘

**表 E-4　十九章顺口溜总表（一章一句）**

| 章 | 口诀 | 一句话记住 |
|---|---|---|
| [第 0 章](p1-01-ch0.md#ch0) | 先上车，再赶路 | 直觉优先：电压像水位、电流像水流——先把画面装上，公式随后就到 |
| [第 1 章](p1-02-ch1.md#ch1) | 寄生是真实价 | 元件都"夹带私货"：线有电感、电容有 ESR/ESL——高频下它们才是主角 |
| [第 2 章](p1-03-ch2.md#ch2) | 0.7V 是门票 | 二极管导通要买 0.7V 的票；想省钱？肖特基半价 |
| [第 3 章](p1-04-ch3.md#ch3) | Q 点居中 | 放大先摆工作点：Q 点居中，信号骑在平衡木上前后都不撞轨 |
| [第 4 章](p1-05-ch4.md#ch4) | 米勒平台 | 开关绕不开米勒电容——栅压爬那条平路时，管子最烫 |
| [第 5 章](p1-06-ch5.md#ch5) | 线与要上拉 | 开漏输出缺上拉就是废物；I2C 那 4.7k 不是随便选的 |
| [第 6 章](p1-07-ch6.md#ch6) | 虚短虚断，两天花板 | 两条金律推演一切；GBW 与压摆率决定运放身手 |
| [第 7 章](p1-08-ch7.md#ch7) | 迟滞免抖 | 噪声在门限附近抖？给比较器一对分离的门槛，判决立刻干净 |
| [第 8 章](p1-09-ch8.md#ch8) | 传输门并联，电荷会踢人 | 模拟开关 NMOS+PMOS 并联才轨到轨；关断那一脚"踢"污染采样 |
| [第 9 章](p1-10-ch9.md#ch9) | 基准是定盘星 | 系统精度的上限由基准定——它飘一步，全链路跟着飘 |
| [第 10 章](p1-11-ch10.md#ch10) | 充到 2/3，放到 1/3 | 555 的两道门限（2Vcc/3、Vcc/3）是一切公式的源头 |
| [第 11 章](p2-01-ch11.md#ch11) | 三组态看阻抗，差分只看差 | 共射反相、共集跟随、共基高频；差分放大器只放大"差" |
| [第 12 章](p2-02-ch12.md#ch12) | 节点方程与工作边界 | 先画回路，再列节点；增益、摆幅、带宽与稳定性分别验 |
| [第 13 章](p2-03-ch13.md#ch13) | 伏秒平衡，死区保平安 | 电感"充的伏秒=放的伏秒"；桥臂换向留死区，免得上下管对撞 |
| [第 14 章](p3-01-ch14.md#ch14) | 先分块，再动手 | 复杂电路拆成"功能块+接口"，每块单独验证，集成才不抓瞎 |
| [第 15 章](p3-02-ch15.md#ch15) | 回流短，去耦近 | 高频电流走最小环路：去耦电容贴引脚、回流路径别开天窗 |
| [第 16 章](p4-01-ch16.md#ch16) | 一次只改一个变量 | 排故像做实验：单变量对照，否则永远不知道是谁修好的 |
| [第 17 章](p4-02-ch17.md#ch17) | 先查电源与时序 | 故障表第一条永远是电源——近一半故障轮不到芯片背锅 |
| [第 18 章](p4-03-ch18.md#ch18) | 仪器比自信可靠 | 示波器从不说谎：相信测量、怀疑直觉，症状按序记录 |
