1. **单源**：所有章节正文只存在于 `docs/*.md`；站点、书、视频旁白稿、社媒文案皆由其派生，无平行中文树、无「书稿目录 vs docs 目录」双源。

## 4. 受众与精通定义

### 4.1 主读者

**零基础能跟，一路通到能独立设计的工程师。**

- 入门：高中物理级电压/电流即可；不要求先修模电课。
- 中段：能算偏置、读 datasheet 关键行、解释一种失效。
- 末端：能在约束下完成小信号/电源/运放应用级设计并写出测试步骤。

### 4.2 「精通」落地标准（过关定义）

读者（或章末设计作业提交物）必须能交出一份**设计说明**，至少含：

| 块 | 必须有 |
|---|---|
| 指标 | 输入/输出范围、带宽或响应、功耗或效率、精度、环境温度 |
| 选型 | 关键器件型号或明确选型窗（含备选与否决理由） |
| 极限工况 | 至少 3 个 corner（温度、负载、供电、容差等）及预期行为 |
| 测试步骤 | 可复现的测量顺序、仪器与合格判据 |
| 失败预案 | 若不合格，优先怀疑点与下一刀测量 |

达不到上表 = 本章/本阶段未过关；题库分数不能替代。

## 6. 章节契约

每一章（ch0–18）重写后必须同时具备：

### 6.1 结构槽位（顺序固定）

1. **钩子现象**（现场或桌上能感知的一件事）
2. **直觉**（不写公式先建立因果）
3. **定量推导**（公式 + 限定条件 + 数量级）
4. **失效边界**（何时模型崩、典型翻车）
5. **动手验证**（仿真步骤或实作步骤，可复现）
6. **自检**（可判定对错；含至少一题指向设计判断）
7. **（可选）进阶框**——跳过仍可过关

### 6.2 每章必交四件套

| 交付物 | 要求 |
|---|---|
| **口诀卡 ×1** | 一句「一点就懂」；进第八篇顺口溜总表同源 |
| **手绘主图 ×≥1** | FA-029 纸墨技术图；有中文标注；图前有提问、图后有含数字的读图指引 |
| **可复现数值例 ×≥1** | 条件写全；结果可手算或仿真复核；无出处不写死 |
| **验收清单** | 读者怎样算过关（观察/计算/测量三条里至少两条可勾） |

### 6.3 事实源

只许来自：现有已校对 docs、厂商 datasheet/应用笔记（写明型号与章节）、已验证算例/仿真。  
**无出处 → 不写死数字**；教学示意须标明「示意」。

## 7. 文风与去 AI 味

### 7.1 声线

- **冷静教练**：短句说清因果；允许现场感；**禁止编造亲身经历**。
- 通篇按 `D:\Users\monidianlu\humanizer-zh.md` 重写；只保留事实、公式、推导与限定条件。

### 7.2 必杀套话（默认删除或改写）

- 假对比：「不是…而是…」「与其说…不如说…」——**真教学对比**（如「开环 ≠ 闭环」）进白名单，其余清掉。现状 docs 中残留「不是…而是」量级约 60+，重写时清零非白名单项。
- 空收尾、万能总结、排比灌鸡汤、伪严谨套话（「值得注意的是」「在本章中我们将」）。
- 过完 humanizer 后再跑一轮 **stop-slop**（仓库既有文风/套话检查习惯保留；无脚本则人工抽检 + 检索高频套话表）。

### 7.3 白名单（允许保留的「对比」）

仅当对比指向**可操作的工程区分**时保留，例如：开环/闭环、典型值/保证值、推挽/开漏、示意/实测。白名单句须能改写成「A 做 X；B 做 Y」而不失信息。

### 7.4 与 CONTRIBUTING 文风条款的关系

CONTRIBUTING「说人话、给数量级、每图配精髓」仍然有效；本 spec 在其上叠加 humanizer 全量重写与套话闸。提示块继续用纯文本粗体标签（如 `> **精髓**：`），不加 emoji 前缀。

## 8. 视觉 DNA 与工具链

### 8.1 统一原则

**几乎所有配图改为手绘技术图；动画也呈手绘气质。**  
手绘 = **FA-029 Geometric Diagrammatic Narrative（精密几何图示叙事）**，不是卡通插画。元件该直的地方仍然直；手绘感来自微弯长线、纸纹、楷体标题、赭石马克笔与纸墨色，**不用** `feTurbulence` 抖线滤镜（性能与印刷不可逆理由见现 `HANDRAW-STYLE.md`）。

### 8.2 分层工具

| 层 | 规范 / 工具 | 用途 |
|---|---|---|
| 正文 / 印刷 / SVG 原理图 | `analog-book/HANDRAW-STYLE.md` + `scripts/handraw.py` | FA-029；纸 C-30 `#fdf8ea`；墨 C-31 `#16202b`；标记 C-29 `#a4630f`；语义色四档规则 |
| 静态分析图补强 | 几何手绘技术图流程（可参考 ningzimu/handdrawn-tech-illustrations 一类 skill 的中文标注与信息密度做法） | 章内 hero / 分析图；中文可读、密度适中 |
| 封面 / EP 缩略图 / 社媒主视觉 | [yang0/handraw-style](https://github.com/yang0/handraw-style) 风格编号与提示词 | 与正文同纸墨气质；只改画幅与装饰密度 |
| SVG 生成铁律 | `scripts/generate_svgs.py` → `assets/svg/` | 禁止只改 SVG 不回灌脚本 |

### 8.3 视觉 DNA（全书锁死）

- 近白暖纸底（C-30）；统一线宽层级；标记色克制（主标记赭石 + 有限语义色，全书 3–5 个「指路」色习惯，不章章换肤）。
- 简体中文标注可读（标题楷体栈 + 正文/图内无衬线栈按 HANDRAW-STYLE；缺字形兜底字体随包）。
- 信息密度适中：一张主图一个问题；禁止装饰性无标注图。
- 封面 / 正文 / 动画 / 印刷 **共用 DNA**；只改裁切与密度。
- 动画：保留教学节奏与**数值、封装、电流路径真实性**；外壳纹理、线型、色板迁到纸墨手绘气质。

### 8.4 禁止

- 每章换画风；花哨渐变科技风；看不清的汉字；无标注装饰图；原理图卡通化；打印版剥掉关键节拍说明（v3.90 已修的回归项继续守）。

## 9. 内容源与派生流水线

### 9.1 顺序（Approach A，强制）

```
① 按章节契约重写 docs/*.md（唯一内容源）
        ↓
② 重建 MkDocs 站点（含搜索、动画画廊、深浅色）
        ↓

        ↓
⑤ 公众号 / B 站 / 小红书切片（同源缩略，不改结论）
```

未完成①不得宣称②–⑤「终态上架」。允许用旧站旧片作过渡，但对外「整包重做完成」必须以①过闸为前提。

### 9.2 同源锁（五线共享）

同一章必须共享：

- 标题（可有介质后缀，如「｜动画」但不改章名语义）
- 口诀卡
- 主图隐喻（同一物理故事）
- 关键数值与条件
- 验收清单条目

五线只改编幅、时长、信息密度。

### 9.3 继承自 v3.90 / SPEC-V4（不回退）

- 图前提问、图后含数字读图指引
- 打印版保留动画叙事关键帧/说明
- 视觉密度下限意识（低密度章重写时优先补 hero 与分析图）
- `docs/` 唯一权威；本 spec 只规划，不把正文写进 spec 目录
