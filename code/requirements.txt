# 为什么不上限得更紧（精确 ==）：读者环境五花八门，锁死小版本会让 Python 3.10

# 更早发现"新版本把教程跑挂了"。
#
# 需要完全复现 CI 环境时，用下面注释里的版本——那是 CI 最近一次全绿的组合。
