## 8.10 模拟黑话速查表：一句话 + 直达章节

> 新手最怕的不是公式，是行话。每个词一句话说完；想知道细节，点最后一列。

**表 G-22　模拟电路黑话速查（一句话 + 直达章节）**

| 黑话 | 一句话 | 直达 |
|---|---|---|
| 虚短/虚断 | 深负反馈下，运放两输入端"电压相等、电流为零"——分析一切闭环运放电路的两公理 | [12.1](p2-02-ch12.md#ch12) |
| 增益带宽积 GBW | 增益×带宽≈常数：要 100 倍增益，1MHz 运放只剩 10kHz 可用带宽 | [6.3](p1-07-ch6.md#ch6) |
| 压摆率 SR | 输出"每微秒最多爬几伏"——大信号正弦变三角波的元凶 | [6.7](p1-07-ch6.md#ch6) |
| 轨到轨 Rail-to-Rail | 输入/输出能贴到电源轨（或几乎贴到）——单电源供电的救命参数 | [6.3](p1-07-ch6.md#ch6) |
| 失调电压 V_OS | 输入为 0 输出却不为 0——运放的"天生长歪"，µV 级是精密分水岭 | [6.3](p1-07-ch6.md#ch6) |
| 共模抑制比 CMRR | 两输入同涨同跌时输出纹丝不动的程度——差分对的看家本领 | [11.2](p2-01-ch11.md#ch11) |
| PSRR | 电源上的纹波被输出"吸走"多少 dB——电源脏了输出也脏 | [6.3](p1-07-ch6.md#ch6) |
| 米勒效应 | 反馈电容被增益放大 A 倍——栅/集电极电容是设计者看不见的拖油瓶 | [第 4 章](p1-05-ch4.md#ch4) |
| 体二极管 | MOSFET 结构自带的寄生二极管，方向永远朝上——H 桥滑行全靠它 | [13.7](p2-03-ch13.md#ch13) |
| 上拉/下拉电阻 | 把悬空的线"请"到一个确定电平的电阻——I2C 4.7kΩ 的由来 | [第 5 章](p1-06-ch5.md#ch5) |
| 线与 Wired-AND | 多个开漏输出并联：任何一家拉低线就是低——没有短路路径的安全并联 | [第 5 章](p1-06-ch5.md#ch5) |
| 死区时间 | 换向瞬间上下管"都别开"的空窗，1~2µs——没有它就是烧管倒计时 | [13.7](p2-03-ch13.md#ch13) |
| 迟滞/回差 | 比较器故意加宽的"模糊带"——噪声在门限附近抖也不误翻 | [第 7 章](p1-08-ch7.md#ch7) |
| 伏秒平衡 | 开关电源稳态：电感一周期"充的伏秒=放的伏秒"——Buck 一切公式的根 | [13.2](p2-03-ch13.md#ch13) |
| 纹波 | 输出电压每周期的小锯齿——设计就是给它划红线 | [13.2](p2-03-ch13.md#ch13) |
| 温漂 ppm/°C | 每升温 1°C 变化百万分之几——基准与精密电阻的身价指标 | [第 9 章](p1-10-ch9.md#ch9) |
| 混叠 Aliasing | 采样不够快，高频信号伪装成低频假信号——软件救不回来的失真 | [13.6](p2-03-ch13.md#ch13) |
| 奈奎斯特 2 倍率 | 采样率必须 > 2×信号最高频率——混叠的第一道防线 | [13.6](p2-03-ch13.md#ch13) |
| LSB 量化台阶 | ADC 把连续电压切成 2^N 格，每格的高度——分辨率的天花板 | [13.6](p2-03-ch13.md#ch13) |
| 波特图 | 增益/相位随频率的"体检报告"——−20dB/dec 是一阶 RC 的指纹 | [12.5](p2-02-ch12.md#ch12) |
| 戴维南等效 | 任何线性网络都能简化成一个电压源串一个电阻——化简万能钥匙 | [1.4](p1-02-ch1.md#ch1) |
| 寄生参数 | 元件"夹带"的 L/C/R——高频下反客为主的隐形元件 | [第 1 章](p1-02-ch1.md#ch1) |

| 自举 Bootstrap | 一只电容把高侧管栅极"举"到比电源还高——否则高侧永远开不透 | [13.7](p2-03-ch13.md#ch13) |
| droop/电荷注入 | 保持电容漏电下垂 + 开关断开踢一脚——采样保持的两大天敌 | [8.4](p1-09-ch8.md#ch8) |
| 巴克豪森判据 | 振荡两个条件：环路增益=1、相移=0°——审视一切振荡电路的尺子 | [13.4](p2-03-ch13.md#ch13) |
