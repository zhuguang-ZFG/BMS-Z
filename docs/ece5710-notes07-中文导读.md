## 一、一页速览

热模型要同时算两件事：电芯内部怎么生热，边界怎么把热交出去（7–1 页）。生热四项后来会反复出现。

| 项 | 谁在发热 | 符号 | 原文 |
|---|---|---|---|
| 不可逆 | 界面反应的过电位，永远非负 | q_i = a_s F j η | 7–11 |
| 可逆 | 熵变，可正可负 | q_r = a_s F j T ∂U_ocp/∂T | 7–11 |
| 固体欧姆 | 固体电流走有效电阻 | q_s = σ_eff (∇φ_s · ∇φ_s) | 7–11 |
| 电解液欧姆 | 离子电流和浓溶液项 | q_e | 7–11 |

> **口诀**　过电位一定发热。熵变看材料，有时吸热。欧姆热跟电流平方走。BMS 报温度，冷却系统搬热，两边别抢同一只接触器。
>
> **能记住**　四项热和佩尔捷系数。**能理解**　为什么 ROM4 省算力、长工况会偏。**能用**　能把「10 °C 翻倍」继续当成口诀，而不是这一章的公式。

## 二、温度、三种传热（§7.1）

精确说法：粒子数和体积不变时，1/T = ∂S/∂U（7–1…7–2 页）。粗说法是温度联系着分子平动动能。热从高温物体自发流向低温物体。

传导靠接触，对流靠流体搬家，辐射不需要介质，高温表面才显著（7–3…7–4 页）。这三项在电芯边界上都会再出现。本章的体方程先处理电芯内部。

## 三、微观热方程（§7.2）

推导依据 Gu 和 Wang 的多相热方程（7–5 页）。讲义把它收到每一相（7–8 页）：

```
ρ_k c_{P,k} ∂T_k/∂t = ∇·(λ_k ∇T_k) − i_k · ∇φ_k
```

右边第一项是传导，第二项是该相电流和电位梯度点乘，也就是欧姆热。界面上还要配边界（7–8 页）：

```
λ_e ∇T_e · n̂_e + λ_s ∇T_s · n̂_s = F j η + F j Π
```

左边是流入两相的热通量。右边第一项是不可逆热，永远为正；第二项是可逆热，符号看反应方向。佩尔捷系数来自 Newman 1995（*Ind. Eng. Chem. Res.* 34, 3208–3216）：

```
Π_j = T ∂U_ocp,j / ∂T
```

∂U_ocp/∂T 是开路电位的温度系数，单位在图上是 mV/K。石墨、LFP、LMO 三条曲线都随嵌锂量变号（7–11 页）：同一颗电芯，有的 SOC 在吸热，有的在放热。

四项体热生成的最终名单也在 7–11 页。接触电阻和集流体电阻另算，q_c = i_app² (R_contact + R_cc)，单位是 W/m²，只铺在接触面上，不要和体热的 W/m³ 加在同一个格子里。

> 【译注】阶段 0 的「每升高约 10 °C 老化翻倍」是口诀，不是这条热方程。可逆热可以是负的，所以「有电流就一定净发热」不成立。保护用的温度阈值仍看数据手册和阶段 0 的事故链，不从熵曲线上读出一个关断点。

## 四、连续介质和边界（§7.3）

体积平均把各相收成电芯尺度的温度场（7–9…7–10 页）。固相和液相电流仍用上一章的有效电导写法。平均之后，界面上的不可逆热和可逆热变成体源，因为比表面积 a_s 把面积摊进体积。

边界三条（7–12…7–13 页）：

- 传导：给定表面温度，或给定热通量。
- 对流：−λ ∂T/∂n = h (T − T_∞)。h 是对流系数。
- 辐射：表面很热时才重要，形式是表面发射和吸收的四次方差。

h 不是材料常数。风冷、液冷、紧贴冷板，差一个数量级很正常。讲义后面的对比用 h = 0、5、25 做灵敏度，不是推荐设计值（7–35 页）。

## 五、降阶：四项热分别怎么省（§7.4–7.6）

降阶要做两截（7–14 页）：先把四项热生成算成总热 q，再用 q 推动平均温度。电位梯度的传递函数可以复用电化学 ROM，因为集流体处的绝对电位不进梯度（7–15…7–16 页）。

**可逆热 q_r**。认真的做法是在电极厚度上取几个 z，查每点的熵，再积分（7–21 页）。ROM1 到 ROM3 用五个点、梯形积分。更粗的 ROM4 假设表面浓度等于平均浓度，积分收成（7–22 页）：

```
q̄_r = i_app(t) T / A · ∂U_ocp(c_avg) / ∂T
```

短脉冲上 ROM1 和 ROM4 差不多，因为固体表面还没拉开梯度。时间一长，ROM1 会明显更好（7–22 页）。负极熵用图上的石墨，正极用 LMO。换了化学体系不能沿用这两条曲线。

**不可逆热 q_i** = a_s F j η，同样在若干 z 上求和（7–23 页）。j 来自传递函数，η 来自非线性关系。讲义还把状态空间的输出乘开，看哪些二次项可以丢掉以省算力（7–24…7–25 页）。ROM2 留全项。省项之前要看总热，不能只看某一项的相对误差。

**固体欧姆热、电解液欧姆热**（7–26…7–29 页）。q_s = σ_eff (∇φ_s · ∇φ_s)。电解液那一项还有 κ_D 和 ln c_e。DRA 线性化时用的是设定点上的 κ_eff(c_e,0)，浓度跑远了要有心理准备。多种工况下 ROM1 更稳，但 ROM3 的总热误差常常已经够小。选哪一档看算力，不看名字。

> 【译注】阶段 6 §6.1.6 把 BMS 和热管理系统的边界写成：BMS 提供温度和允许功率，冷却回路自己闭环。这一章是「热从电化学里怎么算出来」。它不把水泵和压缩机写进 BMS。`code/firmware/` 没有热模型。

## 六、平均温度（§7.7）

沿厚度猜一个形状（7–31 页）：

```
T(x, t) ≈ T_∞ + a(t) + b(t) sin(π x / L_tot)
```

对流边界把 b 锁在 a 上：b = h L_tot a / (λ π)。再对整段厚度平均，平均温度只剩环境温度加一个系数乘 a(t)（7–33 页）。h = 0 时没有这项正弦，公式要换成分段形式，讲义把 B_q 写成 h = 0 和 h ≠ 0 两支（7–34 页）。

UDDS 上，h = 0、5、25 三档，ROM1–4 都贴着全阶模型，ROM4 因为 q_r 太粗而稍差（7–35 页）。温升在这些图里是零点几 K 的量级，那是这条电流和这组传热系数的结果，不是「UDDS 只会热这么多」。

宽范围用法（7–35…7–36 页）：阿伦尼乌斯关系先把参数放到不同温度，离线在 SOC–温度网格上做 ROM；在线一边更新 SOC，一边更新温度，再去掺电化学模型。剩下的难题是物理参数仍然常常要靠拆解和专用实验才能定全（7–36 页）。

> 【译注】不要拆电芯去凑这套参数。阶段 0 的热失控是正反馈：热来不及离开，反应加快，再热。本章的正弦温度型假设在那之前就已经不成立。固件里的过温阈值仍是手册值。阿伦尼乌斯在这里只解释「参数为什么随温度变」，不要把它写成新的保护公式。
