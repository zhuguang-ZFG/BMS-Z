# 按目标选路线：六条任务导向捷径

> 七个阶段是**完整路线**（业余每天 1–2 小时，约 4–8 个月）。但很多人是带着一个具体目标进来的：
> 「我就想把储能柜的数据读到手机上」「我只搞算法，不碰硬件」「我要给航模电池做块保护板」。
> 这一页把线性路线**重排成任务图**：每条捷径只列达成那个目标**必须**读的小节，其余留到想深入时再补。
>
> 还不确定自己在哪一层 → [能力地图](bloom-map.md)（零基础不用先读七阶段表）。还不确定自己要做什么 → [前两周怎么走](getting-started.md)；想看全图 → [学习路线总纲](../bms-resources.md)。
> 已经在动手、需要回查公式或排障 → [参数速查卡](../参数速查卡.md)。

⚠️ **捷径省的是顺序，不是安全。** 任何会碰真电池的路线，[阶段 2](stage-2-保护板实践.md) 的安全纪律与护目镜、防火垫（[器材清单](../budget.md)）都不能跳；本页出现的阈值一律是示例值，以电芯与芯片 datasheet 为准。

|---|---|---|---|---|---|

## A 做一块 3–4 串保护板，并实测保护动作

**布鲁姆层**：主层 [应用](bloom-map.md#应用)。过充为什么致命是 [理解](bloom-map.md#理解)，电压红线和保护名词是 [记忆](bloom-map.md#记忆)。

**场景**：手里有几节 18650 或航模电池，想要一个能真正断开的保护，并且自己说得清它为什么断。这是从零到摸到实物最短的闭环，器材便宜、失败代价小。

**最短路径**

1. [阶段 0 §0.1 锂电池化学基础](stage-0-前置知识.md#01-锂电池化学基础-理解) —— 只读这一节，搞清过充/过放为什么致命
2. [阶段 1 §1.4b 五大保护背后的事故](stage-1-认识BMS.md#14b-五大保护每一条背后都有一个事故-理解) + [§1.6 BMS 的三种形态](stage-1-认识BMS.md#16-bms-的三种形态-理解) —— 确认你要做的是「保护板」这一形态
3. [详解① §1.2 为什么必须两颗背靠背](../circuits/01-功率回路-MOS保护与预充.md#12-为什么必须两颗背靠背-理解) → [§2 DW01 的完整保护大脑](../circuits/01-功率回路-MOS保护与预充.md#2-dw01一颗芯片里的完整保护大脑-理解)
4. [阶段 2 全文](stage-2-保护板实践.md)，核心是 [§2.6 保护板实测方法](stage-2-保护板实践.md#26-保护板实测方法本阶段核心技能-应用)

**器材**：3S/4S 成品保护板 ×2、可调直流电源、万用表，加上用精密电阻搭的电芯模拟器（做法见 §2.6）——先拿分压链练手，不要一上来就接真电池。

**完成标志**：不接真电池，用分压链把过充、过放各触发一次，读出阈值与延时，对得上 datasheet；并能指着板上每个关键器件说出它干什么。

**这条路上可以先不读**：阶段 0 的 §0.2/§0.3、SOC 算法、通信协议——纯硬件保护板上根本没有这些。想继续往上走，接路线 E。

## B 把商用 BMS 的数据读到手机或 Home Assistant

**布鲁姆层**：主层 [应用](bloom-map.md#应用)。先分清读出来的数是什么，那是 [理解](bloom-map.md#理解)。

**场景**：储能柜/电动车上已经有一块 JK、小象（JBD）、Daly 这类成品 BMS，你想把单体电压、电流、SOC 拿出来，上大屏或接进 Home Assistant。不需要自己设计任何硬件。

**最短路径**

1. [阶段 1 §1.3 BMS 的五大功能模块](stage-1-认识BMS.md#13-bms-的五大功能模块-理解) —— 先知道读出来的那堆数各是什么
2. [阶段 5 §5.2 UART](stage-5-通信与集成.md#52-uart商用-bms-的方言普通话-应用) + [§5.5 SMBus 与 BLE](stage-5-通信与集成.md#55-smbus-与-ble笔记本的与手机的-理解) —— 两条最常见的取数通道
3. [ESP32 专题 §1 角色定位](../esp32-bms专题.md#1-角色定位通信层不是安全层) → [§4 通信三件套落地要点](../esp32-bms专题.md#4-通信三件套落地要点) → [§8 参考工程](../esp32-bms专题.md#8-参考工程github按学习价值排序)
4. 协议现成的别自己猜：[总纲 阶段 5](../bms-resources.md#阶段-5系统通信与集成24-周) 的 syssi / batmon-ha 系列就是各品牌协议的事实文档

**器材**：一块 ESP32 开发板（¥25–60）+ **隔离** USB 串口（¥40–100）——[预算清单](../budget.md)把隔离这项标成「别省」，共地风险就靠它挡。

**完成标志**：Home Assistant 或手机上能看到实时单体电压与 SOC，拔插电源后能自动重连；掉线时有「离线」提示而不是停在旧数据（[MQTT 遗嘱](../esp32-bms专题.md#4-通信三件套落地要点)）。

**红线**：ESP32 在这里是**通信层，不是安全层**——它崩了不能影响保护动作，别让它参与任何断开决策（[ESP32 专题 §1](../esp32-bms专题.md#1-角色定位通信层不是安全层)）。想连协议也自己啃，接路线 D。

## C 只做算法：SOC/SOH，全程零器材

**布鲁姆层**：主层 [分析](bloom-map.md#分析)。把 `code/soc` 跑起来是 [应用](bloom-map.md#应用)，用来检验分析，不是代替分析。

**场景**：软件或算法背景，想做电池状态估计，手上没有也不打算有电池。这条路线全程在 PC 上完成。

**最短路径**

1. [阶段 0 §0.1 锂电池化学基础](stage-0-前置知识.md#01-锂电池化学基础-理解) —— §0.2 电路、§0.3 嵌入式可以整段跳过
2. [阶段 1 §1.2 木桶效应](stage-1-认识BMS.md#12-木桶效应亲眼看看浪费有多大-理解) —— 知道为什么包级 SOC 不等于单体平均
3. [阶段 4 全文](stage-4-SOC-SOH算法.md)，顺序别打乱：[§4.2 安时积分](stage-4-SOC-SOH算法.md#42-安时积分库仑计主力但它会梦游-分析) → [§4.3 OCV 法](stage-4-SOC-SOH算法.md#43-ocv-法好尺子但经常够不着-分析) → [§4.4 等效电路模型](stage-4-SOC-SOH算法.md#44-等效电路模型让电压在动态中也能用-分析) → [§4.5 卡尔曼滤波](stage-4-SOC-SOH算法.md#45-卡尔曼滤波两个不完美信息源的联姻-分析)
4. 把公式跑起来：[code/soc 三种估算器的分歧只有「怎么校正」](../../code/README.md#soc三种估算器的分歧只有怎么校正对应阶段-4-分析)
5. 想继续深挖：先 [ECE5720 Notes01 中文导读](../ece5720-notes01-中文导读.md)（BMS 要估什么），再 [ECE5720 Notes03 中文导读](../ece5720-notes03-中文导读.md)（KF/EKF/SPKF）与 [ECE5710 Notes02 中文导读](../ece5710-notes02-中文导读.md)（等效电路建模）

**器材**：零。一台能跑 Python 的电脑。

**完成标志**：能手推 Thevenin 模型下 EKF 的预测/更新五步；自己实现的估算器在 `code/soc` 的工况下误差 <5%；能解释「残差持续偏大说明模型错了，不是滤波器错了」。

**别跳过的现实感**：算法的上限是采样精度与标定质量。等你想知道那 10mV 从哪来，读[详解② §1 采样链全景与误差预算](../circuits/02-采样链与AFE芯片.md#1-采样链全景与误差预算-分析)。

## D 逆向一台不开放协议的 BMS

**布鲁姆层**：主层 [分析](bloom-map.md#分析)。抓包和把解析器跑通是 [应用](bloom-map.md#应用)。

**场景**：买到的 BMS 只有厂家 App，你想自己解析它的帧，或者接进自己的系统。

**最短路径**

1. [阶段 5 §5.1 通信的三个层级](stage-5-通信与集成.md#51-通信在-bms-里的三个层级-理解) —— 先判断你面对的是哪一层
2. [§5.2 UART](stage-5-通信与集成.md#52-uart商用-bms-的方言普通话-应用) —— 调试口最常见，电平与共地先确认
3. [§5.6 协议逆向方法论](stage-5-通信与集成.md#56-协议逆向方法论当一回协议侦探-分析) —— 本路线的主菜：帧头、长度、数据域、校验怎么一层层剥
4. CRC 的五个自由度一个都不能猜错：[code/protocol 五条军规逐条落](../../code/README.md#protocol五条军规逐条落对应阶段-5-应用)
5. 对答案：[总纲 阶段 5](../bms-resources.md#阶段-5系统通信与集成24-周) 的 syssi 系列仓库里有大量已被验证的帧格式

**器材**：**隔离** USB 串口（¥40–100，别用裸 USB-TTL）+ 一块二手商用 BMS 当逆向对象（¥100–300）；BLE 设备另需能抓 GATT 的手机 App 或 dongle。

**完成标志**：从一段抓包里标出帧头/长度/数据域/CRC 四段，写出解析器，对已知帧 100% 通过；换一条没见过的帧也能解对。

## E 自己做一块 8–16 串智能 BMS（AFE + MCU）

**布鲁姆层**：主层 [应用](bloom-map.md#应用)。误差预算和开线是 [分析](bloom-map.md#分析)；高边还是低边是 [评价](bloom-map.md#评价)。

**场景**：要采样、要均衡、要 SOC、要通信——这是从硬件爱好者到 BMS 工程师的分水岭，也是本仓库里最长的一条硬件路线。

**最短路径**

1. **先走完路线 A**。没亲手测过保护动作就上 AFE，调试时分不清是芯片问题还是自己接错
2. 这时候必须补：[阶段 0 §0.2 电路基础](stage-0-前置知识.md#02-电路基础只学-bms-用得上的-理解) + [§0.3 嵌入式开发基础](stage-0-前置知识.md#03-嵌入式开发基础-理解)
3. [阶段 3 全文](stage-3-AFE-MCU智能BMS.md)：[§3.2 AFE 精读](stage-3-AFE-MCU智能BMS.md#32-afe-精读以-bq769x0x2-为线-分析) → [§3.4 固件架构](stage-3-AFE-MCU智能BMS.md#34-固件架构四层--一台状态机-应用) → [§3.6 原理图与 PCB 五条纪律](stage-3-AFE-MCU智能BMS.md#36-原理图与-pcb五条纪律-应用) → [§3.7 先模拟后真电池](stage-3-AFE-MCU智能BMS.md#37-调试流程先模拟后真电池-应用)
4. 采样精度从哪来：[详解② §1 误差预算](../circuits/02-采样链与AFE芯片.md#1-采样链全景与误差预算-分析) 与 [§4 开线检测](../circuits/02-采样链与AFE芯片.md#4-开线检测采样线断了会发生什么-分析)
5. 主控落地：[STM32 专题 §2 选型地图](../stm32-bms专题.md#2-选型地图2026-视角) 与 [§6 咬过人的坑清单](../stm32-bms专题.md#6-咬过人的坑清单)
6. 固件别从白纸开始：[code/firmware 五条纪律的代码落点](../../code/README.md#firmware五条纪律的代码落点对应阶段-3--6-应用)

**器材**：STM32 开发板 + ST-Link、AFE 评估板或自己打板、逻辑分析仪（¥30–60，调 I2C/SPI 的性价比之王）、电芯模拟器、可调电源；明细与替代方案见[预算清单 阶段 3 档](../budget.md)。

**完成标志**：即 [阶段 3 §3.9 动手任务](stage-3-AFE-MCU智能BMS.md#39-动手任务-应用) 和 [§3.10 验收清单](stage-3-AFE-MCU智能BMS.md#310-验收清单-评价)——自研板稳定采集全部串电压（误差 <10mV）、被动均衡可控、全部保护项实测通过。

**顺带会用上**：均衡那三笔账在[详解③ §2 被动均衡](../circuits/03-充电均衡与计量.md#2-被动均衡电路热与调度-分析)；要加 SOC 就接路线 C。

## F 往产品级 / 车规靠：功能安全与量产

**布鲁姆层**：主层 [评价](bloom-map.md#评价)。按 §6.6 把项目做出来是 [创造](bloom-map.md#创造)，用评审量规打分仍是评价。

**场景**：板子能跑了，但要交给别人用——高压、认证、产线、售后追溯一个都躲不掉。

**最短路径**

1. [阶段 6 §6.1 硬件精通](stage-6-精通与毕业项目.md#61-硬件精通-分析)：[高压架构](stage-6-精通与毕业项目.md#611-高压电池系统架构-分析)、[预充](stage-6-精通与毕业项目.md#612-预充回路合闸的艺术-应用)、[绝缘检测](stage-6-精通与毕业项目.md#613-绝缘检测imd-分析)
2. [详解④](../circuits/04-系统安全与量产.md)：[§1 高压安全三件套](../circuits/04-系统安全与量产.md#1-高压安全三件套hvilimd主动放电-理解) → [§2 接触器管理](../circuits/04-系统安全与量产.md#2-接触器管理高压回路的三只闸-分析) → [§3 功能安全落地](../circuits/04-系统安全与量产.md#3-功能安全落地iso-26262-从纸面到电路-评价)；开工前先扫一眼[§0 参数速查](../circuits/04-系统安全与量产.md#0-参数速查-记忆)
3. [§6.2 固件精通](stage-6-精通与毕业项目.md#62-固件精通-应用)：[DTC 体系](stage-6-精通与毕业项目.md#622-故障管理dtc-体系-应用)、[参数与标定](stage-6-精通与毕业项目.md#623-参数与标定系统-应用)、[Bootloader 与 OTA](stage-6-精通与毕业项目.md#624-bootloader-与-ota-应用)
4. [§6.5 量产与测试](stage-6-精通与毕业项目.md#65-量产与测试-评价) + [详解④ §4.2 产线 EOL 测试](../circuits/04-系统安全与量产.md#42-产线-eol-测试出厂前的最后一道筛-评价)
5. 标准按目标市场选读：[总纲 §6.3 功能安全与标准](../bms-resources.md#63-功能安全与标准)

**完成标志**：[总纲的精通自检清单](../bms-resources.md#精通自检清单)里「系统与安全」一栏能全部打勾；做得完整就按 [§6.6 毕业项目指南](stage-6-精通与毕业项目.md#66-毕业项目指南-创造)的量规自评。
