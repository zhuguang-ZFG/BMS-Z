## 一、一页速览

上一章已经能把「一个位置上的表面浓度 / 通量」收成小 ODE。如果每个 x 都要一份，阶数还是无限。这一章按 Smith、Rahn、Wang 的一维路线，用一组传递函数一次给出你点名的那些位置（6–1 页）。文献是 *Energy Conversion and Management* 48 (2007) 2565–2578。

## 二、电荷转移电阻（§6.1）

两条基本假设写在章首（6–2 页）：先盯负极，再说明正极只是换常数和换坐标；线性化围绕一个设定的浓度和通量。Butler–Volmer 在工作点展开以后，过电位和通量成正比（6–4 页）：

```
R_ct = RT / (j₀ F²)
η = F R_ct j
R_s,e = R_ct + R_film
```

R_ct 是活化极化那一段：越过开路电位之后，界面上还要再掉的电压，除以通量再配上 F。膜电阻 R_film 是 SEI 那一层的欧姆。固液表面总电阻是两者之和。开路电位对表面浓度的斜率留在线性项里，真正查表时再换成非线性的 U_ocp。

> 【译注】[Notes02](ece5710-notes02-中文导读.md) 的 R₀ 把集流体、电解液和这部分界面电阻拌在一起，脉冲法分不出 R_ct。`code/soc/cell_model.py` 只有一个 R₀。要讲「界面」和「欧姆」的差别，用这一节的名字，不要改教学代码里的参数。

## 三、阻抗比，然后是两极（§6.2–6.4）

无量纲坐标 z = x/L。z = 0 在集流体，z = 1 在隔膜一侧（6–5 页）。固体电位和电解液电位的方程并到一起，出现阻抗比 ν²(s)：它把反应动力学、双电层以外的扩散时间、以及 σ_eff 和 κ_eff 卷成一个复变量（6–5…6–7 页）。齐次方程的解是 cosh(ν z) 和 sinh(ν z)。

负极表面浓度、固体电流、电位，都写成 I_app(s) 乘上一串双曲函数（6–8…6–11 页）。正极把坐标从隔膜那头再量一次，开路电位用正极材料自己的函数（6–12…6–13 页）。这些传递函数又乱又有无穷多个极零点（6–14 页）。讲义的态度很明确：小的状态空间仍然可以贴得很近。DRA 就是来干这个的，不必把双曲函数留在单片机里。

## 四、电解液浓度和电位（§6.5–6.8）

电解液浓度的 PDE 沿厚度是一维的（6–15 页）。解法走 Sturm–Liouville：先找齐次问题的本征值和本征函数，再用格林恒等式把强迫项投影上去（6–16…6–18 页）。界面上材料参数跳变，要让 δ 函数项消掉，所以浓度和通量在区域边界上要接好（6–19 页）。

时间部分是 e^{−λ t}（6–21 页）。空间部分分成负极、隔膜、正极三段，每段是正弦或余弦，系数由交界条件串起来（6–21…6–23 页）。强迫项是界面反应 (1 − t₊⁰) a_s j（6–24 页）。模态正交，所以每一阶模态是独立的一阶线性方程。讲义把前几阶模态和全 PDE 的浓度梯度画在一起（6–27 页）：留到大约 0 到 10 阶，形状已经贴上。

液相电位从电流和浓度梯度反推（6–30…6–33 页）。它不是又一条独立的扩散，而是已经有了的电流分配再积分一次。

## 五、端电压怎么拼（§6.9–6.10）

线性 DRA 输出的是偏差量。要回到物理量，得把设定点加回去，开路电位用非线性表，过电位用 Butler–Volmer 的逆（6–35…6–37 页）。液相电位还要加一项浓溶液修正，系数里有 (1 − t₊⁰) RT/F 乘 ln(c_e / c_e(0))（6–37 页）。

端电压（6–38 页）：

```
v(t) = φ_s(L_tot, t) − φ_s(0, t)
```

用过电位定义把两端固体电位拆开之后，至少要准备七条传递函数：两端的表面浓度、两端的液相电位、反应分布，再加上积分器状态（6–39 页）。也可以把开路电位在设定点线性化，于是

```
v(t) = OCV(z(t)) − Z i_app(t)
```

这里的 Z 是广义阻抗，不是一个电阻数（6–41 页）。它随频率、位置和工作点变。

> 【译注】阶段 4 写的 U = U_oc + I R₀ + U_rc，就是把这条广义阻抗收成两个数。10 小时工况下 Notes02 的单 RC 可以到几毫伏；这一章告诉你那几毫伏里本来有多少条传递函数。精度不够时先加 RC 或滞回，不必一步跳到七条传递函数。

## 六、全模型和掺模型（§6.11–6.12）

全模型的工序（6–42…6–43 页）：选定要的变量和位置；每条传递函数走 DRA 的前三步；Hankel 拼在一起做一次 Ho–Kalman；截断；再在输出端加非线性。讲义把负极/隔膜边界和正极/隔膜边界的通量、表面浓度拿来和全阶模型比（6–44…6–45 页）。那是模型对模型，不是道路实测。

一个工作点上线性化的 ROM，换 SOC 或温度就会偏（6–46 页）。办法是事先在矩形网格上各做一份 ROM，在线按双线性插值掺（6–46…6–47 页）：

```
θ_z = (SOC − SOC₀) / (SOC₁ − SOC₀)
θ_T = (T − T₀) / (T₁ − T₀)
```

A、C、D 都按四个角点掺。B 在后面的坐标变换里可以变得很简单，不一定四份都掺。状态仍按变系数的状态方程往前走，新的 SOC 再反馈去选 θ（6–48 页）。

章末还做了三次坐标变换，让 A 变成对角、元素按幅度排列，存储从 n×n 降到对角线上的 n 个数（6–49…6–51 页）。物理含义会清楚一些，端口不变。

还没做完的三件事（6–52 页）：物理参数怎么辨识、退化怎么写进模型、模型怎么用在控制器里。热模型是下一章。退化和控制主要在 ECE5720。

> 【译注】阶段 4 §4.8 的「OCV 表分温度、至少四张」是端口上的掺法。这一节是状态矩阵的掺法。两者都在说：一组 25 °C 的参数不要走遍全年。仓库没有这些矩阵。辨识物理参数通常要拆电芯，阶段 0 的安全纪律仍然是不要拆。
