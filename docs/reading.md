# 书籍与阅读路线

先选一个要解决的问题，再读对应章节。零基础从[第 0 天实验](stages/getting-started.md)起步；书稿与教材用于把已做过的实验讲透。

## 本项目伴读书

[《BMS 实战：从一颗电芯到一套证据链》前言](../bms-book/book/00-前言.md)包含 32 章正文与 5 篇附录，围绕测量、模型、保护、通信和工程验证展开。每章先用“本章罗盘”约定核心问题、读完交付与论证边界，再进入现场、原理、练习和附录 E 参考答案。正文免费，采用 CC BY-SA 4.0；教学代码采用 MIT。

站内从[前言](../bms-book/book/00-前言.md)开始，侧栏按七部分顺序排列，支持全文搜索、深色模式和上一章／下一章。需要纸质阅读或断网阅读时，在仓库根运行：

```bash
npm ci
python -m pip install -r bms-book/requirements.txt
python bms-book/build_html.py
python bms-book/check.py
```
::: tip 离线整书已开放下载
当前稳定版提供单文件 HTML 与出版 PDF，并保留版本化副本、文件大小和 SHA-256。<a href="downloads/index.html" target="_self">打开整书下载与校验页 →</a>
:::

打开生成的 `bms-book/dist/bms-book.html`，公式和插图已经嵌入文件。加 `--pdf` 可生成 PDF，需要本机 Chrome/Edge；可通过 `--browser` 指定浏览器路径。完整环境说明见[书稿 README](../bms-book/README.md)。

伴读书现有 68 个图解位置、34 个可点击播放的原理动画，每幅配观察提示与追问；七个分部各有一道“开读押注”，先选答案，再用后文证据核对。想先从画面理解，可以读[第 1 章电化学证据链](../bms-book/book/01-电池里在发生什么.md)、[第 4 章 MOS 与预充](../bms-book/book/04-保护板解剖.md)、[第 6 章 AFE 扫描](../bms-book/book/06-AFE.md)、[第 19 章 CAN 仲裁](../bms-book/book/19-总线全景.md)。[第 7 章](../bms-book/book/07-保护tick48.md)可拖动采样周期、确认拍数与执行时间，对比首次观测后和物理故障最坏两只时钟；[第 10 章](../bms-book/book/10-模型OCV四项.md)可拖动 SOC 与 OCV 斜率；[第 14 章](../bms-book/book/14-SOP与热.md)可调整内阻、热阻、热容与预测窗，直接看约束、功率和温升变化。四组交互支持恢复算例参数。PDF 使用静态矢量快照，同样保留读图问题。

[第 29 章](../bms-book/book/29-帧状态机边界.md)新增逐字节执行轨迹：同一好帧跨三次 `read()` 才闭合，只有明确超时才 `flush()`；配套验收矩阵把 CRC 错、长度错、残帧和重同步分开记账。

## 教材怎么选

完整元数据、ISBN 和来源见[站内书籍清单](../BMS书籍清单.md)，仓库原稿在[根书单](../BMS书籍清单.md)。下表是初读建议，时间指一次选读，不是读完整本书。

| 需要补什么 | 先选哪本 | 难度／初读建议／语言／获取条件 |
|---|---|---|
| 行业和电芯常识 | 《锂光：动力电池硬核入门》 | 入门／30–60 分钟／中文／商业教材，购买或图书馆借阅 |
| 中文算法主线 | 熊瑞《动力电池管理系统核心算法》 | 进阶／每次 45–90 分钟／中文／商业教材，版次和 ISBN 按书单核对 |
| 等效电路建模 | Plett *Battery Management Systems, Volume I* | 进阶／每次 45–90 分钟／英文／商业教材；可先读[开放讲义中文导读](uccs-中文导读路径.md) |
| 状态估计与 EKF | Plett *Volume II* | 进阶／每次 60–90 分钟／英文／商业教材；先完成 SOC 实验 |
| 采样、拓扑与均衡 | Andrea *Battery Management Systems for Large Lithium-Ion Battery Packs* | 进阶／每次 30–60 分钟／英文／商业教材；芯片参数仍查现用器件手册 |
| 物理模型与系统工程 | Plett *Volume III*、Rahn & Wang *Battery Systems Engineering* | 深入／每次 60–120 分钟／英文／商业教材；先掌握等效电路模型 |

预算为零时，先读本项目伴读书、[UCCS 十四章中文导读](uccs-中文导读路径.md)和[基石阅读](基石阅读.md)。商业教材按需要借阅或购买，书单只提供书目与来源，不提供商业书籍扫描件。

## 一次阅读的验收

每次留下一小段记录：我想回答的问题、章节和来源、运行命令或推导、实际结果、还不能证明的结论。读到 RMSE 时分清电压误差与 SOC 误差；读到保护延时时核对采样周期与去抖次数；读到均衡时分清荷电量差与容量衰减。

回到[按目标选路线](stages/按目标选路线.md)选择下一项任务，或用[AI 陪练卡](AI陪练卡.md)练解释与审查。
