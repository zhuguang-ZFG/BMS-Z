## 已落实的改进

1. PDF 与 EPUB 增加同一份纸面实验，三个连续读数、三个问题和对应解答全部可离线阅读。网页答案使用原生 `details`，无 JavaScript 也可打开。
2. 同一模型在 0、10、20、30 A 下分别为 3.70、3.50、3.30、3.10 V；说明只看瞬时欧姆压降，不能据此声称测得容量或真实恢复曲线。
3. 新增一页后重新计算 PDF 总目录、书签、卷号页码和所有原有链接落点。EPUB 加入阅读顺序、导航入口与 NCX；兼容性检查增加该页的小屏大字与深色场景。
4. 页面中的问题与纸面实验对应，读者可先操作电流，再关掉答案复算。原来的“先猜”现在有可检查的结果。

## 仍然存在的差距

- 新增的卷首单元不能代表全部正文都达到同样的教学节奏。逐章的题目难度、对照解与插图连续性还应抽样审阅。
- 已有 GitHub Issues 勘误入口，但还没有逐章社区讨论区；本轮没有替用户发布社区帖子。
- 软件测试可验证结构、显示和跳转，尚不能证明真实读者更容易读懂。实体阅读器导入、刷新、触控及真人试读尚未完成。
- 本书有明确的系统工程范围与假设，不能仅以插图数量或视觉风格来比较专业深度。
