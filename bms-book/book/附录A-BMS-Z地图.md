## A.1 它是什么

BMS-Z 是一套中文、免费、从入门到产品级的 BMS 自学路线：七篇阶段教程、五篇电路详解、154 张 SMIL 动画、八集视频、三份 PC 可运行代码、十一期共学。

本书大量引用了它的实验数字与代码，但两本书的分工不同：

- **BMS-Z**：带你动手，按阶段过关。
- **本书**：把“为什么”和“证据链”讲透。

## A.3 三份代码

**表 A-2**　三份代码目录的内容与运行命令（代码地图，无测量数字）

| 目录 | 内容 | 运行 |
|---|---|---|
| `code/soc/` | Thevenin 模型、三种 SOC 估算器、HPPC、SOP、热、NASA 实测回放 | `cd code/soc && python compare.py --plot` |
| `code/protocol/` | CRC-8/16、UART 帧状态机、坏帧计数/重同步 | `cd code/protocol && python -m pytest tests/ -q` |
| `code/firmware/` | C99 主状态机：去抖、故障快照/锁存、均衡、休眠 | `cd code/firmware && gcc -std=c99 -Wall -Wextra -Werror -o test_bms bms.c test_bms.c && ./test_bms` |

PC 综合实验：`python code/firmware/pc_demo.py`，一次生成 100 拍采样、99 帧遥测、坏 CRC、事件与验收报告。

## A.5 建议用法

1. 先做“第 0 天小实验”，再读本书第 1 章。
2. 每读一章，去 BMS-Z 跑对应代码或共学，把数字抄进笔记。
3. 卡住时回 BMS-Z 的比喻地图、参数速查卡、术语表。
4. 想深入某一节，按本书末尾的引用链接回到原文。
