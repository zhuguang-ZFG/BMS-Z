# soc：三种 SOC 估算器对照 [分析]

主层级是 **分析**：看纯安时积分、带校准点的积分、EKF 为什么会分叉。把程序跑起来是 **应用**，放在读代码之前。

> **先读/后读**：先在本目录跑 `python3 compare.py`（应用），再读 [逐行走读](../README.md#soc三种估算器的分歧只有怎么校正对应阶段-4-分析)（分析）。约定（电流符号、示例阈值）在 [设计约定](../README.md#设计约定与教程全文一致)。这一页不改 `estimators.py` 的算法。

> **原理**　三条曲线共用同一块电池模型。分叉只来自校正通道：纯积分没有锚，校准点在满充和静置把 SOC 拉回绝对参照，EKF 用电压残差按 Q/R 分配信任。
> **证据**　可核验实验：`python3 compare.py` 与 `pytest`（CI 会跑）。模型出处见 [总纲关键论文](../../docs/bms-resources.md#关键论文主线背后的学术骨架) 里的 Plett 2004 与 Tremblay 2009。
> **延伸阅读**　[ECE5720 Notes03 中文导读](../../docs/ece5720-notes03-中文导读.md)（可选，原文英文）。

这里不接真电池。代码里的阈值是示例值。
