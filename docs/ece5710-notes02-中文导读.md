## 一、一页速览

原文从一个理想电压源出发，**逐步加项**，每加一项解决一类观测到的现象，最后拼出完整的 ESC（Enhanced Self-Correcting）模型：

| 模型项 | 解决的现象 | 出处 |
|---|---|---|
| OCV(z, T) | 开路电压随 SOC、温度变化 | §2.1 |
| R₀ 串联内阻 | 加载瞬间的电压跳变 | §2.2 |
| R–C 并联支路（可多个） | 加载/静置时的**缓变**极化电压（扩散电压） | §2.2–2.3 |
| 滞回电压 M·h[k] + M₀s[k] | 同一 SOC 下充放电平衡电压不重合（滞回环） | §2.4 |

最终输出方程（§2.5）：

```
v[k] = OCV(z[k], T[k]) + M₀·s[k] + M·h[k] − Σ Rⱼ·i_Rⱼ[k] − R₀·i[k]
```

> 【译注】这个"每加一项解决一类物理现象"的构造方式，就是判断一个 BMS 模型够不够用的方法：你的残差里有哪种现象，就缺哪一项。本仓库 `code/soc/` 的对比实验（纯积分 vs 校准 vs EKF）跑的正是这套模型的简化版。

## 二、OCV 与 SOC（§2.1）

- **SOC 定义**：满充 z=100%，放空 z=0%；总容量 Q = 从 100% 放到 0% 移出的总电荷（Ah）。
- **SOC 方程**（放电电流为正）：

  ```
  ż(t) = −i(t)·η(t)/Q        →        z[k+1] = z[k] − i[k]·η[k]·Δt/Q
  ```

- **库仑效率 η**：充电时 η≤1（副反应损失电荷），放电时建模为 η=1。锂电典型 ≈99%——注意别和**能量效率**（≈95%，含电阻发热损失）混淆。
- **OCV 同时是温度的函数**，写作 OCV(z(t), T(t))。DOD = 1 − SOC（或以 Ah 计：Q(1−SOC)）。

> 【译注】`z[k+1] = z[k] − iηΔt/Q` 就是安时积分法的全部——它本身没有误差反馈项，所以纯积分必然漂移，这正是我们 SOC 演示里"纯积分 10.62%"漂移的来源。库仑效率 <1 意味着**每循环一次，安时积分就系统性地偏一点**，长期不可忽略。

## 三、线性极化与 R–C 支路（§2.2–2.3）

**串联内阻 R₀**：`v(t) = OCV(z(t)) − i(t)·R₀`。只能描述电流阶跃时电压的**瞬时**跳变。

**扩散电压**：实测中电流阶跃后电压不是立刻到位，而是缓慢趋近；静置后电压也不是立刻回到 OCV，可能衰减一小时以上。这是电芯内部慢扩散过程，用**一个或多个 R–C 并联支路**逼近。单个支路的电流状态方程：

```
di_R1/dt = −(1/R₁C₁)·i_R1 + (1/R₁C₁)·i(t)
```

**离散化**（§2.3，零阶保持假设，原文给了一般标量方程的推导）：代入 a = −1/R₁C₁ 得

```
i_R1[k+1] = exp(−Δt/R₁C₁)·i_R1[k] + (1 − exp(−Δt/R₁C₁))·i[k]
```

**脉冲估参数**（单 R–C 支路的粗标定）：电流脉冲的瞬时压降 v₀ = R₀·i 得 R₀；稳态压降 v∞ = (R₀+R₁)·i 得 R₁；约 4 个时间常数收敛（t ≈ 4R₁C₁）得 C₁。原文实例：i=5 A、|v₀|=41 mV、|v∞|=120 mV → R₀≈8.2 mΩ、R₁≈15.8 mΩ、C₁≈38 kF。

**Warburg 阻抗（了解即可）**：Randles 电路里的 Warburg 元件（Nyquist 图上低频 45° 直线）没有简单的常微分方程形式，工程上用**多个 R–C 支路串联**在某频段内逼近——这就是"多 R–C 支路"的物理依据。

> 【译注】对照熊瑞书 **3.2 等效电路模型**（模型介绍/构建/参数辨识/算例四小节）。熊瑞把建模单列一章、还讲了分数阶模型（3.3）；Plett 这份讲义则在离散化推导上更细（零阶保持的完整推导过程），参数辨识粗标定（脉冲法）直接给了数值算例。两本互补：概念框架看熊瑞中文，推导细节看 Plett。

## 四、滞回电压（§2.4）

**现象**：静置足够久后扩散电压衰减为零，但电压仍回不到唯一值——**同一 SOC 存在一段稳定的"OCV"区间**，充电路径和放电路径不重合（C/30 准平衡测试可见滞回环）。

**与扩散电压的本质区别**：扩散电压随**时间**变化；滞回电压随 **SOC** 变化，不直接是时间的函数。建模时对 z 求导：

```
dh(z,t)/dz = γ·sgn(ż)·(M(z,ż) − h(z,t))
```

即滞回电压以指数速率向主滞回环收敛（γ 调收敛速率）。两边乘 dz/dt 换成时间方程，再离散化（令 A_H[k] = exp(−|η[k]·i[k]·γ·Δt/Q|)，取无量纲状态 −1≤h≤1）：

```
h[k+1] = A_H[k]·h[k] − (1 − A_H[k])·sgn(i[k])        滞回电压 = M·h[k]
```

**注意它是线性时变系统**：A_H[k] 随电流大小逐拍变化。另有**瞬时滞回**（电流换向时立即翻转）：s[k]=sgn(i[k])（i=0 时保持），电压 = M₀·s[k]。总滞回 = M₀·s[k] + M·h[k]。

> 【译注】滞回是 OCV 法估 SOC 的主要误差源之一：LFP 平台区平坦，滞回环宽度可能盖过 OCV 斜率。我们 SOC 演示里"静置锚点"之所以能把估计拉回真值，物理依据就是这段——静置后扩散电压归零，端电压收敛到 OCV+滞回，滞回可用符号项近似扣除。

## 五、ESC 模型总成（§2.5）

状态向量 [z[k]; i_R[k]; h[k]]，状态方程为块对角形式（各 R–C 支路独立演化，滞回时变）：

```
z[k+1]   = z[k] − (η[k]Δt/Q)·i[k]
i_R[k+1] = A_RC·i_R[k] + B_RC·i[k]            A_RC=diag(exp(−Δt/RⱼCⱼ))，B_RCⱼ=1−exp(−Δt/RⱼCⱼ)
h[k+1]   = A_H[k]·h[k] + (A_H[k]−1)·sgn(i[k])
```

**输出方程**：

```
v[k] = OCV(z[k], T[k]) + M₀·s[k] + M·h[k] − Σⱼ Rⱼ·i_Rⱼ[k] − R₀·i[k]
```

**"自校正"的含义**：静置时模型电压收敛到 OCV+滞回；恒流时收敛到 OCV+滞回−iΣR。所有模型参数必须非负。

> 【译注】这套状态/输出方程就是 ECE5720 Notes03 里 EKF/SPKF 的被估对象——滤波器的"模型"部分一行不改地用它。读滤波器章节时回看本文第五节即可。

## 六、OCV 标定实验（§2.5–2.7）

**四段测试脚本**（每个温度下执行）：C/30 极慢速率 + 每步前 25 °C 浸润 ≥2 小时；脚本 1 放到 v_min、脚本 3 充到 v_max，脚本 2/4 是 25 °C 下的"复位"步骤。**为什么需要脚本 2/4**：v_min/v_max 定义的 0%/100% SOC 只在 25 °C 成立——OCV 随温度变，别的温度下放/充到截止电压时真实 SOC 并不是 0%/100%，必须先回 25 °C 复位才能换下一个温度。

**库仑效率**：25 °C 时 η = 总放电 Ah / 总充电 Ah；其他温度用放电/充电 Ah 按 25 °C 复位点折算（公式见原文 2–19 页）。

**逐点 SOC**：DOD(t) = 累计放电 Ah − η·累计充电 Ah（分温度折算），SOC(t) = 1 − DOD(t)/Q；校验点：脚本 4 末 SOC=0%、脚本 8 末 SOC=100%。

**OCV 曲线合成**：低 SOC 用充电电压 + 充电电流×该 SOC 电阻、高 SOC 用放电电压 + 放电电流×该 SOC 电阻（电阻按 0%/50%/100% 三点分段线性），得到近似 OCV（虚线）。

**温度模型**：OCV(z,T) = OCV₀(z) + T·OCVrel(z)。对每个 SOC，把各温度下的近似 OCV 做最小二乘（原文 MATLAB 一行 `X=A\Y`）解出 OCV₀(z) 和 OCVrel(z)——运行时用**两张一维查表**实现，计算量极小，适合 MCU。

> 【译注】"两张一维表代替二维曲面"是嵌入式 BMS 的标准做法，本仓库 stage-4 文档的 OCV 表就是这一路数。测试脚本里"25 °C 复位"这个细节容易被忽略——不做的后果是不同温度的 OCV 数据 SOC 基准错位，拟合出来的曲线自带系统性畸变。
