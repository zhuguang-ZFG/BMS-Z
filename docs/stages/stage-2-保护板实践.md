## 2.1 保护板解剖

拿到一块 3S/4S 保护板，先识别这些要素：

- **保护 IC**：整板的大脑（DW01、S-8254A、中颖 SH367309 等）；
- **功率 MOS**：通常 2 颗以上背靠背（常见 8205A 双 MOS 封装）；
- **检流电阻**：毫欧级，测回路电流（过流/短路判据）；
- **NTC**：贴电芯或板上的温度探头；
- **采样排线**：每节电芯一根（B1、B2…Bn）。

**接线端子**（必须分清）：

| 端子 | 含义 |
|---|---|
| B+ / B- | 电池组总正 / 总负（接电芯） |
| P+ / P- | 对外端口（接负载与充电器） |
| C- | 充电负极（分口板才有） |
| D- | 放电负极（分口板才有） |

- **同口板**：充放电走同一个 P- 端，MOS 一组；
- **分口板**：充电 MOS 与放电 MOS 分开，可独立切断。

## 2.2 单节保护精读：DW01

DW01 是理解所有保护 IC 的最佳起点，只有 6 个引脚：

- **VDD/VSS**：直接跨接电芯，监测单节电压；
- **OD/OC**：分别驱动放电 MOS 与充电 MOS 的栅极；
- **CS**：检流引脚，通过 VSS 与 CS 间的压差感知回路电流；
- **TD**：测试引脚（用于缩短延时、便于出厂测试）；各类保护延时由芯片**内部产生**，无需外接定时元件。

典型保护参数（**以实际料号 datasheet 为准**）：

| 保护项 | 典型阈值 | 典型延时 |
|---|---|---|
| 过充 | 4.30V ±50mV | 1s 级 |
| 过放 | 2.40V ±100mV | 100ms 级 |
| 放电过流 | CS > 0.1–0.2V | 10ms 级 |
| 短路 | CS > 更高阈值 | 微秒级 |
| 充电过流 | CS 反向阈值 | 10ms 级 |

- 过放保护后 DW01 进入低功耗模式，插充电器或电压回升后恢复；
- 配套 MOS 常用 8205A（单封装内两颗 N-MOS，天然背靠背）。

**读懂一张 DW01 应用图 = 掌握了保护板 80% 的原理**：采样（VDD）、执行（OD/OC → MOS）、判流（CS）、内部定时（保护延时由芯片内部产生）。

## 2.3 多节保护：S-8254A 系列

单节方案无法直接堆叠成多串（每节的"地"不同），多串保护 IC 的解决方式：

- 内部集成多个独立的电压检测通道，每通道跨接一节电芯（VDD1-VSS1、VDD2-VSS2…）；
- S-8254A 一颗管 3–4 节（SEL 引脚选择 3/4 节模式）；官方手册定位为 3/4 串保护 IC，**未提供多颗级联方案**——更多串数直接选多通道芯片（见下）；
- 三段过流检测：过流 1（小过载，延时较长）→ 过流 2（大过载，延时短）→ 短路（瞬间动作）；
- 保护阈值由出厂激光修调固定（选型时按化学体系选对应阈值版本，三元 4.2V 满充 vs 铁锂 3.65V 满充**不能混用**）；
- 外置延时电容：每类保护一个引脚，延时 ∝ 电容值。

更多串数的方案：直接选**多通道单芯片**（如中颖 SH367309，一颗覆盖 1–17 串），内部集成全部检测通道——这是国产多串保护板的主流，检测原理与 S-8254A 相同。

## 2.4 MOS 与驱动细节

- **背靠背两种接法**：共漏极（栅极可共驱动，简单）与共源极（体二极管方向相反，阻断更对称）；保护板多用共漏；
- **VGS 限制**：MOS 栅氧耐压通常 ±20V，多串电池组的驱动回路要防止栅压超限（保护 IC 输出级已处理，自己设计时必查）；
- **并联扩流**：大电流板（>30A）多颗 MOS 并联摊薄 I²R 发热；并联时注意均流（同型号、对称布局）；
- **发热估算**：$P = I^2 \times R_{DS(on)} \times$ 数量修正，温升靠 PCB 铜箔与散热片带走——阶段 0 的知识在这里变现。

## 2.5 NTC 与 ID 引脚

- **NTC**：负温度系数热敏电阻，与固定电阻分压后送 ADC（或保护 IC 温度引脚）。温度 ↔ 阻值关系用 B 值方程或查表；
- **ID 引脚**：用电阻值编码电池型号/容量档，主机读取后区分电池包（也用于简单防兼容）。

## 2.6 保护板实测方法（本阶段核心技能）

原则：**先用电源模拟，后用真电池验证**。

1. **电芯模拟**：首选**单电源 + 电阻分压链**——一串电阻跨接一台电源，各分压点天然串联参考，安全；若用多路可调电源，**每一路必须是隔离浮地输出**，并按"上一路的负极接下一路的正极"串联叠成电池串。⚠️ 共地（非隔离）的多路电源直接接到 B1–Bn 会把电池串经地线短路，烧板烧电源；
2. **测过充保护**：缓慢上调某一"节"的电压，记录保护动作电压与延时（对照规格书，误差应在 ±50mV 内）；
3. **测过放保护**：缓慢下调，同上；
4. **测过流保护**：P 口接电子负载，阶梯加大电流，记录各段过流动作点与延时；
5. **测静态功耗**：微安表串入 B+ 回路，正常态与过放休眠态各测一次（μA 级才算合格）；
6. **测恢复**：触发保护后验证恢复条件（卸载/插充）；
7. **带均衡的板子**：把一节电压调高，充电至末端观察该节均衡电阻是否发热工作。

## 2.7 自测题

1. 同口板与分口板的区别？各适合什么场景？
2. DW01 的 CS 引脚为什么能同时判放电过流与充电过流？
3. 多串保护 IC 为什么不能简单把多个 DW01 叠加使用？
4. 三元锂保护板能直接用在磷酸铁锂电池组上吗？为什么？
5. 短路保护为什么必须微秒级动作？（从 MOS 耐受能量角度答）
6. MOS 并联除了扩流还有什么副作用？
