# B05　数据身份与留出：一份数据先证明自己是谁

## 为什么先补这一节

S2 的所有拟合、S1 的误差核对、S3 的能量账，都要回答同一个问题：**这份数据能不能支持这个结论？** 数据没有身份、没有留出、没有单位和工况，再漂亮的曲线也只是巧合。这里补最小够用的一层：数据身份、切分、泄漏和结论边界。

## 1. 数据身份：五个字段缺一不可

一份可用于复算的数据，至少写清：

| 字段 | 回答什么 | 缺失后的后果 |
|---|---|---|
| 来源 | 哪台设备、哪颗电芯、哪次实验或哪份公开数据集 | 无法判断工况是否覆盖你的问题 |
| 版本 | 采集脚本、固件、处理方法、文件摘要 | 重跑得到不同结果，却说不清差在哪 |
| 单位 | 电压 V、电流 A、时间 s、容量 Ah、SOC 0–1 还是 % | 相差 100 倍或 3600 倍 |
| 工况 | 温度、倍率、静置时长、采样间隔、起点 SOC | 把别的工况结论硬套过来 |
| 行数/边界 | 样本数、时间范围、剔除规则 | 不知道结论覆盖哪一段 |

摘要（SHA-256）证明的是"这份文件没变"，不是"这份数据正确"。两者不能互相替代。

## 2. 先切分，再看结果

留出验证的顺序必须是：

1. 在查看任何结果前，固定训练段与验证段；
2. 只在前者上调参、选窗长、定阈值；
3. 后者只在最后跑一次，用固定指标报告；
4. 若看了验证结果再改参数，验证段就变成了训练段。

**泄漏**的三种常见形态：

- 用全段数据的均值/方差去标准化，再声称留出独立；
- 用验证段选模型、选窗长，然后仍叫它"未参与拟合"；
- 同一段轨迹随机打乱后分到两侧，相邻样本几乎相同。

## 3. 合成真值、实测与"看起来对"

- **合成真值**：参数由你设定，可以检验算法能否恢复已知答案；它**不能**证明模型符合真实电芯。
- **实测数据**：含未建模的滞后、温升、老化与测量误差；结论只能覆盖实际测过的工况。
- **拟合优度高**：只说明模型在你选的区间里贴合，不说明外推有效，也不说明参数有物理意义。

因此报告应同时写：数据身份、拟合区间、验证区间、误差指标、失败工况。只写"RMSE 很小"不构成结论。

## 4. 短核对

1. 同一份 CSV 被重新采样为 1 s 间隔，文件摘要变了。应该改哪个字段？
2. 先用全部 180 s 数据选出最优 τ，再报告这段数据的残差。这算独立验证吗？
3. 合成数据上拟合误差 1e−15，能否据此声称模型适合真实电芯？

<details>
<summary>核对答案</summary>

1. 版本（处理方法与文件摘要）与工况（采样间隔）都要改；来源可不变，行数与时间范围随之更新。
2. 不算。选参和评估用了同一段数据，残差只是拟合残差，不是留出误差。
3. 不能。合成数据只检验算法；真实电芯需要实测数据、覆盖工况与独立验证。
