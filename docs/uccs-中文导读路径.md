# UCCS 讲义中文导读路径

Plett 的两门课是一条学习路径，不是十四份互不相干的 PDF。ECE5710 把电芯从「端口长什么样」讲到「里面的热怎么算」。ECE5720 把这些模型用在 BMS 要完成的估计和控制上。

这里每章都是**非官方编译**：公式按讲义页码转述，不是逐字翻译。原文版权归 Gregory L. Plett / UCCS（个别章还有合著者，见各章文首）。课程目录在 [ECE5710](http://mocha-java.uccs.edu/ECE5710/index.html) 和 [ECE5720](http://mocha-java.uccs.edu/ECE5720/index.html)。本地副本在 `books/uccs-ece5710/`、`books/uccs-ece5720/`，PDF 不进 git，本页也不链文件本身。

读的时候按三层问自己：

- **能记住**：这一章的口诀和那一张表。
- **能理解**：它为什么比上一章多出来。
- **能用**：它接上仓库里的哪一节、哪一段代码；哪些数只是讲义算例。

锂离子的过充、过放、析锂和拆电芯，仍以阶段 0 的安全纪律为准。导读里的电压和电流是讲义算例，不是保护阈值。

## 建议走法

| 你想先会什么 | 路径 |
|---|---|
| 先把端口模型用起来 | Notes01（5710）→ Notes02（5710）→ Notes01（5720）→ Notes03（5720），对照 `code/soc/` |
| 要做包和功率 | 上面四章之后：Notes02（5720）→ Notes04 → Notes05 → Notes06 |
| 要看物理模型能多到哪 | Notes03 → Notes04 → Notes05 → Notes06 → Notes07（5710），最后读 Notes07（5720） |

不必十四章连读。每一章文末有短自测和「练完你会怎样」。
