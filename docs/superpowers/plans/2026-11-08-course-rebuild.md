# 连续课程重构执行合同（SPEC v2.6 增补）

生效：2026-11-08。用户要求“从入门到精通”重构，并授权参考 GitHub 和社区。此合同修正 v2.5 的主线组织方式，不撤销原有公式、安全、许可、媒体与发布检查。

## 问题与结果

原阶段 0 在解释 Ah、串联和倍率前使用 16 串 50 Ah / 1C；初学页直接进入电化学推导。32 章末尾又重复整套 KP 解释。标签齐全不能证明读者能连续学下去。

新默认路径为 `docs/course/` 的 24 课、8 个模块，同一组 **4 串、2 Ah 虚拟电池包**贯穿。前三课只需四则运算；第 4 课才引入电脑和最低限度 Python；之后依次完成测量、保护、估算、充电均衡、通信、整合与工程迁移。原阶段教程、32 章和 80 KP 作为专题深读与查阅库，保留旧链接。

“学完”分三件事：读者完成题目；PC 项目通过给定与变式输入；真实工程能力经目标板、真实数据、仪器和他人复核验证。自动化只能证明第二件中的软件行为。W5 真人试读仍待验收，7 个专项授权照片缺口仍保留。

## 教学合同

1. 每课明确先修、唯一主要任务、可核对的数值例子、反例或边界、独立变式题及折叠核对标准。
2. 学习顺序由 `course/manifest.json` 声明，禁止循环先修、先修引用未来课程、孤立课程与跳号。
3. 前 6 课给完整步骤；7–15 课给接口与关键判断；16–21 课给输入输出约束并逐步撤掉算法提示。答案不混入练习题段落。
4. 所有阈值标为教学配置，不构成任意化学体系的安全参数。放电电流为正。秒→小时必须显式转换；串联不增加 Ah。
5. 贯穿项目只用 Python 标准库；先运行已知好样本，随后修改学员工作副本。参考实现与学员待完成文件分开；检查器必须能拒绝错误学员实现。日志保留输入、质量、命令和反馈。
6. 无效/过期采样不能被 0 值、插值或沿用上次绿灯掩盖；超时与故障锁存可从日志定位，远程消息不绕过本地保护。
7. 模块任务累积成作品；毕业任务改变容量、采样周期和故障位置，需说明输出依据和未验证项。

## 出版与视觉合同

- 在线与离线学习版使用同一份 24 课源文，独立生成 `bms-course.html/pdf/epub`，不把全部深读资料重新混入。
- HTML/PDF 保留彩色语义，但正文不靠颜色传达状态；阈值配名称，曲线配线型/标记。暖白纸色、深墨正文、青绿结构色；警告使用红色和文字，示例用浅底。
- PDF 正文 11 pt，矢量图表优先，图表内文字不靠拉大模糊位图解决；390 px EPUB 无横向溢出，代码可换行，目录可导航，答案离线可读。
- 旧完整本仍执行原出版合同；新课程版另有内容覆盖、链接、资源与数值验证，不能沿用旧 380 页检查结果。
