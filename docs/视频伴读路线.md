# BMS 视频伴读路线

视频适合建立画面感，不能替代数据手册、标准、原始数据和可复算实验。本页不是播放量排行榜，而是一条**带任务的伴读路线**：先知道为什么看，再打开视频；看完必须能回答一个问题。

> **核验口径**　下表标题、发布账号、分集或时长已于 **2026-10-31** 通过平台页面或接口核验。平台内容可能变化；链接打不开时，以视频标题和发布账号重新搜索。B 站转载或带资料引流的课程会明确标注，不把“能播放”等同于“权威来源”。

## 长课怎样用，才不会重新掉进资料海

仓库已核验到一些 25 集、70 集或数十小时的合集。它们可以查漏补缺，但不适合作为第一入口：

- 一次只选与当前章节对应的一集，不连续刷完整套；
- 先写下一个问题，再按问题看视频；
- 任何阈值、精度和电路结论都回查数据手册或本书来源锚点；
- 转载且通过私信、群聊或网盘引流的课程，只当线索，不当权威证据；
- 看完必须留下一个产物：一张图、一笔手算、一次 demo 输出或一份差异表。
