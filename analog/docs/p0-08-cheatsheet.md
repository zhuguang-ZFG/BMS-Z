### 直流基础：电压·电流·电源思维（7 条）

一切设计的公共语言：分压带载、源阻抗、回路思维。这几条塌了，上面全塌。

**表 B-1　直流基础设计式与判据**

| 设计式 / 判据 | 什么时候用 · 翻车点 | 出处 |
|---|---|---|
| 电压=水压 / 电流=水流（必须成环）/ 电阻=细水管 / 电容=蓄水池 / 电感=水车惯性 / 二极管=单向阀 / MOSFET=闸门（栅压指挥）/ 地=海平面 | 全书通用语言；电流必须成环——没有"只进不出"的电流，地不是"下水道"而是测量基准。 | [第 0 章](p1-01-ch0.md#ch0) · [动画](p5-00-part5.md#demo39) |
| $V = I \times R$ | 三个量知二求一；反着读才值钱——电流流过电阻会在电阻上"留下"一份电压降，串联路径上阻大分得多。 | [第 0 章](p1-01-ch0.md#ch0) · [动画](p5-00-part5.md#demo39) |
| Vout = V × R2/(R1+R2) | 只在空载时成立！从 Vout 抽电流 = 给 R2 并联了一个电阻 → Vout 塌陷。 | [§0.3](p1-01-ch0.md#sec-0-3) · [动画](p5-00-part5.md#demo39) · [就地算](p1-01-ch0.md#sec-0-3) |
| Vout=10×5/(10+5)=3.3V（R1=R2=10k 分 10V，接 10k 负载，空载应为 5V） | 口诀：分压器带载能力 ≈ 它自己的内阻（R1∥R2）——挂上负载即塌 33%。 | [§0.3](p1-01-ch0.md#sec-0-3) · [动画](p5-00-part5.md#demo39) |
| 三个思维习惯：① 量电压，先问"相对谁"；② 看电路，先追"电流回路"；③ 先直流，后交流 | 电压永远是两点之差，悬空说"这点 5V"没有意义；顺序反了必乱。 | [§0.4](p1-01-ch0.md#sec-0-4) |
| $\Delta V = I \times Z_{out}$（横轴 I、纵轴 V，实际电源曲线斜率的绝对值对应输出阻抗） | 恒压源内阻趋近 0，短路是灾难；恒流源输出阻抗趋近 ∞，开路是灾难。负载一重电压就塌。 | [§0.6](p1-01-ch0.md#sec-0-6) · [动画](p5-00-part5.md#demo78) |
| 横轴 I、纵轴 V：恒压源是水平线（I 怎么变，V 不动），恒流源是竖线（V 怎么变，I 不动） | 恒压源→负载并联（多路 LED 各自串限流电阻）；恒流源→负载串联（多颗 LED 串联恒流驱动）；恒流源全是拿恒压源+负反馈做出来的。 | [§0.6](p1-01-ch0.md#sec-0-6) · [动画](p5-00-part5.md#demo78) |

### 无源元件·频域·谐振（12 条）

| 设计式 / 判据 | 什么时候用 · 翻车点 | 出处 |

| 变压器变比 $V_2/V_1 = N_2/N_1$；电流 $I_2/I_1 = N_1/N_2$；$V_1 I_1 \approx V_2 I_2$ | 升压处电流自动减半，能量原样过；初次级只有磁通耦合="隔离"的物理根源。 | [第 1 章](p1-02-ch1.md#rc-study) · [动画](p5-00-part5.md#demo36) |
| 反电动势 $v=-L\frac{di}{dt}$ | 继电器/电机断电瞬间可产生数百伏尖峰，必须并联续流二极管——不是保护技巧，是电感物理的必然推论。 | [第 1 章](p1-02-ch1.md#rc-study) · [动画](p5-00-part5.md#demo36) |
| $R_{th}=R_N=V_{th}/I_N$；带载 $V_{out}=V_{th}\cdot\dfrac{R_L}{R_{th}+R_L}$ | 任何线性网络压成两个数；$R_L=R_{th}$ 时只剩一半，$R_L=1M\Omega$ 时差 0.5%——"带不带得动"永远只需比 $R_{th}$ 与 $R_L$。 | [第 1 章](p1-02-ch1.md#rc-study) · [动画](p5-00-part5.md#demo36) |
| $f_0=\dfrac{1}{2\pi\sqrt{LC}}$ | 串联谐振 $f_0$ 处阻抗=R 最小（带通）；并联谐振阻抗趋∞（带阻）；LC 交叉点即谐振点。 | [§1.5](p1-02-ch1.md#sec-1-5) |
| $Q = \dfrac{f_0}{BW}$；串联 RLC $Q = \dfrac{1}{R}\sqrt{\dfrac{L}{C}}$ | Q 高=峰尖选频锐利、Q 低=峰钝宽容；Q 高 ≠ 更好——选台要高 Q（锐利），电源滤波要低 Q（防振铃过冲）。 | [§1.5](p1-02-ch1.md#sec-1-5) |
| $\|Z\|=\sqrt{R^2+(X_L-X_C)^2}$；谐振时 $X_L=X_C=\sqrt{\dfrac{L}{C}}$，$V_L=V_C=Q\cdot V_{in}$，$BW=\dfrac{f_0}{Q}$ | 四拍口诀：低频电容拦、谐振两清账、高频电感拦；电源只有 1V 元件上却有 10V。 | [§1.6](p1-02-ch1.md#sec-1-6) |
| $L = L_0 \times 2^{\frac{T_0 - T}{10}}$（10°C 翻倍法则） | 105°C/2000h 的电容在 65°C 得 32000h≈3.7 年——开关电源里第一个坏的总是电解电容。 | [§1.7](p1-02-ch1.md#cap-dc-bias) · [动画](p5-00-part5.md#demo103) · [就地算](p1-02-ch1.md#cap-dc-bias) |
| $\Delta V = \dfrac{\Delta I_L}{8 f_{sw} C}$ | 必须用降容后的有效容值做设计；标称 22µF 实际只剩 10µF 时容性纹波翻一倍多，还可能改变环路稳定性。 | [§1.7](p1-02-ch1.md#cap-dc-bias) · [动画](p5-00-part5.md#demo103) |

### BJT：偏置与开关（11 条）

β 靠不住，靠拓扑：分压偏置 + R_E 负反馈；开关按强制 β 算基极。

**表 B-4　BJT 偏置与开关设计式**

| 设计式 / 判据 | 什么时候用 · 翻车点 | 出处 |
|---|---|---|
| $I_C = \beta \cdot I_B$ | BJT 是电流控制器件；β（h_FE）不是精密常数——同型号离散 50~300，还随温度、$I_C$ 变化，好的设计绝不依赖 β 的具体值。 | [第 3 章](p1-04-ch3.md#ch3) · [动画](p5-00-part5.md#demo40) |
| 三个工作区判据：截止（发射结反偏/零偏，$I_C≈0$）/ 放大（发射结正偏+集电结反偏，$I_C=\beta I_B$）/ 饱和（两结都正偏，$V_{CE}≈0.2V$） | 临界记忆值 $V_{BE}≈0.7V$、$V_{CE(sat)}≈0.2V$；饱和相当于闭合开关。 | [§3.2](p1-04-ch3.md#sec-3-2) · [动画](p5-00-part5.md#demo40) |
| 共射电压增益 $\approx -g_mR_C$ | 共射反相、增益高；共集（射随）增益≈1、输入阻抗高输出阻抗低作缓冲；共基输入阻抗极低、高频用。 | [§3.2](p1-04-ch3.md#sec-3-2) · [动画](p5-00-part5.md#demo40) |
| 固定偏置：$I_B=(V_{CC}-0.7)/R_B$，$I_C=\beta I_B$ | β 离散 3 倍导致工作点完全不可控——这就是工程上必须用分压偏置的原因。 | [§3.4](p1-04-ch3.md#sec-3-4) |
| 分压偏置：$V_B \approx V_{CC}\frac{R_2}{R_1+R_2}$；$V_E = V_B - 0.7$；$I_E = V_E/R_E$（与 β 无关！） | 分压电流 ≫ $I_B$，基流扰动可忽略；$R_E$ 是采样元件、分压器是基准、$V_{BE}$ 是比较器。 | [§3.4](p1-04-ch3.md#sec-3-4) |
| 设计经验法则：$V_E$ 取 1~2V，分压电流取 $I_B$ 的 10 倍以上 | 负反馈机制：温度↑→$I_C$↑→$V_E$↑→$V_{BE}$↓→$I_C$↓；β 从 100 漂到 300，$I_C$ 变化 <5%。 | [§3.4](p1-04-ch3.md#sec-3-4) |
| BJT 开关：取强制 β=10，$I_B = 70mA/10 = 7mA$；$R_B = \frac{V_{MCU}-V_{BE}}{I_B} = \frac{3.3-0.7}{7mA} ≈ 371Ω$（就近取 360Ω） | 分母是 $I_B$ 不是 $I_C$；感性负载必须加续流二极管——不是可选项，是必需品。 | [§3.4](p1-04-ch3.md#sec-3-4) |
| 达林顿：$\beta_{total}\approx\beta_1\beta_2$（可达 10000+） | 三笔代价：$V_{BE}$ 翻倍到 1.4V、$V_{CE(sat)}$ 升到约 0.9V（Q2 无法深度饱和）、速度慢。 | [§3.4](p1-04-ch3.md#sec-3-4) |
| $\text{温度↑} \;\Rightarrow\; V_{BE}\text{↓（}-2\text{mV/°C）} \;\Rightarrow\; I_C\text{↑} \;\Rightarrow\; \text{功耗↑} \;\Rightarrow\; \text{温度↑↑}$ | 唯一的刹车是射极负反馈电阻 $R_E$；没有 $R_E$ 的固定 $I_B$ 偏置没有任何回路能自己刹车。 | [§3.7](p1-04-ch3.md#sec-3-7) · [动画](p5-00-part5.md#demo41) |
| 在线速判（NPN 放大态）：$V_B≈0.7V$、$V_E≈0V$（直耦）或 $V_E=V_B-0.7$、$V_C$ 明显高于 $V_B$ | $V_{BE}=0.7V$ 但 $V_C≈+12V$→查集电极回路；$V_C≈0.2V$→已饱和；$V_{BE}=0V$→查基极回路。先量电压不先拆管子。 | [§3.7](p1-04-ch3.md#sec-3-7) · [动画](p5-00-part5.md#demo41) |
| 最大不失真摆幅 $= 2\times\min(6V,\ 4V) = \mathbf{8.0V_{pp}}$；$\|A_v\| = \frac{R_C}{r_e} ≈ \frac{2kΩ}{26mV/3mA} ≈ 230$ | 摆幅由更小的那份余量决定——Q 点偏置的任务就是把上行/下行余量尽量平分，否则一摆就削顶。 | [§3.7](p1-04-ch3.md#sec-3-7) · [动画](p5-00-part5.md#demo41) |

**表 B-5　MOSFET 驱动与损耗判据**

| 设计式 / 判据 | 什么时候用 · 翻车点 | 出处 |
