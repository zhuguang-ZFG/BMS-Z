# 共学快闪

> **本篇你会学到**　怎么用五天、一台电脑，把 SOC、协议或固件状态机走成能打卡的小胜利。
> **预计用时**　每一期 5 天。一天一块，做完就能停。
> **前置**　会打开终端就行。三期都不接电池。

想找人一起走，不必先买板子。这三期只使用仓库里已经能在 PC 上跑通的代码：算 SOC、拆字节、跑状态机。

⚠️ **锂电会起火。** 快闪期间不要为了「验证一下」去短接真电池。护目镜和防火垫是碰电芯之前的事，见 [阶段 2](../stages/stage-2-保护板实践.md)。这里的电压、电流、RMSE 都是教学仿真或教学帧，不是你手里那颗电芯的测量。

## 三期怎么选

| 你想解锁的感觉 | 去哪一期 | 每天大概 |
|---|---|---|
| 「百分比是算出来的，而且会漂」 | [SOC 五天](01-soc五天.md) | 读一节，跑一条 Python |
| 「一串坏字节里还能救出好帧」 | [协议五天](02-协议五天.md) | 读一节，跑解析器测试 |
| 「保护不是一句 if，是一台状态机」 | [固件五天](03-固件五天.md) | 读一节，用 gcc 跑骨架 |

三期互不挡路。想先有成就感，从 SOC 第 1 天开始：一条命令，三行数字。

## 一天长什么样

每天固定六件事：

1. **读哪节**：链到阶段教程里已经写好的那一节。
2. **看哪张动画**：仓库里的 SVG。看不懂就读图说，动画是帮手不是门槛。
3. **跑哪条命令**：命令都在这个仓库里实际跑通过。换电脑时数字应一致；若不一致，把你看到的原文贴出来，不要改成「差不多」。
4. **交什么**：打卡里写得下的那几行。
5. **当天口诀**：一句能背的。
6. **今天你解锁了**：做完你多了哪一种「我做到了」。

## 打卡

到[讨论区](https://github.com/zhuguang-ZFG/BMS-Z/discussions)发一帖，分类选「打卡」。标题里写期次和天数，例如「【打卡】SOC 第 1 天」。

也可以改用 Issue 模板 [共学打卡](../../.github/ISSUE_TEMPLATE/04-check-in.md)。

贴命令输出时，贴终端原文。仿真 RMSE 不要写成电芯实测。

## 和 14 天路径的关系

零基础先看 [前两周怎么走](../stages/getting-started.md)。快闪是「已经想动手、但只有电脑」的旁路，不取代阶段 0 的安全纪律。

**练完你会怎样**：你能挑一期，独立做完第 1 天，并把终端里的那一行交出去。
