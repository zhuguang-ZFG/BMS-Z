## 一、一页速览

目标形式和任何数字滤波器一样（5–33 页）：

```
x[k+1] = A x[k] + B u[k]
y[k]   = C x[k] + D u[k]
```

难的是 A、B、C、D 从电芯的传递函数来，而且那些传递函数往往不是有理多项式，还有一个在原点的积分极点。

| 5.3 | 马尔可夫参数就是单位脉冲响应 | 5–9…5–11 |
| 5.4–5.5 | 颗粒表面浓度的传递函数有一个 s = 0 的极点，先把平均浓度减掉 | 5–12…5–18 |
| 5.6–5.9 | Ho–Kalman：脉冲响应排成 Hankel 矩阵，用奇异值决定留几阶 | 5–19…5–32 |
| 5.10 | DRA 四步：频域采样 → 阶跃响应 → 离散脉冲响应 → Ho–Kalman | 5–33…5–36 |

## 二、状态空间只是一种写法（§5.1–5.2）

同一个输入输出可以有很多内部状态的选法（5–3…5–4 页）。讲义把一个二阶差分方程写成可控标准形，再提醒：传递函数不是严格真的时候，要先做多项式长除，商放进 D。MATLAB 的 `tf2ss` 做的就是有理传递函数这一类（5–4 页）。电芯的径向扩散不是这一类，所以后面才需要 DRA。

从状态空间回到传递函数时，极点是 det(zI − A) = 0，也就是 A 的特征值（5–6 页）。相似变换 x̄ = T⁻¹ x 会改 A、B、C，不改传递函数（5–7 页）。端口一样，内部坐标可以差一个线性变换。Ho–Kalman 求出来的实现，也只保证端口，不保证状态等于「第 3 层球壳的浓度」。

> 【译注】阶段 4 的 EKF 已经是 x[k+1] = f(x, u) 这种写法。`code/soc/estimators.py` 里的状态是 SOC 和 RC 电压，A 来自欧拉离散，不是这一章的 Ho–Kalman。读 DRA 是为了知道物理降阶长什么样，不是去替换那份教学代码。

## 三、马尔可夫参数（§5.3）

离散系统对单位脉冲的响应有固定结构：第 0 拍是 D，后面是 C B、C A B、C A² B……（5–9…5–10 页）。这些矩阵就叫马尔可夫参数。多输出时，每一行是输入到那一路输出的脉冲响应。

讲义用一个对角 A = diag(0.5, 1) 的例子，让 MATLAB 的 `impulse` 对上手工算出来的序列（5–11 页）。这里的 `dt*impulse` 是为了得到单位脉冲响应而不是冲激响应，后面 DRA 还会再强调一次采样保持。

## 四、固体扩散，先拆掉积分（§5.4–5.5）

表面浓度对通量的传递函数，讲义按 Jacobsen 和 West 的路线从径向扩散方程做拉普拉斯变换（5–12…5–15 页）。它不稳定：s = 0 有一个极点（5–16 页）。直觉很简单——通量是常数时，锂一直在进或一直在出，平均浓度不会停。

处理办法：让传递函数去拟合「表面浓度减平均浓度」。平均浓度的变化只看进出颗粒的锂（5–16…5–17 页）。球体积是 (4/3) π R_s³，表面面积是 4π R_s²，通量 j 乘面积再除体积，得到：

```
d c̃_s,avg / dt = − (3 / R_s) j(t)
```

这一步没有假设锂在球里怎么分布。积分器单独积这份平均浓度；剩下的偏差传递函数是稳定的，才能送进 DRA。非线性优化去凑极点和留数也可以，但容易栽跟头。DRA 是直接从响应生成状态空间的那条路（5–18 页）。

> 【译注】SOC 的库仑计数就是这个积分器的整节版本：ż = −η i / Q。[Notes03](ece5710-notes03-中文导读.md) 已经写过平均浓度对通量。等效电路不单独积颗粒平均浓度，它把 SOC 和扩散电压分成两个状态。不要把 3/R_s 抄进 `cell_model.py`，那份代码没有颗粒半径。

## 五、Ho–Kalman（§5.6–5.9）

问题：手里只有马尔可夫参数，反求阶数 n 和 A、B、C、D（5–19 页）。把脉冲响应排成斜对角常数的 Hankel 矩阵（5–20 页）。它等于扩展可观矩阵乘扩展可控矩阵。

怎么拆这个乘积？原则上任意一对 O、C 只要乘积是 H 都行，相似变换会把实现变成标准形（5–21…5–22 页）。真正用来定阶的是奇异值分解（5–23…5–25 页）。奇异值快速掉下去之后，丢掉的那些方向对端口影响小，这就是降阶。

步骤摘要（5–29 页）：排一个 Hankel 和它的移位版本；做奇异值分解；按保留的奇异值还原 A、B、C。讲义用斐波那契式的二阶系统当答案已知的例子（5–30…5–32 页），真系统和估计系统的极点、脉冲响应对在一张图上。那是算法自检，不是电芯数据。

## 六、DRA 四步（§5.10）

输入是连续传递函数 H(s) 和采样周期 T_s。充分条件是 H(s) 严格稳定且真（5–33 页）。原点上的孤立极点可以单独剥掉，所以积分器不是死路。H(s) 不必是多项式之比——这正是径向扩散用得上它的原因。

1. 在频域高密度采样 H(s)，做逆离散傅里叶变换，近似连续冲激响应 h(t)。
2. 把 h(t) 积分成连续阶跃响应。
3. 假设输入侧有零阶保持，用 h_step(t) − h_step(t − T_s) 再按 T_s 采样，得到离散单位脉冲响应 g_k（5–34 页）。
4. 把 g_k 送进 Ho–Kalman。

频域采样和 z 变换的关系走双线性那种频率弯折，讲义把 s 写成采样率下的正切（5–36 页）。实现时用的是数值 DFT，不是闭式留数。

## 七、三个例子（§5.11–5.13）

**例 1**（5–37 页）：二阶有理传递函数，目标采样 T_s = 0.1 s。先在高频上做出冲激和阶跃，再重采样成脉冲响应，Hankel 用 64 点。截到前两阶之后给出一组 A、B、C（5–41 页）。阶数事先已知，用来对答案。

**例 2**（5–42 页）：H(s) 在原点有极点，严格稳定这个条件不满足。办法是把积分器拆出去，对剩下的稳定部分做 DRA，再把积分状态拼回增广矩阵。截到两阶后的数值在 5–46 页，是这个例子的结果，不要当成电芯参数。

**例 3**（5–47 页）：传递函数是超越函数，阶数事先无限。这才是颗粒扩散的形状。奇异值图用来选阶（5–50 页）。演示是 10 s 放电脉冲，表面锂通量 j = 1×10⁻⁵ mol/m²/s，然后静置 10 s（5–51 页）。附录里的 PDE 初值 c₀ = 10000 mol/m³（5–52 页），同样是例子，不是规格书。

> 【译注】阶段 4 §4.8 说先仿真后上板。DRA 是「物理仿真如何变成小 ODE」的标准工序，算完的 A、B、C 仍然要在端口上对电压。本仓库的回归测试对的是经验 EKF，没有这些传递函数。通量 1×10⁻⁵ 不要写进保护代码。
