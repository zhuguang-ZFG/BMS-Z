# 动画画风规范

> **本篇你会学到**　新动画长什么样，改旧图时先守哪几条。
> **预计用时**　五分钟。动手改 SVG 之前翻一眼。
> **前置**　动画都在 [assets/](assets/)。公式出图看 [tools/README.md](../../tools/README.md)。

口诀：**八百宽、十二字，深浅走类名，数字标示意。**

同一页里不要一会儿无衬线、一会儿等宽，一会儿深蓝底、一会儿近黑底。读者会以为两个人画的。新图按下面来。检查脚本仍保留豁免清单，第 3 批之后清单是空的：每张图都要自己通过。

## 先决定这张图要解释什么

画图前先写一句问题，例如“为什么第三拍才关断”“为什么撤流后电压不会立刻回到 OCV”。一句写不下，说明它应该拆成两张图。

每张动画按同一条解释链组织：

1. 第一帧先放读者认识的对象与初始状态，不先铺满所有箭头和标签。
2. 一次只增加一个部件；部件出现时，标签直接贴在它旁边。
3. 运动必须代表真实变化：电流、热、数据、状态或时间。只闪进闪出不算讲解。
4. 最后一帧落到问题的答案，并让读者能停住复述。
5. 正文或图说给一个观察任务，例如“先盯住最弱单体”“数到第三拍再看 MOS”。

动画负责展示过程，不负责把一整页正文塞进画面。项目级教学契约见[教学设计规范](../教学设计规范.md)。

## 画布和字

- 宽 800。`viewBox="0 0 800 …"`。高度随内容长，别把字裁在边上。
- 字体：`ui-monospace, Consolas, monospace`。
- 标题 16 px、加粗。正文 13 px。辅助说明不少于 12 px。再小，缩在文章里就糊了。
- 卡片里的句子写短。一行放不下就换行，不要让字冲出卡片。

## 一张图的骨架

从上到下四块，读者不用猜先看哪：

1. 标题，一句话点出这张图在讲什么。
2. ①②③ 步骤卡。每步一句，当前步亮、其余淡。
3. 带刻度的图。轴上要有数，不要只画一条光秃秃的线。
4. 底部读数栏。把「现在读到多少」写在曲线外面。

图例放在曲线碰不到的地方：图题那一行，或者轴的下方。不要压在线上。

## 色：浅色一套，深色一套

深浅色只改 `<style>` 里的类。`@media (prefers-color-scheme: dark)` 里换同一批类的填色。不要写 `style="fill:#…"`，也不要在浅色页面上把深色模式的色值写死。`fill="none"` 这种不带颜色的可以留。

配色以 `tools/visual_palette.json` 为准：象牙纸、深墨、孔雀蓝与赭石，浅黄、薄荷、淡粉只做便签底。手帐感放在留白、面板与导览装饰，不扭曲曲线、电路连线或标签。没有装饰空间的技术图只换色，不另塞插画。

| 类 | 浅色 | 深色 | 拿来做什么 |
|---|---|---|---|
| `.bg` | `#fffdf5` | `#192727` | 整张底 |
| `.panel` | `#f7f2e5`，边 `#cfc6b2` | `#223333`，边 `#496160` | 卡片 |
| `.txt` | `#293b3a` | `#edf0e5` | 正文 |
| `.small` | `#626d65` | `#b0beb3` | 辅助说明 |
| `.title` | `#293b3a` | `#edf0e5` | 标题 |
| `.hi` | `#176b73` | `#7ec5c5` | 强调、蓝线 |
| `.warn` | `#b84745` | `#f39b91` | 警告、红线 |
| `.ok` | `#377b60` | `#8fc7a2` | 正常、绿线 |
| `.gold`、金色点线 | `#926717` | `#dfbd78` | 文字、点线、描边 |

便签底使用墨色字；反白字只放在经验证足够深的色块上。透明色块要按与底色合成后的颜色算对比度，不能只检查原始色值。

所有文字角色在纸面与卡片上都必须达到 4.5:1；配色测试同时守住浅/深两套颜色。技术系列仍须有标签或线型区分，不能只靠颜色传达安全状态。换肤只改逐文件、逐选择器核对过的静态颜色，不改任何 SMIL 属性、动画目标的初始颜色、几何、文字、ID、引用、透明度或线型。

## 装饰注记层：让图有手帐气，但不碰技术

2026-10 起每张动画多一层**插入式**装饰，源在 [tools/motion_style.py](../../tools/motion_style.py)：标题荧光笔与手绘下划线、表头右上的小星、提示框虚线贴纸、确认勾的爆花，以及移动光点的柔光。它只增不删，所有元素带 `bms-` 类名与 `aria-hidden="true"`，共用一个 `<style id="bms-motion">`；颜色从 `tools/visual_palette.json` 取浅/深两套。

- 生成图在 `wrap()` 里自动装饰；手写图跑 `python tools/apply_motion_style.py`。该脚本默认刷新：先剥离既有 `bms-` 元素与样式块，再按当前代码重插，所以改了装饰代码直接重跑，不会留下旧样式。
- 装饰里没有文字、没有 `animateMotion`、没有 CSS keyframes。SMIL 是有意保留的装饰手段：只做小星旋转/呼吸与勾的缩放爆花，`keyTimes` 同样 0→1，打印快照能确定性冻结；技术节点的 SMIL 属性与时间轴一概不动。
- 移动光点与确认勾的柔光是纯 CSS `filter: drop-shadow()`，通过 `:has()` 选中本来就带 `animateMotion` / `stroke-check` 的技术节点，只加视觉光晕，不改几何、属性或时序；降级模式下光晕仍在，但它是静态的。
- 标题荧光笔的字号读取样式表里的 `.title` 规则（16/18/28px 各自匹配），不假设固定大小；每个装饰元素自身或其装饰组都带 `aria-hidden="true"`。
- `prefers-reduced-motion: reduce` 只隐藏小星、贴纸闪光和爆花；原有的独立文字说明仍是不看动画也能读的降级路径。
- 合同测试 `bms-book/tests/test_motion_style.py` 守覆盖、类名齐全、装饰不含技术内容、SMIL 合规、标题几何、`aria-hidden`、深色与降级契约。`bms-book/tests/motion_fingerprints.json` 是 154 张原图的技术结构指纹，连 `<animate>` 后的可见尾随文字也算在内；只有**有意**改动几何、文字、ID 或既有 SMIL 时才从 HEAD 原图重算，并在提交说明里写清原因。
- 打印快照照旧跑 `python bms-book/snapshot_visuals.py`，装饰会冻结成静态矢量，脚本显式写 LF；不要手改 `bms-book/assets/print/`。

## 时间：三条曲线，别的不要发明

循环 8 秒或 12 秒。再短，人还没看清就跳走了。

**每个 animate 都要交代时间曲线**——这是 2026-10-18 全库体检后补上的硬规矩：当时 150 张图 1600 个 `animate` 里 `keySplines` 一个都没有，1433 个匀速、167 个硬切，其中 1114 个盯的是 `opacity`。元素在**跳变**而不是**运动**，观感粗糙的根就在这，不在采样（Chromium `setCurrentTime` 逐帧钉住、30 fps、2× 超采样本来就是对的）。三条曲线够用：

| 用途 | `keySplines` | 观感 |
|---|---|---|
| 进场（淡入、滑入） | `0.16 1 0.3 1` | 快起稳落，像东西被放上去 |
| 退场（淡出、滑出） | `0.7 0 0.84 0` | 缓起快走，不拖泥带水 |
| 位移、保持、变形 | `0.42 0 0.58 1` | 两端都软，中段才快 |

`opacity` 按**逐段**挑：值变大用 out、变小用 in、保持不变用 in-out——所以「亮起—保持—淡出」这种三段高亮，三段各配各的曲线（写成一个分号串）。`calcMode="discrete"` 只留给真要断的地方（步进计数、状态切换）。

时间轴上的匀速是**语义正确**的：点沿横轴走代表时间在流，这类保留 `linear`，但要显式写 `data-ease="linear"`——默认不再是「随便」。SMIL 的另外两条硬约束：非 discrete 的 `keyTimes` 必须**以 1 结尾**、`keySplines` 段数必须等于 `keyTimes` 段数减一；`docs` 的检查器与 `spec.py --check` 都拦这两条（本仓库真踩过：脉冲环的 keyTimes 停在 0.20，浏览器直接不执行那条动画）。

运动本身也分三档，往上加：**进场**（淡入 + 小幅位移，交错出现）、**指示物**（令牌/游标沿 `path` 走，`animateMotion` 到站停一下再脉冲）、**证据**（线自己长出来 `stroke-dashoffset`、数据包沿链路走）。只有透明度变化＝「闪进闪出」，是这三档里最低的一档，别整张图都用它。改缓动的验证方式是**同刻对照**：同一张图改造前后在同一批 `setCurrentTime` 上逐帧渲染比对，静止态必须逐像素一致——缓动只改时间，不改几何。仅换配色时，允许已登记的静态颜色不同；同刻的技术几何、文字与动画状态必须一致，并逐图检查非颜色内容没有变化。

- 动效敏感的读者：SMIL 动画不能被 CSS 暂停，markdown 里也注不了脚本，所以**没有自动降级**。装饰层遵守 `prefers-reduced-motion`，但只关掉新加的环境小星与爆花，技术动画本身照旧。降级路径就是每张动画正文里的独立文字描述与图说——不看动画不影响理解（README Q4 的承诺）。这是已知限制，写在这里就不算藏。
- 根元素写 `role="img"`。里面要有 `<title>` 和 `<desc>`。`<desc>` 用一句话讲清图上在动什么；**不能是 `<title>` 的复读**——读屏会把同一句听两遍，检查器拦（`desc-eq-title`）。画布宽 800 也是检查器强制项（`bad-width`）。
- 曲线上的数是公式算出来的教学数，不是示波器，也不是某一颗电芯的实测。写上「示意」。
- 不改 `code/` 里的固件和算法。要复现仿真，就调用现成的 `compare.py`，不要另编一组 RMSE。
