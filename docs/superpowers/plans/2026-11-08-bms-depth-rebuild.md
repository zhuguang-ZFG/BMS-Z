## 0. 执行方式

每次继续先读本页的任务状态、当前批次及未解决项，按任务 ID 开工。阶段状态分别记 `planned / implementing / technical_review / locally_verified / external_pending / accepted`；未取得证据的 checkbox 保持空白。样章先达到内容标准，随后才批量复制制作方法。

每个任务记录：`task_id、scope、owner、dependencies、changed_files、evidence、limitations、next_task`。负责人是本次执行者角色，不预设并不存在的真人审稿者。用户已授权并发；只有文件所有权明确且依赖已满足的任务并发，共享清单与构建器由集成负责人统一修改。

计划中的拟新增文件和 CLI 均为设计落点，不是当前可运行命令。文件名确需调整时先回写本计划与引用，不形成第二套隐性任务表。

### 0.1 任务卡、证据和估算

每个单元执行总SPEC的G01–G10十环。任务卡至少记录 `unit_id / source_blocks / prerequisites / source_ids / claim_ids / scenario_ids / figure_ids / experiment_ids / independent_task / acceptance / owner / dependencies / evidence / pending`。其中 `acceptance` 要写输入、比较对象、误差/时间/状态判据及其来源，不能仅写“测试通过”。暂时无可靠阈值的项目先交测量/标定方案，禁止编一个数作为器件许可。

实施产物按“源稿、实验、图版、登记、审查、出版”归属；实验先固定版本与配置，再保存原始轨迹、派生指标和失败结果，图生成器只消费已登记数据。每个P任务退出时更新实现状态和剩余环节，未执行的外部验收单列。修改模型/参数后必须列出受影响的图、答案、断言和旧回归。

工作量按连续论证、实验复杂度和图点估算；P1完成后据实际返工修订P3–P6的排期。不用每章固定字数或每天出图数量制造进度。每次提交围绕一个可复核交付，报告“完成哪些环节、证据在哪里、下一阻塞是什么”。

### S1 / D04–D05–D08：精度够了，保护为什么反而慢了

**先修**：B01–B04 的对应小节；未学过协方差时先用两组相关读数建立直觉，再给代数式。

**叙事与推导**：

1. 从“平均后的曲线更稳，却超过故障反应窗口”开场，明确测量与动作两个要求。
2. 建立 `y_i=(1+g_c)V_i+b_c+b_i+α_i(T−T0)+n_i+e_dynamic,i`，逐项区分增益、偏置、温漂、随机与动态误差。
3. 推导线性误差最坏界 `Σ|a_i|B_i`，方差 `Σa_i²σ_i²+2Σ_{i<j}a_i a_j Cov_ij`；均方误差还含偏差平方。最大值不是σ；不相关与独立不是同义词。
4. 以 `y=1.002V+0.012 V` 做单点校准，在未参加校准的点看残差，再引出双点校准与温度验收。
5. 从 `|e(t)|=|ΔV|exp(−t/τ)` 推出建立时间；注明这是一阶有效模型，不能把所有 AFE 内部拓扑想成同一颗切换电容。
6. 讨论因果移动平均、噪声方差缩减及群延迟；`σ²/N` 限于等方差、时间不相关的随机项，另给时间相关噪声对照。用真实阈值轨迹证明群延迟不是通用检出延迟。

### S2 / D02–D11–D14：一条电压曲线能识别出多少东西

**先修**：B02/B03/B05、D01 与测量误差基础。先给单节电路和状态身份，再引入矩阵。

**必须展开的关系**：

```text
dz/dt = −I/(3600Q)
dvp/dt = −vp/τ + I/C1，τ=R1C1
V = U(z) − I R0 − vp
a=exp(−Δt/τ)
z[k+1]=z[k]−I[k]Δt/(3600Q)
vp[k+1]=a vp[k]+R1(1−a)I[k]
```

明确 I[k] 的作用区间与电压输出时刻；从积分得到离散式，不能仅贴公式。解释 R0 跳变与极化慢尾、有限脉冲修正 `A=−I R1(1−exp(−Tp/τ))`，再看短窗缺少曲率时的参数混淆。拟合用一段数据，验证换脉冲；参数命中网格边界要报告，不能静默当最优真值。

已知输入和参数、冻结OCV斜率的局部线性模型中，`F=diag(1,a)`、`H=[g,−1]`，两拍观测矩阵的行列式是 `g(1−a)`。讲清该模型下 g=0 的局部 SOC 不可观与短窗病态；某一点导数为零不推出全局非线性不可观。单位不同的状态不能用未经尺度处理的行列式数值直接宣称精度。

**教学参数与解析锚点**：主场景 `S2-pulse-identification` 使用 `U(z)=3.6+0.8(z−0.5) V`，Q=2 Ah、R0=20 mΩ、R1=15 mΩ、C1=3000 F、τ=45 s；z0=0.60、vp0=0、dt=0.5 s、放电2 A。10 s脉冲用于辨识，30 s用于独立验证，各观察撤流后静置180 s。平坦斜率0.08使用独立 `S2-flat-ocv` 场景。

**拟合合同**：只拟合撤流静置尾段，以释放时刻为 `t=0`，联合求 `K+A exp(−t/τ)` 的 K/A/τ；不把最后一个样本当成已知OCV。Q、输入及脉冲持续时间已知；R0由同一状态、输入跳变两侧极限独立获得，有限采样估计误差另作对照。先对τ=10…120 s、步长0.5 s逐点解K/A线性最小二乘，再比较残差；通过有限脉冲修正从A恢复R1，再得C1=τ/R1。短窗为0…5 s，长窗为0…180 s，均含端点；不使用验证脉冲选择网格或调参。

无噪基准要求τ命中45 s网格点、R1/C1相对误差≤1e−6，独立30 s脉冲全轨迹电压RMSE≤1e−8 V。这是浮点解析一致性容差，不是硬件精度。带噪示例固定种子7、σ=1 mV，并记录生成器/版本和输入摘要；另做多种子敏感性，报告目标函数/参数区间，不要求每一次长窗都优于短窗。

### S3 / D07–D08–D23：电容充到95%，为什么还不能直接合闸

**先修**：B01/B02/B04、功率路径、时序和命令/反馈。高压数字只用于仿真和设计审查，不是自行搭建高压台架的操作指南。

**推导与状态链**：从含初始残压的RC方程求电压、电流、瞬时功率和能量；比较无负载与并联负载，考虑容差及重复脉冲；再由剩余压差、器件限制、有效测量与反馈状态构成许可。母线有电可能来自残压、回灌、粘连或测量故障，不能从一个读数确定根因。

```text
VC(t)=VS−(VS−V0)exp(−t/RC)
I(t)=(VS−V0)/R · exp(−t/RC)
ER(t)=0.5 C(VS−V0)^2[1−exp(−2t/RC)]
EC(t)−EC(0)=0.5 C[VC(t)^2−V0^2]
ES(t)=VS C[VC(t)−V0]   （理想恒压源、无其他负载）
ES = ER + ΔEC
```

**冻结基准**：VS=400 V、C=1 mF、R=170 Ω、V0=0。所有值均为教学假设，不代表实际器件选型。

|---|---:|
| τ、初始电流、初始电阻功率 | 0.17 s / 2.35294 A / 941.176 W |
| 达90% / 达95% | 0.39144 / 0.50927 s |
| 达95%时母线/剩余压差 | 380 / 20 V |
| 达95%时源供/电阻耗/电容储 | 152 / 79.8 / 72.2 J |
| 理想稳态源供/电阻耗/电容储 | 160 / 80 / 80 J |

电阻查脉冲功率/能量曲线、持续时间、重复间隔、热降额、工作电压与绝缘；接触器查接通/分断限值、线圈与辅助触点。20 V剩余压差的接通电流还取决于回路电阻/电感，不能只按95%比例签字。

**故障与验收矩阵**：预充拒动、主/预充支路粘连、残压、外部回灌、母线卡值、采样无效、升压过快/过慢、负载未卸、途中保护、反馈超时与复位请求。每项列注入方式、观测点、允许状态转移、命令/反馈截止时间、锁存及人工/自动复位条件。正常下电和短路紧急分断的策略不能混同。

**图版清单**：S3-F1 预充/主回路/泄放的分状态电流路径；S3-F2 源/电阻/电容能量账和VC/I/P曲线；S3-F3 命令、辅助触点、母线、电流和故障共时轴；S3-F4 传感有效性及残压/回灌/粘连的可区分证据；S3-F5 器件限制与重复热的工作点。F1/F4适合手绘电路与机制；F2/F3/F5需要真实比例或明确示意标签。
