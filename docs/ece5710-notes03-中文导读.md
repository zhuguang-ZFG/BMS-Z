## 一、一页速览

讲义把模型分成四级（3–1…3–2 页）：分子尺度不讲；微观尺度看均匀的固体颗粒和均匀的电解液；连续介质尺度把孔隙平均掉；电芯尺度再收成一小撮常微分方程。经验模型（等效电路）能拟合端口，外推能力有限。物理模型难写，但能分别盯住每一种机理。

本章要证明的五条（3–3 页）：

| # | 方程在说什么 | 记住的形式 | 原文 |
|---|---|---|---|
| 1 | 固体里电荷不凭空生灭 | ∇·(σ ∇φ_s) = 0 | 3–3 |
| 2 | 固体里锂只靠扩散搬家 | ∂c_s/∂t = ∇·(D_s ∇c_s) | 3–3 |
| 3 | 电解液里盐的质量守恒 | ∂c_e/∂t = ∇·(D ∇c_e) − (i_e·∇t₊⁰)/F − ∇·(c_e v₀) | 3–3、3–47 |
| 4 | 电解液里电流也守恒 | ∇·(κ ∇φ_e + κ_D ∇ ln c_e) = 0 | 3–3、3–53 |
| 5 | 锂在固液界面按 Butler–Volmer 过界 | j 随过电位 η 指数拉开 | 3–3、3–63 |

> **口诀**　颗粒里面锂要扩散，表面才决定电压。电解液只运盐，界面才交换锂。五条方程，后面全是它们的简化。
>
> **能记住**　五条方程各管一件事。**能理解**　为什么端电压看表面浓度、SOC 看平均浓度。**能用**　看见等效电路里的 R₀、RC、OCV，能指回这五条里的哪一条。

## 二、尺度梯子（§3.1）

课程要做三件事：写出通用锂离子模型、找出参数、仿真预测性能（3–1 页）。经验路线用系统辨识得到常微分方程。物理路线从可测量的材料参数出发，一级级往上平均。

微观尺度把杂质和缺陷先拌匀，看成均匀材料，参数仍能在实验室直接测（3–2 页）。连续介质尺度的每一个小体积里同时有固体和电解液，孔隙细节被平均掉，两相仍分开记账，但必须写下它们在这个小体积里怎么交换。再往上，偏微分方程收成和等效电路差不多大的常微分方程，外推却更有底气。讲义的原话是：物理这条路难得多，也好得多（3–2 页）。

> 【译注】本仓库 `code/soc/cell_model.py` 走的是经验这条路：`U = OCV(SOC) + I·R0 + U_rc`。它不替换本章。读完五条方程，你应该能说出 RC 电压在模仿哪一种慢过程。对照 [Notes02 导读](ece5710-notes02-中文导读.md) 第三节。

## 三、固体里的电荷和锂（§3.2–3.3）

固体这两条不用电化学，所以先证（3–4 页）。

**电荷（§3.2）**。假设线性介质，欧姆定律写成电流密度 i = σ E。磁效应可忽略时，电场是电位的负梯度，于是 i = −σ ∇φ（3–4 页）。电荷只能从体积边界进出，内部不生不灭。体积缩到一点，积分形式变成散度：∇·i_s = 0，也就是 ∇·(σ ∇φ_s) = 0（3–3、3–6 页）。散度为正是源，为负是汇。均匀固体内部没有界面反应，所以电荷散度为零。

**质量（§3.3）**。锂在固体基质里的移动，假设只有扩散、介质线性，这就是菲克定律的点形式（3–8 页）。浓度 c 的单位是 mol/m³。1 mol 是阿伏伽德罗数那么多个粒子，讲义取 N_A = 6.02214×10²³（3–8 页）。扩散系数 D 的单位是 m²/s。质量守恒的点形式是 ∂c_s/∂t = ∇·(D_s ∇c_s)（3–3 页）。

讲义用一维差分演示浓度怎么抹平：前向、后向或中心差分都可以逼近二阶导数（3–11 页）。那是教学动画，不是 BMS 里要抄的网格。

> 【译注】阶段 0 说「离子走里面、电子走外面」。这里把这句话拆开：电子在固体里服从欧姆定律；锂原子在颗粒里服从菲克定律。等效电路的扩散电压，就是这条菲克定律还没抹平时的端口表现。

## 四、热力学只留接口（§3.4–3.8）

后三条方程要先借一套热力学语言。导读不重证每一步，只留后面会再见到的名词。

内能是状态函数。自由能是还能拿来做功的那一部分（3–15 页）。广延量随系统加倍而加倍，强度量不加倍。电化学势是从吉布斯自由能对摩尔数求出来的偏摩尔量（3–21…3–23 页）。吉布斯–杜亥姆关系说：恒温恒压、两组分时，n₁ dμ₁ + n₂ dμ₂ = 0（3–24 页）。它的用处是少写一个独立变量。

活度不是浓度的别名。离子周围有异号离子云，德拜–休克尔–昂萨格理论讲的就是这件事（3–25 页）。古根海姆用绝对活度把化学势和浓度标度连起来；用摩尔浓度还是质量摩尔浓度，比例常数不同，但描述的是同一种势（3–26…3–27 页）。

二元电解液用化学计量数 ν 把盐拆成阳离子和阴离子。Na₂SO₄ 是讲义的计数例子（3–28 页）。锂电常用的盐是 LiPF₆，拆成 Li⁺ 和 PF₆⁻，于是 ν₊ = z₊ = 1（3–47 页）。电流密度是各带电物种通量乘上 zF 之后的和（3–30…3–31 页）。

这些页是工具，不是新的电芯现象。卡住时记住：后面的电解液方程，是在「浓溶液 + 电化学势」上重写菲克定律。稀溶液理论对锂电不够好，所以讲义走 Newman 的浓溶液路线（3–32 页）。

## 五、电解液的质量和电荷（§3.9–3.14）

讲义分四步凑出电解液质量守恒，推导按理想气体碰撞把 Maxwell–Stefan 摩擦力写清楚，再改写成浓溶液（3–32…3–46 页）。工程上要带走的是结果，不是碰撞模型本身。

Doyle 常把 d ln c₀ / d ln c 近似成 0。简化后的质量守恒，对 LiPF₆ 写成（3–47 页）：

```
∂c_e/∂t = ∇·(D ∇c_e) − (i_e · ∇ t₊⁰)/F − ∇·(c_e v₀)
```

t₊⁰ 是阳离子迁移数：电流里有多少份额由阳离子扛。溶剂速度 v₀ 是对流项。固体里没有这项，因为固体没有流动的溶剂。

电荷守恒从 ∇·i = 0 出发。负极反应写成 LiC₆ ⇌ C₆ + Li⁺ + e⁻，正极写成 MO₂ + Li⁺ + e⁻ ⇌ LiMO₂。两边都得到 s₊ = 1、n = 1（3–53 页）。锂电的电解液电荷方程是：

```
∇·i_e = ∇·[ κ ∇φ_e + (2κRT/F) (1 + ∂ln f± / ∂ln c_e) (t₊⁰ − 1) ∇ ln c_e ] = 0
```

常再假设活度项 ∂ln f±/∂ln c_e = 0，并把第二项收成扩散电导 κ_D，得到 ∇·(κ ∇φ_e + κ_D ∇ ln c_e) = 0（3–53 页）。电位梯度推电流，浓度梯度也推电流。这就是浓溶液比「只写欧姆定律」多出来的一项。

> 【译注】等效电路把这一切收成一个 R₀ 加几条 RC。浓度梯度造成的额外电压，不会在电流跳变的那一拍出现，所以它进不了 R₀，只能进慢支路。参数不够时先用 [Notes02](ece5710-notes02-中文导读.md) 的脉冲法，不要在 MCU 上实时解这两条偏微分方程。

## 六、Butler–Volmer：锂怎么过界面（§3.15–3.17）

第五条方程把前四条耦在一起。它算的是锂穿过固体和电解液边界的速率（3–54 页）。

活化络合物理论：反应要先爬过一个过渡态。电极电位改变时，还原方向和氧化方向的势垒一升一降，分配系数是 α（3–55…3–58 页）。平衡时两个方向的电流大小相等，这个共同的值叫交换电流密度 i₀（3–60 页）。静置电位对浓度的依赖就是能斯特方程（3–61 页）。

对锂离子，空位浓度是 c_s,max − c_s,e，还原一侧的浓度就是表面浓度 c_s,e，静置电位写成开路电位 U_ocp。过电位（3–63 页）：

```
η = (φ_s − φ_e) − U_ocp
```

界面电流（A/m²）和摩尔通量 j（mol/m²/s）差一个法拉第常数。讲义把最终形式写成（3–63 页）：

```
j = k₀ c_e^(1−α) (c_s,max − c_s,e)^(1−α) c_s,e^α
    · [ exp((1−α)F η / RT) − exp(−α F η / RT) ]
```

j > 0 表示锂离开颗粒，j < 0 表示锂进入颗粒。小过电位时它接近一条直线，斜率就是后面降阶模型里的电荷转移电阻。大过电位时它是指数，等效电路的线性电阻不再够用。

## 七、边界、整节容量、单颗粒（§3.18–3.20）

五条方程要配边界才能算。本章不跑求解器，下一章才进仿真（3–64 页）。颗粒表面的锂通量必须接上界面反应（3–65 页）：

```
n̂_s · ∇ c_s = −j / D_s
```

颗粒中心对称，通量是零。

整节电芯按这一章的网格去算，算力不够（3–67 页）。但开路电压、容量、SOC 可以不跑全场就写出来。实用电芯不用满整个化学计量窗口，贴边要么老化快，要么功率塌（3–69 页）。负极只用 x_0% 到 x_100%，正极只用 y_0% 到 y_100%。安时容量（3–69 页）：

```
Q_neg = A F L_neg ε_s,neg c_s,max,neg |x_100% − x_0%| / 3600   （Ah）
Q_pos = A F L_pos ε_s,pos c_s,max,pos |y_100% − y_0%| / 3600
Q = min(Q_neg, Q_pos)
```

满充时负极锂最多、正极锂最少；放空则相反（3–70 页）。SOC 对化学计量是线性的（3–71 页）：

```
z = (c_s,avg,neg / c_s,max,neg − x_0%) / (x_100% − x_0%)
```

正极那条等价，只是 y_0% 在满充一侧、数值更大。

**单颗粒模型（§3.20）**承认：固体颗粒里的扩散通常是最慢的，电解液的浓度和电位可以先丢掉（3–72 页）。每个电极收成一颗代表球，用等厚度球壳做有限体积。讲义示例（3–73 页）：半径 R = 10×10⁻⁶ m，c_max = 12000 mol/m³，初值 c₀ = 9500 mol/m³，D = 1×10⁻¹⁴ m²/s，径向 20 层，时间步 1 s。通量示例 j₀ = 5000·R/3/1800 mol/m²/s，先放 1800 s 再歇 3600 s，然后反过来充电。这些是教学常数，不是某种商品电芯的规格。

外加电流怎么变成表面通量（3–76 页）：

```
j = i_app / (a_s F A L)
```

SOC 看电极平均浓度，电压看表面浓度 c_s,e。两颗球、两条开路电位曲线，电芯电压是 U_ocp,pos(y) − U_ocp,neg(x)（3–76 页）。

> 【译注】「电压看表面、SOC 看平均」是这条讲义和 [ECE5720 Notes01](ece5720-notes01-中文导读.md) 对上的那一句。`code/soc/` 的 EKF 只有一个 SOC 状态加一个 RC 电压，没有表面浓度。它能演示校正，不能演示颗粒内部的梯度。单颗粒模型也还不是本仓库的代码。过充过放的事故链仍以阶段 0 为准：贴化学计量边界会加速老化，保护阈值不要从这组教学常数里读。

## 九、短自测

先盖住答案。四题都对得上讲义，不另造数。

1. 五条方程里，哪一条允许浓度梯度也推动电解液电流？

3. 为什么 SOC 用平均浓度，电压却要表面浓度？
4. 整节容量为什么取两极容量的最小值？

<details>
<summary><b>参考答案（先自己想完再展开）</b></summary>

1. 第四条，电解液电荷守恒。简化后是 ∇·(κ ∇φ_e + κ_D ∇ ln c_e) = 0（3–53 页）。固体电荷守恒里没有浓度项。
2. D = 1×10⁻¹⁴ m²/s，和 R = 10 µm、c_max = 12000 mol/m³ 一起出现在 3–73 页的教学脚本里。不是某种电芯的出厂规格。
3. 开路电位和 Butler–Volmer 都用界面上的浓度；库仑计数和化学计量窗口用的是整个颗粒（整个电极）里的锂（3–71、3–76 页）。
4. 能用的锂由较瘦的那一极锁死，Q = min(Q_neg, Q_pos)（3–70 页）。另一极多出来的窗口用不上，还常常是为了躲开退化。
