# D28 综合设计与独立复核

> P6 的 D28，工程支线收官：综合设计决策赢得信任靠两样东西——**复核包**（决策→声明→缺口→保真地板的证据束）与**独立复核**（复核人≠作者、实测复跑、边界复述）。复核 verdict pass 不升级为产品结论：SRC06（待补）与 UDS/HIL 边界原样不动。

## D28.1 定位

计划主线 P6：D28 的先修清单最长（D10–D26 十四个单元），它站在整条工程支线的出口。前面每个单元交付时都自带边界句；综合设计的第一个风险就是把所有"局部成立"组装成"整体成立"——组装不传递信任，**复核**才传递。

本单元交付复核方法的两个工件：复核包组装器与独立复核审计器，并用一个教学决策走完全程。

## D28.2 证据分级与产线边界

- 离线方法工件：复核包、三条独立规则、跨切面门；
- 真实产线资料：SRC06（待补）——教学决策声明的缺口 G02 仍开放；
- 教学值：D28-D1 决策与独立复核员角色。

## D28.3 机制：复核包与三条独立规则

种子决策 D28-D1（教学值）：**预充继电器粘连检测采用电流残差判据而非单纯计时**——计时只能证明时间到了，残差异常才指向粘连。链接声明 D23-C01（预充高压）与 D22-C01（诊断锁存），声明缺口 G02（SRC06）。

复核包 `build_review_packet(root)` 从登记组装：决策表述、作者、复核人、链接声明（从 claims.json 解析出 unit/anchor/statement/source_ids）、声明缺口、复核人边界复述，外加登记内 claim 总数。

独立复核审计 `audit_review(root, packet, rerun_packet)`：

| 规则 | 检查 | 严重级 |
|---|---|---|
| I1 | 复核人缺失或与作者同一人——自复核是起草不是复核 | error |
| I2 | 复跑且**fail-closed**：复核方重新组装复核包，链接声明集合不一致即 `rerun_diverged`；复跑包必须带 provenance（精确复跑命令 + 产生者），缺命令或产生者与作者同人分别报 `rerun_evidence_missing`/`rerun_not_independent`——空手比对自己构造的两份字典不算复跑 | error |
| I3 | 边界复述：复核人第一句必须复述本决策**不做什么**，且含边界词（不能/不证明/边界/待验/不适用） | error |
| 跨切面 | 链接声明必须在登记内存在；决策表述必须过 D27 全局保真地板 | error |

I2 是灵魂：复核不信任包，复核**重做**包。

## D28.4 反例教学：三种假复核

`test_d28_design_review.py` 钉住：作者给自己复核（I1）、边界复述写成"看过了，没问题"（I3）、决策表述越过全局地板说"直接给出功能安全结论"（跨切面）、复跑少链接一条声明（I2）、链接指向不存在的声明（unknown_claim_ref）。

## D28.5 动手验证（学生任务）

```bash
python -m pytest code/engineering/review -q

```

入门：跑通，解释为什么 I2 要求"复跑"而不是"阅读"。
进阶：把种子决策换成你自己的（换一个链接声明组合），先不合 I3 跑一次，修到 pass；把 `reviewer` 改成与 `author` 同字符串看 I1。
精通：对 D28-D1 写一段 200 字独立复核意见，必须含边界复述与至少一条"我不知道"（对应 G02 未闭合）；然后回答：复核意见本身进不进 claims evidence？为什么？

## D28.6 冻结数字（E21）

- 种子决策 1 条，链接声明 2 条（D23-C01、D22-C01），声明缺口 1 条（G02）；
- 复跑一致（fresh 子进程经 `run_fresh_review` 真跑 CLI 产出的包带 provenance，I2 空跑通过），审计 verdict `pass`，findings 0；无复跑/无命令 provenance/复跑者与作者同人均被 I2 fail-closed 拦截；
- 决策表述过全局保真地板：无寿命预测/保修/产线放行/功能安全结论字样。

## D28.7 与相邻单元的关系

- 综合：D28 不复述各单元机制，只组装它们的证据束——机制在各单元，信任在复核；
- 与 D24/D25/D27 的咬合：登记审计（D24）保链接声明存在，论证缺口（D25）保 G02 有人认领，保真地板（D27）保决策表述不越界；
- 研究支线 R01–R04 的每个结论进登记时，同样要过复核包纪律。

## D28.8 验收边界

- 复核 verdict pass 只证明独立性、复跑一致、边界复述存在，**不升级为产品结论**；
- SRC06 闭合前，D28-D1 是教学决策；真实决策的复核包须附带各自 SRC06 语境；
- 复核人署名是责任链声明，不是能力认证。
