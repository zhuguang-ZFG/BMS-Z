# 第 16 章 探头负载与接地

- 电路：源阻 100 kΩ 的理想阶跃源，分别接 ×1 探头（1 MΩ ∥ 100 pF）与 ×10 探头（10 MΩ ∥ 10 pF）。
- 输入：1 V 阶跃，周期 10 ms；`.tran` 扫 100 µs，步长 0.1 µs。
- 期望：直流终值约 0.909 V / 0.990 V，10–90% 上升时间约 20 µs / 2.2 µs，具体容差见 `assert.json`。
- 运行：`python scripts/run_spice.py --root assets/spice`（需要 ngspice；缺失时用例跳过）。
- 数据：`probe.dat` 由本 deck 的 `wrdata` 生成，不是手写或拟合数据。
- 模型边界：电阻与电容都是理想线性元件，没有探头电缆谐振、地线电感、共模效应与介电吸收；源边沿也按 1 ns 的理想阶跃处理。真实探头在几百 MHz 以上还会出现谐振与滚降，正文用 `ch16-probe-model.svg` 说明了这些边界。
