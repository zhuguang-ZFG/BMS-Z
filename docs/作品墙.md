# 作品墙

> **本篇你会学到**　做完一块板、一段仿真或一次协议解析之后，怎样把作品交到墙上来。
> **预计用时**　读规则 5 分钟。做作品的时间不算在这里。
> **前置**　作品是你自己的。转载要有作者授权。

## 怎样算一件作品

收这些：

- 你画的原理图或 PCB（截图，并写明工具）
- 你跑出来的仿真曲线或擂台 RMSE（贴命令和终端原文，标明**仿真结果**）
- 你解析出来的一帧（教学帧或你自己抓的；别人的抓包要有出处）
- 你填好的阶段 2 实测表（那是 [读者贡献](../.github/ISSUE_TEMPLATE/03-reader-contribution.md)，也可以同时出现在这里）

不收这些：

- 商品页截图，除非你在讲「我买的就是这一页」，并且不把它说成你的设计
- 没有署名的图
- 编出来的效率、价格、认证编号
- 把仓库 SVG 重新导出，当成自己的实测波形

## 投稿

到[讨论区](https://github.com/zhuguang-ZFG/BMS-Z/discussions)发帖，分类选「作品展示」。三件不能少：本人作品、署名、截图或仿真输出。

也可以用 Issue 模板 [晒作品](../.github/ISSUE_TEMPLATE/05-show-work.md)。

核对过的一行，由维护者写回上面的表。你自己的 Issue 就是留底。

共建者名单不在这张墙上，在 [README 末尾](../README.md#共建者)。那一节只写 GitHub 贡献者图上有的账号。

**练完你会怎样**：你知道墙是空的，是因为还没有人交，不是因为你来晚了。你的第一件可以就是共学第 1 天的终端输出。
