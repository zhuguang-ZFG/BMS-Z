# BMS 连续课程：从读懂电池到交付验证

从 [第 1 课：电压、电流与电量](01-units.md) 开始。前三课只需四则运算、纸笔和计算器；第 4 课起用电脑。全程使用虚拟数据，默认不需要购买、拆解或连接真实电池。

你会一直跟踪同一组 **4 串、2 Ah 教学电池包**：先算它有多少能量，再读采样、加保护、记电量、处理充电和通信，最后交付一个能回放故障的 PC 项目。每课有独立题目，做完再展开核对。前面的课给步骤，后面逐渐只给任务和验收条件。

这里的“2 Ah”是额定容量；电压和保护阈值都是注明条件的教学配置，不能直接用于选购保护板或设定真实电芯限值。课程里的电脑结果只证明模型和软件行为。

## 怎么判断自己能继续

读完不是完成标志。合上例子，先做变式题，再说明“输入是什么、用了什么条件、结果能说明什么”。错在单位就回第 1 课，错在时间就回第 6 或 8 课；不必重刷整本书。

每个模块保留计算、修改的文件、实际命令与输出。第 21 课更换容量、采样周期和故障，检查你是否能迁移；第 22–24 课把软件作品变成真实工程任务。达到熟练或精通，还需要真实数据、目标板验证和他人复核。
