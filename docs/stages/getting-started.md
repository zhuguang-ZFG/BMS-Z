# 零基础：前两周怎么走

先做下面的第 0 天。做完就打开 [阶段 0 主线：电芯与保护](stage-0-主线-电池.md)，再读[充电与剩余电量](stage-0-主线-充电与电量.md)。两篇读完即可进入阶段 1。

> 只读中文也能走完前两周。英文视频/原文一律**可选**。  
> 安全装备与预算见 [器材清单](../budget.md)；生词查 [术语表](../glossary.md)。

⚠️ **真电池会起火。** 前两周尽量只用量好的旧电芯做**开路电压测量**；鼓包、漏液、电压异常的直接报废。护目镜与防火垫在碰真电池前备好——不要等阶段 2。

只有电脑的读者，做完第 0 天可以选择一期 [五天共学](../共学/README.md)。以后转做硬件实验时，仍需遵守本页的安全要求。

## 你属于哪一类？

| 你现在 | 怎么走 |
|---|---|
| **零基础**（没学过电路/嵌入式） | 按下面「14 天路径」原速走 |
| **会一点电路**（认识电阻电容、用过万用表） | 阶段 0 的 §0.2 可快读；重点仍是 §0.1 电池化学 |
| **会嵌入式**（写过 STM32/Arduino） | §0.3 可扫读；仍建议过一遍 I2C/SPI「翻车现场」 |

已经有明确目标（保护板、读取商用 BMS 数据、算法或协议逆向）的，做完第 0 天后可以 [按目标选路线](按目标选路线.md)，每条路线列出必读小节。前两周结束后，用 [能力地图](bloom-map.md)检查掌握程度。

## 第 0 天：30 分钟小胜利（零器材也能做一半）

目标：亲手确认「电池有电压、充电会变慢」，建立直觉。

1. **有万用表 + 一节旧 18650/手机电池**（不鼓包）：静置后测开路电压，记下来。三元大约 3.0–4.2V，铁锂大约 2.5–3.65V——对不上也不要紧，阶段 0 会解释。  
2. **只有手机**：把电放到约 20%，插上充电器看进度——前半段快、接近 100% 变慢。那就是后面要讲的 **CC → CV**。  
3. 打开 [阶段 0 动画：锂离子与电子分头行动](../circuits/assets/li-ion-working.svg)（浏览器打开，GitHub 网页也能播），看懂「离子走里面、电子走外面」。

记录你测到的电压或观察到的充电变化，带着这份记录读阶段 0。

## 14 天路径（零基础默认）

| 天 | 做什么 | 完成标志 |
|---|---|---|
| 0 | 上面「第 0 天」 | 测过一次电压，或观察过一次充电变慢 |
| 1–4 | 阶段 0 两篇主线：[电芯与保护](stage-0-主线-电池.md) → [充电与剩余电量](stage-0-主线-充电与电量.md) | 能讲清：为何不能过充/过放、为何低温慎充、4.2 V 为何不等于充满 |
| 5–6 | 按需要读[阶段 0 电路选读](stage-0-选读-电路.md)：RC / ADC / MOS / 电流采样 / 隔离 | 知道背靠背 MOS 为什么要两颗 |
| 7 | 回答第二篇主线末尾的三个核对题；嵌入式先不读 | 三题能用自己的话说清即可进入阶段 1 |
| 8–12 | **[阶段 1](stage-1-认识BMS.md)** 全文 + 自测 | 能画出五大模块框图，背出五大保护 |
| 13–14 | 扫一眼 [预算清单 阶段 0–2](../budget.md)；可选：[瑞萨导读](../renesas-bms-tutorial-中文导读.md) 前两章 | 清楚阶段 2 要买什么；准备护目镜/防火垫 |

**阶段 0 嵌入式选读**：拖到开始抄保护板或碰 AFE 之前补齐即可，不挡你认识 BMS。
