# 第 2 章 桥式整流与电容滤波

- 电路：10 V 峰值、50 Hz 交流源，源内阻 1 Ω，四只二极管桥，1000 µF 滤波电容，200 Ω 负载。
- 期望：稳态平均输出约 8.0 V，纹波峰峰值约 0.4 V，二极管峰值电流约 0.5 A。
  理想二极管手算给出 8.5 V / 0.41 V（ΔV≈I/(2f·C)，100 Hz 纹波）；把两只二极管的
  0.65 V 正向压降、导通角与源内阻算进去，平均电压降到 8.0 V、纹波降到约 0.33 V。
  早先此处写的 0.7 V 比模型上界还大约七成（按 50 Hz 估会得到 0.83 V，也对不上），
  属于口径不合；现按仿真与手算校正为 0.40±0.12。
  `assert.json` 用容差覆盖这组模型差异，只验证拓扑与量级。
- 运行：`python scripts/run_spice.py --root assets/spice`
- 数据：`rectifier.dat` 由本 deck 的 `wrdata` 生成，不是手写或拟合数据。
- 模型边界：二极管用 `Is/N/Rs/Cjo` 的简化模型，不含反向恢复、结电容温度效应、变压器漏感与电容 ESR；
  用于验证整流拓扑、纹波量级与峰值电流，不代表实测。
