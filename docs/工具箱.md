# 软件工具箱

> **本篇你会学到**　仿真、画板、上位机、抓包、数据集各去哪家官网，以及页面上到底有没有写「免费」。
> **预计用时**　当目录翻。装哪一个，看你当前的阶段。
> **前置**　无。这些都是电脑上的工具或数据包，不是购物清单。器材价格仍看 [预算清单](budget.md)。

⚠️ 工具再顺手，也不能替你决定保护阈值。数据包里的截止电压属于那一次实验，不是你的板子该用的数。

免费与否只写 2026-10-06 能打开的官网原文里站得住的那句。没打开的页面不转写。

## 仿真

### LTspice

- **用途**　先在仿真里看功率回路和 RC，再决定要不要做板。
- **对应阶段**　[阶段 0](stages/stage-0-前置知识.md) 的电路，以及 [详解①](circuits/01-功率回路-MOS保护与预充.md)。
- **平台 / 是否免费**　本环境打开 analog.com 超时，没有读到系统列表，也没有读到 free 这个词。**不标免费，也不标收费。** 该域名因为传输层假死，已经在巡检里整站排除，见 [维护说明](维护说明.md)。
- **官网**　[LTspice](https://www.analog.com/en/resources/design-tools-and-calculators/ltspice-simulator.html)

### PyBaMM

- **用途**　用开源的物理模型看电芯里的过程，而不是只做安时积分。
- **对应阶段**　[阶段 4](stages/stage-4-SOC-SOH算法.md)，总纲也把它放在 [阶段 6 前沿](bms-resources.md#65-前沿方向)。
- **平台**　Python。官网没有在首页另列一份操作系统表。
- **是否免费**　首页写 open source，并写任何人可以使用、修改和分发。没有标价。
- **官网**　[pybamm.org](https://pybamm.org/)

## 画板

### KiCad

- **用途**　画原理图和 PCB。阶段 3 抄板、电路板专章对检查表时用得上。
- **对应阶段**　[阶段 3](stages/stage-3-AFE-MCU智能BMS.md)、[电路板绘制](circuits/05-BMS电路板绘制与设计要点.md)。
- **平台**　下载页列出 Windows、macOS、Linux、Docker。
- **是否免费**　首页写 Cross Platform and Open Source。下载页没有标价。
- **官网**　[kicad.org](https://www.kicad.org/) · [下载页](https://www.kicad.org/download/)

## 上位机

### BQStudio

- **用途**　在电脑上看 TI 电池管理芯片的寄存器、做校准和学习周期。页面写明 bq20xxx、bq30xxx 不在 bqStudio 里，要回各自的产品页找评估软件。
- **对应阶段**　[阶段 3](stages/stage-3-AFE-MCU智能BMS.md)、[详解②](circuits/02-采样链与AFE芯片.md)。
- **平台**　下载项是 Windows Installer（页面上的稳定版写着 1.3.101.1，2020-05-07）。
- **是否免费**　这一页没有写 free，也没有标价。下载锁的说明是 “Requires export approval (1 minute)”。这里不把它写成免费软件，也不写成付费软件。
- **官网**　[BQSTUDIO](https://www.ti.com/tool/BQSTUDIO)

## 抓包

### SavvyCAN

- **用途**　抓 CAN、看 DBC、把原始字节换成信号。阶段 5 学仲裁和逆向时，用它看「线上到底有什么」。
- **对应阶段**　[阶段 5](stages/stage-5-通信与集成.md)。
- **平台**　官网写 cross platform 的 Qt 程序，并写有 Linux 与 Windows 的二进制。更新日志里出现过 OSX 修复；一份完整的现行系统表以你打开下载页时为准。
- **是否免费**　官网写 free and open source。
- **官网**　[savvycan.com](https://www.savvycan.com/)

### PulseView

- **用途**　配逻辑分析仪看 UART 字节和时序。没有分析仪时，先读阶段 5 的状态机也行，软件不是门槛。
- **对应阶段**　[阶段 2](stages/stage-2-保护板实践.md) 看波形，[阶段 5](stages/stage-5-通信与集成.md) 对帧。
- **平台**　Wiki 写它是基于 Qt 的界面，下载方式包括二进制、发行版包和源码。不在这里抄一份可能过期的系统名单。
- **是否免费**　Wiki 写许可是 GNU GPL，第 3 版或更新。
- **官网**　[PulseView](https://sigrok.org/wiki/PulseView)

## 数据集

### NASA 电池数据包

- **用途**　公开仓库里的电池老化数据，用来练「数据长什么样」。第 5 号是 Battery Data Set。不要把某一圈的截止电压当成保护阈值。
- **对应阶段**　[阶段 4](stages/stage-4-SOC-SOH算法.md)。
- **平台**　网页列出可下载的数据包。
- **是否免费**　页面把数据包放在可下载列表里，没有标价。引用请用页面上的 Data Set Citation。
- **官网**　[PCoE Data Set Repository](https://www.nasa.gov/intelligent-systems-division/discovery-and-systems-health/pcoe/pcoe-data-set-repository/)

### CALCE 电池数据

- **用途**　另一组公开的循环、存储、驾驶剖面和开路电压数据。和 NASA 那包不是同一批电芯，不要拼成一条曲线。
- **对应阶段**　[阶段 4](stages/stage-4-SOC-SOH算法.md)。
- **平台**　网页内按电池型号提供下载。
- **是否免费**　页面写 open access，并写数据可在下方下载。没有标价。发表时按页面的 Suggested Citation。
- **官网**　[CALCE Battery Data](https://calce.umd.edu/battery-data)
