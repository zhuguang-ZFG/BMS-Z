## 一、一页速览

电池包的健康，最常被收成两句话：现在的总容量，现在的等效串联电阻（4–1 页）。

## 二、健康是什么，老化长什么样（§4.1–4.3）

总容量随副反应和结构破坏下降，这叫容量衰减。功率能力更常被电阻抬高卡住（4–2…4–3 页）。OCV 曲线会随两极容量损失而变，但常见化学体系里，这份变化往往小到不容易从电压里看出来（4–3 页）。别的参数也会漂，健康摘要仍先抓容量和 ESR。

老化机制讲义按 Vetter 等人的综述做定性，不在这里做定量寿命模型（4–4 页）。负极三层：颗粒表面、颗粒内部、整个复合电极。SEI 形成消耗锂，膜多孔所以锂仍能进出，但离子通过更难（4–5 页）。SEI 的成分并不清楚。颗粒充放电的体积变化通常不到 10%，各向异性应力会让颗粒开裂，新表面再长 SEI（4–6 页）。复合电极里还会失去颗粒之间、颗粒和集流体、颗粒和粘结剂的接触（4–7 页）。讲义表格里用粗体标出更严重的路径（4–8 页）。

正极同样分表面、活性物质内部、电极体（4–9 页）。有的相变可逆；有的会让层状结构在过充时塌掉，容量迅速下降（4–10…4–11 页）。这些是机理清单。把它写成「过充必坏」已经在阶段 0；具体电压仍看那种化学的手册，不要从综述表里读出一个通用截止电压。

> 【译注】阶段 4 §4.6 的动画把健康画成容量往 80% 滑、内阻上翘。80% 是仓库里的教学 EOL 线，不是这一章测出来的数。本章只说容量下降、电阻上升。过充导致的结构坍塌，保护仍按阶段 0 的事故链做，不按这篇综述临时改阈值。

## 三、谁好估，谁难估（§4.4）

电阻好估，因为电压对它敏感。大电流时，敏感度里直接有 −i/v 这一项（4–12 页）。相邻两拍电压相减，可以把慢变的 OCV 消掉一截，再得到一个 R₀ 的瞬时估计。然后做滤波（4–13 页）：

```
R̂₀,k = α R̂₀,k−1 + (1 − α) R₀,k    0 ≤ α < 1
```

α 越接近 1，越平滑，也越慢。电阻还随 SOC 变，也随温度变。温度可以用阿伦尼乌斯形式：R₀ = R_ref exp[ E (1/T_ref − 1/T) ]（4–13 页）。包如果长期停在一个温度，别的温度上的表会被带偏。可以改成对 SOC 和温度的一张电阻表做自适应。

容量难估。OCV 对 SOC 的斜率在大部分区间很浅，电压对 Q 的敏感度被这个斜率再压一次（4–14 页）。噪声很容易盖过「容量变了一点点」造成的电压差。所以不要指望用和估电阻同一套瞬时公式去估容量。

## 四、参数也是卡尔曼滤波（§4.5–4.8）

状态滤波假设参数已知。把参数本身写成随机游走（4–15…4–17 页）：

```
θ_{k+1} = θ_k + r_k
```

r_k 是虚构过程噪声，让滤波器还肯改参数。测量方程是电芯模型 h(x, u, θ)。SPKF 和 EKF 都能做。EKF 的时间更新因为参数方程是线性的，所以就是 θ̂⁻ = θ̂⁺（4–19 页）。雅可比要穿过状态方程：参数影响下一拍状态，状态再影响电压，链式求导在 4–21 页。

状态和参数一起估，有两条路（4–22…4–24 页）。联合：拼成一个大状态，一个滤波器。双滤波：一个快的估状态，一个慢的估参数，互相把对方的结果当已知。信息在两个滤波器之间交换。附录把 EKF/SPKF 的联合和双滤波公式列全（4–70 页起），导读不重抄矩阵。

只估电阻时，可以把模型收成 v = OCV(z) − R₀ i + e，R₀ 带一点虚构噪声（4–28 页）。SOC 若已有外部估计，这个小模型就能跑。充放电电阻不同、随 SOC 或温度变化，就把标量改成表。

只估容量时（4–28 页）：

```
Q_{k+1} = Q_k + r_k
d_k = z_k − z_{k−1} + η_{k−1} i_{k−1} Δt / Q_{k−1} + e_k
```

d_k 的期望按构造是 0。滤波器看到它偏离 0，就去改 Q。前提是这一拍和上一拍的 SOC 都要像样。静置时 i ≈ 0，这条方程没有信息。

收敛没有内置保证（4–26 页）。滤波器让模型端口贴近数据，不保证参数等于材料真相。激励不够时要冻结慢更新。这一点和阶段 4 的可观测性警告是同一句话。

> 【译注】`code/soc/estimators.py` 的 EKF 只估 SOC 和 RC 电压，Q 和 R₀ 是常数。阶段 4 §4.6 描述的快慢双滤波器，就是 4–23 页的双滤波。仓库还没有慢滤波器。不要把教学仿真里的内阻当成在线估计结果。

## 五、容量为什么不能普通最小二乘（§4.9–4.15）

安时积分和 SOC 差的关系是 y ≈ Q x：y 是电流积分，x 是 ΔSOC（4–29…4–31 页）。普通最小二乘假设只有 y 有噪声。SOC 估计不完美，x 也有噪声，问题变成 (y − ε_y) = Q (x − ε_x)。忽略 ε_x，Q 会被系统地带偏。

加权普通最小二乘（WLS）最小化 y 方向的加权残差，并且可以做成递归、带遗忘因子（4–31…4–34 页）。总最小二乘（TLS）承认两边都有噪声，几何上是斜着量到拟合直线的距离（4–35 页）。加权总最小二乘（WTLS）用拉格朗日乘子，结果好，但不适合边运行边存储全部历史（4–36…4–39 页）。

拟合好不好，在噪声独立高斯时用卡方检验（4–40…4–41 页）。容量估计还要方差，才能写 Q̂ ± 3σ 这种区间（4–42 页）。没有误差带的容量，拿去算剩余能量会偏乐观或偏悲观（4–69 页）。

嵌入式要闭式、要递归。若 σ_x 和 σ_y 只差一个固定比例，二次方程就能解（4–44…4–47 页）。比例不固定时，讲义给近似加权总最小二乘（AWTLS）：代价函数对参数求导得到四次方程，用 Ferrari 方法求根，再拿代价函数挑选那一个真正的最小值（4–49…4–56 页）。它保留 WLS 的好处：不用迭代特征值，能遗忘，能递归。

## 六、HEV 和 EV 的例子（§4.16–4.18）

六个场景都用带遗忘的四种方法（4–57 页）。HEV 的特点是很少充到一个精确已知的 SOC，所以每个 x 都是两次 SOC 估计之差（4–59 页）。若一次 SOC 的标准差是 0.01，则 σ_x² = 2×(0.01)²。

场景 1 的传感器假设要整组一起看（4–59 页）：名义容量 Q_nom = 10 Ah；电流传感器量程 ±30 Q_nom；10 bit 模数转换；量化台阶 q = 60 Q_nom / 1024；每 300 s 的 1 Hz 采样积一次分，量化噪声按 σ_y² = q² m / (12 × 3600²)。这些数字是仿真设定，不是某种 HEV 电池的测量。

场景 2 在收到数据前就给了容量初值。另一场景让真容量每更新一次掉 0.001 Ah，遗忘因子 γ = 0.99（4–62 页）。EV / PHEV 场景的更新更稀：往往要等到充电，才有一段够大的 ΔSOC（4–63…4–65 页）。图上 WTLS 和 AWTLS 的误差带更诚实；只在 y 上加噪声的 WLS 会偏。讨论（4–67…4–69 页）的结论可以背下来：SOC 噪声必须进模型；知道其中一个 SOC 精确时，σ_x 下降，估计会好一截；AWTLS 至少不差于其他三种。

> 【译注】阶段 4 的满充校准就是「其中一个 SOC 你比较有把握」的工程版：CV 末端电流很小、持续够久，才把 z 拉到满。没有这段锚点时，容量估计要吃两次 SOC 的噪声。`code/soc/` 不估容量。10 Ah、0.01、300 s、10 bit 都留在讲义的场景里。

1. 电流大时，电压对 R₀ 的敏感度里有 −i/v（4–12 页）。容量要经过很平的 OCV 斜率，电压几乎不动（4–14 页）。

4. 不是。它是虚构噪声，用来允许 θ 慢慢变（4–17、4–28 页）。激励不足时不该让它带着估计乱走。
