# 第 14 章 PT100 信号链与误差预算

- 电路：1 mA 恒流激励一只理想 PT100（$R=100(1+0.00385T)$），仪放增益 40，输出再叠加 4 V 偏置。
- 输入：温度 0°C / 50°C / 100°C；`.dc` 扫描 `VTEMP`，步长 50°C。
- 期望：$V_{out}$ 三点为 8.00 V / 8.77 V / 9.54 V，具体容差见 `assert.json`。
- 运行：`python scripts/run_spice.py --root assets/spice`（需要 ngspice；缺失时用例跳过）。
- 数据：`pt100.dat` 由本 deck 的 `wrdata` 生成，不是手写或拟合数据。
- 模型边界：`BPT` 只是线性化的行为电阻，没有引线电阻、自热、非线性项与失配；`VTEMP` 是理想温度源。**4 V 偏置只是为了在单电源演示里把输出抬离 0 V，不代表实际 ADC 链的量化与基准**——正文信号链的输出范围是 0~1.54 V，ADC 标定另算。
